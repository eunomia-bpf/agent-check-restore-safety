\section{Canonical Epoch and Durable Kernel}
\label{sec:semantics}

\subsection{Residual epoch synthesis}

For a language $F$ and trace $\sigma$, its right residual is
\[
  F/\sigma=\{\rho\mid\sigma\rho\in F\}.
\]
The canonical epoch for request $R$ is the deterministic transition system
\begin{equation}
\label{eq:canonical-epoch}
\begin{split}
 Q_R &=\{F_R/\sigma\mid\sigma\in F_R\},\\
 q_R^0&=F_R/\epsilon,\\
 (F_R/\sigma)\xrightarrow{d}(F_R/\sigma d)
   &\quad\Longleftrightarrow\quad \sigma d\in F_R .
\end{split}
\end{equation}
Equality of residuals makes the transition well defined: if
$F_R/\sigma=F_R/\tau$, then $d\rho$ belongs to one residual exactly when it
belongs to the other.  Write $\mathsf{Can}(R)$ for this program together with
the target gate-use bindings and request scope.

\begin{lemma}[Exact residual epoch]
\label{lem:residual-exact}
For every well-formed $R$,
\[
  \mathsf{FreshTraces}(\mathsf{Can}(R))=F_R .
\]
Moreover, $\mathsf{Can}(R)$ is the unique smallest deterministic realization
of $F_R$ up to state renaming.
\end{lemma}
\begin{proof}
After reading $\sigma\in F_R$, induction on $|\sigma|$ places the epoch in
$F_R/\sigma$.  The transition rule enables $d$ exactly when
$\sigma d\in F_R$, proving both inclusions.  The last statement is the
standard distinguishable-residual argument; we use it only for canonical
representation, not as a novelty claim.
\end{proof}

The epoch preserves the \emph{entire} atomic-monitor language.  Promises do
not select a smaller safe implementation: they decide whether installing this
edge can honestly retain the behavior its type and leaf contract advertise.

\subsection{Durable kernel state}

The store state relevant to one authority scope is
\[
 S=(\kappa,\nu,\delta,\mathsf{phase},\mathsf{bind},
       \mathsf{prog},\mathsf{q},\mathsf{rcpt}).
\]
$\kappa$ and $\nu$ are policy and Agent-view versions; $\delta$ is the
append-only authority receipt trace.  For each controller epoch,
$\mathsf{phase}\in\{\mathsf{inactive},\mathsf{active},\mathsf{closed}\}$.
$\mathsf{bind}$ resolves gate uses to epochs, $\mathsf{prog}$ stores their
verified programs, $\mathsf q$ their current states, and $\mathsf{rcpt}$ maps
redeemed cells to immutable receipts and settlement phases.  A well-formed
scope has one authoritative active epoch after a canonical installation; all
live Agent branches route protected actions through it.

A seal is
\[
 Z=(\kappa_Z,\nu_Z,\delta_Z,\mathsf{src}_Z,
       \mathsf{targetUses}_Z,H_R,H_{\mathsf{Can}},\eta_Z),
\]
where the two hashes bind the normalized request and canonical program and
$\eta_Z$ is fresh.  The active source set is derived from the typed view and
authenticated source anchors.  A caller cannot omit an authoritative source
epoch and still satisfy the equality check below.

\paragraph{Fresh preparation}
Let gate use $j$ resolve to active epoch $\eta$ and handle $h$ to cell
$d=q_{\rm cell}(h)$.  The security linearization point is
\begin{equation}
\label{eq:prepare-rule}
\frac{
\begin{gathered}
 \mathsf{phase}(\eta)=\mathsf{active}\quad
 \mathsf{bind}(j)=\eta\quad d\notin\operatorname{dom}(\mathsf{rcpt})\\[-2pt]
 \mathsf q(\eta)\xrightarrow{d}_{\mathsf{prog}(\eta)}q'
\quad \ell(d)\text{ is unspent}
\end{gathered}}
{\begin{aligned}
 S&\xrightarrow{\mathsf{Prepare}(j,h)}S'\\[-2pt]
 S'&=S[\mathsf q(\eta):=q',\
   \delta:=\delta\ell(d),\\[-2pt]
 &\hspace{22mm}\mathsf{rcpt}(d):=\mathsf{prepared}]
\end{aligned}} .
\end{equation}
The transition, receipt append, and authority consumption are one durable
atomic step.  Dispatch may occur after it; ambiguous remote outcomes are
settled by a separate protocol.

\paragraph{Atomic installation}
Programs may be preloaded while inactive.  Publishing one uses the single
compare-and-install rule
\begin{equation}
\label{eq:install-rule}
\frac{
\begin{gathered}
 \kappa=\kappa_Z\quad\nu=\nu_Z\quad\delta=\delta_Z\\[-2pt]
 \mathsf{ActiveSources}(S)=\mathsf{src}_Z\quad
 \mathsf{hash}(R)=H_R\\[-2pt]
 \mathsf{Verify}(\mathsf{Can}(R),H_{\mathsf{Can}})
\end{gathered}}
{\begin{aligned}
 S&\xrightarrow{\mathsf{Install}(Z)}S'\\[-2pt]
 S'=S[&
   \mathsf{src}_Z:=\mathsf{closed},\
   \eta_Z:=\mathsf{active},\\[-2pt]
  &\mathsf{targetUses}_Z\mapsto\eta_Z,\
   \mathsf q(\eta_Z):=q_R^0,\\[-2pt]
  &\nu:=\nu+1]
\end{aligned}} .
\end{equation}
Closing every source, opening the target, rebinding its uses, and advancing
the view version occur at one linearization point.  If any premise fails,
\textsc{Install} returns stale and leaves $S$ unchanged.  A retained
continuation, as in live Restore, is rebound inside $\eta_Z$; its source epoch
does not remain active beside the target.

\paragraph{Stutters and crashes}
If $d$ already has a receipt, \textsc{Retry} or \textsc{Replay} returns it
without a $d$ transition.  \textsc{Dispatch} and \textsc{Settle} update only
the receipt phase.  A crash discards nondurable computation but not any field
of $S$.  In particular, no recovery rule reopens a closed generation.

\subsection{Ideal history-cut monitor}

For comparison, define $\mathsf{Ref}$ to store the same durable fields but to
interpret the active request directly with \cref{eq:gm-step}, consulting
$F_R$ rather than an emitted program.  It uses the same atomic history-cut
guard as \cref{eq:install-rule}: a cut is enabled only at the named policy
version, view, receipt trace, and complete source set.  Thus $\mathsf{Ref}$ is
the strongest serialized monitor extended with an ideal atomic
Fork/Restore/Merge operation.

Relate a compiled state $S$ and reference state $\bar S$ when their durable
fields, bindings, and active request agree and, for the within-epoch fresh
trace $\sigma$,
\begin{equation}
\label{eq:kernel-reference-relation}
 \mathsf q(\eta)=F_R/\sigma
 \quad\text{and}\quad
 \bar S.\mathsf{monitorTrace}=\sigma .
\end{equation}
This relation exposes the intended proof boundary: the compiler replaces
online membership in $F_R$ with one state of its residual program, while the
durable installation protocol remains observable on both sides.

\subsection{The cut race}

\textsc{Prepare} and \textsc{Install} both linearize through the same store.
If an old \Prepare{} wins, it changes $\delta$ before the install comparison;
the seal is stale.  If \textsc{Install} wins, every source epoch becomes
closed before any later step, so \cref{eq:prepare-rule} has no premise through
an old binding.  There is no execution in which an old fresh event is absent
from the compared frontier yet commits after the target becomes active.

Each successful target \Prepare{} advances both the canonical residual and
the durable trace.  At the next history edge the compiler uses this new trace
as $\delta_Z$; seals cannot be inherited across receipt growth.  The result in
\cref{sec:results} lifts this one-cut argument to an arbitrary online sequence
of Agent edges under one policy version.  Changing $\kappa$ invalidates the
seal and begins a new theorem instance after policy migration.
