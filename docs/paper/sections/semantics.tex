\section{Exact History Admission}
% 精确历史准入
\label{sec:admission}

Recall the authority-label alphabet \(\mathcal U\) and regular prefix-closed policy \(\mathcal A\subseteq\mathcal U^*\).
% 回顾权限标签字母表 \(\mathcal U\) 和正则前缀闭合策略 \(\mathcal A\subseteq\mathcal U^*\)。
For the authenticated receipt ledger \(\Delta\), write \(\mathsf{lab}(\Delta)\in\mathcal A\) for its authority word and \(D_\Delta\) for its receipted cells.
% 对于经认证的回执账本 \(\Delta\)，用 \(\mathsf{lab}(\Delta)\in\mathcal A\) 表示其权限词，用 \(D_\Delta\) 表示其中已有回执的单元。
Fix the admission instance \(\Theta=(\kappa,H,\Delta,\mathcal A,u)\) and its unique schema derivation
% 固定准入实例 \(\Theta=(\kappa,H,\Delta,\mathcal A,u)\) 及其唯一的模式推导如下：
\[
 \Sigma_\zeta;H\vdash u\Downarrow
 (H',\mathcal C_{H,u},\eta^-,\eta^+).
\]
Let \(\rho'\) be the authenticated target registry in \(H'\) and \(O_{H,u}=O_{\mathcal C_{H,u}}\).
% 令 \(\rho'\) 为 \(H'\) 中经认证的目标注册表，并令 \(O_{H,u}=O_{\mathcal C_{H,u}}\)。
All languages below depend on \(\Theta\), the schema registry, and \(\rho'\).
% 下文所有语言均依赖于 \(\Theta\)、模式注册表和 \(\rho'\)。
We write only \(H,u\) where the remaining parameters are fixed.
% 当其余参数固定时，我们仅写作 \(H,u\)。

\subsection{\Fresh and \Alias resolution}
% \Fresh 与 \Alias 解析

Resolution never erases an occurrence retained by the derived contract.
% 解析绝不会擦除派生契约所保留的发生项。
Starting with \(R_0=D_\Delta\), the deterministic transducer \(\Resolve^{\rho'}_\Delta\) maps a raw word \(w=x_1\cdots x_n\) to a resolved word \(z_1\cdots z_n\).
% 从 \(R_0=D_\Delta\) 开始，确定性转换器 \(\Resolve^{\rho'}_\Delta\) 将原始词 \(w=x_1\cdots x_n\) 映射为已解析词 \(z_1\cdots z_n\)。
For \(d_i=q^{\rho'}_{\rm cell}(x_i)\),
% 对于 \(d_i=q^{\rho'}_{\rm cell}(x_i)\)，定义 \(z_i\) 如下：
\begin{equation}
\label{eq:resolve}
 z_i=
 \begin{cases}
  \Fresh(x_i,d_i), & d_i\notin R_{i-1},
       \quad R_i=R_{i-1}\cup\{d_i\};\\
  \Alias(x_i,d_i), & d_i\in R_{i-1},
       \quad R_i=R_{i-1}.
 \end{cases}
\end{equation}
The authority projection erases \Alias symbols and maps each \Fresh symbol to its cell's authority label.
% 权限投影会擦除 \Alias 符号，并将每个 \Fresh 符号映射到其单元的权限标签。
\[
 \mathsf{auth}(\Fresh(x,d))=\ell_{\rho'}(d),\qquad
 \mathsf{auth}(\Alias(x,d))=\epsilon .
\]
For resolved \(z\), \(\mathsf{raw}(z)\) drops the \Fresh/\Alias mode and cell but preserves ordered occurrence identifiers.
% 对于已解析的 \(z\)，\(\mathsf{raw}(z)\) 会去除 \Fresh/\Alias 模式和单元，但保留有序的发生项标识符。
A \Retry repeats the same invocation and adds no occurrence.
% \Retry 重复同一次调用，不增加任何发生项。
Restored occurrences sharing a cell remain distinct and may resolve differently.
% 共享同一单元的恢复发生项仍彼此有别，并且可能得到不同的解析结果。

\begin{lemma}[Resolution]
% 解析
\label{lem:resolution}
\(\Resolve^{\rho'}_\Delta\) is deterministic, length preserving, and prefix compatible.
% \(\Resolve^{\rho'}_\Delta\) 是确定性的、保持长度的，并且与前缀兼容。
Its \Fresh projection contains each cell at most once outside \(D_\Delta\), while its occurrence projection is exactly the input word.
% 在 \(D_\Delta\) 之外，其 \Fresh 投影至多包含每个单元一次，而其发生项投影恰好就是输入词。
Moreover, if \(\Resolve^{\rho'}_\Delta(rv)=zv'\), then \(z=\Resolve^{\rho'}_\Delta(r)\) and \(v'=\Resolve^{\rho'}_{\Delta_z}(v)\), where \(\Delta_z\) extends \(\Delta\) by the \Fresh events of \(z\).
% 此外，若 \(\Resolve^{\rho'}_\Delta(rv)=zv'\)，则 \(z=\Resolve^{\rho'}_\Delta(r)\) 且 \(v'=\Resolve^{\rho'}_{\Delta_z}(v)\)，其中 \(\Delta_z\) 通过加入 \(z\) 的 \Fresh 事件来扩展 \(\Delta\)。
\end{lemma}
\begin{proof}
Induction on input length shows that the transducer emits one prefix-determined output symbol per input symbol and updates \(R_i\) only for \Fresh.
% 对输入长度作归纳表明，该转换器为每个输入符号发出一个由前缀决定的输出符号，并且仅在 \Fresh 时更新 \(R_i\)。
Set membership ensures one \Fresh emission per cell.
% 集合成员关系确保每个单元仅产生一次 \Fresh。
Both cases retain \(x_i\).
% 两种情形都会保留 \(x_i\)。
Splitting after \(r\) gives the streaming equation.
% 在 \(r\) 之后拆分即可得到流式等式。
\end{proof}
Thus a retry stutters in both histories.
% 因此，重试在两种历史中都表现为停顿。
A copied occurrence that resolves as \Alias stutters only in the authority history because it advances causal history without changing the authority word.
% 解析为 \Alias 的复制发生项只在权限历史中表现为停顿，因为它会推进因果历史而不改变权限词。

\subsection{Prefix-robust history admission}
% 前缀鲁棒的历史准入

For each structurally derived outcome \(o\in O_{H,u}\), define its set of resolved completions and the corresponding safe subset.
% 对每个结构化派生的结果 \(o\in O_{H,u}\)，定义其已解析完成路径的集合及相应的安全子集。
\begin{equation}
\label{eq:safe-completions}
\begin{aligned}
 R_o(H,u)&=\{\Resolve^{\rho'}_\Delta(w)\mid w\in\Lin(p_o)\},\\
 M_o(H,u)&=\{z\in R_o(H,u)\mid
   \mathsf{lab}(\Delta)\mathsf{auth}(z)\in\mathcal A\}.
\end{aligned}
\end{equation}
Thus \(M_o\) contains the policy-safe resolved words for \(o\).
% 因此，\(M_o\) 包含结果 \(o\) 的策略安全已解析词。
Individual outcome safety is insufficient because a shared prefix can strand a contract-compatible outcome, so admission closes safe completions under every shared prefix.
% 单个结果的安全性并不充分，因为共享前缀可能使一个与契约兼容的结果陷入无后续状态，因此准入要求安全完成路径集合在每个共享前缀下闭合。
For a resolved prefix \(z\), let
% 对于已解析前缀 \(z\)，定义 \(\mathsf{Compat}(z)\) 如下：
\[
 \mathsf{Compat}(z)=
 \{o\mid \mathsf{raw}(z)\preceq_{\rm pref}w
		          \text{ for some }w\in\Lin(p_o)\}.
\]
Identical resolved words may belong to different indexed outcomes, so the fixed point must not quotient their identities.
% 相同的已解析词可能属于不同的带索引结果，因此该不动点不得对这些结果标识取商。
Put
% 令 \(\widehat B_0\) 如下：
\[
 \widehat B_0=\biguplus_{o\in O_{H,u}}\{o\}\times M_o .
\]
For \(\widehat B\subseteq\widehat B_0\), define the monotone operator
% 对于 \(\widehat B\subseteq\widehat B_0\)，定义如下单调算子：
\begin{equation}
\label{eq:robust-operator}
\widehat\Phi(\widehat B)=
\left\{(o,b)\in\widehat B_0\ \middle|\
\begin{array}{l}
\forall z\preceq_{\rm pref} b.\ \forall v\in\mathsf{Compat}(z).\\[-2pt]
\exists (v,b')\in\widehat B.\ z\preceq_{\rm pref}b'
\end{array}\right\}.
\end{equation}
Set \(\widehat B_{i+1}=\widehat\Phi(\widehat B_i)\).
% 令 \(\widehat B_{i+1}=\widehat\Phi(\widehat B_i)\)。
Since \(\widehat B_1\subseteq\widehat B_0\), monotonicity yields a finite descending chain, whose limit is
% 由于 \(\widehat B_1\subseteq\widehat B_0\)，单调性产生一条有限下降链，其极限如下：
\[
\begin{aligned}
 \widehat B^\dagger_{H,u}
   &=\nu\widehat B.\widehat\Phi(\widehat B)
     =\bigcap_{i\geq 0}\widehat B_i,\\
 B^\dagger_{H,u}&=\pi_2\widehat B^\dagger_{H,u},
 &W^\dagger_{H,u}&=\Pref(B^\dagger_{H,u}).
\end{aligned}
\]
The operator removes completions that strand a contract-compatible outcome, including through cascading earlier loss.
% 该算子会移除使某个契约兼容结果陷入无后续状态的完成路径，包括由更早损失级联导致的此类完成路径。
Runtime uses only the projected pair \((W^\dagger,B^\dagger)\).
% 运行时仅使用投影后的二元组 \((W^\dagger,B^\dagger)\)。
The installation checker and seal retain the indexed witness \(\widehat B^\dagger\).
% 安装检查器和封印保留带索引见证 \(\widehat B^\dagger\)。

\begin{definition}[Agent history admission]
% Agent 历史准入
\label{def:admission}
\begin{equation}
\label{eq:admission}
\mathsf{Admit}(H,u,\Delta,\mathcal A)
 \quad\Longleftrightarrow\quad
 \widehat B^\dagger_{H,u}\ne\varnothing .
\end{equation}
\end{definition}
The abbreviation \(\mathsf{Admit}(H,u)\) assumes \(\Theta\) and both registries fixed.
% 缩写 \(\mathsf{Admit}(H,u)\) 假定 \(\Theta\) 和两个注册表均已固定。
At \(z=\epsilon\), all outcomes are compatible, so nonemptiness gives initial coverage.
% 当 \(z=\epsilon\) 时，所有结果均兼容，因此非空性给出初始覆盖。
The existential selects a linearization without fairness.
% 该存在量词选择一种线性化，而不要求公平性。
The universal prefix condition prevents later deletion.
% 全称前缀条件可防止后续删除。

\begin{definition}[Indexed realization]
% 带索引实现
\label{def:realization}
A generated language and indexed marked family \((L,\widehat B)\) realize \((H,u)\) when all conditions below hold.
% 当下列全部条件成立时，生成语言和带索引的标记族 \((L,\widehat B)\) 实现 \((H,u)\)。
\begin{enumerate}[leftmargin=*,itemsep=1pt]
 \item \(\widehat B\ne\varnothing\);
% \(\widehat B\) 非空；
 \item \emph{history fidelity:} \(\widehat B\subseteq \biguplus_{o\in O_{H,u}}\{o\}\times R_o(H,u)\) and \(L\subseteq\Pref(\bigcup_{o\in O_{H,u}}R_o(H,u))\);
% 历史忠实性：\(\widehat B\subseteq \biguplus_{o\in O_{H,u}}\{o\}\times R_o(H,u)\)，且 \(L\subseteq\Pref(\bigcup_{o\in O_{H,u}}R_o(H,u))\)。
 \item \emph{policy safety:} \(\mathsf{lab}(\Delta)\,\mathsf{auth}(z)\in\mathcal A\) for every \(z\in L\);
% 策略安全性：对每个 \(z\in L\)，均有 \(\mathsf{lab}(\Delta)\,\mathsf{auth}(z)\in\mathcal A\)。
 \item \emph{completion nonblocking:} \(L=\Pref(\pi_2\widehat B)\); and
% 完成非阻塞性：\(L=\Pref(\pi_2\widehat B)\)；并且
 \item \emph{persistent outcome coverage:} for every \(z\in L\) and \(o\in\mathsf{Compat}(z)\), some \((o,b)\in\widehat B\) extends \(z\).
% 持续的结果覆盖：对于每个 \(z\in L\) 和 \(o\in\mathsf{Compat}(z)\)，都存在某个 \((o,b)\in\widehat B\) 扩展 \(z\)。
\end{enumerate}
\end{definition}

\begin{lemma}[Prefix-robust greatest realization]
% 前缀鲁棒的最大实现
\label{lem:greatest-realization}
A realization exists iff \(\mathsf{Admit}(H,u)\).
% 当且仅当 \(\mathsf{Admit}(H,u)\) 成立时，实现存在。
On admission, \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\) is a realization, and every realization \((L,\widehat B)\) satisfies \(\widehat B\subseteq\widehat B^\dagger_{H,u}\) and \(L\subseteq W^\dagger_{H,u}\).
% 准入时，\((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\) 是一个实现，并且每个实现 \((L,\widehat B)\) 都满足 \(\widehat B\subseteq\widehat B^\dagger_{H,u}\) 和 \(L\subseteq W^\dagger_{H,u}\)。
\end{lemma}
\begin{proof}
Fidelity, completion nonblocking, and safety place any realization's indexed marked family inside \(\widehat B_0\); persistent coverage makes it post-fixed, so monotonicity and finite Knaster--Tarski place it inside \(\widehat B^\dagger\), and projected prefixes give \(L\subseteq W^\dagger\).
% 忠实性、完成非阻塞性和安全性使任意实现的带索引标记族包含于 \(\widehat B_0\)；持续覆盖使其成为后不动点，因此由单调性和有限 Knaster--Tarski 可知其包含于 \(\widehat B^\dagger\)，而投影前缀给出 \(L\subseteq W^\dagger\)。
Conversely, \(\widehat B^\dagger=\widehat\Phi(\widehat B^\dagger)\) supplies persistent coverage, \(\widehat B^\dagger\subseteq\widehat B_0\) supplies fidelity and safe marked words, prefix closure of \(\mathcal A\) supplies prefix safety, and \(W^\dagger=\Pref(\pi_2\widehat B^\dagger)\) supplies nonblocking.
% 反之，\(\widehat B^\dagger=\widehat\Phi(\widehat B^\dagger)\) 提供持续覆盖，\(\widehat B^\dagger\subseteq\widehat B_0\) 提供忠实性和安全标记词，\(\mathcal A\) 的前缀闭合性提供前缀安全性，而 \(W^\dagger=\Pref(\pi_2\widehat B^\dagger)\) 提供非阻塞性。
Hence the fixed point is a realization exactly when nonempty.
% 因此，该不动点恰在非空时构成实现。
\end{proof}

Define \(\mathsf{GReal}(H,u;L,\widehat B)\) to mean that \((L,\widehat B)\) is an indexed realization and contains every other realization componentwise.
% 定义 \(\mathsf{GReal}(H,u;L,\widehat B)\) 表示 \((L,\widehat B)\) 是一个带索引实现，并且按分量包含其他每个实现。
When this predicate has a witness, that witness is unique; write \(\mathsf{Spec}(H,u)=(L^*,\widehat B^*)\).
% 当该谓词存在见证时，见证是唯一的；将其记为 \(\mathsf{Spec}(H,u)=(L^*,\widehat B^*)\)。
This is a declarative security specification quantified over realizations, not a definition by the fixed point or compiler.
% 这是一个在实现上量化的声明式安全规范，而不是通过不动点或编译器给出的定义。
\Cref{lem:greatest-realization} proves that \(\mathsf{Spec}(H,u)\) is defined exactly when \(\widehat B^\dagger_{H,u}\ne\varnothing\), and then equals \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\).
% \Cref{lem:greatest-realization} 证明，当且仅当 \(\widehat B^\dagger_{H,u}\ne\varnothing\) 时 \(\mathsf{Spec}(H,u)\) 有定义，并且此时它等于 \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\)。

The following shared-prefix instance shows why derived conditional markings matter even when every \(M_o\) is nonempty.
% 下列共享前缀实例说明了为何即使每个 \(M_o\) 都非空，所派生的条件标记仍然重要。
Let singleton contracts \(X,Y,Z\) contain \(x_o,y_o,z_o\), and let the target registry map them to distinct previously unreceipted cells \(d_x,d_y,d_z\) labeled \(x,y,z\), respectively.
% 令单元素契约 \(X,Y,Z\) 分别包含 \(x_o,y_o,z_o\)，并令目标注册表将它们映射到此前无回执且标签分别为 \(x,y,z\) 的不同单元 \(d_x,d_y,d_z\)。
Write \(\bar x=\Fresh(x_o,d_x)\), \(\bar y=\Fresh(y_o,d_y)\), and \(\bar z=\Fresh(z_o,d_z)\).
% 记 \(\bar x=\Fresh(x_o,d_x)\)、\(\bar y=\Fresh(y_o,d_y)\)、\(\bar z=\Fresh(z_o,d_z)\)。
For \(\mathcal C=X\otimes(Y\oplus Z)\) and \(\mathcal A=\Pref\{yx,xz\}\), the \(X\otimes Y\) and \(X\otimes Z\) outcomes initially have safe resolved completions \(\bar y\bar x\) and \(\bar x\bar z\), with authority projections \(yx\) and \(xz\).
% 对于 \(\mathcal C=X\otimes(Y\oplus Z)\) 和 \(\mathcal A=\Pref\{yx,xz\}\)，\(X\otimes Y\) 与 \(X\otimes Z\) 结果最初分别具有安全的已解析完成路径 \(\bar y\bar x\) 和 \(\bar x\bar z\)，其权限投影为 \(yx\) 和 \(xz\)。
Yet prefix \(\bar x\) from \(\bar x\bar z\) remains contract-compatible with \(X\otimes Y\) but leaves no safe continuation.
% 然而，\(\bar x\bar z\) 的前缀 \(\bar x\) 仍与 \(X\otimes Y\) 契约兼容，却不留下安全后续。
The first fixed-point iteration removes \(\bar x\bar z\), and the next removes \(\bar y\bar x\) after root coverage is lost.
% 第一次不动点迭代移除 \(\bar x\bar z\)，根覆盖丢失后下一次迭代再移除 \(\bar y\bar x\)。
Thus the edit is rejected, whereas the independent \(\forall o.\,M_o\ne\varnothing\) test admits it.
% 因此，该编辑会被拒绝，而独立的 \(\forall o.\,M_o\ne\varnothing\) 检验会准入它。

\begin{proposition}[Outcome-indexed nonblocking correspondence]
% 结果索引的非阻塞对应关系
\label{prop:outcome-necessary}
For nonempty \(\widehat B\subseteq\widehat B_0\), let \(G_{\widehat B}\) be the prefix trie of \(L_{\widehat B}=\Pref(\pi_2\widehat B)\).
% 对于非空的 \(\widehat B\subseteq\widehat B_0\)，令 \(G_{\widehat B}\) 为 \(L_{\widehat B}=\Pref(\pi_2\widehat B)\) 的前缀字典树。
Mark state \(z\) by \(\alpha_o\) exactly when \(o\in\mathsf{Compat}(z)\), and mark state \(b\) by \(\omega_o\) exactly when \((o,b)\in\widehat B\).
% 当且仅当 \(o\in\mathsf{Compat}(z)\) 时用 \(\alpha_o\) 标记状态 \(z\)，并且当且仅当 \((o,b)\in\widehat B\) 时用 \(\omega_o\) 标记状态 \(b\)。
Then
% 则有以下等价关系：
\[
\begin{gathered}
 \widehat B\subseteq\widehat\Phi(\widehat B)\\[-2pt]
 \Longleftrightarrow\
 \forall o\in O_{H,u}.\;
 G_{\widehat B}\text{ is }(\alpha_o,\omega_o)\text{-nonblocking}.
\end{gathered}
\]
Consequently, if \(\widehat B^\dagger\) is nonempty, it is the greatest nonempty completion subfamily of \(\widehat B_0\) satisfying these conditional nonblocking obligations.
% 因此，若 \(\widehat B^\dagger\) 非空，则它是 \(\widehat B_0\) 中满足这些条件非阻塞义务的最大非空完成路径子族。
If it is empty, no nonempty subfamily satisfies them.
% 若它为空，则没有任何非空子族满足这些义务。
Ordinary marker nonblocking of the unaugmented projected language is strictly weaker.
% 未增广投影语言的普通标记非阻塞性严格更弱。
\end{proposition}
\begin{proof}
From reachable prefix \(z\), an \(\omega_o\)-marked state is reachable exactly when some \((o,b)\in\widehat B\) extends \(z\).
% 从可达前缀 \(z\) 出发，当且仅当某个 \((o,b)\in\widehat B\) 扩展 \(z\) 时，才可到达一个带 \(\omega_o\) 标记的状态。
Quantifying over exactly the states marked \(\alpha_o\) is therefore the post-fixed-point condition.
% 因此，恰好对带 \(\alpha_o\) 标记的状态进行量化就是后不动点条件。
Greatestness follows from the greatest-fixed-point construction.
% 最大性由最大不动点构造得到。
For strictness, the preceding instance has the marker-nonblocking projected pair \((\Pref\{\bar y\bar x,\bar x\bar z\}, \{\bar y\bar x,\bar x\bar z\})\), but its indexed fixed point is empty.
% 关于严格性，前述实例具有标记非阻塞的投影二元组 \((\Pref\{\bar y\bar x,\bar x\bar z\}, \{\bar y\bar x,\bar x\bar z\})\)，但其带索引不动点为空。
\end{proof}

Malik and Leduc define generalized nonblocking through conditional plant and terminal markings, while de Queiroz et al.\ synthesize supervisors for multiple persistent tasks~\cite{dequeiroz2005multitasking,malik2008generalised}.
% Malik 与 Leduc 通过条件化的被控对象标记和终止标记定义广义非阻塞，而 de Queiroz 等人则为多个持久任务综合监督器~\cite{dequeiroz2005multitasking,malik2008generalised}。
Once the conditional markings are supplied, \cref{prop:outcome-necessary} is an instance of that established theory rather than a new fixed-point algorithm.
% 一旦给定条件标记，\cref{prop:outcome-necessary} 就是该既有理论的一个实例，而非一种新的不动点算法。
A fixed-plant encoding takes the full prefix trie of \(\widehat B_0\) and adds one controllable outcome-specific terminal edge after each indexed completion, so selecting terminal edges selects \(\widehat B\).
% 一种固定被控对象编码取 \(\widehat B_0\) 的完整前缀字典树，并在每个带索引完成路径之后添加一条可控的结果特定终止边，因此选择终止边就等同于选择 \(\widehat B\)。
The synthesis alphabet contains committed resolved events, and complete mediation makes every \Fresh/\Alias commit controllable even though the Agent may issue arbitrary requests.
% 综合字母表包含已提交的解析事件，而完全中介使每个 \Fresh/\Alias 提交均可控，即使 Agent 可以发出任意请求。
Request arrival, crash, settlement, delivery, and scheduling of a prepared dispatch are uncontrollable but do not advance the resolved word; a deployment with uncontrollable resolved events must instead compute a supremal controllable sublanguage.
% 请求到达、崩溃、结算、交付以及已准备派发的调度不可控，但不会推进解析词；具有不可控解析事件的部署必须改为计算上确界可控子语言。
The Agent-specific problem is to derive those markings and terminal incidences from authenticated topology, schema-authorized retirement, occurrence-to-cell effect identity, and irreversible receipts.
% Agent 特有的问题在于，从经认证的拓扑、模式授权退役、发生项到单元的效果标识以及不可逆回执中推导这些标记与终止关联。
Erasing that relational evidence leaves a target-only trace view that cannot support an exact history compiler (\cref{thm:exact-history}).
% 擦除这些关系证据后，只剩下仅含目标轨迹的视图，而该视图无法支持精确的历史编译器（\cref{thm:exact-history}）。

For every \((o_{\rm rem},b)\in\widehat B_i\setminus\widehat B_{i+1}\), the rejection certificate records rank \(i\), prefix \(z\preceq b\), and \(o_{\rm miss}\in\mathsf{Compat}(z)\) for which no \((o_{\rm miss},b')\in\widehat B_i\) extends \(z\).
% 对每个 \((o_{\rm rem},b)\in\widehat B_i\setminus\widehat B_{i+1}\)，拒绝证书都会记录秩 \(i\)、前缀 \(z\preceq b\)，以及一个 \(o_{\rm miss}\in\mathsf{Compat}(z)\)，使得没有 \((o_{\rm miss},b')\in\widehat B_i\) 扩展 \(z\)。
For any post-fixed family \(P\), induction gives \(P\subseteq\widehat B_i\).
% 对任意后不动点族 \(P\)，归纳可得 \(P\subseteq\widehat B_i\)。
The base case follows from \(\widehat B_0\), and each cause excludes its removed pair from the next round.
% 基础情形由 \(\widehat B_0\) 得到，而每个原因都会将其对应的被移除二元组排除在下一轮之外。
Thus an empty final family excludes every realization.
% 因此，最终族为空即可排除所有实现。
The installation checker recomputes \(\widehat B_0\), the chain, causes, and survivor witnesses.
% 安装检查器会重新计算 \(\widehat B_0\)、淘汰链、原因和幸存者见证。

To preserve admission after each permitted prefix, fix \(H,u,\mathcal A\) after deriving \(\mathcal C\), and write \(W^\dagger(\mathcal C,\Delta)\) and \(\widehat B^\dagger(\mathcal C,\Delta)\) with those parameters suppressed.
% 为在每个允许的前缀之后保持准入，先在派生 \(\mathcal C\) 后固定 \(H,u,\mathcal A\)，再将省略这些参数的记法写作 \(W^\dagger(\mathcal C,\Delta)\) 和 \(\widehat B^\dagger(\mathcal C,\Delta)\)。
\begin{lemma}[Residual coherence]
% 残余一致性
\label{lem:residual-coherence}
If \(z\in W^\dagger(\mathcal C,\Delta)\), then
% 若 \(z\in W^\dagger(\mathcal C,\Delta)\)，则：
\(\Resolve^{\rho'}_\Delta(\mathsf{raw}(z))=z\),
\(\mathsf{lab}(\Delta_z)=
 \mathsf{lab}(\Delta)\mathsf{auth}(z)\), and
\[
\begin{aligned}
 W^\dagger(\mathcal C,\Delta)/z
  &=W^\dagger(\mathcal C/\mathsf{raw}(z),\Delta_z),\\
 \widehat B^\dagger(\mathcal C,\Delta)/z
  &=\widehat B^\dagger(
      \mathcal C/\mathsf{raw}(z),\Delta_z),
\end{aligned}
\]
where
% 其中
\(\widehat B/z=\{(o,v)\mid(o,zv)\in\widehat B\}\).
\end{lemma}
\begin{proof}
Because \(z\) prefixes a projected member of \(\widehat B^\dagger\), raw recoverability and streaming in \cref{lem:resolution} give the recoverability and receipt-ledger equalities.
% 因为 \(z\) 是 \(\widehat B^\dagger\) 某个投影成员的前缀，\cref{lem:resolution} 中的原始词可恢复性和流式性质给出可恢复性等式与回执账本等式。
The indexed residual removes exactly that raw prefix, retains every compatible outcome identity, and gives
% 带索引残余恰好移除该原始前缀，保留每个兼容结果标识，并给出
\[
 \mathsf{Compat}_{\mathcal C/\mathsf{raw}(z)}(s)
 =\mathsf{Compat}_{\mathcal C}(zs).
\]
Together with authority concatenation, streaming resolution therefore yields the key equality
% 结合权限串接，流式解析因此给出如下关键等式：
\[
 \widehat B_0(\mathcal C,\Delta)/z
 =\widehat B_0(\mathcal C/\mathsf{raw}(z),\Delta_z),
\]
with the same retained outcome identities, policy, and target registry.
% 且保留的结果标识、策略和目标注册表均相同。
Thus \(\widehat B^\dagger/z\) is post-fixed for the residual operator and lies within its greatest fixed point \(Y\).
% 因此，\(\widehat B^\dagger/z\) 是残余算子的后不动点，并包含于其最大不动点 \(Y\)。
Conversely, streaming and residual policy safety put \(zY=\{(o,zy)\mid(o,y)\in Y\}\) inside the original \(\widehat B_0\).
% 反之，流式性质和残余策略安全性使 \(zY=\{(o,zy)\mid(o,y)\in Y\}\) 包含于原始 \(\widehat B_0\)。
The union \(\widehat B^\dagger\cup zY\) is post-fixed because prefixes \(t\preceq z\) use existing witnesses, while prefixes \(t=zs\) use witnesses in \(Y\).
% 并集 \(\widehat B^\dagger\cup zY\) 是后不动点，因为前缀 \(t\preceq z\) 使用已有见证，而前缀 \(t=zs\) 使用 \(Y\) 中的见证。
Greatestness gives \(zY\subseteq\widehat B^\dagger\), hence \(Y=\widehat B^\dagger/z\).
% 最大性给出 \(zY\subseteq\widehat B^\dagger\)，因此 \(Y=\widehat B^\dagger/z\)。
Finally, \(\Pref(B)/z=\Pref(B/z)\) yields the generated-language equality.
% 最后，\(\Pref(B)/z=\Pref(B/z)\) 给出生成语言等式。
\end{proof}
Thus every admitted prefix retains a safe completion for every residual outcome index still contract-compatible with that prefix.
% 因此，每个已准入前缀都会为仍与该前缀契约兼容的每个残余结果索引保留一条安全完成路径。

\subsection{The ideal atomic history machine}
% 理想原子历史机
\label{sec:ideal}

The ideal labeled transition system (LTS) retains abstract gate and epoch identities for protected calls and history edges but omits the compiler, monitor representation, phase protocols, seals, preloading, and handoff microsteps.
% 理想标号转移系统（LTS）保留受保护调用和历史边所需的抽象门与纪元标识，但省略编译器、监控器表示、阶段协议、封印、预加载和交接微步骤。
Its durable state is \((\kappa,H,\Delta,\mathsf{out})\), current semantic cut \(c=(H_c,u,L^*,\widehat B^*)\), and resolved prefix \(r\).
% 其持久状态为 \((\kappa,H,\Delta,\mathsf{out})\)、当前语义切点 \(c=(H_c,u,L^*,\widehat B^*)\) 和已解析前缀 \(r\)。

\paragraph{History edge}
% 历史边
For the current pre-edge history \(H_0=H\), \(\mathsf{Edge}(u)\) is enabled exactly when the unique judgment \(\Sigma_\zeta;H_0\vdash u\Downarrow(H',\mathcal C,\eta^-,\eta^+)\) exists and \(\mathsf{Spec}(H_0,u)=(L^*,\widehat B^*)\) is defined.
% 对于当前编辑前历史 \(H_0=H\)，当且仅当唯一判定 \(\Sigma_\zeta;H_0\vdash u\Downarrow(H',\mathcal C,\eta^-,\eta^+)\) 存在且 \(\mathsf{Spec}(H_0,u)=(L^*,\widehat B^*)\) 有定义时，\(\mathsf{Edge}(u)\) 才启用。
One atomic transition persists version-advanced \(H'\), closes \(\eta^-\), activates \(\eta^+\), binds the schema-derived target gates, stores \(c:=(H_0,u,L^*,\widehat B^*)\), resets \(r:=\epsilon\), and returns \(\mathcal H_u^+\).
% 一个原子转移持久化已推进版本的 \(H'\)、关闭 \(\eta^-\)、激活 \(\eta^+\)、绑定由模式派生的目标门、存储 \(c:=(H_0,u,L^*,\widehat B^*)\)、将 \(r\) 重置为 \(\epsilon\)，并返回 \(\mathcal H_u^+\)。
This rule is defined through \(\mathsf{Spec}\), rather than operationally invoking \(\mathsf{Admit}\), the fixed-point computation, \(\mathsf{Compile}\), or installation.
% 该规则通过 \(\mathsf{Spec}\) 定义，而不会在操作上调用 \(\mathsf{Admit}\)、不动点计算、\(\mathsf{Compile}\) 或安装过程。

\paragraph{Protected occurrence}
% 受保护发生项
For submitted invocation \(m\), an enabled current-frontier occurrence \(x\) passes the ideal guard exactly when its gate and authenticated handle bind cell \(d\) and \(\mathsf{canon}_\kappa(m)=\mathsf{inv}_\rho(d)\); current receipts then determine \(a\in\{\Fresh(x,d),\Alias(x,d)\}\).
% 对于提交的调用 \(m\)，当且仅当已启用的当前前沿发生项 \(x\) 的门和认证句柄绑定单元 \(d\)，且 \(\mathsf{canon}_\kappa(m)=\mathsf{inv}_\rho(d)\) 时，它才通过理想守卫；随后，当前回执确定 \(a\in\{\Fresh(x,d),\Alias(x,d)\}\)。
Exactly when \(ra\in L^*\), one atomic transition residualizes the frontier by \(x\), appends \(a\) to \(\chi\), advances \(\nu\), and sets \(r:=ra\).
% 当且仅当 \(ra\in L^*\) 时，一个原子转移以 \(x\) 对前沿取残余，将 \(a\) 追加到 \(\chi\)，推进 \(\nu\)，并设置 \(r:=ra\)。
\Fresh also appends to \(\Delta\) an immutable receipt for \(d\) labeled \(\ell(d)\) and enqueues \((d,\mathsf{canon}_\kappa(m))\); \Alias changes neither field.
% \Fresh 还向 \(\Delta\) 追加一条标签为 \(\ell(d)\) 且关于 \(d\) 的不可变回执，并将 \((d,\mathsf{canon}_\kappa(m))\) 入队；\Alias 不改变这两个字段。

An invalid occurrence, gate, handle, or invocation, a disabled branch, or \(ra\notin L^*\) fails the guard and returns \(\mathsf{deny}(x)\) without changing state.
% 无效的发生项、门、句柄或调用、禁用分支或 \(ra\notin L^*\) 会使守卫失败，并返回 \(\mathsf{deny}(x)\) 且不改变状态。
\Alias binds the restored occurrence to its cell's durable result future, advancing causal history without inventing a result not yet produced by the original invocation.
% \Alias 将恢复的发生项绑定到其单元的持久结果期值，从而推进因果历史，却不虚构原始调用尚未产生的结果。

\paragraph{Retry, release, and crash}
% 重试、释放与崩溃
\(\mathsf{Save}\) takes the trusted checkpoint transition in \cref{sec:model} as a \(\tau\)-step.
% \(\mathsf{Save}\) 将 \cref{sec:model} 中的可信检查点转移作为一个 \(\tau\) 步。
An authenticated same-invocation retry follows its \(\chi\)-to-receipt link and returns the same stable result future without changing history, whereas an unauthenticated or argument-changing lookup is denied.
% 经认证的同调用重试沿其从 \(\chi\) 到回执的链接返回同一稳定结果期值，且不改变历史，而未认证或改变参数的查找会被拒绝。
\Dispatch releases exactly the stored invocation in the oldest prepared outbox item and marks that item released, making the release trace a prefix of \Fresh preparation order.
% \Dispatch 恰好释放最早已准备发件箱条目中存储的调用并将该条目标记为已释放，使释放轨迹成为 \Fresh 准备次序的前缀。
Settlement monotonically advances a receipt's phase and fills its durable result future with the stable result, changing no history or authority field.
% 结算单调推进回执阶段，并以稳定结果填充其持久结果期值，且不改变历史或权限字段。
Crash discards nondurable computation without changing LTS state; we make no claim about completion order inside an external network after release.
% 崩溃丢弃非持久计算而不改变 LTS 状态；我们不对释放后外部网络内部的完成顺序作任何主张。

By \cref{lem:greatest-realization}, every reachable ideal-machine prefix retains a policy-safe completion until the next explicit history edge changes the contract.
% 根据 \cref{lem:greatest-realization}，理想机的每个可达前缀都会保留一条策略安全完成路径，直到下一条显式历史边改变契约。
The next sections implement this machine without consulting the full completion set at every call.
% 后续章节实现该机器，而无需在每次调用时查询完整完成路径集合。
