\section{Exact Safety Check for Execution Edits}
% 执行编辑的精确安全检查
\label{sec:admission}

The preceding section derives an edited workflow from the authenticated source record and requested edit.
% 前一节从经认证源记录和请求的编辑中推导编辑后的工作流。
This section decides whether that workflow has a policy-safe implementation that preserves every still-possible required outcome.
% 本节判定该工作流是否存在满足策略且保留每个仍可能且仍要求实现结果的安全实现。
It first determines whether each copied call needs a new receipt or reuses an existing one.
% 它首先确定每个复制调用需要新回执还是复用已有回执。
It then computes the largest family of completed executions that remains safe after every partial execution.
% 随后，它计算在每段部分执行之后都保持安全的最大完整执行族。
Finally, it presents the ideal atomic execution machine used to prove the installed runtime correct in \cref{sec:kernel}.
% 最后，它给出用于在 \cref{sec:kernel} 中证明已安装运行时正确的理想原子执行机。

Recall the authority-label alphabet \(\mathcal U\) and regular prefix-closed policy \(\mathcal A\subseteq\mathcal U^*\).
% 回顾权限标签字母表 \(\mathcal U\) 和正则前缀闭合策略 \(\mathcal A\subseteq\mathcal U^*\)。
For the authenticated receipt log \(\Delta\), \(\mathsf{lab}(\Delta)\in\mathcal A\) is its permission trace and \(D_\Delta\) is the set of effect identities that already have receipts.
% 对于经认证回执日志 \(\Delta\)，\(\mathsf{lab}(\Delta)\in\mathcal A\) 是其权限轨迹，\(D_\Delta\) 是已经具有回执的效果标识集合。
Fix \(\Theta=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\) and write \(\mathsf{src}(\Theta)=(\kappa,H,\Delta,\mathsf{out},\mathcal A)\).
% 固定 \(\Theta=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，并记 \(\mathsf{src}(\Theta)=(\kappa,H,\Delta,\mathsf{out},\mathcal A)\)。
When defined, the tagged root, execution-edit, or registered-extension derivation is unique.
% 带标签的根、执行编辑或已注册扩展推导在有定义时是唯一的。
Write \(\mathsf{Derive}(\Theta)=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\).
% 记为 \(\mathsf{Derive}(\Theta)=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\)。
Root derivation additionally requires that \(\mathsf{CheckReg}(\mathcal W,R)\) accept.
% 根推导还要求 \(\mathsf{CheckReg}(\mathcal W,R)\) 接受。
An execution edit has \((\kappa_u,\mathcal A_u)=(\kappa,\mathcal A)\) and uses the unique execution-edit judgment.
% 执行编辑满足 \((\kappa_u,\mathcal A_u)=(\kappa,\mathcal A)\) 并使用唯一的执行编辑判定。
\(\mathsf{Extend}(\xi)\) uses the authenticated judgment in \cref{sec:model}.
% \(\mathsf{Extend}(\xi)\) 使用 \cref{sec:model} 中的认证判定。
Let \(\rho_u\) be the authenticated target registry in \(H_u\), let \(O_{H,u}=O_{\mathcal C_u}\), and use \(H'=H_u\) and \(\rho'=\rho_u\) where earlier notation is convenient.
% 令 \(\rho_u\) 为 \(H_u\) 中经认证的目标注册表，令 \(O_{H,u}=O_{\mathcal C_u}\)，并在沿用先前记法更方便时使用 \(H'=H_u\) 和 \(\rho'=\rho_u\)。
All languages below depend on \(\Theta\), the schema registry, \(\rho_u\), and target policy \(\mathcal A_u\), but not on the dispatch queue \(\mathsf{out}\).
% 下文所有语言均依赖于 \(\Theta\)、模式注册表、\(\rho_u\) 与目标策略 \(\mathcal A_u\)，但不依赖派发队列 \(\mathsf{out}\)。
The executable checker nevertheless binds \(\mathsf{out}\) into the authenticated source snapshot used for installation.
% 可执行检查器仍会把 \(\mathsf{out}\) 绑定到安装所用的认证源状态快照中。
We write only \(H,u\) where the remaining parameters are fixed.
% 当其余参数固定时，我们仅写作 \(H,u\)。

\subsection{\Fresh and \Alias resolution}
% \Fresh 与 \Alias 解析

Resolution never erases an occurrence retained by the derived contract.
% 解析绝不会擦除派生契约所保留的发生项。
Starting with \(D_0=D_\Delta\), the deterministic transducer \(\Resolve^{\rho_u}_\Delta\) maps a raw word \(w=x_1\cdots x_n\) to a resolved word \(z_1\cdots z_n\).
% 从 \(D_0=D_\Delta\) 开始，确定性转换器 \(\Resolve^{\rho_u}_\Delta\) 将原始词 \(w=x_1\cdots x_n\) 映射为已解析词 \(z_1\cdots z_n\)。
For \(d_i=q^{\rho_u}_{\rm cell}(x_i)\),
% 对于 \(d_i=q^{\rho_u}_{\rm cell}(x_i)\)，定义 \(z_i\) 如下：
\begin{equation}
\label{eq:resolve}
 z_i=
 \begin{cases}
  \Fresh(x_i,d_i), & d_i\notin D_{i-1},
       \quad D_i=D_{i-1}\cup\{d_i\};\\
  \Alias(x_i,d_i), & d_i\in D_{i-1},
       \quad D_i=D_{i-1}.
 \end{cases}
\end{equation}
The permission projection erases \Alias symbols and maps each \Fresh symbol to its effect identity's permission label.
% 权限投影会擦除 \Alias 符号，并将每个 \Fresh 符号映射到其效果标识的权限标签。
\[
 \mathsf{auth}(\Fresh(x,d))=\ell_{\rho_u}(d),\qquad
 \mathsf{auth}(\Alias(x,d))=\epsilon .
\]
For resolved \(z\), \(\mathsf{raw}(z)\) drops the \Fresh/\Alias mode and effect identity but preserves the ordered occurrence identifiers.
% 对于已解析的 \(z\)，\(\mathsf{raw}(z)\) 会去除 \Fresh/\Alias 模式和效果标识，但保留有序发生项标识符。
A \Retry repeats the same invocation and adds no occurrence.
% \Retry 重复同一次调用，不增加任何发生项。
Restored occurrences sharing an effect identity remain distinct and may resolve differently.
% 共享同一效果标识的恢复发生项仍彼此有别，并且可能得到不同的解析结果。

\begin{lemma}[Resolution]
% 解析
\label{lem:resolution}
\(\Resolve^{\rho_u}_\Delta\) is deterministic, length preserving, and prefix compatible.
% \(\Resolve^{\rho_u}_\Delta\) 是确定性的、保持长度的，并且与前缀兼容。
Its \Fresh projection contains each effect identity at most once outside \(D_\Delta\), while its occurrence projection is exactly the input word.
% 在 \(D_\Delta\) 之外，其 \Fresh 投影至多包含每个效果标识一次，而其发生项投影恰好就是输入词。
Moreover, if \(\Resolve^{\rho_u}_\Delta(rv)=zv'\), then \(z=\Resolve^{\rho_u}_\Delta(r)\) and \(v'=\Resolve^{\rho_u}_{\Delta_z}(v)\), where \(\Delta_z\) extends \(\Delta\) by the \Fresh events of \(z\).
% 此外，若 \(\Resolve^{\rho_u}_\Delta(rv)=zv'\)，则 \(z=\Resolve^{\rho_u}_\Delta(r)\) 且 \(v'=\Resolve^{\rho_u}_{\Delta_z}(v)\)，其中 \(\Delta_z\) 通过加入 \(z\) 的 \Fresh 事件来扩展 \(\Delta\)。
\end{lemma}
\begin{proof}
Induction on input length shows that the transducer emits one prefix-determined output symbol per input symbol and updates \(D_i\) only for \Fresh.
% 对输入长度作归纳表明，该转换器为每个输入符号发出一个由前缀决定的输出符号，并且仅在 \Fresh 时更新 \(D_i\)。
Set membership ensures one \Fresh emission per effect identity.
% 集合成员关系确保每个效果标识仅产生一次 \Fresh。
Both cases retain \(x_i\).
% 两种情形都会保留 \(x_i\)。
Splitting after \(r\) gives the streaming equation.
% 在 \(r\) 之后拆分即可得到流式等式。
\end{proof}
Thus a retry stutters in the resolved causal and authority histories, although its successful API reply is observable as \(\mathsf{Return}(t,[v]_{\cong})\).
% 因而，重试在已解析因果历史与权限历史中表现为停顿，但其成功 API 回复仍可观测为 \(\mathsf{Return}(t,[v]_{\cong})\)。
A copied occurrence that resolves as \Alias stutters only in the authority history because it advances causal history without changing the authority word.
% 解析为 \Alias 的复制发生项只在权限历史中表现为停顿，因为它会推进因果历史而不改变权限词。

\subsection{Safe Completion After Every Prefix}
% 每个前缀之后的安全完成

\subsubsection{Largest family safe after every prefix}
% 每个前缀之后都安全的最大执行族

For each derived outcome \(o\in O_{H,u}\), define all of its completed executions and the subset allowed by policy.
% 对每个推导出的结果 \(o\in O_{H,u}\)，定义其全部完整执行以及策略允许的子集。
\begin{equation}
\label{eq:safe-completions}
\begin{aligned}
 R_o(H,u)&=\{\Resolve^{\rho_u}_\Delta(w)\mid w\in\Lin(p_o)\},\\
 M_o(H,u)&=\{z\in R_o(H,u)\mid
   \mathsf{lab}(\Delta)\mathsf{auth}(z)\in\mathcal A_u\}.
\end{aligned}
\end{equation}
Checking each outcome separately is insufficient.
% 单独检查每个结果并不充分。
After a partial execution shared by several outcomes, every outcome still compatible with that partial execution must retain a policy-safe completion.
% 在多个结果共享的一段部分执行之后，每个仍与该部分执行兼容的结果都必须保留一条策略安全的完成路径。
The operator below removes exactly the completed executions that violate this condition.
% 下列算子恰好删除违反这一条件的完整执行。
For a resolved prefix \(z\), let
% 对于已解析前缀 \(z\)，定义 \(\mathsf{Compat}(z)\) 如下：
\[
 \mathsf{Compat}(z)=
 \{o\mid \mathsf{raw}(z)\preceq_{\rm pref}w
		          \text{ for some }w\in\Lin(p_o)\}.
\]
Put
% 令 \(\widehat B_0\) 如下：
\[
 \widehat B_0=\biguplus_{o\in O_{H,u}}\{o\}\times M_o .
\]
For \(\widehat B\subseteq\widehat B_0\), define the monotone operator
% 对于 \(\widehat B\subseteq\widehat B_0\)，定义如下单调算子：
\begin{equation}
\label{eq:robust-operator}
\widehat\Phi(\widehat B)=
\left\{(o,b)\in\widehat B_0\ \middle|\
\begin{array}{l}
\forall z\preceq_{\rm pref} b.\ \forall v\in\mathsf{Compat}(z).\\[-2pt]
\exists (v,b')\in\widehat B.\ z\preceq_{\rm pref}b'
\end{array}\right\}.
\end{equation}
Set \(\widehat B_{i+1}=\widehat\Phi(\widehat B_i)\).
% 令 \(\widehat B_{i+1}=\widehat\Phi(\widehat B_i)\)。
Since \(\widehat B_1\subseteq\widehat B_0\), monotonicity yields a finite descending chain, whose limit is
% 由于 \(\widehat B_1\subseteq\widehat B_0\)，单调性产生一条有限下降链，其极限如下：
\[
\begin{aligned}
 \widehat B^\dagger_{H,u}
   &=\nu\widehat B.\widehat\Phi(\widehat B)
     =\bigcap_{i\geq 0}\widehat B_i,\\
 B^\dagger_{H,u}&=\pi_2\widehat B^\dagger_{H,u},
 &W^\dagger_{H,u}&=\Pref(B^\dagger_{H,u}).
\end{aligned}
\]
Runtime uses \((W^\dagger,B^\dagger)\), while the checker and seal retain indexed witness \(\widehat B^\dagger\).
% 运行时使用 \((W^\dagger,B^\dagger)\)，而检查器与封印保留带索引见证 \(\widehat B^\dagger\)。

\begin{definition}[Safe execution edit]
% 安全执行编辑
\label{def:admission}
If \(\mathsf{Derive}(\Theta)\) is undefined, then \(\mathsf{SafeEdit}(\Theta)\) is false.
% 若 \(\mathsf{Derive}(\Theta)\) 无定义，则 \(\mathsf{SafeEdit}(\Theta)\) 为假。
Otherwise,
% 否则，
\begin{equation}
\label{eq:admission}
\mathsf{SafeEdit}(\Theta)
 \quad\Longleftrightarrow\quad
 \widehat B^\dagger_{H,u}\ne\varnothing .
\end{equation}
\end{definition}
\(\mathsf{SafeEdit}(H,u)\) fixes \(\Theta\) and both registries.
% \(\mathsf{SafeEdit}(H,u)\) 固定 \(\Theta\) 与两个注册表。
At \(z=\epsilon\), nonemptiness covers every required outcome.
% 在 \(z=\epsilon\) 处，非空性覆盖每个要求实现的结果。
The existential quantifier chooses a call order without assuming fairness, and the universal condition keeps every compatible outcome completable after every prefix.
% 存在量词在不假设公平性的情况下选择调用顺序，而全称条件保证每个兼容结果在每个前缀之后仍可完成。
Relation \(\mathsf{Preserve}\) requires every source outcome that is neither completed nor authorized for removal to have a checked lift into \(\widehat B\); \cref{app:spc} gives its full definition.
% 关系 \(\mathsf{Preserve}\) 要求每个既未完成、也未获授权移除的源结果在 \(\widehat B\) 中都有经检查的提升；\cref{app:spc} 给出完整定义。

\begin{definition}[Indexed realization]
% 带索引实现
\label{def:realization}
A generated language and indexed marked family \((L,\widehat B)\) realize \((H,u)\) when all conditions below hold.
% 当下列全部条件成立时，生成语言和带索引的标记族 \((L,\widehat B)\) 实现 \((H,u)\)。
\begin{enumerate}[leftmargin=*,itemsep=1pt]
 \item \(\widehat B\ne\varnothing\);
% \(\widehat B\) 非空；
 \item \emph{source and target fidelity:} \(\mathsf{Preserve}(H,u,\widehat B)\), \(\widehat B\subseteq \biguplus_{o\in O_{H,u}}\{o\}\times R_o(H,u)\), and \(L\subseteq\Pref(\bigcup_{o\in O_{H,u}}R_o(H,u))\);
% 源与目标忠实性：\(\mathsf{Preserve}(H,u,\widehat B)\)、\(\widehat B\subseteq \biguplus_{o\in O_{H,u}}\{o\}\times R_o(H,u)\)，且 \(L\subseteq\Pref(\bigcup_{o\in O_{H,u}}R_o(H,u))\)。
 \item \emph{policy safety:} \(\mathsf{lab}(\Delta)\,\mathsf{auth}(z)\in\mathcal A_u\) for every \(z\in L\);
% 策略安全性：对每个 \(z\in L\)，均有 \(\mathsf{lab}(\Delta)\,\mathsf{auth}(z)\in\mathcal A_u\)。
 \item \emph{completion nonblocking:} \(L=\Pref(\pi_2\widehat B)\); and
% 完成非阻塞性：\(L=\Pref(\pi_2\widehat B)\)；并且
 \item \emph{persistent outcome coverage:} for every \(z\in L\) and \(o\in\mathsf{Compat}(z)\), some \((o,b)\in\widehat B\) extends \(z\).
% 持续的结果覆盖：对于每个 \(z\in L\) 和 \(o\in\mathsf{Compat}(z)\)，都存在某个 \((o,b)\in\widehat B\) 扩展 \(z\)。
\end{enumerate}
\end{definition}

\begin{lemma}[Largest safe realization]
% 最大安全实现
\label{lem:greatest-realization}
A realization exists iff \(\mathsf{SafeEdit}(H,u)\).
% 当且仅当 \(\mathsf{SafeEdit}(H,u)\) 成立时，实现存在。
When the edit is safe, \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\) is a realization, and every realization \((L,\widehat B)\) satisfies \(\widehat B\subseteq\widehat B^\dagger_{H,u}\) and \(L\subseteq W^\dagger_{H,u}\).
% 当编辑安全时，\((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\) 是一个实现，并且每个实现 \((L,\widehat B)\) 都满足 \(\widehat B\subseteq\widehat B^\dagger_{H,u}\) 和 \(L\subseteq W^\dagger_{H,u}\)。
\end{lemma}
\begin{proof}
Fidelity, completion nonblocking, and safety place any realization's indexed marked family inside \(\widehat B_0\).
% 忠实性、完成非阻塞性和安全性使任意实现的带索引标记族包含于 \(\widehat B_0\)。
Persistent coverage makes it post-fixed, so monotonicity and finite Knaster--Tarski place it inside \(\widehat B^\dagger\), and projected prefixes give \(L\subseteq W^\dagger\).
% 持续覆盖使其成为后不动点，因此由单调性和有限 Knaster--Tarski 可知其包含于 \(\widehat B^\dagger\)，而投影前缀给出 \(L\subseteq W^\dagger\)。
Conversely, \(\widehat B^\dagger=\widehat\Phi(\widehat B^\dagger)\) supplies persistent coverage.
% 反之，\(\widehat B^\dagger=\widehat\Phi(\widehat B^\dagger)\) 提供持续覆盖。
Together with checked lifts, this coverage establishes \(\mathsf{Preserve}\) at \(\epsilon\).
% 该覆盖与经检查的提升共同在 \(\epsilon\) 处建立 \(\mathsf{Preserve}\)。
The inclusion \(\widehat B^\dagger\subseteq\widehat B_0\) supplies target fidelity and safe marked words, while prefix closure of \(\mathcal A_u\) supplies prefix safety.
% 包含关系 \(\widehat B^\dagger\subseteq\widehat B_0\) 提供目标忠实性和安全标记词，而 \(\mathcal A_u\) 的前缀闭包提供前缀安全性。
Finally, \(W^\dagger=\Pref(\pi_2\widehat B^\dagger)\) supplies nonblocking.
% 反之，\(\widehat B^\dagger=\widehat\Phi(\widehat B^\dagger)\) 提供持续覆盖，它与经检查的提升共同在 \(\epsilon\) 处建立 \(\mathsf{Preserve}\)；\(\widehat B^\dagger\subseteq\widehat B_0\) 提供目标忠实性和安全标记词，\(\mathcal A_u\) 的前缀闭合性提供前缀安全性，而 \(W^\dagger=\Pref(\pi_2\widehat B^\dagger)\) 提供非阻塞性。
Hence the fixed point is a realization exactly when nonempty.
% 因此，该不动点恰在非空时构成实现。
\end{proof}

\(\mathsf{GReal}(\Theta;L,\widehat B)\) declaratively denotes a realization containing every other one componentwise, and its unique witness is \(\mathsf{Spec}(\Theta)\).
% \(\mathsf{GReal}(\Theta;L,\widehat B)\) 声明式表示一个按分量包含其他所有实现的实现，其唯一见证记为 \(\mathsf{Spec}(\Theta)\)。
\Cref{lem:greatest-realization} proves that this witness exists exactly when \(\widehat B^\dagger_{H,u}\ne\varnothing\) and then equals \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\).
% \Cref{lem:greatest-realization} 证明该见证恰在 \(\widehat B^\dagger_{H,u}\ne\varnothing\) 时存在，并且此时等于 \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\)。

The following shared-prefix example shows why each outcome needs its own completion condition even when every \(M_o\) is nonempty.
% 下列共享前缀例子说明，即使每个 \(M_o\) 都非空，每个结果仍需要自己的完成条件。
Let singleton contracts \(X,Y,Z\) contain \(x_o,y_o,z_o\), and let the target registry map them to distinct effect identities \(d_x,d_y,d_z\) that do not yet have receipts and have labels \(x,y,z\), respectively.
% 令单元素契约 \(X,Y,Z\) 分别包含 \(x_o,y_o,z_o\)，并令目标注册表将它们映射到尚无回执且标签分别为 \(x,y,z\) 的不同效果标识 \(d_x,d_y,d_z\)。
Write \(\bar x=\Fresh(x_o,d_x)\), \(\bar y=\Fresh(y_o,d_y)\), and \(\bar z=\Fresh(z_o,d_z)\).
% 记 \(\bar x=\Fresh(x_o,d_x)\)、\(\bar y=\Fresh(y_o,d_y)\)、\(\bar z=\Fresh(z_o,d_z)\)。
\subsubsection{Why Individual Outcome Safety Is Insufficient}

For \(\mathcal C=X\otimes(Y\oplus Z)\) and \(\mathcal A=\Pref\{yx,xz\}\), the \(X\otimes Y\) and \(X\otimes Z\) outcomes initially have safe completed executions \(\bar y\bar x\) and \(\bar x\bar z\), with permission traces \(yx\) and \(xz\).
% 对于 \(\mathcal C=X\otimes(Y\oplus Z)\) 和 \(\mathcal A=\Pref\{yx,xz\}\)，\(X\otimes Y\) 与 \(X\otimes Z\) 结果最初分别具有安全完整执行 \(\bar y\bar x\) 和 \(\bar x\bar z\)，其权限轨迹为 \(yx\) 和 \(xz\)。
Yet prefix \(\bar x\) from \(\bar x\bar z\) remains contract-compatible with \(X\otimes Y\) but leaves no safe continuation.
% 然而，\(\bar x\bar z\) 的前缀 \(\bar x\) 仍与 \(X\otimes Y\) 契约兼容，却不留下安全后续。
The first fixed-point iteration removes \(\bar x\bar z\).
% 第一次不动点迭代移除 \(\bar x\bar z\)。
The next removes \(\bar y\bar x\) because the empty prefix no longer has a completion for every outcome.
% 下一次迭代移除 \(\bar y\bar x\)，因为空前缀不再为每个结果保留完成路径。
Thus the edit is rejected, whereas the independent \(\forall o.\,M_o\ne\varnothing\) test accepts it.
% 因此，该编辑会被拒绝，而独立的 \(\forall o.\,M_o\ne\varnothing\) 检验会接受它。

\begin{proposition}[Outcome-indexed nonblocking correspondence]
% 结果索引的非阻塞对应关系
\label{prop:outcome-necessary}
For nonempty \(\widehat B\subseteq\widehat B_0\), let \(G_{\widehat B}\) be the prefix trie of \(L_{\widehat B}=\Pref(\pi_2\widehat B)\).
% 对于非空的 \(\widehat B\subseteq\widehat B_0\)，令 \(G_{\widehat B}\) 为 \(L_{\widehat B}=\Pref(\pi_2\widehat B)\) 的前缀字典树。
Mark state \(z\) by \(\alpha_o\) exactly when \(o\in\mathsf{Compat}(z)\), and mark state \(b\) by \(\omega_o\) exactly when \((o,b)\in\widehat B\).
% 当且仅当 \(o\in\mathsf{Compat}(z)\) 时用 \(\alpha_o\) 标记状态 \(z\)，并且当且仅当 \((o,b)\in\widehat B\) 时用 \(\omega_o\) 标记状态 \(b\)。
Then
% 则有以下等价关系：
\[
\begin{gathered}
 \widehat B\subseteq\widehat\Phi(\widehat B)\\[-2pt]
 \Longleftrightarrow\
 \forall o\in O_{H,u}.\;
 G_{\widehat B}\text{ is }(\alpha_o,\omega_o)\text{-nonblocking}.
\end{gathered}
\]
Consequently, if \(\widehat B^\dagger\) is nonempty, it is the largest nonempty completion subfamily of \(\widehat B_0\) satisfying these outcome-specific nonblocking conditions.
% 因此，若 \(\widehat B^\dagger\) 非空，则它是 \(\widehat B_0\) 中满足这些特定于结果的非阻塞条件的最大非空完成路径子族。
If it is empty, no nonempty subfamily satisfies the conditions.
% 若它为空，则没有任何非空子族满足这些条件。
Ordinary marker nonblocking of the unaugmented projected language is strictly weaker.
% 未增广投影语言的普通标记非阻塞性严格更弱。
\end{proposition}
\begin{proof}
From reachable prefix \(z\), an \(\omega_o\)-marked state is reachable exactly when some \((o,b)\in\widehat B\) extends \(z\).
% 从可达前缀 \(z\) 出发，当且仅当某个 \((o,b)\in\widehat B\) 扩展 \(z\) 时，才可到达一个带 \(\omega_o\) 标记的状态。
Quantifying over exactly the states marked \(\alpha_o\) is therefore the post-fixed-point condition.
% 因此，恰好对带 \(\alpha_o\) 标记的状态进行量化就是后不动点条件。
Greatestness follows from the greatest-fixed-point construction.
% 最大性由最大不动点构造得到。
For strictness, the preceding instance has the marker-nonblocking projected pair \((\Pref\{\bar y\bar x,\bar x\bar z\}, \{\bar y\bar x,\bar x\bar z\})\), but its indexed fixed point is empty.
% 关于严格性，前述实例具有标记非阻塞的投影二元组 \((\Pref\{\bar y\bar x,\bar x\bar z\}, \{\bar y\bar x,\bar x\bar z\})\)，但其带索引不动点为空。
\end{proof}

\Cref{prop:outcome-necessary} gives the exact interface to generalized nonblocking~\cite{dequeiroz2005multitasking,malik2008generalised}.
% \Cref{prop:outcome-necessary} 给出与广义非阻塞之间的精确接口~\cite{dequeiroz2005multitasking,malik2008generalised}。
After the trusted controller derives \(\alpha_o,\omega_o\) from the requested edit, authorized removals, effect identities, receipts, and source snapshot, a generalized-nonblocking solver computes the same largest family.
% 在可信控制器根据请求的编辑、获授权移除、效果标识、回执和源状态快照推导出 \(\alpha_o,\omega_o\) 之后，广义非阻塞求解器会计算同一个最大执行族。
Complete mediation makes \Fresh/\Alias controllable.
% 完全中介使 \Fresh/\Alias 可控。
Deployments with uncontrollable resolved events need the usual supremal-controllable refinement.
% 具有不可控已解析事件的部署需要通常的上确界可控精化。
Our theory additionally constructs the most permissive Agent monitor or an impossibility certificate, carries the result through atomic installation, and proves that neither a caller-proposed workflow nor its traces contain enough information to reproduce the derivation.
% 我们的理论还构造限制最少的 Agent 监控器或不可能性证书，将结果贯穿原子安装，并证明调用方提出的工作流及其轨迹都不包含足以复现该推导的信息。

Each removed \((o_{\rm rem},b)\) records its rank \(i\), a prefix \(z\preceq b\), and uncovered \(o_{\rm miss}\in\mathsf{Compat}(z)\).
% 每个被移除的 \((o_{\rm rem},b)\) 记录其秩 \(i\)、前缀 \(z\preceq b\) 与未覆盖的 \(o_{\rm miss}\in\mathsf{Compat}(z)\)。
Induction shows that every post-fixed \(P\) is contained in every \(\widehat B_i\).
% 归纳表明每个后不动点 \(P\) 都包含于每个 \(\widehat B_i\)。
An empty final family therefore excludes every realization, and installation recomputes the ranked rejection certificate and the remaining witnesses.
% 因此，最终执行族为空会排除每个实现，而安装会重新计算带秩拒绝证书和剩余见证。

\subsubsection{Rejection certificates and repeated checking}
% 拒绝证书与重复检查

To show that the checker can be applied again after each permitted partial execution, fix \(H,u,\mathcal A_u\) after deriving \(\mathcal C\), and write \(W^\dagger(\mathcal C,\Delta)\) and \(\widehat B^\dagger(\mathcal C,\Delta)\) with those parameters suppressed.
% 为证明检查器能在每段允许的部分执行之后再次应用，先在推导 \(\mathcal C\) 后固定 \(H,u,\mathcal A_u\)，再将省略这些参数的记法写作 \(W^\dagger(\mathcal C,\Delta)\) 和 \(\widehat B^\dagger(\mathcal C,\Delta)\)。
\begin{lemma}[Residual coherence]
% 残余一致性
\label{lem:residual-coherence}
If \(z\in W^\dagger(\mathcal C,\Delta)\), then
% 若 \(z\in W^\dagger(\mathcal C,\Delta)\)，则：
\(\Resolve^{\rho'}_\Delta(\mathsf{raw}(z))=z\),
\(\mathsf{lab}(\Delta_z)=
 \mathsf{lab}(\Delta)\mathsf{auth}(z)\), and
\[
\begin{aligned}
 W^\dagger(\mathcal C,\Delta)/z
  &=W^\dagger(\mathcal C/\mathsf{raw}(z),\Delta_z),\\
 \widehat B^\dagger(\mathcal C,\Delta)/z
  &=\widehat B^\dagger(
      \mathcal C/\mathsf{raw}(z),\Delta_z),
\end{aligned}
\]
where
% 其中
\(\widehat B/z=\{(o,v)\mid(o,zv)\in\widehat B\}\).
\end{lemma}
\begin{proof}
Because \(z\) prefixes a projected member of \(\widehat B^\dagger\), raw recoverability and streaming in \cref{lem:resolution} give the recoverability and receipt-ledger equalities.
% 因为 \(z\) 是 \(\widehat B^\dagger\) 某个投影成员的前缀，\cref{lem:resolution} 中的原始词可恢复性和流式性质给出可恢复性等式与回执账本等式。
The indexed residual removes exactly that raw prefix, retains every compatible outcome identity, and gives
% 带索引残余恰好移除该原始前缀，保留每个兼容结果标识，并给出
\[
 \mathsf{Compat}_{\mathcal C/\mathsf{raw}(z)}(s)
 =\mathsf{Compat}_{\mathcal C}(zs).
\]
Together with authority concatenation, streaming resolution therefore yields the key equality
% 结合权限串接，流式解析因此给出如下关键等式：
\[
 \widehat B_0(\mathcal C,\Delta)/z
 =\widehat B_0(\mathcal C/\mathsf{raw}(z),\Delta_z),
\]
with the same retained outcome identities, policy, and target registry.
% 且保留的结果标识、策略和目标注册表均相同。
Thus \(\widehat B^\dagger/z\) is post-fixed for the residual operator and lies within its greatest fixed point \(Y\).
% 因此，\(\widehat B^\dagger/z\) 是残余算子的后不动点，并包含于其最大不动点 \(Y\)。
Conversely, streaming and residual policy safety put \(zY=\{(o,zy)\mid(o,y)\in Y\}\) inside the original \(\widehat B_0\).
% 反之，流式性质和残余策略安全性使 \(zY=\{(o,zy)\mid(o,y)\in Y\}\) 包含于原始 \(\widehat B_0\)。
The union \(\widehat B^\dagger\cup zY\) is post-fixed because prefixes \(t\preceq z\) use existing witnesses, while prefixes \(t=zs\) use witnesses in \(Y\).
% 并集 \(\widehat B^\dagger\cup zY\) 是后不动点，因为前缀 \(t\preceq z\) 使用已有见证，而前缀 \(t=zs\) 使用 \(Y\) 中的见证。
Greatestness gives \(zY\subseteq\widehat B^\dagger\), hence \(Y=\widehat B^\dagger/z\).
% 最大性给出 \(zY\subseteq\widehat B^\dagger\)，因此 \(Y=\widehat B^\dagger/z\)。
Finally, \(\Pref(B)/z=\Pref(B/z)\) yields the generated-language equality.
% 最后，\(\Pref(B)/z=\Pref(B/z)\) 给出生成语言等式。
\end{proof}
Thus every accepted prefix retains a safe completion for every residual outcome index still contract-compatible with that prefix.
% 因此，每个被接受的前缀都会为仍与该前缀契约兼容的每个残余结果索引保留一条安全完成路径。

\subsubsection{Registered extension}
% 已注册扩展

\begin{lemma}[Registered extension preserves safety]
% 已注册扩展保持安全
\label{lem:live-extension}
For an authenticated \(\mathsf{Extend}(\xi)\), the current residual indexed realization is a post-fixed family for the extension instance and is therefore contained in \(\widehat B^\dagger_{H,\mathsf{Extend}(\xi)}\ne\varnothing\).
% 对于经认证的 \(\mathsf{Extend}(\xi)\)，当前残余的带索引实现是扩展实例的一个后不动点族，因此包含于 \(\widehat B^\dagger_{H,\mathsf{Extend}(\xi)}\ne\varnothing\)。
Consequently, a valid registered extension cannot remove a currently required outcome or leave it without a safe completion.
% 因此，有效的已注册扩展既不能移除当前要求实现的结果，也不能使其失去安全完成路径。
\end{lemma}
The proof is in \cref{app:live-extension-proof}.
% 证明见 \cref{app:live-extension-proof}。

\subsection{The ideal atomic execution machine}
% 理想原子执行机
\label{sec:ideal}

The ideal labeled transition system (LTS) retains abstract monitor-entry and version identities for protected calls and installed edits.
% 理想标号转移系统（LTS）保留受控调用和已安装编辑所需的抽象监控器入口与版本标识。
It omits compilation, the monitor representation, transaction phases, authenticators, preloading, and installation microsteps.
% 它省略编译、监控器表示、事务阶段、认证器、预加载和安装微步骤。
An ideal state is \(I=(\kappa,H,\Delta,\mathsf{out},\mathcal A,c,r)\), where \(c=(H_c,u,L^*,\widehat B^*)\).
% 理想状态为 \(I=(\kappa,H,\Delta,\mathsf{out},\mathcal A,c,r)\)，其中 \(c=(H_c,u,L^*,\widehat B^*)\)。
\(H.\eta\) and \(H.\beta\) are its current abstract epoch and live bindings.
% \(H.\eta\) 与 \(H.\beta\) 是其当前抽象纪元与活跃绑定。

\paragraph{Edit transition}
% 编辑转移
For \(\Theta_I(u)=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\), the rule \(I\xrightarrow{\mathsf{Edge}(u,[\mathcal H_u^+]_{\cong})}(\kappa_u,H_u,\Delta,\mathsf{out},\mathcal A_u,(H,u,L^*,\widehat B^*),\epsilon)\) exists exactly when \(\mathsf{Derive}(\Theta_I(u))=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\) and \(\mathsf{Spec}(\Theta_I(u))=(L^*,\widehat B^*)\).
% 对 \(\Theta_I(u)=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，当且仅当 \(\mathsf{Derive}(\Theta_I(u))=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\) 且 \(\mathsf{Spec}(\Theta_I(u))=(L^*,\widehat B^*)\) 时，规则 \(I\xrightarrow{\mathsf{Edge}(u,[\mathcal H_u^+]_{\cong})}(\kappa_u,H_u,\Delta,\mathsf{out},\mathcal A_u,(H,u,L^*,\widehat B^*),\epsilon)\) 存在。
\(H_u\) records the monitor-version change and target entries.
% \(H_u\) 记录监控器版本变更和目标入口。
\(\mathsf{Spec}\) is a declarative definition that does not invoke the executable checker or installer.
% \(\mathsf{Spec}\) 是一个不调用可执行检查器或安装器的声明式定义。
Undefined derivation yields the state-preserving \(\mathsf{Invalid}(u,[\gamma,C_{\rm str}]_{\cong})\) with a verified invalid-edit transcript.
% 未定义推导产生带有经验证无效编辑记录且保持状态的 \(\mathsf{Invalid}(u,[\gamma,C_{\rm str}]_{\cong})\)。
A derivation with no \(\mathsf{GReal}\) witness yields the state-preserving \(\mathsf{Reject}(u,[\gamma,C_{\rm fp}]_{\cong})\) with a ranked rejection certificate ending in the empty family.
% 存在推导但没有 \(\mathsf{GReal}\) 见证时，产生带有以空执行族结束的带秩拒绝证书且保持状态的 \(\mathsf{Reject}(u,[\gamma,C_{\rm fp}]_{\cong})\)。
Together with \(\mathsf{Edge}\), these current-\(\gamma(\Theta_I(u))\) verdicts are mutually exclusive and exhaustive.
% 这些绑定当前 \(\gamma(\Theta_I(u))\) 的判定与 \(\mathsf{Edge}\) 一起构成互斥且穷尽的三类结果。

\paragraph{Protected call}
% 受控调用
For submitted tool request \(m\), an enabled occurrence \(x\) in the active workflow passes the ideal guard exactly when \(H.\beta(x)=(j,H.\eta)\), its authorization token binds monitor entry \(j\) and effect identity \(d\), and \(\mathsf{canon}_\kappa(m)=\mathsf{inv}_\rho(d)\).
% 对于提交的工具请求 \(m\)，当且仅当当前工作流中已启用的发生项 \(x\) 满足 \(H.\beta(x)=(j,H.\eta)\)、其授权令牌绑定监控器入口 \(j\) 与效果标识 \(d\)，且 \(\mathsf{canon}_\kappa(m)=\mathsf{inv}_\rho(d)\) 时，它才通过理想守卫。
Current receipts then determine \(a\in\{\Fresh(x,d),\Alias(x,d)\}\).
% 随后，当前回执确定 \(a\in\{\Fresh(x,d),\Alias(x,d)\}\)。
Exactly when \(ra\in L^*\), one atomic transition applies \(\mathsf{HStep}((G,T),a)\), appends \(a\) to the global resolved-occurrence trace \(\chi\), advances \(\nu\), removes \(x\) from \(H.\beta\), and sets \(r:=ra\).
% 当且仅当 \(ra\in L^*\) 时，一个原子转移应用 \(\mathsf{HStep}((G,T),a)\)，将 \(a\) 追加到全局已解析发生项轨迹 \(\chi\)，推进 \(\nu\)，从 \(H.\beta\) 中移除 \(x\)，并设置 \(r:=ra\)。
\Fresh also appends to \(\Delta\) an immutable receipt for \(d\) labeled \(\ell(d)\) and enqueues \((d,\mathsf{canon}_\kappa(m))\).
% \Fresh 还向 \(\Delta\) 追加一条标签为 \(\ell(d)\) 且关于 \(d\) 的不可变回执，并将 \((d,\mathsf{canon}_\kappa(m))\) 入队。
\Alias changes neither field.
% \Alias 不改变这两个字段。

An invalid occurrence, gate, handle, or invocation, a disabled branch, or \(ra\notin L^*\) fails the guard and returns \(\mathsf{deny}(x)\) without changing state.
% 无效的发生项、门、句柄或调用、禁用分支或 \(ra\notin L^*\) 会使守卫失败，并返回 \(\mathsf{deny}(x)\) 且不改变状态。
\Alias binds the restored occurrence to the effect identity's durable return record.
% \Alias 将恢复的发生项绑定到该效果标识的持久返回记录。
It advances the workflow without inventing a return value that the original call has not yet produced.
% 它推进工作流，但不会虚构原始调用尚未产生的返回值。

\paragraph{Retry, release, and crash}
% 重试、释放与崩溃
\(\mathsf{Save}\) takes the trusted checkpoint transition in \cref{sec:model} as a \(\tau\)-step.
% \(\mathsf{Save}\) 将 \cref{sec:model} 中的可信检查点转移作为一个 \(\tau\) 步。
An authenticated retry of the same tool request follows its \(\chi\)-to-receipt link and emits \(\mathsf{Return}(t,[v]_{\cong})\) for the same durable return record without changing the execution record.
% 对同一工具请求的认证重试沿其从 \(\chi\) 到回执的链接，为同一持久返回记录发出 \(\mathsf{Return}(t,[v]_{\cong})\)，且不改变执行记录。
An unauthenticated lookup or a lookup with different arguments is denied.
% 未经认证的查找或参数不同的查找会被拒绝。
\Dispatch releases exactly the stored invocation in the oldest prepared outbox item and marks that item released, making the release trace a prefix of \Fresh preparation order.
% \Dispatch 恰好释放最早已准备发件箱条目中存储的调用并将该条目标记为已释放，使释放轨迹成为 \Fresh 准备次序的前缀。
Settlement emits \(\mathsf{Settle}(d,[v]_{\cong})\), advances a receipt's phase, and fills its durable return record with the stable return value.
% 结算发出 \(\mathsf{Settle}(d,[v]_{\cong})\)，推进回执阶段，并以稳定返回值填充其持久返回记录。
It changes neither the execution record nor the permission trace.
% 它既不改变执行记录，也不改变权限轨迹。
Crash discards nondurable computation without changing LTS state.
% 崩溃丢弃非持久计算而不改变 LTS 状态。
We make no claim about completion order inside an external network after release.
% 我们不对释放后外部网络内部的完成顺序作任何主张。
The ideal LTS is the least relation generated by these edit answers, protected-call success or denial, Save, retry, retrieval, delivery, \(\Dispatch\), settlement, and recovered-crash rules.
% 理想 LTS 是由这些编辑答案、受控调用成功或拒绝、Save、重试、取回、交付、\(\Dispatch\)、结算与恢复崩溃规则生成的最小关系。
No other transition, including compiler computation, exists.
% 不存在包括编译器计算在内的其他转移。

By \cref{lem:greatest-realization}, every reachable partial execution of the ideal machine retains a policy-safe completion until the next edit transition changes the workflow contract.
% 根据 \cref{lem:greatest-realization}，理想机的每段可达部分执行都会保留一条策略安全完成路径，直到下一次编辑转移改变工作流契约。
The next sections implement this machine without consulting the full completion set at every call.
% 后续章节实现该机器，而无需在每次调用时查询完整完成路径集合。
