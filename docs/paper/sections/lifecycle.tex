\section{A Running Agent History Cut}
\label{sec:lifecycle}

\subsection{Procurement with a live supplier choice}

Consider a procurement Agent that has durably reserved the budget for one
order and now explores two suppliers.  Its authenticated receipt trace is
\(\delta=r\), where \(r\) records the reservation.  The Agent asks for a
choice Fork whose protected target slice is
\[
  (a_A;p_A;s_A)\ \oplus\ (a_B;p_B;s_B).
\]
Here \(a_x\), \(p_x\), and \(s_x\) are raw handle occurrences for approval,
payment to supplier \(x\), and shipment.  Sequence means that approval
precedes payment and payment precedes shipment; tagged choice means that both
supplier outcomes remain available but one execution cannot pay both.

Copied history does not make every occurrence a fresh effect.  Authenticated
ledger anchors establish
\[
  q_{\rm cell}(a_A)=q_{\rm cell}(a_B)=a,\qquad
  q_{\rm cell}(s_A)=q_{\rm cell}(s_B)=s,
\]
whereas \(q_{\rm cell}(p_A)=p_A\) and
\(q_{\rm cell}(p_B)=p_B\) remain distinct.  Thus both arms refer to the same
order approval and shipment, but to different supplier payments.  A first
successful redemption emits its semantic cell; an alias retry resolves the
existing receipt and stutters.

Suppose the durable-authority policy permits exactly one supplier payment
after approval and permits shipment only after that payment.  At receipt
prefix \(r\), the strongest atomic monitor has normalized future
\begin{equation}
\label{eq:procurement-future}
  F_R=
  \{\epsilon,\ a,\ ap_A,\ ap_As,\ ap_B,\ ap_Bs\}.
\end{equation}
This language preserves distinctions that endpoint sets erase:
\(ap_A\) is legal while \(p_Aa\) is not, and \(ap_Ap_B\) is forbidden even
though either two-event prefix is legal.  The Fork promises two outcomes,
\(a\prec p_A\prec s\) and \(a\prec p_B\prec s\); each has a linearization in
\(F_R\).

The residual controller in \cref{fig:procurement-epoch} is scoped to this
history cut.  At \(q_1\), either payment is possible.  Once \(p_A\) commits,
the residual enables only \(s\), so a copied supplier-\(B\) gate cannot turn
exclusive exploration into two payments.  This finite automaton is classical;
the Agent-specific problem is deriving its language and installing it while
the old choice controller may still be executing.

\subsection{Selection and the frontier race}

Assume the Agent reaches \(q_1\), chooses supplier \(A\), and requests
\(\mathsf{MergeSelect}_A\) before either payment commits.  The new target slice
is \(p_A;s\); the losing supplier-\(B\) continuation must be canceled.  Merely
publishing the target automaton is unsafe because an old gate may concurrently
prepare \(p_B\).

The history cut has exactly two safe linearizations.  If the old
\(\Prepare(p_B)\) linearizes first, it appends \(p_B\) to the receipt trace,
so an installation sealed for prefix \(ra\) fails its frontier comparison
without changing controller state.  If installation linearizes first, it
closes every source controller class, mints the selected target epoch, and
binds its gate uses in one cut; the old supplier-\(B\) controller then has no
fresh-\Prepare{} transition.  Replay, retry, and settlement may still resolve
old receipts, but they emit no fresh authority event.

This race is not a supervisor-localization detail.  With a fixed plant, the
residual automaton already decides which next symbols are legal.  Here the
plant, the active controller set, and the receipt prefix change in competing
operations.  Removing the atomic source-epoch cut makes the trace theorem
false even when the target automaton is perfect: an unfenced old controller
can append \(p_B\) after the target has been published.  The installation
invariant is therefore part of history-admission semantics rather than an
adapter attestation.

The same distinction applies to all six operations formalized in
\cref{tab:edge-semantics}.  Choice Fork retains alternative outcomes, while
parallel Fork permits their order-preserving shuffle; replacing Restore
retires the current continuation, while live Restore rebinds both versions.
Select Merge names a winner and closes its loser before the post-Merge plan,
whereas join Merge places that plan causally after both inputs.  Their target
languages and source-controller cuts are therefore both security semantics,
not six labels for three endpoint-family constructors.

\subsection{The admission target}

A request contains the typed bounded slice, policy and view versions,
ledger-backed cell and source-controller anchors, and the exact receipt trace.
Normalization and the durable policy derive \(F_R\); the edge derives a finite
set of promised partial-order outcomes.  History admission must either return
one promise having no policy-legal linearization, or emit an epoch whose fresh
language is exactly \(F_R\), whose target bindings are compiler minted, and
whose installation closes the complete source set at the proved frontier.
Language equality prevents safety by deleting optional legal behavior; the
promise check prevents equality from disguising an edge that cannot deliver
its advertised outcome.  \Cref{sec:model} defines these objects and the threat
boundary; \cref{sec:results} proves the target for successive cuts.
