\paragraph{Theorem boundary}
% 定理边界
Agent systems provide versioned histories, checkpoint forks, staged effects, transactions, and recovery checks, but none derives an edit's preserved outcomes and effect identities and then returns its greatest monitor or an impossibility proof~\cite{yu2026shepherd,li2025agentgit,langchain2026timetravel,patil2024goex,chang2025sagallm,mohammadi2026atomix,chen2026cordon,yang2026dart}.
% Agent 系统提供版本化历史、检查点分叉、分阶段效果、事务和恢复检查，但没有系统会推导编辑所保留的结果与效果标识，再返回其最大监控器或不可能性证明~\cite{yu2026shepherd,li2025agentgit,langchain2026timetravel,patil2024goex,chang2025sagallm,mohammadi2026atomix,chen2026cordon,yang2026dart}。
Synthesis and enforcement assume supplied plants, histories, or policies, while rollback, fencing, and outboxes implement rather than decide an admitted edit; \cref{thm:exact-history} derives the missing instance and proves its exact epoch-mediated realization~\cite{malik2008generalised,finkbeiner2022live,abadi2003history,palumbo2026forge,elnozahy2002rollback,zheng2026acrfence,santos2026committime,aws2026outbox}.
% 综合与执行机制假定已有被控对象、历史或策略，而回滚、隔离和发件箱只实现而不决定已接纳编辑；\cref{thm:exact-history} 推导缺失的实例，并证明其可由纪元中介机制精确实现~\cite{malik2008generalised,finkbeiner2022live,abadi2003history,palumbo2026forge,elnozahy2002rollback,zheng2026acrfence,santos2026committime,aws2026outbox}。
