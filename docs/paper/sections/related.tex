\section{Related Work}
% 相关工作
\label{sec:related}

\paragraph{History-sensitive authorization}
% 历史敏感授权
History-based authorization, event-structure monitoring, FORGE, and suppression synthesis judge or constrain the next action from an existing history~\cite{abadi2003history,krukow2008history,palumbo2026forge,aceto2018suppressions}.
% 基于历史的授权、事件结构监控、FORGE 和抑制综合根据既有历史判断或约束下一动作~\cite{abadi2003history,krukow2008history,palumbo2026forge,aceto2018suppressions}。
We instead judge a topology-changing edit and preserve a safe completion for every compatible outcome after every admitted prefix, including receipt-silent \Alias.
% 我们则判定改变拓扑的编辑，并在每个已准入前缀之后为每个兼容结果保留一条安全完成路径，其中包括不产生回执的 \Alias。

\paragraph{Reversal and update}
% 逆转与更新
Reversible sessions, workflow inheritance, dynamic update, and REBOUND preserve or authorize supplied rollback or update structures~\cite{dezani2016checkpoints,mezzina2025checkpoint,vanderaalst2002inheritance,nahabedian2020dynamic,amram2022dynamic,bresolin2021static,burke2026rebound}.
% 可逆会话、工作流继承、动态更新和 REBOUND 保持或授权给定的回滚或更新结构~\cite{dezani2016checkpoints,mezzina2025checkpoint,vanderaalst2002inheritance,nahabedian2020dynamic,amram2022dynamic,bresolin2021static,burke2026rebound}。
Our theory instead derives outcomes that cannot be discarded and occurrence-to-cell effect identity from authenticated Agent history, then proves that erasure can reverse the correct decision.
% 我们的理论则从经认证的 Agent 历史中推导不可丢弃的结果与发生项到单元的效果标识，随后证明擦除这些信息可能反转正确判定。

\paragraph{Automata and causality}
% 自动机与因果性
Security automata, supervisory control, and generalized nonblocking enforce prefix properties or synthesize legal marked behavior~\cite{schneider2000enforceable,ramadge1987supervisory,dequeiroz2005multitasking,malik2008generalised}.
% 安全自动机、监督控制和广义非阻塞强制执行前缀性质，或综合合法的标记行为~\cite{schneider2000enforceable,ramadge1987supervisory,dequeiroz2005multitasking,malik2008generalised}。
Given markings, \cref{prop:outcome-necessary} reduces synthesis to generalized nonblocking; \cref{thm:exact-history} derives them and proves that target-only state and epoch fences cannot recover source obligations or occurrence-to-cell effect identity.
% 给定标记后，\cref{prop:outcome-necessary} 将综合归约到广义非阻塞；\cref{thm:exact-history} 推导这些标记，并证明仅含目标的状态和纪元隔离无法恢复源义务或发生项到单元的效果标识。
Derivatives and pomsets provide the recognizer and causal representation~\cite{brzozowski1964derivatives,winskel1987event,vanglabbeek2009configuration}.
% 导数和偏序事件集提供识别器与因果表示~\cite{brzozowski1964derivatives,winskel1987event,vanglabbeek2009configuration}。

\paragraph{Durable effects}
% 持久效果
Rollback security, checkpoint trees, and ACRFence address restored state or authority~\cite{elnozahy2002rollback,parno2011memoir,matetic2017rote,brandenburger2017lcm,garfinkel2005virtual,zheng2026acrfence}.
% 回滚安全、检查点树和 ACRFence 处理被恢复的状态或权限~\cite{elnozahy2002rollback,parno2011memoir,matetic2017rote,brandenburger2017lcm,garfinkel2005virtual,zheng2026acrfence}。
Consumable credentials, commit checks, fencing, outboxes, and idempotency protect individual effects~\cite{bowers2007consumable,santos2026committime,santos2026lingering,aws2026outbox,aws2026idempotency}; we characterize whole edits and order receipts and \Alias progress before monitor activation.
% 可消费凭据、提交检查、隔离、发件箱和幂等性保护单个效果~\cite{bowers2007consumable,santos2026committime,santos2026lingering,aws2026outbox,aws2026idempotency}；我们则刻画完整编辑，并在监控器激活之前确定回执与 \Alias 进展的顺序。
