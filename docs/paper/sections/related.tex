\section{Related Work}
% 相关工作
\label{sec:related}

\paragraph{Recovery, workflow update, and synthesis}
% 恢复、工作流更新与综合
Output-commit recovery reconstructs a fixed computation, while generalized nonblocking and Live Synthesis start from supplied transition systems, completion conditions, or prior specifications~\cite{strom1985optimistic,elnozahy2002rollback,dequeiroz2005multitasking,malik2008generalised,finkbeiner2022live}.
% 输出提交恢复重建一个固定计算，而广义非阻塞与 Live Synthesis 从给定的转移系统、完成条件或先前规范出发~\cite{strom1985optimistic,elnozahy2002rollback,dequeiroz2005multitasking,malik2008generalised,finkbeiner2022live}。
Workflow inheritance checks whether a running case can move between supplied workflow models, while dynamic controller update synthesizes a bridge between supplied old and new specifications~\cite{vanderaalst2002inheritance,nahabedian2020dynamic,amram2022dynamic}.
% 工作流继承检查运行中实例能否在给定的工作流模型之间迁移，而动态控制器更新则在给定的新旧规范之间综合桥接控制器~\cite{vanderaalst2002inheritance,nahabedian2020dynamic,amram2022dynamic}。
A structurally valid migration does not by itself answer our Restore question: whether the old and copied approval occurrences share one already-receipted protected effect, or how that alias is ordered against monitor replacement.
% 仅有结构上有效的迁移并不能回答我们的 Restore 问题：原审批与复制出的审批发生项是否共享同一个已有回执的受控效果，以及这一别名如何与监控器替换排序。
Our controller derives that alias, the edited workflow, still-required outcomes, and controllers that must be replaced from the authenticated Agent record, then installs the resulting exact monitor against fresh and alias races.
% 我们的控制器从经认证的 Agent 记录中推导这一别名关系、编辑后的工作流、仍要求实现的结果以及必须替换的控制器，继而针对新授权与别名竞态安装所得精确监控器。

\paragraph{Agent recovery mechanisms}
% Agent 恢复机制
ACRFence blocks replay after Restore, DART selects checkpoints, Atomix delays settlement, and Rebound makes rollback atomic and auditable~\cite{zheng2026acrfence,yang2026dart,mohammadi2026atomix,burke2026rebound}.
% ACRFence 阻止 Restore 后重放，DART 选择检查点，Atomix 延迟结算，而 Rebound 使回滚具有原子性与可审计性~\cite{zheng2026acrfence,yang2026dart,mohammadi2026atomix,burke2026rebound}。
They address replay, checkpoint choice, staged effects, or atomic rollback rather than the exact safe realization of all six derived Agent edits.
% 它们处理重放、检查点选择、分阶段效果或原子回滚，而不是全部六种由系统推导的 Agent 编辑的精确安全实现。
