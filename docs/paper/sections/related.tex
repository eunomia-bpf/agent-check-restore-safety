\section{Related Work}
% 相关工作
\label{sec:related}

\paragraph{Recovery, workflow update, and synthesis}
% 恢复、工作流更新与综合
Output-commit recovery reconstructs a fixed computation.
% 输出提交恢复重建固定计算。
Generalized nonblocking and Live Synthesis solve supplied transition systems and completion conditions, while workflow inheritance and dynamic controller update connect supplied old and new specifications~\cite{strom1985optimistic,elnozahy2002rollback,dequeiroz2005multitasking,malik2008generalised,finkbeiner2022live,vanderaalst2002inheritance,nahabedian2020dynamic,amram2022dynamic}.
% 广义非阻塞与 Live Synthesis 求解给定的转移系统及完成条件，而工作流继承与动态控制器更新连接给定的新旧规范~\cite{strom1985optimistic,elnozahy2002rollback,dequeiroz2005multitasking,malik2008generalised,finkbeiner2022live,vanderaalst2002inheritance,nahabedian2020dynamic,amram2022dynamic}。
Our runtime derives the edited workflow, action reuse, still-required results, completion conditions, and new runtime rules directly from the execution record.
% 我们的运行时直接从执行记录推导编辑后的工作流、动作复用、仍要求实现的结果、完成条件与新运行时规则。
It computes the largest safe execution set and puts the corresponding rules into effect atomically with new authorization or authorization reuse.
% 它计算最大安全执行集合，并使相应规则与新授权或授权复用原子生效。

\paragraph{Agent recovery mechanisms}
% Agent 恢复机制
ACRFence blocks replay after Restore, DART selects checkpoints, Atomix delays external actions until commit, and Rebound makes rollback atomic and auditable~\cite{zheng2026acrfence,yang2026dart,mohammadi2026atomix,burke2026rebound}.
% ACRFence 阻止 Restore 后重放，DART 选择检查点，Atomix 把外部动作推迟到提交时执行，而 Rebound 使回滚具有原子性与可审计性~\cite{zheng2026acrfence,yang2026dart,mohammadi2026atomix,burke2026rebound}。
Our formal results give exact criteria for Checkpoint and all six forms of Fork, Restore, and Merge, a rejection proof, and a lower bound showing that omitting any one record part wholesale can change the correct answer.
% 我们的形式结果为 Checkpoint 以及 Fork、Restore 和 Merge 的全部六种形式给出精确判据与拒绝证明；信息下界还表明，完整省略任何一个记录部分都可能改变正确答案。
These guarantees continue through the atomic rule update and arbitrary finite execution.
% 这些保证在原子规则更新与任意有限执行中继续成立。
