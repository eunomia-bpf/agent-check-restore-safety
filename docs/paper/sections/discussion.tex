\section{Scope and Limitations}
\label{sec:discussion}

\paragraph{Contracts and progress}
Contracts cover finite registered slices.  An unregistered protected call fails
closed until another admission.  Prefix-free complete traces distinguish
stopping from continuing.  Completion nonblocking preserves a safe completion
for each contract-compatible outcome, but guarantees neither fairness, task completion,
nor later admission.  Policy covers authority commitments, not prompt
integrity, confidentiality, action quality, or Agent alignment.

\paragraph{Deployment}
The theorem assumes complete mediation and linearizable, crash-stable
transactions.  Remote exactly-once execution still requires idempotency,
queryable outcomes, or a transactional sink.  A policy-version change requires
re-admission.  Each disjoint domain has one policy-domain epoch and state machine,
possibly replicated behind a fault-tolerant store.  Deployment must protect registries and lineage, mediate every
protected effect, and minimize provenance.  The artifact neither integrates
with Agent runtimes nor causes external effects or human-subject risk, and it
does not prove the theorem.  Decentralized controllers and symbolic reduction
remain future work.

\section{Conclusion}

An Agent may rewrite its logical history but not committed world facts.  The
Exact Agent History Realization Theorem decides whether a registered edit has
a prefix-robust implementation, then constructs its greatest canonical monitor
or certifies impossibility.  The Agent only requests Fork, Restore, or Merge.
The trusted installation checker decides, and the durable kernel atomically installs
the result across \Fresh/\Alias and cut races.  History editing is authority
editing with exact admission.
