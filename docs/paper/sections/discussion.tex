\section{Scope and Limitations}
% 范围与局限
\label{sec:discussion}

\paragraph{Contracts and progress}
% 契约与进展
Each admission covers a finite registered protected-call slice; \cref{thm:exact-history} keeps its security state closed after every finite prefix of arbitrarily long sequences, while unregistered calls fail closed.
% 每次准入覆盖一个有限的已注册受保护调用切片；\cref{thm:exact-history} 使其安全状态在任意长序列的每个有限前缀之后保持闭合，而未注册调用以关闭方式失败。
Prefix-free complete traces distinguish stopping from continuing.
% 无前缀关系的完整轨迹区分停止与继续。
Completion nonblocking preserves one safe completion per compatible outcome but guarantees neither fairness, task completion, nor later admission.
% 完成非阻塞性为每个兼容结果保留一条安全完成路径，但不保证公平性、任务完成或后续准入。
Policy governs authority, not prompt integrity, confidentiality, action quality, or alignment.
% 策略治理权限，而不治理提示完整性、机密性、动作质量或对齐。

\paragraph{Deployment}
% 部署
Deployment assumes complete mediation, crash-stable linearizable transactions, and one epoch per disjoint domain.
% 部署假设完全中介、崩溃稳定的可线性化事务，以及每个互不相交的域拥有一个纪元。
Remote exactly-once needs an idempotent or queryable sink; policy changes require re-admission.
% 远程恰好一次执行需要幂等或可查询的接收端；策略变更需要重新准入。
The artifact omits Agent-runtime integration, external effects, and full mechanization.
% 该制品不包含 Agent 运行时集成、外部效果和完整机械化。
