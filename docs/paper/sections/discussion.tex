\section{Scope and Limitations}
\label{sec:discussion}

\paragraph{Contracts and progress}
A contract covers one finite registered slice of protected calls; Agent
reasoning and unprotected computation remain open ended.  An unregistered
protected call fails closed and requires another admission.  Complete raw
traces must be prefix-free, so stopping versus continuing requires an explicit
logical occurrence.  Completion nonblocking preserves a safe completion for
every still-compatible outcome, but implies neither fairness, useful task
completion, nor admission of a later edit.  The policy governs authority
commitments, not prompt integrity, branch confidentiality, action quality, or
Agent alignment.

\paragraph{Durability and distribution}
The theorem assumes complete mediation and linearizable, crash-stable
occurrence and installation transactions.  Remote physical exactly-once
execution still requires idempotency, queryable outcomes, or a transactional
sink.  Changing policy version \(\kappa\) invalidates seals and requires
re-admission.  Each disjoint policy domain has one logical epoch and state
machine, possibly replicated behind a fault-tolerant store; decentralized
branch controllers are future work.  Enumeration can be exponential, inviting
symbolic pomsets and partial-order reduction.

\paragraph{Deployment}
The bounded artifact is not an integration claiming that current Agent
histories are trustworthy.  Deployment must protect registries, authenticate
tool contracts and cell lineage, mediate every protected effect, and minimize
sensitive provenance.  Our synthetic validation causes no external effects or
human-subject risk.

\section{Conclusion}

An Agent may rewrite its logical past but not facts committed to the world.
Agent history admission makes this mismatch precise.  Within our finite
registered model, the Exact Agent History Realization Theorem characterizes
when a schema-derived edit has a prefix-robust implementation, constructs its
greatest durable monitor, and certifies impossibility otherwise.  It covers
arbitrary Fork, Restore, Merge, fresh/alias, and cut races.  History editing is
authority editing---and can be admitted exactly.
