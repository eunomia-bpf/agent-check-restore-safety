\section{Scope and Limitations}
% 范围与局限
\label{sec:discussion}

Each admission covers one finite registered slice, remains closed after every finite prefix, and rejects unregistered calls.
% 每次准入覆盖一个有限的已注册切片，在每个有限前缀后保持闭合，并拒绝未注册调用。
Completion nonblocking preserves a safe completion per compatible outcome but guarantees neither fairness, task completion, later admission, prompt integrity, confidentiality, action quality, nor alignment.
% 完成非阻塞性为每个兼容结果保留一条安全完成路径，但不保证公平性、任务完成、后续准入、提示完整性、机密性、动作质量或对齐。

Deployment requires complete mediation, crash-stable linearizable domain transactions, and one active epoch per policy domain; policy changes require re-admission, and remote exactly-once needs an idempotent/queryable sink.
% 部署要求完全中介、崩溃稳定的可线性化域事务，以及每个策略域只有一个活跃纪元；策略变更需要重新准入，而远程恰好一次执行需要幂等或可查询的接收端。
The artifact omits runtime integration, external effects, and full mechanization; it uses only synthetic local histories, so no participants or user data are involved.
% 本制品不包含运行时集成、外部效果和完整机械化；它只使用本地合成历史，因此不涉及参与者或用户数据。

Agent History Admission yields each edit's greatest safe monitor or an impossibility proof.
% Agent 历史准入为每次编辑给出其最大安全监控器或不可能性证明。
