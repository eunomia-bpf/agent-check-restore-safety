\section{Introduction}
% 引言
\label{sec:introduction}

A tool-using Agent can Fork live continuations, Restore a checkpoint, and Merge descendants~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}.
% 使用工具的 Agent 可以 Fork 活跃延续、Restore 检查点，并 Merge 后代~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}。
The world does not rewind: a pre-Restore payment remains charged, copied occurrences may share one-use authority, and an old call may race a Merge.
% 现实世界不会倒转：Restore 前的付款仍已扣款，复制的发生项可能共享一次性权限，而旧调用可能与 Merge 发生竞态。
History editing changes \emph{which past continuations can still produce a future} while commitments remain irreversible.
% 历史编辑会改变\emph{哪些过去的延续仍能产生未来}，而既有承诺仍不可逆。

This paper asks the following question.
% 本文提出以下问题。
\begin{quote}
\emph{When does an Agent history rewrite have a policy-safe, history-faithful, completion-nonblocking realization preserving every structurally promised outcome, and how can a reference monitor realize exactly that boundary while effects race the rewrite?}
% Agent 历史重写何时具有一种策略安全、历史忠实且完成非阻塞的实现，能够保留每个结构性承诺的结果；当效应与重写发生竞态时，参考监控器又如何精确实现这一边界？
\end{quote}

Endpoint safety is insufficient.
% 仅保证端点安全并不充分。
Two outcomes may each have a safe completion, yet after a shared causal prefix one can remain structurally possible with no safe continuation.
% 两个结果可能各自都有安全的完成路径，但在共享一个因果前缀后，其中一个结果可能在结构上仍然可行，却不存在安全的后续路径。
Admitting that prefix silently retracts an Agent promise.
% 接纳该前缀会悄然撤回 Agent 的一项承诺。
The failure cascades when removing that completion destroys coverage at an earlier prefix, so testing each outcome independently is unsound.
% 当移除该完成路径会破坏更早前缀处的覆盖性时，失败便会级联，因此独立测试每个结果并不可靠。

Prior theories control neighboring boundaries: history monitors judge a next action~\cite{abadi2003history,krukow2008history,palumbo2026forge}, commit-time authorization judges one effect~\cite{santos2026committime}, and reversible sessions or dynamic update preserve given specifications ~\cite{dezani2016checkpoints,mezzina2025checkpoint,nahabedian2020dynamic, amram2022dynamic}.
% 既有理论控制相邻的边界：历史监控器判断下一个动作~\cite{abadi2003history,krukow2008history,palumbo2026forge}，提交时授权判断单个效应~\cite{santos2026committime}，而可逆会话或动态更新则保持给定规约~\cite{dezani2016checkpoints,mezzina2025checkpoint,nahabedian2020dynamic, amram2022dynamic}。
Agent history admission judges the edit itself: it derives future obligations, preserves them after every admitted prefix, and respects irreversible receipts.
% Agent 历史准入判断编辑本身：它推导未来义务，在每个已准入前缀之后保持这些义务，并尊重不可逆的回执。

Our key observation is that safe Agent history editing is one greatest-fixed-point problem over \emph{outcome-indexed causal completions}.
% 我们的关键观察是，安全的 Agent 历史编辑归结为\emph{按结果索引的因果完成路径}上的一个最大不动点问题。
From the policy-safe resolved completions \(\widehat B_0\), an operator removes any completion having a prefix without a surviving continuation for even one contract-compatible outcome.
% 从策略安全的已解析完成路径 \(\widehat B_0\) 出发，算子会移除任何包含这样一个前缀的完成路径：哪怕仅对一个与契约兼容的结果，该前缀都没有仍然存活的后续路径。
\[
 \widehat B^\dagger=\nu\widehat B.\widehat\Phi(\widehat B),
 \qquad B^\dagger=\pi_2\widehat B^\dagger,\qquad
 W^\dagger=\Pref(B^\dagger).
\]
The edit is admissible exactly when \(\widehat B^\dagger\neq\varnothing\).
% 当且仅当 \(\widehat B^\dagger\neq\varnothing\) 时，该编辑才可接纳。
Its permitted behavior is \(W^\dagger\).
% 其允许的行为是 \(W^\dagger\)。
This recursive closure turns policy safety into a persistent Agent-history promise.
% 这一递归闭包将策略安全转化为持久的 Agent 历史承诺。
It also identifies information that ordinary trace-only nonblocking loses: the same projected safe language may be marker-nonblocking even though one contract-compatible outcome has been stranded (\cref{prop:outcome-necessary}).
% 它还揭示了普通的纯轨迹非阻塞性会丢失的信息：即使一个与契约兼容的结果已陷入无路可走的状态，同一个投影后的安全语言仍可能是标记非阻塞的（\cref{prop:outcome-necessary}）。

The Agent names only live objects and an immutable schema.
% Agent 仅指名活对象和不可变模式。
A trusted judgment derives the target and preserves outcomes, occurrences, cells, lineage, and causal order except under schema-authorized retirement.
% 可信判断推导目标，并保持结果、发生项、单元、谱系和因果顺序，除非模式授权将其退役。
Resolution records \Fresh commitments and receipt-silent \Alias occurrences.
% 解析过程记录 \Fresh 承诺以及不产生回执的 \Alias 发生项。
Each cut replaces the whole policy domain's epoch, ordering old uses and target activation.
% 每个切点都会替换整个策略域的纪元，并为旧使用与目标激活规定顺序。

\paragraph{Theory as a security compiler}
% 作为安全编译器的理论
The \emph{Exact Agent History Realization Theorem} equates admission, realization existence, and exact compilation.
% \emph{精确 Agent 历史实现定理}证明准入、实现的存在性与精确编译三者等价。
It yields the greatest realization or a finite impossibility certificate.
% 它给出最大实现，或给出有限的不可能性证书。
Platform developers register policy and schemas describing what an edit carries, clones, or retires.
% 平台开发者注册策略和模式，用以描述一次编辑会携带、克隆或退役哪些内容。
The Agent submits only \(u\).
% Agent 仅提交 \(u\)。
The installation checker re-derives the schema judgment and fixed point.
% 安装检查器重新推导模式判定和不动点。
On acceptance, the kernel atomically installs \(\mathsf{Can}(W^\dagger,B^\dagger)\), minted gates, and authenticated replacement handles under one new epoch.
% 接纳后，内核在一个新纪元下原子地安装 \(\mathsf{Can}(W^\dagger,B^\dagger)\)、新铸造的门和经过认证的替换句柄。
The monitor then authenticates the occurrence, gate, handle, cell, and epoch of every protected call and permits only current-program transitions.
% 随后，监控器认证每个受保护调用的发生项、门、句柄、单元和纪元，并且只允许当前程序的转换。
A valid \Retry only returns its stable result.
% 有效的 \Retry 只返回其稳定结果。
The Agent cannot discard obligations outside schema-authorized retirement or bypass admission.
% Agent 无法丢弃模式授权退役范围之外的义务，也无法绕过准入。

We prove weak bisimulation with an independent ideal Agent-history labeled transition system (LTS) across arbitrary edit sequences, protected uses, retries, dispatch, crashes, and \Fresh/\Alias/install races.
% 我们证明了该系统与一个独立的理想 Agent 历史标号转换系统（LTS）之间的弱互模拟，涵盖任意编辑序列、受保护使用、重试、派发、崩溃以及 \Fresh/\Alias/安装竞态。
A bounded artifact validator exercises the decision kernel and race fixtures.
% 一个有界制品验证器会运行判定内核和竞态测试实例。

\paragraph{Contribution}
% 贡献
We contribute a unified Agent History-Admission Theory centered on one Exact Realization Theorem, which provides three inseparable deliverables: (1) trusted semantics for all six edits, (2) an exact criterion that constructs the greatest prefix-robust behavior or certifies impossibility, and (3) a security compiler weakly bisimilar to the ideal Agent-history machine across successive edits and races (\cref{sec:model,sec:admission,sec:kernel,sec:results}).
% 我们提出以一个精确实现定理为核心的统一 Agent 历史准入理论，它提供三项不可分割的成果：(1) 六种编辑的可信语义；(2) 构造最大前缀鲁棒行为或证明不可能性的精确判据；以及 (3) 一个安全编译器，它在连续编辑和竞态下与理想 Agent 历史机弱互模拟（\cref{sec:model,sec:admission,sec:kernel,sec:results}）。
The bounded artifact validator exercises the decision kernel and selected race fixtures (\cref{sec:validation}).
% 有界制品验证器会运行判定内核和选定的竞态测试实例（\cref{sec:validation}）。
