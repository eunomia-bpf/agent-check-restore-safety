\section{Introduction}
\label{sec:introduction}

A tool-using Agent can Fork live continuations, Restore a checkpoint, and
Merge descendants~\cite{codexappserver,claudesessions,claudecheckpoint,
wang2026fork,wu2026crab,zhang2026agentlibos}.  The world does not rewind: a
pre-Restore payment remains charged, copied occurrences may share one-use
authority, and an old call may race a Merge.  History editing changes
\emph{which past continuations can still produce a future} while commitments
remain irreversible.

This paper asks the following question.
\begin{quote}
\emph{When does an Agent history rewrite have a policy-safe,
history-faithful, completion-nonblocking realization preserving every
structurally promised outcome, and how can a reference monitor realize exactly
that boundary while effects race the rewrite?}
\end{quote}

Endpoint safety is insufficient.  Two outcomes may each have a safe
completion, yet after a shared causal prefix one can remain structurally
possible with no safe continuation.  Admitting that prefix silently retracts
an Agent promise.  The failure cascades when removing that completion destroys
coverage at an earlier prefix, so testing each outcome independently is
unsound.

Prior theories control neighboring boundaries: history monitors judge a next
action~\cite{abadi2003history,krukow2008history,palumbo2026forge}, commit-time
authorization judges one effect~\cite{santos2026committime}, and reversible
sessions or dynamic update preserve given specifications
~\cite{dezani2016checkpoints,mezzina2025checkpoint,nahabedian2020dynamic,
amram2022dynamic}.  Agent history admission judges the edit itself: it derives
future obligations, preserves them after every admitted prefix, and respects
irreversible receipts.

Our key observation is that safe Agent history editing is one
greatest-fixed-point problem over \emph{outcome-indexed causal completions}.
From the policy-safe resolved completions \(\widehat B_0\), an operator removes
any completion having a prefix without a surviving continuation for even one
contract-compatible outcome.
\[
 \widehat B^\dagger=\nu\widehat B.\widehat\Phi(\widehat B),
 \qquad B^\dagger=\pi_2\widehat B^\dagger,\qquad
 W^\dagger=\Pref(B^\dagger).
\]
The edit is admissible exactly when \(\widehat B^\dagger\neq\varnothing\).
Its permitted behavior is \(W^\dagger\).  This recursive closure turns policy safety
into a persistent Agent-history promise.  It also identifies information that
ordinary trace-only nonblocking loses: the same projected safe language may be
marker-nonblocking even though one contract-compatible outcome has been stranded
(\cref{prop:outcome-necessary}).

The Agent names only live objects and an immutable schema.  A trusted judgment
derives the target and preserves outcomes, occurrences, cells, lineage, and
causal order except under schema-authorized retirement.  Resolution records
\Fresh commitments and receipt-silent \Alias occurrences.  Each cut replaces
the whole policy domain's epoch, ordering old uses and target activation.

\paragraph{Theory as a security compiler}
The \emph{Exact Agent History Realization Theorem} equates admission,
realization existence, and exact compilation.  It yields the greatest
realization or a finite impossibility certificate.  Platform developers
register policy and schemas describing what an edit carries, clones, or
retires.  The Agent submits only \(u\).  The installation checker re-derives
the schema judgment and fixed point.  On acceptance, the kernel atomically
installs \(\mathsf{Can}(W^\dagger,B^\dagger)\), minted gates, and authenticated
replacement handles under one new epoch.  The monitor then authenticates the
occurrence, gate, handle, cell, and epoch of every protected call and permits
only current-program transitions.  A valid \Retry only returns its stable
result.  The Agent cannot discard obligations outside schema-authorized
retirement or bypass admission.

We prove weak bisimulation with an independent ideal Agent-history labeled
transition system (LTS) across arbitrary edit sequences, protected uses,
retries, dispatch, crashes, and \Fresh/\Alias/install races.  A bounded
artifact validator exercises the decision kernel and race fixtures.

\paragraph{Contribution}
We contribute a unified Agent History-Admission Theory centered on one Exact
Realization Theorem, which provides three inseparable deliverables:
(1) trusted semantics for all six edits, (2) an exact criterion that constructs
the greatest prefix-robust behavior or certifies impossibility, and (3) a security
compiler weakly bisimilar to the ideal Agent-history machine across successive edits and races
(\cref{sec:model,sec:admission,sec:kernel,sec:results}).  The bounded artifact
validator exercises the decision kernel and selected race fixtures
(\cref{sec:validation}).
