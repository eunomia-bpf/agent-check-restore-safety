\section{Introduction}
% 引言
\label{sec:introduction}

A tool-using Agent can Fork live continuations, Restore a checkpoint, and Merge descendants~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}.
% 使用工具的 Agent 可以 Fork 活跃延续、Restore 检查点，并 Merge 后代~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}。
The world does not rewind.
% 现实世界不会倒转。
A pre-Restore payment remains charged, copied occurrences may share one-use authority, and an old call may race a Merge.
% Restore 前的付款仍已扣款，复制的发生项可能共享一次性权限，而旧调用可能与 Merge 发生竞态。
History editing changes \emph{which past continuations can still produce a future} while commitments remain irreversible.
% 历史编辑会改变\emph{哪些过去的延续仍能产生未来}，而既有承诺仍不可逆。

This paper asks the following question.
% 本文提出以下问题。
\begin{quote}
\emph{When does an Agent history rewrite have a policy-safe, history-faithful, completion-nonblocking realization preserving every structurally promised outcome, and how can a reference monitor realize exactly that boundary while effects race the rewrite?}
% Agent 历史重写何时具有一种策略安全、历史忠实且完成非阻塞的实现，能够保留每个结构性承诺的结果；当效应与重写发生竞态时，参考监控器又如何精确实现这一边界？
\end{quote}

\paragraph{One Restore, end to end}
% 一次 Restore 的端到端过程
In our running procurement history, the Agent saves checkpoint \(k\) before approval, the approval later commits, and the Agent eventually submits only \(u=\mathsf{RestoreLive}(b,k,\sigma)\).
% 在贯穿全文的采购历史中，Agent 在审批前保存检查点 \(k\)，该审批随后提交，而 Agent 最终仅提交 \(u=\mathsf{RestoreLive}(b,k,\sigma)\)。
Before execution, \(\mathsf{CheckReg}(\mathcal W,R)\) checks the typed procurement effect boundary against the finite registered slice \(R\) and establishes \(\mathcal W\sqsubseteq_\lambda R\) for the registered lowering \(\lambda\).
% 执行之前，\(\mathsf{CheckReg}(\mathcal W,R)\) 根据有限注册切片 \(R\) 检查类型化采购效果边界，并为已注册降低映射 \(\lambda\) 建立 \(\mathcal W\sqsubseteq_\lambda R\)。
Registration derives cells from canonical invocations, and the checker rejects a missing promised outcome, an unmediated durable edge, or an inconsistent receipt binding.
% 注册过程从规范调用推导单元，而检查器会拒绝遗漏承诺结果、未受中介的持久边或不一致的回执绑定。
At Restore, the trusted controller snapshots \((\kappa,H,\Delta,\mathsf{out},\mathcal A)\), re-derives every schema-preserved outcome and occurrence--cell identity, and computes the greatest prefix-robust fixed point.
% 在 Restore 时，可信控制器快照 \((\kappa,H,\Delta,\mathsf{out},\mathcal A)\)，重新推导模式所保留的每个结果及发生项--单元标识关系，并计算前缀鲁棒最大不动点。
Its uncapped semantic result is either \(\mathsf{Install}(\mathsf{Can}(W^\dagger,B^\dagger),\eta^+)\) or \(\mathsf{Reject}(\mathit{certificate})\).
% 它的无上限语义结果要么是 \(\mathsf{Install}(\mathsf{Can}(W^\dagger,B^\dagger),\eta^+)\)，要么是 \(\mathsf{Reject}(\mathit{certificate})\)。
After installation, every protected call is classified as \Fresh, \Alias, or denied, and the restored approval becomes a receipt-reusing \Alias rather than a second local outbox preparation.
% 安装之后，每个受保护调用都被分类为 \Fresh、\Alias 或拒绝，而恢复后的审批成为复用回执的 \Alias，而非第二次本地发件箱准备。
A verified empty fixed point rejects the Restore with a ranked elimination certificate, and the Agent can neither weaken the derived target nor bypass the installed monitor.
% 经验证的空不动点会以带秩淘汰证书拒绝 Restore，且 Agent 既不能弱化派生目标，也不能绕过已安装监控器。
\Cref{sec:lifecycle} carries this exact history through Fork, Merge, both cut races, and the later Restore.
% \Cref{sec:lifecycle} 沿用这段完全相同的历史，依次展开 Fork、Merge、两类切点竞态和随后的 Restore。

Closest Agent systems provide branching, versioned histories, staged effects, transactions, or recovery checks, but none characterizes exactly which topology-changing edits preserve every promised outcome or constructs the greatest enforcing monitor~\cite{yu2026shepherd,li2025agentgit,langchain2026timetravel,patil2024goex,chang2025sagallm,mohammadi2026atomix,chen2026cordon,yang2026dart}.
% 最接近的 Agent 系统提供分支、版本化历史、分阶段效果、事务或恢复检查，但没有系统精确刻画哪些改变拓扑的编辑会保留每个已承诺结果，也没有构造最大的执行监控器~\cite{yu2026shepherd,li2025agentgit,langchain2026timetravel,patil2024goex,chang2025sagallm,mohammadi2026atomix,chen2026cordon,yang2026dart}。
Generalized nonblocking and multitasking control synthesize maximal behavior once the plant and conditional task markings are supplied.
% 广义非阻塞与多任务控制在被控对象和条件任务标记给定后综合最大行为。
Live synthesis derives unfinished obligations from a supplied old specification and execution, while suppression enforcement synthesizes correct monitors from a supplied formula~\cite{dequeiroz2005multitasking,malik2008generalised,finkbeiner2022live,aceto2018suppressions}.
% 在线综合从给定的旧规范和执行中推导未完成义务，而抑制式执行从给定公式综合正确监控器~\cite{dequeiroz2005multitasking,malik2008generalised,finkbeiner2022live,aceto2018suppressions}。
Our theorem begins at the checked typed Agent workflow and ends at the installed history edge: authenticated history determines outcomes, occurrence--cell/receipt state, and the exact cut consumed by synthesis, and an epoch transaction realizes the answer.
% 我们的定理始于经检查的类型化 Agent 工作流，止于已安装的历史边：经认证历史决定综合所需的结果、发生项--单元/回执状态与精确切点，而纪元事务实现该判定。
For every projection omitting one of the four semantic factors, two finite registered histories have the same retained view but require opposite admission or installation decisions.
% 对于每个遗漏四个语义因子之一的投影，都存在两条有限注册历史具有相同的保留视图，却要求相反的准入或安装判定。
The same holds for either incidence erasure proved in the appendix.
% 附录证明的两种关联擦除也具有同样性质。
The full state remains closed across successive edits, protected calls, and authenticated live schema/policy extensions rather than characterizing only one rewrite.
% 完整状态在连续编辑、受保护调用以及经认证的在线模式/策略扩展之间保持闭合，而非只刻画一次重写。

Once the trusted semantics has derived this Agent-specific state, conditional generalized nonblocking supplies the synthesis backend~\cite{malik2008generalised}.
% 可信语义推导出这一 Agent 特有状态之后，条件广义非阻塞提供综合后端~\cite{malik2008generalised}。
From the policy-safe resolved completions \(\widehat B_0\), the pruning operator \(\widehat\Phi\) removes any completion having a prefix without a surviving continuation for even one contract-compatible outcome.
% 从策略安全的已解析完成路径 \(\widehat B_0\) 出发，裁剪算子 \(\widehat\Phi\) 会移除任何包含如下前缀的完成路径：哪怕仅对一个与契约兼容的结果，该前缀都没有仍然存活的后续路径。
\[
 \widehat B^\dagger=\nu\widehat B.\widehat\Phi(\widehat B),
 \qquad B^\dagger=\pi_2\widehat B^\dagger,\qquad
 W^\dagger=\Pref(B^\dagger).
\]
The edit is admissible exactly when \(\widehat B^\dagger\neq\varnothing\).
% 当且仅当 \(\widehat B^\dagger\neq\varnothing\) 时，该编辑才可接纳。
When nonempty, it yields the greatest permitted behavior \(W^\dagger\), and when empty, its ranked elimination chain proves impossibility.
% 当该不动点非空时，它给出最大的允许行为 \(W^\dagger\)，而当其为空时，带秩的淘汰链证明不可能性。
Ordinary marker nonblocking over traces alone loses both outcome compatibility and occurrence--cell identity (\cref{prop:outcome-necessary,thm:exact-history}).
% 普通的纯轨迹标记非阻塞会丢失结果兼容性和发生项--单元标识这两类信息（\cref{prop:outcome-necessary,thm:exact-history}）。

For a structural edit, the Agent names only live objects and an immutable schema.
% 对于结构编辑，Agent 仅指名活对象和不可变模式。
For online growth, it names only an authenticated extension-record identifier.
% 对于在线增长，它仅指名一个经认证的扩展记录标识符。
A trusted judgment derives the target and preserves outcomes, occurrences, cells, lineage, and causal order except under schema-authorized retirement.
% 可信判定推导目标，并保持结果、发生项、单元、谱系和因果顺序，除非模式授权将其退役。
Resolution distinguishes \Fresh commitments from receipt-silent \Alias progress, and each cut replaces the whole policy-domain epoch to order old uses against target activation.
% 解析区分 \Fresh 承诺与不产生回执的 \Alias 进展，而每个切点都会替换整个策略域纪元，从而确定旧使用与目标激活的次序。

\paragraph{Contribution}
% 贡献
We contribute one unified Agent History Admission Theory in which a checked typed effect boundary becomes the relational security state used by both exact admission and installation.
% 我们提出一套统一的 Agent 历史准入理论，其中经检查的类型化效果边界转化为精确准入与安装共同使用的关系安全状态。
For every \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\), the theorem establishes one equivalence among source-level safe realizability, a nonempty history-derived fixed point, successful installation, and an enabled ideal history edge.
% 对每个 \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\)，该定理在源级安全可实现性、非空的历史派生不动点、成功安装和已启用的理想历史边之间建立一个统一等价关系。
Registration reflection, information lower bounds, sequence closure, and weak bisimulation show that the same equivalence is application-grounded, information-tight, stable under Agent evolution, and durably realizable (\cref{sec:model,sec:admission,sec:kernel,sec:results}).
% 注册反射、信息下界、序列闭包与弱互模拟表明，同一等价关系以应用为基础、在信息上紧致、在 Agent 演化下稳定，并可持久实现（\cref{sec:model,sec:admission,sec:kernel,sec:results}）。
