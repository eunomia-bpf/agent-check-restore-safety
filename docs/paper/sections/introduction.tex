\section{Introduction}
% 引言
\label{sec:introduction}

A tool-using Agent can Fork live continuations, Restore a checkpoint, and Merge descendants~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}.
% 使用工具的 Agent 可以 Fork 活跃延续、Restore 检查点，并 Merge 后代~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}。
The world does not rewind.
% 现实世界不会倒转。
A pre-Restore payment remains charged, copied occurrences may share one-use authority, and an old call may race a Merge.
% Restore 前的付款仍已扣款，复制的发生项可能共享一次性权限，而旧调用可能与 Merge 发生竞态。
History editing changes \emph{which past continuations can still produce a future} while commitments remain irreversible.
% 历史编辑会改变\emph{哪些过去的延续仍能产生未来}，而既有承诺仍不可逆。

This paper asks the following question.
% 本文提出以下问题。
\begin{quote}
\emph{When does an Agent history rewrite have a policy-safe, history-faithful, completion-nonblocking realization preserving every structurally promised outcome, and how can a reference monitor realize exactly that boundary while effects race the rewrite?}
% Agent 历史重写何时具有一种策略安全、历史忠实且完成非阻塞的实现，能够保留每个结构性承诺的结果；当效应与重写发生竞态时，参考监控器又如何精确实现这一边界？
\end{quote}

\paragraph{One Restore, end to end}
% 一次 Restore 的端到端过程
In our running procurement history, the Agent saves checkpoint \(k\) before approval, the approval later commits, and the Agent eventually submits only \(u=\mathsf{RestoreLive}(b,k,\sigma)\).
% 在贯穿全文的采购历史中，Agent 在审批前保存检查点 \(k\)，该审批随后提交，而 Agent 最终仅提交 \(u=\mathsf{RestoreLive}(b,k,\sigma)\)。
The trusted controller snapshots \((\kappa,H,\Delta,\mathsf{out},\mathcal A)\), re-derives every schema-preserved outcome and occurrence--cell identity, and computes the greatest prefix-robust fixed point.
% 可信控制器快照 \((\kappa,H,\Delta,\mathsf{out},\mathcal A)\)，重新推导模式所保留的每个结果及发生项--单元标识关系，并计算前缀鲁棒最大不动点。
Its external result is either \(\mathsf{Install}(\mathsf{Can}(W^\dagger,B^\dagger),\eta^+)\) or \(\mathsf{Reject}(\mathit{certificate})\).
% 它的外部结果要么是 \(\mathsf{Install}(\mathsf{Can}(W^\dagger,B^\dagger),\eta^+)\)，要么是 \(\mathsf{Reject}(\mathit{certificate})\)。
After installation, every protected call is classified as \Fresh, \Alias, or denied, and the restored approval becomes a receipt-reusing \Alias rather than a second local outbox preparation.
% 安装之后，每个受保护调用都被分类为 \Fresh、\Alias 或拒绝，而恢复后的审批成为复用回执的 \Alias，而非第二次本地发件箱准备。
An empty result rejects the Restore with a ranked elimination certificate, and the Agent can neither weaken the derived target nor bypass the installed monitor.
% 空结果会以带秩淘汰证书拒绝 Restore，且 Agent 既不能弱化派生目标，也不能绕过已安装监控器。
\Cref{sec:lifecycle} carries this exact history through Fork, Merge, both cut races, and the later Restore.
% \Cref{sec:lifecycle} 沿用这段完全相同的历史，依次展开 Fork、Merge、两类切点竞态和随后的 Restore。

Closest Agent systems provide branching, versioned histories, staged effects, transactions, or recovery checks, but none characterizes exactly which topology-changing edits preserve every promised outcome or constructs the greatest enforcing monitor~\cite{yu2026shepherd,li2025agentgit,langchain2026timetravel,patil2024goex,chang2025sagallm,mohammadi2026atomix,chen2026cordon,yang2026dart}.
% 最接近的 Agent 系统提供分支、版本化历史、分阶段效果、事务或恢复检查，但没有系统精确刻画哪些改变拓扑的编辑会保留每个已承诺结果，也没有构造最大的执行监控器~\cite{yu2026shepherd,li2025agentgit,langchain2026timetravel,patil2024goex,chang2025sagallm,mohammadi2026atomix,chen2026cordon,yang2026dart}。
Generalized nonblocking and live synthesis compute behavior from supplied plants and obligations, while history authorization and runtime enforcement judge supplied histories, actions, or policies~\cite{malik2008generalised,finkbeiner2022live,zhu2022duties,abadi2003history,krukow2008history,palumbo2026forge,santos2026committime}.
% 广义非阻塞与在线综合根据给定的被控对象和义务计算行为，而历史授权与运行时执行判断给定的历史、动作或策略~\cite{malik2008generalised,finkbeiner2022live,zhu2022duties,abadi2003history,krukow2008history,palumbo2026forge,santos2026committime}。
Our theorem covers the missing end-to-end boundary by deriving outcomes, occurrence--cell identities, irreversible receipts, and the exact cut from authenticated Agent history and connecting them to exact admission, greatest enforcement, and atomic realization.
% 我们的定理覆盖这一缺失的端到端边界：从经认证的 Agent 历史推导结果、发生项--单元标识、不可逆回执和精确切点，并将它们连接到精确准入、最大执行与原子实现。
For each proper projection of this relational security state, two finite registered histories have the same retained view but require opposite admission or installation decisions.
% 对这一关系安全状态的每个真投影，都存在两条有限注册历史具有相同的保留视图，却要求相反的准入或安装判定。
The full state remains closed across successive edits rather than characterizing only one rewrite.
% 完整状态在连续编辑之间保持闭合，而非只刻画一次重写。

Once the trusted semantics has derived this Agent-specific state, conditional generalized nonblocking supplies the synthesis backend~\cite{malik2008generalised}.
% 可信语义推导出这一 Agent 特有状态之后，条件广义非阻塞提供综合后端~\cite{malik2008generalised}。
From the policy-safe resolved completions \(\widehat B_0\), the pruning operator \(\widehat\Phi\) removes any completion having a prefix without a surviving continuation for even one contract-compatible outcome.
% 从策略安全的已解析完成路径 \(\widehat B_0\) 出发，裁剪算子 \(\widehat\Phi\) 会移除任何包含如下前缀的完成路径：哪怕仅对一个与契约兼容的结果，该前缀都没有仍然存活的后续路径。
\[
 \widehat B^\dagger=\nu\widehat B.\widehat\Phi(\widehat B),
 \qquad B^\dagger=\pi_2\widehat B^\dagger,\qquad
 W^\dagger=\Pref(B^\dagger).
\]
The edit is admissible exactly when \(\widehat B^\dagger\neq\varnothing\).
% 当且仅当 \(\widehat B^\dagger\neq\varnothing\) 时，该编辑才可接纳。
When nonempty, it yields the greatest permitted behavior \(W^\dagger\), and when empty, its ranked elimination chain proves impossibility.
% 当该不动点非空时，它给出最大的允许行为 \(W^\dagger\)，而当其为空时，带秩的淘汰链证明不可能性。
Ordinary marker nonblocking over traces alone loses both outcome compatibility and occurrence--cell identity (\cref{prop:outcome-necessary,thm:exact-history}).
% 普通的纯轨迹标记非阻塞会丢失结果兼容性和发生项--单元标识这两类信息（\cref{prop:outcome-necessary,thm:exact-history}）。

The Agent names only live objects and an immutable schema; a trusted judgment derives the target and preserves outcomes, occurrences, cells, lineage, and causal order except under schema-authorized retirement.
% Agent 仅指名活对象和不可变模式；可信判定推导目标，并保持结果、发生项、单元、谱系和因果顺序，除非模式授权将其退役。
Resolution distinguishes \Fresh commitments from receipt-silent \Alias progress, and each cut replaces the whole policy-domain epoch to order old uses against target activation.
% 解析区分 \Fresh 承诺与不产生回执的 \Alias 进展，而每个切点都会替换整个策略域纪元，从而确定旧使用与目标激活的次序。

\paragraph{Contribution}
% 贡献
We contribute one unified Agent History Admission Theory in which the relational security state is both the exact admission boundary and the compiler interface.
% 我们提出一套统一的 Agent 历史准入理论，其中关系安全状态既是精确准入边界，也是编译器接口。
The theorem establishes one equivalence among safe realizability, a nonempty derived fixed point, successful installation, and an enabled ideal history edge.
% 该定理在安全可实现性、非空派生不动点、成功安装和已启用的理想历史边之间建立一个统一等价关系。
Its lower bounds, closure result, and weak bisimulation show that the same equivalence is information-tight, stable across successive edits, and durably realizable (\cref{sec:model,sec:admission,sec:kernel,sec:results}).
% 其下界、闭包结果和弱互模拟表明，同一等价关系在信息上是紧致的，能够跨连续编辑保持，并可持久实现（\cref{sec:model,sec:admission,sec:kernel,sec:results}）。
