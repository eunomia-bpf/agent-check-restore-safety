\section{Introduction}
% 引言
\label{sec:introduction}

A tool-using Agent can Fork live continuations, Restore a checkpoint, and Merge descendants~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}.
% 使用工具的 Agent 可以 Fork 活跃延续、Restore 检查点，并 Merge 后代~\cite{codexappserver,claudesessions,claudecheckpoint, wang2026fork,wu2026crab,zhang2026agentlibos}。
The world does not rewind.
% 现实世界不会倒转。
A pre-Restore payment remains charged, copied occurrences may share one-use authority, and an old call may race a Merge.
% Restore 前的付款仍已扣款，复制的发生项可能共享一次性权限，而旧调用可能与 Merge 发生竞态。
History editing changes \emph{which past continuations can still produce a future} while commitments remain irreversible.
% 历史编辑会改变\emph{哪些过去的延续仍能产生未来}，而既有承诺仍不可逆。

This paper asks the following question.
% 本文提出以下问题。
\begin{quote}
\emph{When does an Agent history rewrite have a policy-safe, history-faithful, completion-nonblocking realization preserving every structurally promised outcome, and how can a reference monitor realize exactly that boundary while effects race the rewrite?}
% Agent 历史重写何时具有一种策略安全、历史忠实且完成非阻塞的实现，能够保留每个结构性承诺的结果；当效应与重写发生竞态时，参考监控器又如何精确实现这一边界？
\end{quote}

Endpoint safety is insufficient.
% 仅保证端点安全并不充分。
Two outcomes may each have a safe completion, yet after a shared causal prefix one can remain structurally possible with no safe continuation.
% 两个结果可能各自都有安全的完成路径，但在共享一个因果前缀后，其中一个结果可能在结构上仍然可行，却不存在安全的后续路径。
Admitting that prefix silently retracts an Agent promise.
% 接纳该前缀会悄然撤回 Agent 的一项承诺。
The failure cascades when removing that completion destroys coverage at an earlier prefix, so testing each outcome independently is unsound.
% 当移除该完成路径会破坏更早前缀处的覆盖性时，失败便会级联，因此独立测试每个结果并不可靠。

Prior theories address adjacent enforcement problems.
% 既有理论处理相邻的强制执行问题。
History monitors judge a next action~\cite{abadi2003history,krukow2008history,palumbo2026forge}, commit-time authorization judges one effect~\cite{santos2026committime}, and reversible sessions or dynamic update preserve given specifications~\cite{dezani2016checkpoints,mezzina2025checkpoint,nahabedian2020dynamic,amram2022dynamic}.
% 历史监控器判断下一个动作~\cite{abadi2003history,krukow2008history,palumbo2026forge}，提交时授权判断单个效果~\cite{santos2026committime}，而可逆会话或动态更新保持给定规约~\cite{dezani2016checkpoints,mezzina2025checkpoint,nahabedian2020dynamic,amram2022dynamic}。
Agent history admission judges the edit itself by deriving future obligations, preserving them after every admitted prefix, and respecting irreversible receipts.
% Agent 历史准入通过推导未来义务、在每个已准入前缀之后保持这些义务并尊重不可逆回执，来判断编辑本身。

Our key observation is that exact Agent history editing requires one relational security state spanning promised causal futures, occurrence-to-cell effect identity, irreversible receipts, and the live history cut.
% 我们的关键观察是，精确的 Agent 历史编辑需要一种关系化安全状态，它同时涵盖已承诺的因果未来、发生项到单元的效果标识关系、不可逆回执和活跃历史切点。
None of these factors is merely implementation metadata.
% 这些因子都不只是实现元数据。
For each proper factor projection, two finite registered histories expose the same retained view but require opposite admission or installation decisions.
% 对每个真因子投影，都存在两条有限的注册历史，它们呈现相同的保留视图，却要求相反的准入或安装判定。
The relational state remains closed after every finite prefix of an arbitrarily long online sequence of trusted edits and protected calls, rather than applying only to one rewrite.
% 对可信编辑和受保护调用组成的任意长在线序列，该关系状态在每个有限前缀之后仍保持闭合，而不只适用于一次重写。

Once the trusted semantics has derived this Agent-specific state, conditional generalized nonblocking supplies the synthesis backend.
% 可信语义推导出这一 Agent 特有状态之后，条件广义非阻塞提供综合后端。
From the policy-safe resolved completions \(\widehat B_0\), its operator removes any completion having a prefix without a surviving continuation for even one contract-compatible outcome.
% 从策略安全的已解析完成路径 \(\widehat B_0\) 出发，该算子会移除任何包含如下前缀的完成路径：哪怕仅对一个与契约兼容的结果，该前缀都没有仍然存活的后续路径。
\[
 \widehat B^\dagger=\nu\widehat B.\widehat\Phi(\widehat B),
 \qquad B^\dagger=\pi_2\widehat B^\dagger,\qquad
 W^\dagger=\Pref(B^\dagger).
\]
The edit is admissible exactly when \(\widehat B^\dagger\neq\varnothing\).
% 当且仅当 \(\widehat B^\dagger\neq\varnothing\) 时，该编辑才可接纳。
When nonempty, it yields the greatest permitted behavior \(W^\dagger\), and when empty, its ranked elimination chain proves impossibility.
% 当该不动点非空时，它给出最大的允许行为 \(W^\dagger\)，而当其为空时，带秩的淘汰链证明不可能性。
Ordinary marker nonblocking over traces alone loses both outcome compatibility and occurrence-to-cell effect identity (\cref{prop:outcome-necessary,thm:exact-history}).
% 普通的纯轨迹标记非阻塞会丢失结果兼容性和发生项到单元的效果标识这两类信息（\cref{prop:outcome-necessary,thm:exact-history}）。

The Agent names only live objects and an immutable schema.
% Agent 仅指名活对象和不可变模式。
A trusted judgment derives the target and preserves outcomes, occurrences, cells, lineage, and causal order except under schema-authorized retirement.
% 可信判定推导目标，并保持结果、发生项、单元、谱系和因果顺序，除非模式授权将其退役。
Resolution records \Fresh commitments and receipt-silent \Alias occurrences.
% 解析过程记录 \Fresh 承诺以及不产生回执的 \Alias 发生项。
Each cut replaces the whole policy domain's epoch, ordering old uses and target activation.
% 每个切点都会替换整个策略域的纪元，并为旧使用与目标激活规定顺序。

\paragraph{Theory as a security compiler}
% 作为安全编译器的理论
The \emph{Agent Security-State Characterization Theorem} makes this state the basis of a security compiler rather than an application proof obligation.
% \emph{Agent 安全状态刻画定理}使这一状态成为安全编译器的基础，而不是应用承担的证明义务。
Platform developers register policy and schemas describing what an edit carries, clones, or retires.
% 平台开发者注册策略和模式，用以描述一次编辑会携带、克隆或退役哪些内容。
The Agent submits only \(u\).
% Agent 仅提交 \(u\)。
The installation checker re-derives the obligations, effect identities, receipt frontier, exact cut, and nonblocking solution.
% 安装检查器重新推导义务、效果标识、回执前沿、精确切点和非阻塞解。
On acceptance, the kernel atomically installs \(\mathsf{Can}(W^\dagger,B^\dagger)\), minted gates, and authenticated replacement handles under one new epoch.
% 接纳后，内核在一个新纪元下原子地安装 \(\mathsf{Can}(W^\dagger,B^\dagger)\)、新铸造的门和经过认证的替换句柄。
The monitor then authenticates the occurrence, gate, handle, cell, and epoch of every protected call and permits only transitions in the current program.
% 随后，监控器认证每个受保护调用的发生项、门、句柄、单元和纪元，并且只允许当前程序中的转移。
A valid \Retry only returns its stable result.
% 有效的 \Retry 只返回其稳定结果。
The Agent cannot discard obligations outside schema-authorized retirement or bypass admission.
% Agent 无法丢弃模式授权退役范围之外的义务，也无法绕过准入。

\paragraph{Contribution}
% 贡献
We contribute one unified Agent History-Admission Theory whose central thesis is that history rewriting is exactly governable by the joined security state above.
% 我们提出一套统一的 Agent 历史准入理论，其中心论点是，历史重写恰可由上述联合安全状态治理。
Its characterization theorem proves exact synthesis or certified impossibility, factor-projection lower bounds, closure across successive edits, and weak bisimulation between the compiled monitor and an independent ideal Agent-history machine (\cref{sec:model,sec:admission,sec:kernel,sec:results}).
% 其刻画定理证明精确综合或经认证的不可能性、因子投影下界、连续编辑下的闭包性，以及编译监控器与独立理想 Agent 历史机之间的弱互模拟（\cref{sec:model,sec:admission,sec:kernel,sec:results}）。
The artifact exercises the bounded decision kernel, examples that erase one identity relation at a time, and cut races (\cref{sec:validation}).
% 该制品运行有界判定内核、每次擦除一种标识关系的案例和切点竞态（\cref{sec:validation}）。
