\section{Introduction}
\label{sec:introduction}

Tool-using Agents increasingly construct their execution graph while they
work.  They fork alternatives, keep descendants live in parallel, restore
saved sessions, and merge results, while tool calls mutate services outside
any restorable workspace.  Codex, Claude, and emerging Agent substrates
already expose parts of this lifecycle
~\cite{codexappserver,claudesessions,wang2026fork,wu2026crab}.  Security must
therefore follow not only the Agent's reconstructed state, but also the causal
future and controller epoch created at each history cut.

An Agent history edge can preserve the same effect set while violating the
outcome it claims to preserve.  Consider a procurement Agent that forks two
exclusive suppliers after reserving one order budget.  Approval must precede
payment, exactly one supplier may be paid, and shipment follows the selected
payment; nevertheless, a stale supplier controller may race a select-Merge
that cancels its branch.  A set of eventual effects cannot distinguish
approval--payment from payment--approval, nor can a pointwise authorization
decision establish whether the stale payment or the history cut linearized
first.

The root cause is that an Agent history has three independently evolving
views.  The workspace records reconstructable context, the durable ledger
records an ordered prefix of commitments that Restore cannot erase, and
controller instances determine which effects can still be prepared.  Fork,
Restore, and Merge change the latter two relationships online: they introduce
choice or parallelism, retire or retain old continuations, and place a join
continuation after one or both inputs.  Treating the future as a
downward-closed family of endpoint sets loses this causal and cut structure.

Existing mechanisms each protect a fixed part of this boundary but do not by
themselves close the dynamic history cut.  Rollback recovery and continuity
protect reconstructed past state
~\cite{elnozahy2002rollback,parno2011memoir,zheng2026acrfence}; consumable
credentials and commit-time authorization can linearize individual durable
effects~\cite{bowers2007consumable,santos2026lingering,
santos2026committime}; and history-sensitive monitors can enforce declared
Agent policies~\cite{palumbo2026forge}.  Prefix-closed enforcement, residual
automata, and supervisory control are also classical
~\cite{schneider2000enforceable,ramadge1987supervisory,yin2017range}.  Merely
localizing such a supervisor would not be a contribution: the missing result
is a semantics and correctness theorem for changing the plant and its live
controllers at an online Agent edge while a durable receipt may race that
change.

We observe that a protected Agent history edge should be treated as a
\emph{causal epoch-compilation request}.  The request describes only the
bounded protected slice ending at the next history edge, so it need not
predict the Agent's unrestricted future.  Its typed before/after operation
derives a causal plant; authenticated receipts select the exact future of the
strongest atomic monitor; and compilation produces the controller program
that will own the target epoch.  Admission asks whether every outcome promised
by the operation has a linearization in that reference future, not whether
each next action is pointwise authorized.

Realizing this observation requires one proof to cross four representation
boundaries.  Raw plans name handle and gate-use occurrences, while security
depends on ledger-backed redemption cells and authoritative controller
instances.  The reference future must preserve sequence, exclusive choice,
parallel shuffle, branch cancellation, and Merge causality.  Finally, a
correct compiler result is useless unless installation atomically closes the
source controller classes and binds the target program to the same policy
version, history view, and exact receipt trace used by its proof.

We present \emph{Agent history admission} and its Canonical Causal Epoch
Theorem.  A small plan calculus gives causal semantics to choice and parallel
Fork, replacing and live Restore, and select and join Merge; ledger anchors
normalize aliases, and a prefix-closed durable-authority policy defines the
reference future at the observed cut.  The canonical construction is the
residual automaton of that future.  The theorem proves equivalence between
promised-outcome feasibility and the existence of a monitor-sound epoch,
proves that the canonical epoch realizes the full reference language, and
then proves by induction over the durable kernel LTS that a
version/frontier-bound installation preserves the result across
\Prepare{}/Install races and successive edges.  The residual construction is
established automata machinery; the claimed result is its end-to-end
raw-Agent-edge-to-installed-epoch correctness boundary.

We ask three questions.  \emph{RQ1:} which causal language and promised
outcomes does each typed Agent history cut generate after ledger-backed
normalization?  \emph{RQ2:} when does a canonical epoch exist, and does it
realize exactly the atomic monitor's surviving future rather than a pruned
approximation?  \emph{RQ3:} does the version/frontier installation rule
preserve that equivalence when old \Prepare{} operations and new history edges
race?  The causal theorem and installer invariant receive self-contained
paper proofs.  Existing Lean~4 and Python evidence is used only for the
permutation-invariant endpoint corollary; it does not mechanize the causal
theorem, authenticate a production adapter, or establish real
Codex/Claude complete mediation.

\noindent\textbf{Contributions.}
This paper makes three contributions to one history-admission theorem.
\nopagebreak[4]

\begin{enumerate}[leftmargin=*,itemsep=2pt]
  \item A raw protected-slice calculus and normalization semantics for Agent
  Fork, Restore, and Merge.  It separates ledger-cell identity from
  controller identity and derives causal traces and bounded promised outcomes
  without assuming a complete future execution graph
  (\cref{sec:lifecycle,sec:model,sec:semantics}).

  \item The Canonical Causal Epoch Theorem.  It characterizes promised-outcome
  feasibility, constructs an epoch whose fresh-trace language equals the
  strongest atomic monitor's reference future, and gives a missing outcome as
  a complete impossibility witness (\cref{sec:results}).

  \item A version/frontier-bound installation semantics and preservation
  proof.  Its atomic cut closes source controller classes, binds a
  compiler-produced target epoch, and resolves every
  \Prepare{}/Install race by ledger order; the artifact boundary explicitly
  limits existing mechanization and executable evidence to the unordered
  corollary (\cref{sec:algorithm,sec:validation}).
\end{enumerate}
