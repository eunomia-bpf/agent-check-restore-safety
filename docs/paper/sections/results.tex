\section{Agent Security-State Characterization}
% Agent 安全状态刻画
\label{sec:results}

The main theorem characterizes one state unifying schema checking, nonblocking synthesis, and epoch installation.
% 主定理刻画一种统一模式检查、非阻塞综合与纪元安装的状态。
For a history-judgment witness \(\delta=(H^+,\mathcal C,\eta^-,\eta^+)\), an \emph{exact atomic realization} \((M,\widehat B_M)\) realizes \((H,u)\) through \((\mathsf{Gen}(M,q^0),\widehat B_M)\) with \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\).
% 对于历史判定见证 \(\delta=(H^+,\mathcal C,\eta^-,\eta^+)\)，\emph{精确原子实现} \((M,\widehat B_M)\) 通过 \((\mathsf{Gen}(M,q^0),\widehat B_M)\) 实现 \((H,u)\)，满足 \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\)。
Independently, it swaps in \(H^+\), closes \(\eta^-\), activates \(M\) at \(\eta^+\), binds its target gates, and then publishes replacement handles.
% 独立地，它换入 \(H^+\)、关闭 \(\eta^-\)、在 \(\eta^+\) 激活 \(M\)、绑定其目标门，随后发布替换句柄。
The swap is defined independently of \(\mathsf{Admit}\), \(\widehat B^\dagger\), \(\mathsf{Compile}\), \(\mathsf{Edge}\), and the canonical monitor.
% 该切换独立于 \(\mathsf{Admit}\)、\(\widehat B^\dagger\)、\(\mathsf{Compile}\)、\(\mathsf{Edge}\) 和规范监控器而定义。

\paragraph{Relational evidence}
% 关系证据
At a checked cut, four finite keyed factors record (1) live/checkpoint contracts, schemas, lifts, and retirement in \(\mathbf P\); (2) occurrence--cell, gate, handle, lineage, label, and digest incidence in \(\mathbf I\); (3) cursors, receipt--cell records, result futures, outbox order, and residual policy in \(\mathbf E\); and (4) domain and policy/schema versions, finite epoch phase/freshness, the active epoch, generations, certificate metadata, and checkpoint coordinates in \(\mathbf C\).
% 在一个经检查的切点处，四个有限带键因子分别记录：(1) \(\mathbf P\) 中的活跃/检查点契约、模式、提升和退役；(2) \(\mathbf I\) 中的发生项--单元、门、句柄、谱系、标签和摘要关联；(3) \(\mathbf E\) 中的游标、回执--单元记录、结果期值、发件箱次序和残余策略；以及 (4) \(\mathbf C\) 中的域与策略/模式版本、有限纪元阶段/新鲜性、活跃纪元、世代、证书元数据和检查点坐标。
Their normalized natural join \(\bowtie\) uses shared typed outcome, occurrence, cell, checkpoint, domain, and version keys, is undefined on disagreement, stores each semantic field once, and canonically recomposes raw checked certificates.
% 它们的规范化自然连接 \(\bowtie\) 使用共享的类型化结果、发生项、单元、检查点、域和版本键，在值不一致时无定义，每个语义字段只存储一次，并规范重组原始的经检查证书。
For \(\mathsf{AgentSec}(S;c,r)\), define the incidence-preserving evidence view
% 对于 \(\mathsf{AgentSec}(S;c,r)\)，定义保持关联关系的证据视图
\[
 \mathsf{Sec}(S;c,r)=
 \mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C .
\]
This view binds checkpoints to contracts/cursors/registries, occurrences to outcomes/cells, receipts to cells, and the cursor to the live cut.
% 该视图把检查点绑定到契约/游标/注册表，把发生项绑定到结果/单元，把回执绑定到单元，并把游标绑定到活跃切点。
For \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\), \(\pi_J\) projects to the named records modulo private-identifier renaming that fixes public labels and the request, recursively removing foreign-key paths, certificate components, seals, and digests whose payload mentions an erased field.
% 对 \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\)，\(\pi_J\) 在固定公开标签与请求的私有标识重命名意义下投影到具名记录，并递归移除载荷提及已擦除字段的外键路径、证书组件、封印和摘要。
\(\pi_{\neg oc}\) retains all marginal occurrence/cell records but recursively erases their incidence; \(\pi_{\neg rc}\) similarly retains marginal receipt, creator, occurrence, and cell records but erases receipt--cell incidence and reconstructing paths, including receipt--creator and cursor--receipt links.
% \(\pi_{\neg oc}\) 保留全部边际发生项/单元记录，但递归擦除其关联；\(\pi_{\neg rc}\) 类似地保留边际回执、创建者、发生项和单元记录，但擦除回执--单元关联及其重建路径，其中包括回执--创建者和游标--回执链接。
For edit or installation query \(q\), an end-to-end compiler-installer through \(\pi_J\) depends only on \(([\pi_J\mathsf{Sec}]_{\cong},q)\) and is \emph{exact} iff it rejects exactly unrealizable edits, returns every realizable edit's greatest realization, and installs only at its derivation cut.
% 对于编辑或安装查询 \(q\)，经由 \(\pi_J\) 的端到端编译器-安装器仅依赖 \(([\pi_J\mathsf{Sec}]_{\cong},q)\)，并且当且仅当它恰好拒绝不可实现的编辑、返回每个可实现编辑的最大实现且仅在其推导切点安装时是\emph{精确的}。
Call this existence predicate \(\mathsf{Exact}(\pi_J)\).
% 将这一存在性谓词记为 \(\mathsf{Exact}(\pi_J)\)。

The security observation alphabet is
% 安全观测字母表为
\[
\begin{split}
\mathcal O=\{&\mathsf{Edge}(u),\Fresh(x,d),\Alias(x,d),\\[-2pt]
             &\mathsf{deny}(x),\Dispatch(d)\}.
\end{split}
\]
A fully parameterized trusted event record \(e\) carries every hidden payload used by its guard, and pairs \(([\mathsf{Sec}]_{\cong},e)\) are quotiented simultaneously by private-identifier renaming.
% 参数完整的可信事件记录 \(e\) 携带其守卫使用的全部隐藏载荷，并且二元组 \(([\mathsf{Sec}]_{\cong},e)\) 按私有标识的同步重命名取商。
The relabeling satisfies \(\mathsf{obs}(\Use_x/a)=a\), maps a successful installation record \((\mathsf{Edge}(u),Z,\delta)\) to \(\mathsf{Edge}(u)\), preserves \(\mathsf{deny}(x)\) and \(\Dispatch(d)\), and maps every other label to \(\tau\).
% 重标记满足 \(\mathsf{obs}(\Use_x/a)=a\)，把成功安装记录 \((\mathsf{Edge}(u),Z,\delta)\) 映射为 \(\mathsf{Edge}(u)\)，保持 \(\mathsf{deny}(x)\) 和 \(\Dispatch(d)\)，并把其他所有标签映射为 \(\tau\)。
Write \(\xRightarrow{\ell}\) for \(\tau^*\ell\tau^*\), with \(\xRightarrow{\tau}=\tau^*\).
% 用 \(\xRightarrow{\ell}\) 表示 \(\tau^*\ell\tau^*\)，其中 \(\xRightarrow{\tau}=\tau^*\)。
Let \(\mathcal Q\) contain the normalized history, receipts, outbox, admitted cut, resolved prefix, result futures, current abstract epoch, and live gate bindings, excluding phase protocol, seals, preload contents, and handoff metadata.
% 令 \(\mathcal Q\) 包含规范化历史、回执、发件箱、已准入切点、已解析前缀、结果期值、当前抽象纪元和活跃门绑定，但不包含阶段协议、封印、预加载内容与交接元数据。
\(\alpha_I(I;c,r)\) reads \(\mathcal Q\) from the ideal state, while \(\alpha_S(S;c,r)\) normalizes compiled factors into it, retaining only \(\mathbf C\)'s active epoch and live gate bindings.
% \(\alpha_I(I;c,r)\) 从理想状态读取 \(\mathcal Q\)，而 \(\alpha_S(S;c,r)\) 将编译后因子规范化到其中，仅保留 \(\mathbf C\) 的活跃纪元和活跃门绑定。
Define
% 定义
\[
\begin{aligned}
 I\,\mathcal R\,S\quad\Longleftrightarrow\quad
 &\exists c,r.\ \mathsf{AgentSec}(S;c,r)\\[-2pt]
 &{}\land\alpha_I(I;c,r)=\alpha_S(S;c,r).
\end{aligned}
\]
A \emph{good initial pair} satisfies \(\mathcal R\) with \(r=\epsilon\) immediately after a checked atomic installation.
% \emph{良好初始对}在一次经检查的原子安装后立即以 \(r=\epsilon\) 满足 \(\mathcal R\)。

\paragraph{Event derivatives}
% 事件导数
The pair \((G_e,\mathsf U_e)\) is: (i) for \Use, \cref{eq:use-rule} and \(\mathsf{Advance}\); (ii) for successful \(\mathsf{Edge}\), \cref{eq:install-premise} and atomic installation; (iii) for \(\mathsf{Save}\), the checkpoint guard and the \(K,\nu\) update; (iv) for dispatch and settlement, their ledger guards and \(\mathbf E\) updates; (v) for retry, retrieval, delivery, and denial, their authentication guards and unchanged joined state; (vi) for preload, an inactive-and-unbound guard and content update; and (vii) for failed or stale installation and crash, their transition conditions and unchanged joined state.
% \((G_e,\mathsf U_e)\) 对为：(i) 对 \Use，采用 \cref{eq:use-rule} 与 \(\mathsf{Advance}\)；(ii) 对成功的 \(\mathsf{Edge}\)，采用 \cref{eq:install-premise} 与原子安装；(iii) 对 \(\mathsf{Save}\)，采用检查点守卫与 \(K,\nu\) 更新；(iv) 对派发和结算，采用各自的账本守卫与 \(\mathbf E\) 更新；(v) 对重试、取回、交付和拒绝，采用各自的认证守卫并保持联合状态不变；(vi) 对预加载，采用非活跃且未绑定守卫与内容更新；(vii) 对失败或过期的安装和崩溃，采用各自的转移条件并保持联合状态不变。
Define \(\partial_e([V]_{\cong})=[\mathsf U_e(V)]_{\cong}\) exactly when the rule guard \(G_e(V)\) holds.
% 当且仅当规则守卫 \(G_e(V)\) 成立时，定义 \(\partial_e([V]_{\cong})=[\mathsf U_e(V)]_{\cong}\)。
Witnesses are \Use: \((c,ra)\), successful \(\mathsf{Edge}\): \((c_\delta^+,\epsilon)\), and all others: \((c,r)\).
% 见证为：\Use 对应 \((c,ra)\)，成功的 \(\mathsf{Edge}\) 对应 \((c_\delta^+,\epsilon)\)，其余事件对应 \((c,r)\)。
In ideal-to-compiled order, \Use matches \(a\) to \(a\), successful \(\mathsf{Edge}\) matches \(\mathsf{Edge}\) to \(\tau^*\mathsf{Edge}\tau^*\), \(\Dispatch\) and denial match themselves, and all other events match \(\tau^*\) to \(\tau^*\).
% 按理想机到编译机的次序，\Use 以 \(a\) 匹配 \(a\)，成功的 \(\mathsf{Edge}\) 以 \(\mathsf{Edge}\) 匹配 \(\tau^*\mathsf{Edge}\tau^*\)，\(\Dispatch\) 和拒绝与自身匹配，其余事件以 \(\tau^*\) 匹配 \(\tau^*\)。

\begin{theorem}[Agent Security-State Characterization]
% Agent 安全状态刻画
\label{thm:exact-history}
Assume the trusted boundary of \cref{sec:model}.
% 假定 \cref{sec:model} 的可信边界。
Let \(S\) be any finite reachable state satisfying \(\mathsf{AgentSec}(S;c,r)\), and let \(u\) be any syntactically well-formed request naming registered objects.
% 令 \(S\) 为任意满足 \(\mathsf{AgentSec}(S;c,r)\) 的有限可达状态，并令 \(u\) 为任意指名已注册对象且语法良构的请求。
\begin{enumerate}[leftmargin=*,itemsep=2pt]
\item \textbf{Exact compilation.}
% 精确编译。
For each derivation witness \(\delta\), let \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathcal A,u)\) and \(c_\delta^+\) be its compiler result and checked post-installation record; other subscripts denote \(\delta\)-derived quantities.
% 对每个推导见证 \(\delta\)，令 \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathcal A,u)\) 和 \(c_\delta^+\) 分别为其编译结果与经检查的安装后记录；其他下标表示由 \(\delta\) 派生的量。
The following total conditions are equivalent.
% 下列全定义条件等价。
\[
\begin{aligned}
 &\widehat B^\dagger_\delta\ne\varnothing;\\
 &\text{an exact atomic realization of }(H,u,\delta)\text{ exists};\\
% \((H,u,\delta)\) 的精确原子实现存在。
 &\mathsf{Out}_\delta\models\cref{eq:install-premise};\\
 &\exists S^+.\ S\xRightarrow{\mathsf{Edge}(u)}S^+
       \land\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon).
\end{aligned}
\]
When they hold, \((W^\dagger_\delta,\widehat B^\dagger_\delta)\) is the greatest realization by componentwise language inclusion, and \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) is its canonical monitor.
% 当这些条件成立时，\((W^\dagger_\delta,\widehat B^\dagger_\delta)\) 按分量语言包含关系是最大实现，并且 \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) 是其规范监控器。
Absent \(\delta\), structural failure certifies an invalid edit; for existing \(\delta\), a ranked chain ending in \(\varnothing\) excludes every realization.
% 若 \(\delta\) 不存在，结构失败会认证编辑无效；对于已存在的 \(\delta\)，以 \(\varnothing\) 结束的带秩链会排除所有实现。

\item \textbf{Factor tightness.}
% 因子紧致性。
Uniform exact compilation through the factor projections satisfies
% 经由上述因子投影的统一精确编译满足
\[
 \mathsf{Exact}(\pi_J)
 \quad\Longleftrightarrow\quad
 J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
Moreover, \(\neg\mathsf{Exact}(\pi_{\neg oc})\) and \(\neg\mathsf{Exact}(\pi_{\neg rc})\), even though both views retain every marginal record.
% 此外，\(\neg\mathsf{Exact}(\pi_{\neg oc})\) 且 \(\neg\mathsf{Exact}(\pi_{\neg rc})\)，尽管两种视图都保留每条边际记录。
No exact end-to-end Agent history compiler factors through \(\tau_{\rm tgt}\), which exposes only a caller-proposed target plant, markings, and epoch before trusted derivation, although generalized nonblocking is exact after a valid derivation supplies the target and markings.
% 不存在经由 \(\tau_{\rm tgt}\) 的精确端到端 Agent 历史编译器；该视图在可信推导之前仅暴露调用方提出的目标被控对象、标记和纪元，尽管广义非阻塞在有效推导提供目标与标记后是精确的。

\item \textbf{Sequence closure.}
% 序列闭包。
The guarded updates define partial functions \(\{\partial_e\}_e\) on finite security-state isomorphism classes, with \(\partial_e([\mathsf{Sec}]_{\cong})\) defined exactly when fully parameterized trusted event \(e\)'s rule is enabled.
% 带守卫更新定义了作用于有限安全状态同构类的偏函数族 \(\{\partial_e\}_e\)；当且仅当参数完整的可信事件 \(e\) 的规则启用时，\(\partial_e([\mathsf{Sec}]_{\cong})\) 有定义。
Moreover,
% 此外，
\[
\begin{aligned}
&\mathsf{AgentSec}(S;c,r)\land S\xrightarrow e S'\\[-2pt]
&\quad\Longrightarrow \exists c',r'.\
  \mathsf{AgentSec}(S';c',r')\\[-2pt]
&\qquad\land [\mathsf{Sec}(S';c',r')]_{\cong}
  =\partial_e([\mathsf{Sec}(S;c,r)]_{\cong}).
\end{aligned}
\]
The event family covers all six edits, protected use, \(\mathsf{Save}\), preload, retry, denial, retrieval, delivery, dispatch, settlement, successful or failed installation, and crash.
% 该事件族覆盖全部六种编辑、受保护使用、\(\mathsf{Save}\)、预加载、重试、拒绝、取回、交付、派发、结算、成功或失败的安装以及崩溃。
Consequently, the same characterization applies after every finite prefix of an arbitrarily long online edit-and-use sequence.
% 因此，对于任意长的在线编辑与使用序列，其每个有限前缀之后都适用同一刻画。

\item \textbf{Durable realization.}
% 持久实现。
\(\mathcal R\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}\): if either related side steps with label \(\ell\), the other takes a matching \(\xRightarrow{\mathsf{obs}(\ell)}\) path to a related state, in both directions.
% \(\mathcal R\) 在 \(\mathsf{obs}\) 下是发散不敏感弱互模拟：若相关的任一侧执行标签为 \(\ell\) 的一步，则另一侧沿匹配的 \(\xRightarrow{\mathsf{obs}(\ell)}\) 路径到达相关状态，且两个方向均成立。
Hence every good initial pair satisfies \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\).
% 因此，每个良好初始对都满足 \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\)。
\end{enumerate}
\end{theorem}

Because \(\mathcal R\) is componentwise, whole-cut domains with disjoint cells, receipt ledgers, and policies compose by the standard asynchronous-product congruence for weak bisimulation.
% 由于 \(\mathcal R\) 按分量定义，单元、回执账本和策略互不相交的完整切点域可依据弱互模拟的标准异步积同余进行组合。

% 精确编译。
\Cref{lem:history-derivation} either rejects or uniquely supplies \(\delta\) and every required \(\mathsf{Lift}_u\) witness; then \(\mathbf P,\mathbf I,\mathbf E\) determine \(\widehat B_0\), and \cref{lem:greatest-realization} makes \(\widehat B^\dagger_\delta\) the greatest realizable family.
% \Cref{lem:history-derivation} 要么拒绝请求，要么唯一给出 \(\delta\) 和每个必需的 \(\mathsf{Lift}_u\) 见证；随后 \(\mathbf P,\mathbf I,\mathbf E\) 决定 \(\widehat B_0\)，而 \cref{lem:greatest-realization} 使 \(\widehat B^\dagger_\delta\) 成为最大的可实现族。
When nonempty, \cref{lem:compiled-language} and the independent swap construct the realization, while \(\mathsf{Verify}_Z\), \(\mathsf{ReCut}\), and \cref{eq:install-premise} accept it exactly at its source cut and establish \(\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon)\); when empty, ranked missing-witness induction excludes every realization.
% 当其非空时，\cref{lem:compiled-language} 与独立切换构造该实现，而 \(\mathsf{Verify}_Z\)、\(\mathsf{ReCut}\) 与 \cref{eq:install-premise} 恰在其源切点接纳它并建立 \(\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon)\)；当其为空时，带秩的缺失见证归纳排除所有实现。

These values directly satisfy all five \(\mathsf{AgentSec}(\mathsf{Boot}(V);c_V,\epsilon)\) clauses.
% 这些值直接满足 \(\mathsf{AgentSec}(\mathsf{Boot}(V);c_V,\epsilon)\) 的全部五个条款。
