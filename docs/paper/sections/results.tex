\section{Agent Security-State Characterization}
% Agent 安全状态刻画
\label{sec:results}

The main theorem characterizes one state unifying schema checking, nonblocking synthesis, and epoch installation.
% 主定理刻画一种统一模式检查、非阻塞综合与纪元安装的状态。
For a history-judgment witness \(\delta=(H^+,\mathcal C,\eta^-,\eta^+)\), an \emph{exact atomic realization} \((M,\widehat B_M)\) realizes \((H,u)\) through \((\mathsf{Gen}(M,q^0),\widehat B_M)\) with \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\).
% 对于历史判定见证 \(\delta=(H^+,\mathcal C,\eta^-,\eta^+)\)，\emph{精确原子实现} \((M,\widehat B_M)\) 通过 \((\mathsf{Gen}(M,q^0),\widehat B_M)\) 实现 \((H,u)\)，满足 \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\)。
An exact atomic realization swaps in \(H^+\), closes \(\eta^-\), activates \(M\) at \(\eta^+\), binds the target gates, and then publishes replacement handles.
% 精确原子实现换入 \(H^+\)、关闭 \(\eta^-\)、在 \(\eta^+\) 激活 \(M\)、绑定目标门，随后发布替换句柄。
The swap is defined independently of \(\mathsf{Admit}\), \(\widehat B^\dagger\), \(\mathsf{Compile}\), \(\mathsf{Edge}\), and the canonical monitor.
% 该切换独立于 \(\mathsf{Admit}\)、\(\widehat B^\dagger\)、\(\mathsf{Compile}\)、\(\mathsf{Edge}\) 和规范监控器而定义。

\paragraph{Relational evidence}
% 关系证据
At a checked cut, four finite keyed factors record promised topology, schemas, lifts, and retirement in \(\mathbf P\); occurrence--cell identity, invocation, and lineage in \(\mathbf I\); resolved progress, receipts, results, outbox, and policy in \(\mathbf E\); and versions, epoch ownership, certificates, and cut coordinates in \(\mathbf C\).
% 在一个经检查的切点处，四个有限带键因子分别记录：\(\mathbf P\) 中的承诺拓扑、模式、提升和退役；\(\mathbf I\) 中的发生项--单元标识、调用和谱系；\(\mathbf E\) 中的已解析进展、回执、结果、发件箱和策略；以及 \(\mathbf C\) 中的版本、纪元所有权、证书和切点坐标。
The appendix enumerates every owned base field and transitive dependency.
% 附录枚举每个具有所有者的基础字段及其传递依赖。
Their normalized natural join \(\bowtie\) uses shared typed outcome, occurrence, cell, checkpoint, domain, and version keys, is undefined on disagreement, stores each semantic field once, and canonically recomposes raw checked certificates.
% 它们的规范化自然连接 \(\bowtie\) 使用共享的类型化结果、发生项、单元、检查点、域和版本键，在值不一致时无定义，每个语义字段只存储一次，并规范重组原始的经检查证书。
For \(\mathsf{AgentSec}(S;c,r)\), define the incidence-preserving evidence view
% 对于 \(\mathsf{AgentSec}(S;c,r)\)，定义保持关联关系的证据视图
\[
 \mathsf{Sec}(S;c,r)=
 \mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C .
\]
This view binds checkpoints to contracts/cursors/registries, occurrences to outcomes/cells, receipts to cells, and the cursor to the history cut.
% 该视图把检查点绑定到契约/游标/注册表，把发生项绑定到结果/单元，把回执绑定到单元，并把游标绑定到历史切点。
For \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\), \(\pi_J\) projects to the named records modulo sort-preserving private-identifier renaming that fixes public keys, recursively removing foreign-key paths, certificate components, seals, and digests whose payload mentions an erased field.
% 对 \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\)，\(\pi_J\) 在固定公开键且保持类型的私有标识重命名意义下投影到具名记录，并递归移除载荷提及已擦除字段的外键路径、证书组件、封印和摘要。
\(\pi_{\neg oc}\) retains all marginal occurrence/cell records but recursively erases their incidence; \(\pi_{\neg rc}\) similarly retains marginal receipt, creator, occurrence, and cell records but erases receipt--cell incidence and reconstructing paths, including receipt--creator and cursor--receipt links.
% \(\pi_{\neg oc}\) 保留全部边际发生项/单元记录，但递归擦除其关联；\(\pi_{\neg rc}\) 类似地保留边际回执、创建者、发生项和单元记录，但擦除回执--单元关联及其重建路径，其中包括回执--创建者和游标--回执链接。
For a finite valid full view \(V\) and typed edit or installation query \(q\), let \(\mathsf{Ans}(V,q)\) be the semantic answer: structural rejection, the greatest realization, or the history-cut installation decision.
% 对于有限有效的完整视图 \(V\) 和带类型的编辑或安装查询 \(q\)，令 \(\mathsf{Ans}(V,q)\) 表示语义答案：结构拒绝、最大实现或历史切点安装判定。
Let \(\mathsf{supp}(q)\) recursively contain every identifier in \(q\), including identifiers inside a supplied symbolic certificate \(Z\), and let \(V\cong_qV'\) require a sort-preserving bijection that fixes public keys and \(\mathsf{supp}(q)\) pointwise.
% 令 \(\mathsf{supp}(q)\) 递归包含 \(q\) 中的每个标识符，包括所提供符号证书 \(Z\) 内的标识符；并令 \(V\cong_qV'\) 要求存在保持类型且逐点固定公开键与 \(\mathsf{supp}(q)\) 的双射。
Write \(\langle V,q\rangle_{\cong}\) for the joint orbit under simultaneous renaming of the state and query.
% 用 \(\langle V,q\rangle_{\cong}\) 表示在同步重命名状态与查询下得到的联合轨道。
An equivariant state abstraction \(\tau\) is \emph{exact} when some equivariant decoder \(D_\tau\) satisfies
% 当存在某个等变解码器 \(D_\tau\) 满足下式时，等变状态抽象 \(\tau\) 是\emph{精确的}：
\[
 \mathsf{Exact}(\tau)\ \Longleftrightarrow\
 \exists D_\tau.\ \forall V,q.\
 D_\tau(\langle\tau(V),q\rangle_{\cong})
   =[\mathsf{Ans}(V,q)]_{\cong}.
\]
Thus exactness constrains information, not a literal storage layout: any opposite-answer pair must remain distinguishable, while an implementation may encode or compress the evidence.
% 因而，精确性约束的是信息而非字面存储布局：任何答案相反的历史对都必须保持可区分，而实现可以对证据进行编码或压缩。

The security observation alphabet is
% 安全观测字母表为
\[
\begin{split}
\mathcal O=\{&\mathsf{Edge}(u),\Fresh(x,d),\Alias(x,d),\\[-2pt]
             &\mathsf{deny}(x),\Dispatch(d)\}.
\end{split}
\]
A fully parameterized trusted event record \(e\) carries every hidden payload used by its guard; write \(\langle V,e\rangle_{\cong}\) for the joint orbit under one simultaneous sort-preserving renaming of the state and event.
% 参数完整的可信事件记录 \(e\) 携带其守卫使用的全部隐藏载荷；用 \(\langle V,e\rangle_{\cong}\) 表示在一次保持类型的同步状态与事件重命名下得到的联合轨道。
The relabeling satisfies \(\mathsf{obs}(\Use_x(m)/a)=a\), maps a successful installation record \((\mathsf{Edge}(u),Z,\delta)\) to \(\mathsf{Edge}(u)\), preserves \(\mathsf{deny}(x)\) and \(\Dispatch(d)\), and maps every other label to \(\tau\).
% 重标记满足 \(\mathsf{obs}(\Use_x(m)/a)=a\)，把成功安装记录 \((\mathsf{Edge}(u),Z,\delta)\) 映射为 \(\mathsf{Edge}(u)\)，保持 \(\mathsf{deny}(x)\) 和 \(\Dispatch(d)\)，并把其他所有标签映射为 \(\tau\)。
Write \(\xRightarrow{\ell}\) for \(\tau^*\ell\tau^*\), with \(\xRightarrow{\tau}=\tau^*\).
% 用 \(\xRightarrow{\ell}\) 表示 \(\tau^*\ell\tau^*\)，其中 \(\xRightarrow{\tau}=\tau^*\)。
Let \(\mathcal Q\) contain the normalized history, receipt ledger, outbox, admitted history cut, resolved prefix, result futures, current abstract epoch, and live gate bindings, excluding phase protocol, seals, preload contents, and handoff metadata.
% 令 \(\mathcal Q\) 包含规范化历史、回执账本、发件箱、已准入历史切点、已解析前缀、结果期值、当前抽象纪元和活跃门绑定，但不包含阶段协议、封印、预加载内容与交接元数据。
\(\alpha_I(I;\mathsf{icut}(c),r)\) reads \(\mathcal Q\) from the ideal state, while \(\alpha_S(S;c,r)\) normalizes compiled factors into it, retaining only \(\mathbf C\)'s active epoch and live gate bindings.
% \(\alpha_I(I;\mathsf{icut}(c),r)\) 从理想状态读取 \(\mathcal Q\)，而 \(\alpha_S(S;c,r)\) 将编译后因子规范化到其中，仅保留 \(\mathbf C\) 的活跃纪元和活跃门绑定。
Define
% 定义
\[
\begin{aligned}
 I\,\mathcal R\,S\quad\Longleftrightarrow\quad
 &\exists c,r.\ \mathsf{AgentSec}(S;c,r)\\[-2pt]
 &{}\land\alpha_I(I;\mathsf{icut}(c),r)=\alpha_S(S;c,r).
\end{aligned}
\]
A \emph{good initial pair} satisfies \(\mathcal R\) with \(r=\epsilon\) immediately after a checked atomic installation.
% \emph{良好初始对}在一次经检查的原子安装后立即以 \(r=\epsilon\) 满足 \(\mathcal R\)。

\paragraph{Event derivatives}
% 事件导数
For every fully parameterized trusted event \(e\), let \(G_e\) and \(\mathsf U_e\) be exactly its explicit LTS guard and durable update, and define \(\partial(\langle V,e\rangle_{\cong})=[\mathsf U_e(V)]_{\cong}\) exactly when \(G_e(V)\) holds.
% 对于每个参数完整的可信事件 \(e\)，令 \(G_e\) 和 \(\mathsf U_e\) 恰为其显式 LTS 守卫与持久更新，并且当且仅当 \(G_e(V)\) 成立时定义 \(\partial(\langle V,e\rangle_{\cong})=[\mathsf U_e(V)]_{\cong}\)。
The appendix enumerates all event classes, invariant witnesses, and bidirectional matches; \Use advances to \((c,ra)\), successful \(\mathsf{Edge}\) resets to \((c_\delta^+,\epsilon)\), and every other event retains \((c,r)\).
% 附录枚举全部事件类别、不变量见证和双向匹配；\Use 推进到 \((c,ra)\)，成功的 \(\mathsf{Edge}\) 重置到 \((c_\delta^+,\epsilon)\)，而其他每个事件都保持 \((c,r)\)。

\begin{theorem}[Agent Security-State Characterization]
% Agent 安全状态刻画
\label{thm:exact-history}
Assume the trusted boundary of \cref{sec:model}.
% 假定 \cref{sec:model} 的可信边界。
Let \(S\) be any finite reachable state satisfying \(\mathsf{AgentSec}(S;c,r)\), and let \(u\) be one of the six well-formed structural-edit requests over registered objects.
% 令 \(S\) 为任意满足 \(\mathsf{AgentSec}(S;c,r)\) 的有限可达状态，并令 \(u\) 为作用于已注册对象的六种良构结构编辑请求之一。
\begin{enumerate}[leftmargin=*,itemsep=2pt]
\item \textbf{Exact compilation.}
% 精确编译。
Without a history derivation, \(\mathsf{Compile}\) rejects structurally and both machines disable \(\mathsf{Edge}(u)\).
% 若历史推导不存在，\(\mathsf{Compile}\) 会作出结构拒绝，且两台机器都禁用 \(\mathsf{Edge}(u)\)。
Otherwise let \(\delta\) be its unique witness, set \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\), and let \(c_\delta^+\) be the checked installed record; all subscripts below are \(\delta\)-derived, and the following are equivalent.
% 否则，令 \(\delta\) 为其唯一见证，置 \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，并令 \(c_\delta^+\) 为经检查的安装记录；下文所有下标均由 \(\delta\) 派生，且以下条件等价。
\[
\begin{aligned}
 &\widehat B^\dagger_\delta\ne\varnothing;\\
 &\text{an exact atomic realization of }(H,u,\delta)\text{ exists};\\
 &\mathsf{Out}_\delta\models\cref{eq:install-premise};\\
 &\exists S^+.\ S\xRightarrow{\mathsf{Edge}(u)}S^+
       \land\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon).
\end{aligned}
\]
When these conditions hold, \((W^\dagger_\delta,\widehat B^\dagger_\delta)\) is greatest and \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) is canonical.
% 当这些条件成立时，\((W^\dagger_\delta,\widehat B^\dagger_\delta)\) 为最大实现，且 \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) 为规范监控器。
Invalid edits have no derivation; a ranked chain ending in \(\varnothing\) excludes every realization.
% 无效编辑不存在推导；以 \(\varnothing\) 结束的带秩链会排除所有实现。

\item \textbf{Factor tightness.}
% 因子紧致性。
The full join is sufficient, and every proper factor projection is insufficient:
% 完整连接是充分的，而每个真因子投影均不充分：
\[
 \mathsf{Exact}(\pi_J)
 \quad\Longleftrightarrow\quad
 J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
Every exact abstraction must distinguish the opposite-answer pairs in \cref{tab:projection-pairs}; both incidence erasures remain inexact despite retaining all marginals.
% 每个精确抽象都必须区分 \cref{tab:projection-pairs} 中答案相反的配对；两种关联擦除即使保留全部边际记录仍不精确。
No exact compiler factors through caller-proposed target-only \(\tau_{\rm tgt}\); generalized nonblocking becomes exact only after trusted derivation supplies the target and markings.
% 不存在经由调用方提出的仅目标 \(\tau_{\rm tgt}\) 的精确编译器；广义非阻塞只有在可信推导提供目标与标记之后才变得精确。

\item \textbf{Sequence closure.}
% 序列闭包。
Each fully parameterized trusted event \(e\) induces a partial function \(\partial\) on pointed state--event orbits, defined exactly when \(e\) is enabled:
% 每个参数完整的可信事件 \(e\) 在带指向的状态--事件轨道上诱导一个偏函数 \(\partial\)，且该函数恰在 \(e\) 启用时有定义：
\[
\begin{aligned}
&\mathsf{AgentSec}(S;c,r)\land S\xrightarrow e S'\\[-2pt]
&\quad\Longrightarrow \exists c',r'.\
  \mathsf{AgentSec}(S';c',r')\\[-2pt]
&\qquad\land [\mathsf{Sec}(S';c',r')]_{\cong}
  =\partial(\langle\mathsf{Sec}(S;c,r),e\rangle_{\cong}).
\end{aligned}
\]
The family covers all six edits and modeled use, ledger, installation, and crash events in an installed registered slice.
% 该事件族覆盖已安装注册切片内全部六种编辑以及已建模的使用、账本、安装和崩溃事件。
For a finite event word \(\bar e\), the iterated derivative uses \(\langle V,\bar e\rangle_{\cong}\) with one renaming of \(V\) and the whole word, so identifiers carried between events cannot be renamed independently.
% 对于有限事件词 \(\bar e\)，迭代导数使用 \(\langle V,\bar e\rangle_{\cong}\)，并对 \(V\) 与整个事件词应用同一次重命名，因此事件之间传递的标识符不能被独立重命名。
Thus the characterization holds after every finite prefix of an arbitrarily long sequence of these events; registration is a separate root-admission phase.
% 因此，该刻画在这些事件组成的任意长序列的每个有限前缀后均成立；注册属于独立的根准入阶段。

\item \textbf{Durable realization.}
% 持久实现。
\(\mathcal R\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}\): either side's step with label \(\ell\) has a matching \(\xRightarrow{\mathsf{obs}(\ell)}\) path to a related state.
% \(\mathcal R\) 在 \(\mathsf{obs}\) 下是发散不敏感弱互模拟：任一侧标签为 \(\ell\) 的一步都有一条匹配的 \(\xRightarrow{\mathsf{obs}(\ell)}\) 路径到达相关状态。
Hence every good initial pair satisfies \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\).
% 因此，每个良好初始对都满足 \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\)。
\end{enumerate}
\end{theorem}

\(\mathcal R\) composes disjoint policy domains by asynchronous product.
% \(\mathcal R\) 通过异步积组合互不相交的策略域。
