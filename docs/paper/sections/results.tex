\section{Agent Security-State Characterization}
% Agent 安全状态刻画
\label{sec:results}

The main theorem characterizes one state unifying schema checking, nonblocking synthesis, and epoch installation.
% 主定理刻画一种统一模式检查、非阻塞综合与纪元安装的状态。
For a history-judgment witness \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\), an \emph{exact atomic realization} \((M,\widehat B_M)\) realizes \((H,u)\) through \((\mathsf{Gen}(M,q^0),\widehat B_M)\) with \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\).
% 对于历史判定见证 \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\)，\emph{精确原子实现} \((M,\widehat B_M)\) 通过 \((\mathsf{Gen}(M,q^0),\widehat B_M)\) 实现 \((H,u)\)，满足 \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\)。
An exact atomic realization swaps in \((\kappa_u,H_u,\mathcal A_u)\), closes \(\eta^-\), activates \(M\) at \(\eta^+\), binds the target gates, and then publishes replacement handles.
% 精确原子实现换入 \((\kappa_u,H_u,\mathcal A_u)\)、关闭 \(\eta^-\)、在 \(\eta^+\) 激活 \(M\)、绑定目标门，随后发布替换句柄。
The swap is defined independently of \(\mathsf{Admit}\), \(\widehat B^\dagger\), \(\mathsf{Compile}\), \(\mathsf{Edge}\), and the canonical monitor.
% 该切换独立于 \(\mathsf{Admit}\)、\(\widehat B^\dagger\)、\(\mathsf{Compile}\)、\(\mathsf{Edge}\) 和规范监控器而定义。

\paragraph{Relational evidence}
% 关系证据
At a checked cut, four finite keyed factors record promised topology, schemas, lifts, and retirement in \(\mathbf P\); occurrence--cell identity, invocation, and lineage in \(\mathbf I\); resolved progress, receipts, results, outbox, and policy in \(\mathbf E\); and versions, epoch ownership, certificates, and cut coordinates in \(\mathbf C\).
% 在一个经检查的切点处，四个有限带键因子分别记录：\(\mathbf P\) 中的承诺拓扑、模式、提升和退役；\(\mathbf I\) 中的发生项--单元标识、调用和谱系；\(\mathbf E\) 中的已解析进展、回执、结果、发件箱和策略；以及 \(\mathbf C\) 中的版本、纪元所有权、证书和切点坐标。
Their normalized natural join is the incidence-preserving view
% 它们的规范化自然连接是保持关联关系的视图
\[
 \mathsf{Sec}(S;c,r)=
 \mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C .
\]
The appendix assigns every base field and transitive dependency, defines dependency-closed projections \(\pi_J,\pi_{\neg oc},\pi_{\neg rc}\), and fixes query-relative private-name orbits \(\langle V,q\rangle_{\cong}\).
% 附录为每个基础字段及传递依赖指定所有者，定义依赖闭合投影 \(\pi_J,\pi_{\neg oc},\pi_{\neg rc}\)，并确定关于查询的私有名称轨道 \(\langle V,q\rangle_{\cong}\)。
For semantic answer \(\mathsf{Ans}(V,q)\), an equivariant abstraction \(\tau\) is exact when some decoder satisfies
% 对于语义答案 \(\mathsf{Ans}(V,q)\)，当存在某个解码器满足下式时，等变抽象 \(\tau\) 是精确的：
\[
 \mathsf{Exact}(\tau)\Longleftrightarrow
 \exists D_\tau.\ \forall V,q.\
 D_\tau(\langle\tau(V),q\rangle_{\cong})=[\mathsf{Ans}(V,q)]_{\cong}.
\]
Thus the lower bound concerns information, not a literal storage layout.
% 因而，该下界约束的是信息，而非字面存储布局。

\paragraph{Durable observation}
% 持久观测
The security alphabet is \(\mathcal O=\{\mathsf{Edge}(u),\Fresh(x,d),\Alias(x,d),\mathsf{deny}(x),\Dispatch(d)\}\).
% 安全字母表为 \(\mathcal O=\{\mathsf{Edge}(u),\Fresh(x,d),\Alias(x,d),\mathsf{deny}(x),\Dispatch(d)\}\)。
The relabeling \(\mathsf{obs}\) exposes protected \Fresh/\Alias uses, successful history edges, denials, and dispatches and maps compilation protocol to \(\tau\); write \(\xRightarrow{\ell}=\tau^*\ell\tau^*\).
% 重标记 \(\mathsf{obs}\) 暴露受保护的 \Fresh/\Alias 使用、成功历史边、拒绝与派发，并把编译协议映射为 \(\tau\)；记 \(\xRightarrow{\ell}=\tau^*\ell\tau^*\)。
The normalizations \(\alpha_I,\alpha_S\) retain history, receipts, outbox, semantic cut, resolved prefix, results, current epoch, and live bindings but erase representation-only protocol state.
% 规范化 \(\alpha_I,\alpha_S\) 保留历史、回执、发件箱、语义切点、已解析前缀、结果、当前纪元与活跃绑定，但擦除仅与表示有关的协议状态。
Define
% 定义
\[
\begin{aligned}
 I\,\mathcal R\,S\quad\Longleftrightarrow\quad
 &\exists c,r.\ \mathsf{AgentSec}(S;c,r)\\[-2pt]
 &{}\land\alpha_I(I;\mathsf{icut}(c),r)=\alpha_S(S;c,r).
\end{aligned}
\]
A \emph{good initial pair} satisfies \(\mathcal R\) with \(r=\epsilon\) immediately after a checked atomic installation.
% \emph{良好初始对}在一次经检查的原子安装后立即以 \(r=\epsilon\) 满足 \(\mathcal R\)。

\begin{theorem}[Agent Security-State Characterization]
% Agent 安全状态刻画
\label{thm:exact-history}
Assume the trusted boundary of \cref{sec:model}.
% 假定 \cref{sec:model} 的可信边界。
For every finite typed Agent workflow \(A\) and registered slice \(R\), the first clause holds.
% 对每个有限类型化 Agent 工作流 \(A\) 与注册切片 \(R\)，第一条款均成立。
Whenever registration accepts and checked root installation has produced a finite reachable \(S\) satisfying \(\mathsf{AgentSec}(S;c,r)\), let \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\); the remaining clauses hold for every such state and request.
% 只要注册被接受且经检查的根安装已经产生一个满足 \(\mathsf{AgentSec}(S;c,r)\) 的有限可达状态 \(S\)，就令 \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\)；其余条款对每个这样的状态和请求均成立。
\begin{enumerate}[leftmargin=*,itemsep=2pt]
\item \textbf{Registration reflection.}
% 注册反射。
\(\mathsf{CheckReg}(A,R)\) accepts iff \(A\sqsubseteq R\) satisfies \cref{def:registration-refinement}.
% 当且仅当 \(A\sqsubseteq R\) 满足 \cref{def:registration-refinement} 时，\(\mathsf{CheckReg}(A,R)\) 才接受。
On acceptance, compilation and pullback are inverse on source and registered realizations, preserving outcome indices, causal order, canonical cell equality, \Fresh/\Alias resolution, and admission.
% 接受时，编译与回拉在源工作流实现和注册实现上互为逆映射，并保持结果索引、因果次序、规范单元相等性、\Fresh/\Alias 解析与准入。
Thus a greatest registered monitor induces the greatest source-workflow monitor, while a missing promise, inconsistent cell row, or unmediated durable edge is rejected before bootstrap.
% 因而，最大的注册监控器会诱导最大的源工作流监控器，而缺失的承诺、不一致的单元记录或未经中介的持久边会在引导前被拒绝。

\item \textbf{Exact compilation.}
% 精确编译。
Without a history derivation, \(\mathsf{Compile}\) rejects structurally and both machines disable \(\mathsf{Edge}(u)\).
% 若历史推导不存在，\(\mathsf{Compile}\) 会作出结构拒绝，且两台机器都禁用 \(\mathsf{Edge}(u)\)。
Otherwise let \(\delta\) be its unique witness, set \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\), and let \(c_\delta^+\) be the checked installed record; all subscripts below are \(\delta\)-derived, and the following are equivalent.
% 否则，令 \(\delta\) 为其唯一见证，置 \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，并令 \(c_\delta^+\) 为经检查的安装记录；下文所有下标均由 \(\delta\) 派生，且以下条件等价。
\[
\begin{aligned}
 &\widehat B^\dagger_\delta\ne\varnothing;\\
 &\text{an exact atomic realization of }(H,u,\delta)\text{ exists};\\
 &\mathsf{Out}_\delta\models\cref{eq:install-premise};\\
 &\exists S^+.\ S\xRightarrow{\mathsf{Edge}(u)}S^+
       \land\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon).
\end{aligned}
\]
When these conditions hold, \((W^\dagger_\delta,\widehat B^\dagger_\delta)\) is greatest and \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) is canonical.
% 当这些条件成立时，\((W^\dagger_\delta,\widehat B^\dagger_\delta)\) 为最大实现，且 \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) 为规范监控器。
Invalid requests have no derivation; a ranked chain ending in \(\varnothing\) excludes every realization.
% 无效请求不存在推导；以 \(\varnothing\) 结束的带秩链会排除所有实现。

\item \textbf{Factor tightness.}
% 因子紧致性。
The full join is sufficient, and every proper factor projection is insufficient:
% 完整连接是充分的，而每个真因子投影均不充分：
\[
 \mathsf{Exact}(\pi_J)
 \quad\Longleftrightarrow\quad
 J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
Every exact abstraction must distinguish the opposite-answer pairs in \cref{tab:projection-pairs}; both incidence erasures remain inexact despite retaining all marginals.
% 每个精确抽象都必须区分 \cref{tab:projection-pairs} 中答案相反的配对；两种关联擦除即使保留全部边际记录仍不精确。
No exact compiler factors through caller-proposed target-only \(\tau_{\rm tgt}\); generalized nonblocking becomes exact only after trusted derivation supplies the target and markings.
% 不存在经由调用方提出的仅目标 \(\tau_{\rm tgt}\) 的精确编译器；广义非阻塞只有在可信推导提供目标与标记之后才变得精确。

\item \textbf{Sequence closure.}
% 序列闭包。
Each fully parameterized trusted event \(e\) induces a partial function \(\partial\) on pointed state--event orbits, defined exactly when \(e\) is enabled:
% 每个参数完整的可信事件 \(e\) 在带指向的状态--事件轨道上诱导一个偏函数 \(\partial\)，且该函数恰在 \(e\) 启用时有定义：
\[
\begin{aligned}
&\mathsf{AgentSec}(S;c,r)\land S\xrightarrow e S'\\[-2pt]
&\quad\Longrightarrow \exists c',r'.\
  \mathsf{AgentSec}(S';c',r')\\[-2pt]
&\qquad\land [\mathsf{Sec}(S';c',r')]_{\cong}
  =\partial(\langle\mathsf{Sec}(S;c,r),e\rangle_{\cong}).
\end{aligned}
\]
The family covers all six edits, authenticated live extension, use, ledger, installation, and crash; iterating \(\partial\) on one jointly renamed finite event word proves the characterization after every finite prefix of an arbitrarily long history, including additive schema/policy growth without reset.
% 该事件族覆盖全部六种编辑、经认证在线扩展、使用、账本、安装与崩溃；在一个联合重命名的有限事件词上迭代 \(\partial\)，即可证明该刻画在任意长历史的每个有限前缀后成立，其中包括无需重置的仅追加模式/策略增长。

\item \textbf{Durable realization.}
% 持久实现。
\(\mathcal R\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}\): either side's step with label \(\ell\) has a matching \(\xRightarrow{\mathsf{obs}(\ell)}\) path to a related state.
% \(\mathcal R\) 在 \(\mathsf{obs}\) 下是发散不敏感弱互模拟：任一侧标签为 \(\ell\) 的一步都有一条匹配的 \(\xRightarrow{\mathsf{obs}(\ell)}\) 路径到达相关状态。
Hence every good initial pair satisfies \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\).
% 因此，每个良好初始对都满足 \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\)。
\end{enumerate}
\end{theorem}

\(\mathcal R\) composes disjoint policy domains by asynchronous product.
% \(\mathcal R\) 通过异步积组合互不相交的策略域。

\begin{proof}[Proof sketch]
% 证明概要。
Finite-checker reflection, greatest-fixed-point induction, opposite-answer pairs, and event induction prove the five clauses; the appendix gives the witnesses and durable simulation.
% 有限检查器反射、最大不动点归纳、答案相反配对与事件归纳证明五个条款；附录给出见证与持久模拟。
\end{proof}
