\section{Agent Security-State Characterization}
% Agent 安全状态刻画
\label{sec:results}

The main theorem characterizes one state unifying schema checking, nonblocking synthesis, and epoch installation.
% 主定理刻画一种统一模式检查、非阻塞综合与纪元安装的状态。
For a history-judgment witness \(\delta=(H^+,\mathcal C,\eta^-,\eta^+)\), an \emph{exact atomic realization} \((M,\widehat B_M)\) realizes \((H,u)\) through \((\mathsf{Gen}(M,q^0),\widehat B_M)\) with \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\).
% 对于历史判定见证 \(\delta=(H^+,\mathcal C,\eta^-,\eta^+)\)，\emph{精确原子实现} \((M,\widehat B_M)\) 通过 \((\mathsf{Gen}(M,q^0),\widehat B_M)\) 实现 \((H,u)\)，满足 \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\)。
An exact atomic realization swaps in \(H^+\), closes \(\eta^-\), activates \(M\) at \(\eta^+\), binds the target gates, and then publishes replacement handles.
% 精确原子实现换入 \(H^+\)、关闭 \(\eta^-\)、在 \(\eta^+\) 激活 \(M\)、绑定目标门，随后发布替换句柄。
The swap is defined independently of \(\mathsf{Admit}\), \(\widehat B^\dagger\), \(\mathsf{Compile}\), \(\mathsf{Edge}\), and the canonical monitor.
% 该切换独立于 \(\mathsf{Admit}\)、\(\widehat B^\dagger\)、\(\mathsf{Compile}\)、\(\mathsf{Edge}\) 和规范监控器而定义。

\paragraph{Relational evidence}
% 关系证据
At a checked cut, four finite keyed factors record (1) live/checkpoint contracts, schemas, lifts, and retirement in \(\mathbf P\); (2) occurrence--cell, gate, handle, lineage, label, and digest incidence in \(\mathbf I\); (3) cursors, receipt--cell records, result futures, outbox order, and residual policy in \(\mathbf E\); and (4) domain and policy/schema versions, finite epoch phase/freshness and gate ownership, the active epoch, generations, certificate metadata, and checkpoint coordinates in \(\mathbf C\).
% 在一个经检查的切点处，四个有限带键因子分别记录：(1) \(\mathbf P\) 中的活跃/检查点契约、模式、提升和退役；(2) \(\mathbf I\) 中的发生项--单元、门、句柄、谱系、标签和摘要关联；(3) \(\mathbf E\) 中的游标、回执--单元记录、结果期值、发件箱次序和残余策略；以及 (4) \(\mathbf C\) 中的域与策略/模式版本、有限纪元阶段/新鲜性与门所有权、活跃纪元、世代、证书元数据和检查点坐标。
Their normalized natural join \(\bowtie\) uses shared typed outcome, occurrence, cell, checkpoint, domain, and version keys, is undefined on disagreement, stores each semantic field once, and canonically recomposes raw checked certificates.
% 它们的规范化自然连接 \(\bowtie\) 使用共享的类型化结果、发生项、单元、检查点、域和版本键，在值不一致时无定义，每个语义字段只存储一次，并规范重组原始的经检查证书。
For \(\mathsf{AgentSec}(S;c,r)\), define the incidence-preserving evidence view
% 对于 \(\mathsf{AgentSec}(S;c,r)\)，定义保持关联关系的证据视图
\[
 \mathsf{Sec}(S;c,r)=
 \mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C .
\]
This view binds checkpoints to contracts/cursors/registries, occurrences to outcomes/cells, receipts to cells, and the cursor to the history cut.
% 该视图把检查点绑定到契约/游标/注册表，把发生项绑定到结果/单元，把回执绑定到单元，并把游标绑定到历史切点。
For \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\), \(\pi_J\) projects to the named records modulo private-identifier renaming that fixes public labels and the request, recursively removing foreign-key paths, certificate components, seals, and digests whose payload mentions an erased field.
% 对 \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\)，\(\pi_J\) 在固定公开标签与请求的私有标识重命名意义下投影到具名记录，并递归移除载荷提及已擦除字段的外键路径、证书组件、封印和摘要。
\(\pi_{\neg oc}\) retains all marginal occurrence/cell records but recursively erases their incidence; \(\pi_{\neg rc}\) similarly retains marginal receipt, creator, occurrence, and cell records but erases receipt--cell incidence and reconstructing paths, including receipt--creator and cursor--receipt links.
% \(\pi_{\neg oc}\) 保留全部边际发生项/单元记录，但递归擦除其关联；\(\pi_{\neg rc}\) 类似地保留边际回执、创建者、发生项和单元记录，但擦除回执--单元关联及其重建路径，其中包括回执--创建者和游标--回执链接。
For a finite valid full view \(V\) and typed edit or installation query \(q\), let \(\mathsf{Ans}(V,q)\) be the semantic answer: structural rejection, the greatest realization, or the history-cut installation decision.
% 对于有限有效的完整视图 \(V\) 和带类型的编辑或安装查询 \(q\)，令 \(\mathsf{Ans}(V,q)\) 表示语义答案：结构拒绝、最大实现或历史切点安装判定。
An arbitrary state abstraction \(\tau\) is \emph{exact} when some decoder \(D_\tau\) satisfies
% 当存在某个解码器 \(D_\tau\) 满足下式时，任意状态抽象 \(\tau\) 是\emph{精确的}：
\[
 \mathsf{Exact}(\tau)\ \Longleftrightarrow\
 \exists D_\tau.\ \forall V,q.\
 D_\tau(\tau(V),q)=\mathsf{Ans}(V,q).
\]
Thus exactness constrains information, not a literal storage layout: any opposite-answer pair must remain distinguishable, while an implementation may encode or compress the evidence.
% 因而，精确性约束的是信息而非字面存储布局：任何答案相反的历史对都必须保持可区分，而实现可以对证据进行编码或压缩。

The security observation alphabet is
% 安全观测字母表为
\[
\begin{split}
\mathcal O=\{&\mathsf{Edge}(u),\Fresh(x,d),\Alias(x,d),\\[-2pt]
             &\mathsf{deny}(x),\Dispatch(d)\}.
\end{split}
\]
A fully parameterized trusted event record \(e\) carries every hidden payload used by its guard, and pairs \(([\mathsf{Sec}]_{\cong},e)\) are quotiented simultaneously by private-identifier renaming.
% 参数完整的可信事件记录 \(e\) 携带其守卫使用的全部隐藏载荷，并且二元组 \(([\mathsf{Sec}]_{\cong},e)\) 按私有标识的同步重命名取商。
The relabeling satisfies \(\mathsf{obs}(\Use_x(m)/a)=a\), maps a successful installation record \((\mathsf{Edge}(u),Z,\delta)\) to \(\mathsf{Edge}(u)\), preserves \(\mathsf{deny}(x)\) and \(\Dispatch(d)\), and maps every other label to \(\tau\).
% 重标记满足 \(\mathsf{obs}(\Use_x(m)/a)=a\)，把成功安装记录 \((\mathsf{Edge}(u),Z,\delta)\) 映射为 \(\mathsf{Edge}(u)\)，保持 \(\mathsf{deny}(x)\) 和 \(\Dispatch(d)\)，并把其他所有标签映射为 \(\tau\)。
Write \(\xRightarrow{\ell}\) for \(\tau^*\ell\tau^*\), with \(\xRightarrow{\tau}=\tau^*\).
% 用 \(\xRightarrow{\ell}\) 表示 \(\tau^*\ell\tau^*\)，其中 \(\xRightarrow{\tau}=\tau^*\)。
Let \(\mathcal Q\) contain the normalized history, receipt ledger, outbox, admitted history cut, resolved prefix, result futures, current abstract epoch, and live gate bindings, excluding phase protocol, seals, preload contents, and handoff metadata.
% 令 \(\mathcal Q\) 包含规范化历史、回执账本、发件箱、已准入历史切点、已解析前缀、结果期值、当前抽象纪元和活跃门绑定，但不包含阶段协议、封印、预加载内容与交接元数据。
\(\alpha_I(I;\mathsf{icut}(c),r)\) reads \(\mathcal Q\) from the ideal state, while \(\alpha_S(S;c,r)\) normalizes compiled factors into it, retaining only \(\mathbf C\)'s active epoch and live gate bindings.
% \(\alpha_I(I;\mathsf{icut}(c),r)\) 从理想状态读取 \(\mathcal Q\)，而 \(\alpha_S(S;c,r)\) 将编译后因子规范化到其中，仅保留 \(\mathbf C\) 的活跃纪元和活跃门绑定。
Define
% 定义
\[
\begin{aligned}
 I\,\mathcal R\,S\quad\Longleftrightarrow\quad
 &\exists c,r.\ \mathsf{AgentSec}(S;c,r)\\[-2pt]
 &{}\land\alpha_I(I;\mathsf{icut}(c),r)=\alpha_S(S;c,r).
\end{aligned}
\]
A \emph{good initial pair} satisfies \(\mathcal R\) with \(r=\epsilon\) immediately after a checked atomic installation.
% \emph{良好初始对}在一次经检查的原子安装后立即以 \(r=\epsilon\) 满足 \(\mathcal R\)。

\paragraph{Event derivatives}
% 事件导数
For every fully parameterized trusted event \(e\), let \(G_e\) and \(\mathsf U_e\) be exactly its explicit LTS guard and durable update, and define \(\partial_e([V]_{\cong})=[\mathsf U_e(V)]_{\cong}\) exactly when \(G_e(V)\) holds.
% 对于每个参数完整的可信事件 \(e\)，令 \(G_e\) 和 \(\mathsf U_e\) 恰为其显式 LTS 守卫与持久更新，并且当且仅当 \(G_e(V)\) 成立时定义 \(\partial_e([V]_{\cong})=[\mathsf U_e(V)]_{\cong}\)。
The appendix enumerates all event classes, invariant witnesses, and bidirectional matches; \Use advances to \((c,ra)\), successful \(\mathsf{Edge}\) resets to \((c_\delta^+,\epsilon)\), and every other event retains \((c,r)\).
% 附录枚举全部事件类别、不变量见证和双向匹配；\Use 推进到 \((c,ra)\)，成功的 \(\mathsf{Edge}\) 重置到 \((c_\delta^+,\epsilon)\)，而其他每个事件都保持 \((c,r)\)。

\begin{theorem}[Agent Security-State Characterization]
% Agent 安全状态刻画
\label{thm:exact-history}
Assume the trusted boundary of \cref{sec:model}.
% 假定 \cref{sec:model} 的可信边界。
Let \(S\) be any finite reachable state satisfying \(\mathsf{AgentSec}(S;c,r)\), and let \(u\) be any syntactically well-formed request naming registered objects.
% 令 \(S\) 为任意满足 \(\mathsf{AgentSec}(S;c,r)\) 的有限可达状态，并令 \(u\) 为任意指名已注册对象且语法良构的请求。
\begin{enumerate}[leftmargin=*,itemsep=2pt]
\item \textbf{Exact compilation.}
% 精确编译。
For each derivation witness \(\delta\), write \(\mathsf{Out}_\delta\) for \(\mathsf{Compile}(\kappa,H,\Delta,\mathcal A,u)\) and \(c_\delta^+\) for its checked post-installation record; other subscripts are \(\delta\)-derived.
% 对每个推导见证 \(\delta\)，用 \(\mathsf{Out}_\delta\) 表示 \(\mathsf{Compile}(\kappa,H,\Delta,\mathcal A,u)\)，用 \(c_\delta^+\) 表示其经检查的安装后记录；其他下标均由 \(\delta\) 派生。
The following conditions are equivalent.
% 下列条件等价。
\[
\begin{aligned}
 &\widehat B^\dagger_\delta\ne\varnothing;\\
 &\text{an exact atomic realization of }(H,u,\delta)\text{ exists};\\
 &\mathsf{Out}_\delta\models\cref{eq:install-premise};\\
 &\exists S^+.\ S\xRightarrow{\mathsf{Edge}(u)}S^+
       \land\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon).
\end{aligned}
\]
When they hold, \((W^\dagger_\delta,\widehat B^\dagger_\delta)\) is the greatest realization by componentwise language inclusion, and \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) is its canonical monitor.
% 当这些条件成立时，\((W^\dagger_\delta,\widehat B^\dagger_\delta)\) 按分量语言包含关系是最大实现，并且 \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) 是其规范监控器。
If no derivation witness exists, structural failure certifies an invalid edit; for existing \(\delta\), a ranked chain ending in \(\varnothing\) excludes every realization.
% 若不存在推导见证，结构失败会认证编辑无效；对于已存在的 \(\delta\)，以 \(\varnothing\) 结束的带秩链会排除所有实现。

\item \textbf{Factor tightness.}
% 因子紧致性。
The full join is sufficient, its proper factor projections are insufficient, and
% 完整连接是充分的，其任意真因子投影均不充分，并且
\[
 \mathsf{Exact}(\pi_J)
 \quad\Longleftrightarrow\quad
 J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
More generally, every exact abstraction \(\tau\) must distinguish each opposite-answer pair in \cref{tab:projection-pairs}; this observational lower bound permits any lossless encoding and does not require the four tables literally.
% 更一般地，每个精确抽象 \(\tau\) 都必须区分 \cref{tab:projection-pairs} 中每个答案相反的历史对；这一观测下界允许任意无损编码，而不要求按字面存储四张表。
Moreover, \(\neg\mathsf{Exact}(\pi_{\neg oc})\) and \(\neg\mathsf{Exact}(\pi_{\neg rc})\), even though both views retain every marginal record.
% 此外，\(\neg\mathsf{Exact}(\pi_{\neg oc})\) 且 \(\neg\mathsf{Exact}(\pi_{\neg rc})\)，尽管两种视图都保留每条边际记录。
No exact end-to-end Agent history compiler factors through \(\tau_{\rm tgt}\), which exposes only a caller-proposed target plant, markings, and epoch before trusted derivation, although generalized nonblocking is exact after a valid derivation supplies the target and markings.
% 不存在经由 \(\tau_{\rm tgt}\) 的精确端到端 Agent 历史编译器；该视图在可信推导之前仅暴露调用方提出的目标被控对象、标记和纪元，尽管广义非阻塞在有效推导提供目标与标记后是精确的。

\item \textbf{Sequence closure.}
% 序列闭包。
The guarded updates define partial functions \(\{\partial_e\}_e\) on finite security-state isomorphism classes, with \(\partial_e([\mathsf{Sec}]_{\cong})\) defined exactly when the rule for fully parameterized trusted event \(e\) is enabled.
% 带守卫更新定义了作用于有限安全状态同构类的偏函数族 \(\{\partial_e\}_e\)；当且仅当参数完整的可信事件 \(e\) 的规则启用时，\(\partial_e([\mathsf{Sec}]_{\cong})\) 有定义。
Moreover,
% 此外，
\[
\begin{aligned}
&\mathsf{AgentSec}(S;c,r)\land S\xrightarrow e S'\\[-2pt]
&\quad\Longrightarrow \exists c',r'.\
  \mathsf{AgentSec}(S';c',r')\\[-2pt]
&\qquad\land [\mathsf{Sec}(S';c',r')]_{\cong}
  =\partial_e([\mathsf{Sec}(S;c,r)]_{\cong}).
\end{aligned}
\]
This family covers all six edits and every modeled use, ledger, installation, and crash event in an installed registered protected-call slice, so the characterization applies after every finite prefix of an arbitrarily long sequence; new registrations require a new admission.
% 该事件族覆盖已安装的已注册受保护调用切片内全部六种编辑以及每项已建模的使用、账本、安装和崩溃事件，因此该刻画适用于任意长序列的每个有限前缀；新的注册需要一次新的准入。

\item \textbf{Durable realization.}
% 持久实现。
\(\mathcal R\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}\): if either related side steps with label \(\ell\), the other takes a matching \(\xRightarrow{\mathsf{obs}(\ell)}\) path to a related state, in both directions.
% \(\mathcal R\) 在 \(\mathsf{obs}\) 下是发散不敏感弱互模拟：若相关的任一侧执行标签为 \(\ell\) 的一步，则另一侧沿匹配的 \(\xRightarrow{\mathsf{obs}(\ell)}\) 路径到达相关状态，且两个方向均成立。
Hence every good initial pair satisfies \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\).
% 因此，每个良好初始对都满足 \(S_0\approx_{\mathcal O}^{\mathsf{di}}I_0\)。
\end{enumerate}
\end{theorem}

Componentwise \(\mathcal R\) composes independent policy domains by standard asynchronous-product congruence when their cells, receipt ledgers, and policies are disjoint.
% 当单元、回执账本和策略互不相交时，按分量定义的 \(\mathcal R\) 通过标准异步积同余组合独立策略域。
