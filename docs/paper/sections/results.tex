\section{The Exact Safety Theorem}
% 精确安全定理
\label{sec:results}

The main theorem states the paper's complete theory in one place.
% 主定理在一处陈述本文的完整理论。
It connects authenticated edit derivation, the safety checker, monitor construction, and atomic installation.
% 它连接经认证编辑推导、安全检查器、监控器构造与原子安装。
Here \emph{exact} means that the checker accepts if and only if a safe implementation exists.
% 这里的\emph{精确}是指，当且仅当安全实现存在时，检查器才会接受。
Clause~2 is the central equivalence.
% 第 2 条是核心等价关系。
Clauses~1, 3, 4, and~5 prove faithful registration, the necessity of all four state components, repeated applicability, and correctness of the installed runtime.
% 第 1、3、4、5 条分别证明忠实注册、四类状态信息的必要性、重复适用性以及已安装运行时的正确性。

Fix a derivation witness \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\).
% 固定一个推导见证 \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\)。
An independently defined \emph{installed realization} is a pair \((M,\widehat B_M)\) such that \((\mathsf{Gen}(M,q^0),\widehat B_M)\) realizes \((H,u)\) according to \cref{def:realization} and \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\).
% 独立定义的\emph{已安装实现}是一个二元组 \((M,\widehat B_M)\)，其中 \((\mathsf{Gen}(M,q^0),\widehat B_M)\) 按照 \cref{def:realization} 实现 \((H,u)\)，且 \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\)。
The domain transaction must atomically install \((\kappa_u,H_u,\mathcal A_u,M)\) at \(\eta^+\), close \(\eta^-\), bind the target monitor entries, and publish replacement authorization tokens.
% 域事务必须在 \(\eta^+\) 原子安装 \((\kappa_u,H_u,\mathcal A_u,M)\)、关闭 \(\eta^-\)、绑定目标监控器入口，并发布替代授权令牌。

\paragraph{Information required by any exact checker}
% 任何精确检查器所需的信息
Let \(S\) be the compiled runtime state and \(\mathsf{AgentSec}\) its security invariant.
% 令 \(S\) 为编译后运行时状态，\(\mathsf{AgentSec}\) 为其安全不变量。
At a checked source snapshot, \(\mathsf{Sec}(S;c,r)=\mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C\) joins four kinds of information: workflow structure and edit schemas (\(\mathbf P\)), call-to-effect identity (\(\mathbf I\)), completed and pending effects (\(\mathbf E\)), and monitor-version and installation coordinates (\(\mathbf C\)).
% 在经检查源状态快照处，\(\mathsf{Sec}(S;c,r)=\mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C\) 连接四类信息：工作流结构与编辑模式（\(\mathbf P\)）、调用到效果标识的关系（\(\mathbf I\)）、已完成与待处理效果（\(\mathbf E\)），以及监控器版本与安装坐标（\(\mathbf C\)）。
States are compared up to consistent renaming of private identifiers.
% 状态在私有标识符一致重命名的意义下比较。
\(\mathcal Q_{\rm sec}\) contains every well-typed decide or install query.
% \(\mathcal Q_{\rm sec}\) 包含每个良好定型的判定或安装查询。
For an information map \(f\), define
% 对于信息映射 \(f\)，定义
\[
\mathsf{Exact}(f)\Longleftrightarrow
\exists D_f.\ \forall(V,q)\in\mathcal Q_{\rm sec}.\quad
D_f(\langle f(V),q\rangle_{\cong})
=[\mathsf{Ans}(V,q)]_{\cong}.
\]
Thus \(f\) is exact when some decoder can reproduce every correct answer from the retained information.
% 因此，如果某个解码器能从保留的信息中复现每个正确答案，则 \(f\) 是精确的。
For \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\), projection \(\pi_J\) keeps the factors in \(J\) and removes every field that depends on a discarded factor.
% 对于 \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\)，投影 \(\pi_J\) 保留 \(J\) 中的因子，并删除依赖被丢弃因子的每个字段。
\(\mathsf{TargetOnly}\) keeps only the replacement workflow and completion data proposed by the caller.
% \(\mathsf{TargetOnly}\) 只保留调用方提出的替代工作流与完成数据。
\Cref{app:evidence} gives the complete field dependencies and query semantics.
% \Cref{app:evidence} 给出完整字段依赖与查询语义。
The lower bound concerns information, not its storage layout.
% 该下界约束信息，而非其存储布局。

\paragraph{Required-outcome preservation}
% 要求实现结果的保留
The main theorem uses the following compact condition from \cref{app:spc}:
% 主定理使用 \cref{app:spc} 中的下列紧凑条件：
\[
\begin{aligned}
\mathsf{Preserve}(H,u,\widehat B)
\Longleftrightarrow
\forall a\in\mathsf{Req}_u.\ \exists t\in O_{H,u},b.\quad
\mathsf{Lift}_u(t,a)\land(t,b)\in\widehat B .
\end{aligned}
\]
It says that every required source outcome appears in some accepted target outcome.
% 它表示每个要求实现的源结果都出现在某个被接受的目标结果中。

\paragraph{Visible runtime behavior}
% 可见运行时行为
\(\mathcal O_{\rm api}\) exposes edit answers bound to a specific source snapshot, installed edits, protected-call answers, dispatch, settlement, and authenticated returns.
% \(\mathcal O_{\rm api}\) 暴露绑定特定源状态快照的编辑答案、已安装编辑、受控调用答案、派发、结算与经认证返回。
It quotients private names but preserves public bytes.
% 它对私有名称取商，但保留公开字节。
\(\mathsf{obs}_{\rm api}\) hides only internal computation, preload, Save, stale attempts, and recovered crash.
% \(\mathsf{obs}_{\rm api}\) 只隐藏内部计算、预加载、Save、过期尝试与恢复崩溃。
\(\mathcal R\) relates ideal and compiled states when \(\mathsf{AgentSec}\), source snapshot and current partial execution, monitor version, current bindings, and visible fields agree.
% 当 \(\mathsf{AgentSec}\)、源状态快照与当前部分执行、监控器版本、当前绑定和可见字段一致时，\(\mathcal R\) 关联理想状态与编译状态。
\Cref{app:bisimulation} gives its typed maps, reply linkage, and good initial pairs.
% \Cref{app:bisimulation} 给出其类型化映射、回复链接与良好初始对。

\begin{theorem}[Exact Edit-Safety]
% 精确编辑安全
\label{thm:exact-history}
Under \cref{sec:model}'s boundary, clause 1 holds for every finite-state \(\mathcal W\) and finite \(R\).
% 在 \cref{sec:model} 的边界下，第 1 条对每个有限状态 \(\mathcal W\) 与有限 \(R\) 成立，第 2--5 条对每个满足 \(\mathsf{AgentSec}\) 的有限可达状态上的每个 \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) 成立；注册接受蕴含边界有限性。
Clauses 2--5 hold for every \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) at every finite reachable state satisfying \(\mathsf{AgentSec}\).
% 第 2--5 条对每个满足 \(\mathsf{AgentSec}\) 的有限可达状态上的每个 \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) 成立。
Registration acceptance entails boundary-finiteness.
% 注册接受蕴含边界有限性。
\begin{enumerate}[leftmargin=*,itemsep=0pt]
\item \textbf{Registration reflection.}
% 注册反射。
\(\mathsf{CheckReg}(\mathcal W,R)\) accepts iff stored \(\lambda\) witnesses \(\mathcal W\sqsubseteq_\lambda R\).
% 当且仅当所存 \(\lambda\) 见证 \(\mathcal W\sqsubseteq_\lambda R\) 时，\(\mathsf{CheckReg}(\mathcal W,R)\) 才接受；此时模 \(\equiv_\partial\) 的源执行与 \(\mathsf{BRuns}(R)\) 序同构，并保持结果、次序、单元、\Fresh/\Alias、准入与最大监控器，而缺失承诺、不一致单元或未经中介的持久边会在引导前被拒绝。
Source executions modulo \(\equiv_\partial\) are then order-isomorphic to \(\mathsf{BRuns}(R)\), preserving outcomes, order, cells, \Fresh/\Alias, the safety decision, and the greatest monitor.
% 此时模 \(\equiv_\partial\) 的源执行与 \(\mathsf{BRuns}(R)\) 序同构，并保持结果、次序、单元、\Fresh/\Alias、安全判定与最大监控器。
Missing promises, inconsistent cells, or unmediated durable edges reject before bootstrap.
% 缺失承诺、不一致单元或未经中介的持久边会在引导前被拒绝。

\item \textbf{Exact compilation.}
% 精确编译。
For \(\Theta=\Theta_S(u)\), both machines share one trichotomy bound to the same decision cut.
% 对于 \(\Theta=\Theta_S(u)\)，两台机器共享一种绑定切点的三分判定：未定义推导给出经验证且保持状态的 \(\mathsf{Invalid}\)；唯一 \(\delta\) 满足 \(\widehat B^\dagger_\delta=\varnothing\) 时给出经验证且保持状态的 \(\mathsf{Reject}\)，且不存在精确实现；否则令 \(Y=\mathsf{Compile}(\Theta)\)，并令 \(c_\delta^+\) 为经检查记录。
An undefined derivation gives a verified, state-preserving \(\mathsf{Invalid}\).
% 未定义推导给出经验证且保持状态的 \(\mathsf{Invalid}\)。
A unique \(\delta\) with \(\widehat B^\dagger_\delta=\varnothing\) gives a verified, state-preserving \(\mathsf{Reject}\) and no installed atomic realization.
% 唯一 \(\delta\) 满足 \(\widehat B^\dagger_\delta=\varnothing\) 时给出经验证且保持状态的 \(\mathsf{Reject}\)，且不存在精确实现。
Otherwise, let \(Y=\mathsf{Compile}(\Theta)\) and \(c_\delta^+\) be the checked record.
% 否则，令 \(Y=\mathsf{Compile}(\Theta)\)，并令 \(c_\delta^+\) 为经检查记录。
In this positive case, the following conditions are equivalent: (1) \(\widehat B^\dagger_\delta\ne\varnothing\), (2) an installed atomic realization exists, (3) \(\mathsf{Ready}(S,u,Y)\) holds, and (4) an \(\mathsf{Edge}(u,[\mathcal H_u^+]_{\cong})\) successor satisfies \(\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon)\).
% 在正面情形中，\(\widehat B^\dagger_\delta\ne\varnothing\)、精确实现存在、\(\mathsf{Ready}(S,u,Y)\) 以及存在满足 \(\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon)\) 的 \(\mathsf{Edge}(u,[\mathcal H_u^+]_{\cong})\) 后继彼此等价；最大见证与规范监控器满足 \(\mathsf{SPC}\)，而该边保留 \(\mathsf{Done}_{H,u}\) 的证据并记录 \(\mathsf{Dec}_{H,u}\)。
The greatest witness and canonical monitor satisfy \(\mathsf{SPC}\), while the edge retains \(\mathsf{Done}_{H,u}\)'s evidence and records \(\mathsf{Dec}_{H,u}\).
% 最大见证与规范监控器满足 \(\mathsf{SPC}\)，而该边保留 \(\mathsf{Done}_{H,u}\) 的证据并记录 \(\mathsf{Dec}_{H,u}\)。
The three verdict classes are mutually exclusive and exhaustive at the same decision cut.
% 三类判定在同一决策切点上互斥且穷尽。

\item \textbf{Factor tightness.}
% 因子紧致性。
The full join is sufficient, and every proper factor projection is insufficient:
% 完整连接充分而每个真因子投影均不充分：\(\mathsf{Exact}(\pi_J)\Longleftrightarrow J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\)。
\[
\mathsf{Exact}(\pi_J)\Longleftrightarrow
J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
Every exact abstraction distinguishes \cref{tab:projection-pairs}; incidence erasures and caller-proposed target-only \(\tau_{\rm tgt}\) remain inexact, while generalized nonblocking becomes exact after trusted target/marking derivation.
% 每个精确抽象都区分 \cref{tab:projection-pairs}；关联擦除与调用方提出的仅目标 \(\tau_{\rm tgt}\) 仍不精确，而广义非阻塞在可信目标/标记派生之后变得精确。

\item \textbf{Sequence closure.}
% 序列闭包。
Every enabled fully parameterized event induces the corresponding partial derivative on the private-name equivalence classes of \(\mathsf{Sec}\) and preserves \(\mathsf{AgentSec}\).
% 每个启用且参数完整的事件都在安全状态轨道上诱导相应的偏导数，并保持 \(\mathsf{AgentSec}\)。
Iteration covers every finite prefix of edits, live extension, protected use, ledger, installation, and crash, with finite cuts but no uniform history-length bound.
% 迭代覆盖编辑、在线扩展、受保护使用、账本、安装与崩溃组成的每个有限前缀；每个切点有限，但不存在统一历史长度界。

\item \textbf{Durable Agent-API realization.}
% 持久 Agent API 实现。
\(\mathcal R\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}_{\rm api}\), so every good pair satisfies \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\).
% \(\mathcal R\) 在 \(\mathsf{obs}_{\rm api}\) 下是发散不敏感弱互模拟，因此每个良好对均满足 \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\)。
The observation includes verdicts tied to the authenticated history cut, bundles, and results, but excludes time, fairness, and post-\(\Dispatch\) networking.
% \(\mathcal R\) 在 \(\mathsf{obs}_{\rm api}\) 下是发散不敏感弱互模拟，所以每个良好对都满足 \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\)，其中包括绑定切点的判定、包与结果，但不包括时间、公平性与 \(\Dispatch\) 后网络行为。
Disjoint domains compose asynchronously.
% 互不相交的域异步组合。
\end{enumerate}
\end{theorem}

\begin{proof}[Proof sketch]
% 证明概要。
Schema conservation and finite-checker reflection prove Clause~1, fixed-point reasoning proves Clause~2, opposite-answer pairs prove Clause~3, and event induction together with durable simulation proves Clauses~4 and~5.
% 模式守恒与有限检查器反射证明第 1 条，不动点推理证明第 2 条，相反答案对证明第 3 条，事件归纳证明第 4 条和第 5 条。
The appendix supplies the witnesses and durable simulation.
% 模式守恒、有限检查器反射、不动点与事件归纳以及答案相反配对证明这些条款；附录给出全部见证与持久模拟。
\end{proof}
