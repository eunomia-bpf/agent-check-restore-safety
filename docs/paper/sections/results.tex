\section{The Exact Safety Theorem}
% 精确安全定理
\label{sec:results}

The theorem connects authenticated edit derivation, exact checking, monitor construction, atomic installation, and every later runtime step.
% 该定理连接经认证编辑推导、精确检查、监控器构造、原子安装以及此后的每个运行时步骤。
Its central clause says that the checker accepts if and only if a safe implementation exists; the other clauses establish faithful registration, necessary state information, repeated use, and runtime correctness.
% 其核心条款表明，当且仅当安全实现存在时，检查器才会接受；其余条款建立忠实注册、必要状态信息、重复使用与运行时正确性。

Fix \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\).
% 固定 \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\)。
An \emph{installed realization} is a pair \((M,\widehat B_M)\) whose generated and marked languages realize \((H,u)\) as in \cref{def:realization}, installed atomically at \(\eta^+\) while \(\eta^-\) is closed and all target monitor entries and tokens are replaced.
% \emph{已安装实现}是二元组 \((M,\widehat B_M)\)，其生成语言与标记语言按 \cref{def:realization} 实现 \((H,u)\)，并在关闭 \(\eta^-\) 且替换全部目标监控器入口与令牌的同时原子安装到 \(\eta^+\)。

\paragraph{Information required end to end}
% 端到端所需的信息
At a checked source snapshot, \(\mathsf{Sec}(S;c,r)=\mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C\) joins workflow structure and schemas (\(\mathbf P\)), call--effect identity (\(\mathbf I\)), effect progress (\(\mathbf E\)), and monitor-version and installation coordinates (\(\mathbf C\)).
% 在经检查源状态快照处，\(\mathsf{Sec}(S;c,r)=\mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C\) 连接工作流结构与模式（\(\mathbf P\)）、调用—效果标识（\(\mathbf I\)）、效果进度（\(\mathbf E\)），以及监控器版本与安装坐标（\(\mathbf C\)）。
For every well-typed decide or install query \((V,q)\in\mathcal Q_{\rm sec}\), compare private names up to consistent renaming and define an equivariant information map \(f\) to be exact when
% 对每个良好定型的判定或安装查询 \((V,q)\in\mathcal Q_{\rm sec}\)，私有名称按一致重命名比较，并在下列条件成立时称等变信息映射 \(f\) 是精确的：
\[
\begin{aligned}
\mathsf{Exact}(f)
&\Longleftrightarrow
\exists D_f.\ \forall(V,q)\in\mathcal Q_{\rm sec},\\[-2pt]
&\qquad D_f(\langle f(V),q\rangle_{\cong})
=[\mathsf{Ans}(V,q)]_{\cong}.
\end{aligned}
\]
Projection \(\pi_J\) keeps \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\) and deletes dependent fields; \(\mathsf{TargetOnly}\) keeps only caller-proposed target data.
% 投影 \(\pi_J\) 保留 \(J\subseteq\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}\) 并删除依赖字段；\(\mathsf{TargetOnly}\) 只保留调用方提出的目标数据。
\Cref{app:evidence} gives the exact dependencies and shows that the lower bound concerns information, not storage layout.
% \Cref{app:evidence} 给出精确依赖关系，并说明该下界约束信息而非存储布局。

\paragraph{Required-outcome preservation}
% 要求实现结果的保留
\[
\begin{aligned}
\mathsf{Preserve}(H,u,\widehat B)
&\Longleftrightarrow
\forall a\in\mathsf{Req}_u.\ \exists t\in O_{H,u},b,\\[-2pt]
&\qquad \mathsf{Lift}_u(t,a)\land(t,b)\in\widehat B .
\end{aligned}
\]
Thus every required source outcome appears in an accepted target outcome.
% 因而，每个要求实现的源结果都出现在某个被接受的目标结果中。

\paragraph{Visible runtime behavior}
% 可见运行时行为
\(\mathcal O_{\rm api}\) exposes snapshot-bound edit answers, installed edits, protected-call answers, dispatch, settlement, and authenticated returns, while hiding only internal work, Save, stale attempts, and recovered crashes.
% \(\mathcal O_{\rm api}\) 暴露绑定状态快照的编辑答案、已安装编辑、受控调用答案、派发、结算与经认证返回，同时只隐藏内部工作、Save、过期尝试与恢复后的崩溃。
\(\mathcal B\) matches ideal and compiled states on \(\mathsf{AgentSec}\) and these visible fields; \cref{app:bisimulation} gives the full relation.
% \(\mathcal B\) 在 \(\mathsf{AgentSec}\) 与这些可见字段上匹配理想状态和编译后状态；\cref{app:bisimulation} 给出完整关系。

\begin{theorem}[Exact Edit-Safety]
% 精确编辑安全
\label{thm:exact-history}
Clause~1 holds for finite-state \(\mathcal W\) and finite \(R\).
% 第 1 条对有限状态 \(\mathcal W\) 与有限 \(R\) 成立。
For Clauses~2--5, assume accepted registration, complete control and mediation of every protected call, and crash-stable linearizable transactions within each policy domain.
% 对于第 2--5 条，假设注册已通过、每次受控调用都受到完全控制与中介，并且每个策略域内采用崩溃稳定且可线性化的事务。
Then they hold for every \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) at every finite reachable \(\mathsf{AgentSec}\) state.
% 此时，它们对每个有限可达 \(\mathsf{AgentSec}\) 状态上的每个 \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) 成立。
\begin{enumerate}[leftmargin=*,itemsep=0pt]
\item \textbf{Faithful registration.}
% 忠实注册。
\(\mathsf{CheckReg}(\mathcal W,R)\) accepts iff stored \(\lambda\) witnesses \(\mathcal W\sqsubseteq_\lambda R\).
% 当且仅当所存 \(\lambda\) 见证 \(\mathcal W\sqsubseteq_\lambda R\) 时，\(\mathsf{CheckReg}(\mathcal W,R)\) 才接受。
On acceptance, the source workflow's protected-call traces and \(\mathsf{BRuns}(R)\) are order-isomorphic and preserve outcomes, effect identities, \Fresh/\Alias, the safety answer, and the most permissive monitor; malformed registrations fail before startup.
% 接受时，源工作流的受控调用轨迹与 \(\mathsf{BRuns}(R)\) 序同构，并保持结果、效果标识、\Fresh/\Alias、安全答案与限制最少的监控器；不合格的注册在启动前失败。

\item \textbf{Exact checking and construction.}
% 精确检查与构造。
The ideal and compiled machines return the same mutually exclusive and exhaustive answer for \(\Theta=\Theta_S(u)\): undefined derivation gives state-preserving \(\mathsf{Invalid}\), and \(\widehat B^\dagger_\delta=\varnothing\) gives state-preserving \(\mathsf{Reject}\) with no installed realization.
% 对于 \(\Theta=\Theta_S(u)\)，理想机与编译后机器返回相同且互斥穷尽的答案：未定义推导给出保持状态的 \(\mathsf{Invalid}\)，而 \(\widehat B^\dagger_\delta=\varnothing\) 给出保持状态的 \(\mathsf{Reject}\)，且不存在已安装实现。
Otherwise, for \(Y=\mathsf{Compile}(\Theta)\), nonempty \(\widehat B^\dagger_\delta\), existence of an installed realization, \(\mathsf{Ready}(S,u,Y)\), and an \(\mathsf{AgentSec}\)-preserving installed successor are equivalent.
% 否则，对于 \(Y=\mathsf{Compile}(\Theta)\)，\(\widehat B^\dagger_\delta\) 非空、已安装实现存在、\(\mathsf{Ready}(S,u,Y)\) 成立，以及存在保持 \(\mathsf{AgentSec}\) 的已安装后继，这四项彼此等价。
The largest execution family satisfies \(\mathsf{Preserve}\), retains recorded evidence for every already-satisfied source outcome, and records every authorized removal.
% 最大执行族满足 \(\mathsf{Preserve}\)，保留每个已满足源结果的记录证据，并记录每项获授权移除。

\item \textbf{Each of four state relations is necessary for exact answers.}
% 四类状态关系中的每一类都是精确答案所必需的。
Within this field decomposition, the full information view is sufficient, and every projection that discards a relation is insufficient:
% 在这一字段分解下，完整信息视图是充分的，而丢弃任一关系的每种投影都不充分：
\[
\mathsf{Exact}(\pi_J)\Longleftrightarrow
J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
Every exact decision-and-installation information map distinguishes every separating state--query pair in \cref{tab:projection-pairs}.
% 每个精确信息映射都区分 \cref{tab:projection-pairs} 中的每对分离状态—查询对。
Maps that erase the call-to-effect link or the link between authorization records and effect identities, as well as \(\mathsf{TargetOnly}\), are inexact.
% 擦除调用到效果标识关系、授权记录到效果标识关系的信息映射以及 \(\mathsf{TargetOnly}\) 都不精确。
Generalized nonblocking can serve as an exact solver only after the trusted controller derives the workflow and outcome-specific completion conditions.
% 只有在可信控制器推导出工作流以及特定于结果的完成条件之后，广义非阻塞才能作为精确求解器。

\item \textbf{Repeated use.}
% 重复使用。
Every enabled event preserves \(\mathsf{AgentSec}\), so the theorem applies after every finite reachable sequence of edits, registered extensions, protected calls, authorization-log updates, installations, and crashes, without a uniform execution-length bound.
% 每个启用事件都保持 \(\mathsf{AgentSec}\)，因此该定理适用于由编辑、已注册扩展、受控调用、授权日志更新、安装和崩溃组成的每个有限可达序列，而无需统一的执行长度上界。

\item \textbf{Runtime correctness.}
% 运行时正确性。
\(\mathcal B\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}_{\rm api}\), so every good pair satisfies \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\).
% \(\mathcal B\) 在 \(\mathsf{obs}_{\rm api}\) 下是发散不敏感弱互模拟，因此每个良好对均满足 \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\)。
The observation includes snapshot-bound answers, replacement authorization tokens, and returns, but excludes time, fairness, and networking after \(\Dispatch\); disjoint domains compose asynchronously.
% 该观测包括绑定状态快照的答案、替代授权令牌与返回，但不包括时间、公平性和 \(\Dispatch\) 之后的网络行为；互不相交的域异步组合。
\end{enumerate}
\end{theorem}

The appendix proves all five clauses and supplies the separating witnesses and runtime simulation.
% 附录证明全部五项条款，并给出分离见证与运行时模拟。
