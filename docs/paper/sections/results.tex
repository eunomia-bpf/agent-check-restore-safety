\section{Agent Security-State Characterization}
% Agent 安全状态刻画
\label{sec:results}

The main theorem characterizes one state unifying schema checking, nonblocking synthesis, and epoch installation.
% 主定理刻画一种统一模式检查、非阻塞综合与纪元安装的状态。
For a history-judgment witness \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\), an \emph{exact atomic realization} \((M,\widehat B_M)\) realizes \((H,u)\) through \((\mathsf{Gen}(M,q^0),\widehat B_M)\) with \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\).
% 对于历史判定见证 \(\delta=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\)，\emph{精确原子实现} \((M,\widehat B_M)\) 通过 \((\mathsf{Gen}(M,q^0),\widehat B_M)\) 实现 \((H,u)\)，满足 \(\mathsf{Mark}(M,q^0)=\pi_2\widehat B_M\)。
An exact atomic realization swaps in \((\kappa_u,H_u,\mathcal A_u)\), closes \(\eta^-\), activates \(M\) at \(\eta^+\), binds the target gates, and then publishes replacement handles.
% 精确原子实现换入 \((\kappa_u,H_u,\mathcal A_u)\)、关闭 \(\eta^-\)、在 \(\eta^+\) 激活 \(M\)、绑定目标门，随后发布替换句柄。
The swap is defined independently of \(\mathsf{Admit}\), \(\widehat B^\dagger\), \(\mathsf{Compile}\), \(\mathsf{Edge}\), and the canonical monitor.
% 该切换独立于 \(\mathsf{Admit}\)、\(\widehat B^\dagger\)、\(\mathsf{Compile}\)、\(\mathsf{Edge}\) 和规范监控器而定义。

\paragraph{Relational evidence}
% 关系证据
At a checked cut, four finite keyed factors record promised topology, schemas, lifts, and retirement in \(\mathbf P\); occurrence--cell identity, invocation, and lineage in \(\mathbf I\); resolved progress, receipts, results, outbox, and policy in \(\mathbf E\); and versions, epoch ownership, certificates, and cut coordinates in \(\mathbf C\).
% 在一个经检查的切点处，四个有限带键因子分别记录：\(\mathbf P\) 中的承诺拓扑、模式、提升和退役；\(\mathbf I\) 中的发生项--单元标识、调用和谱系；\(\mathbf E\) 中的已解析进展、回执、结果、发件箱和策略；以及 \(\mathbf C\) 中的版本、纪元所有权、证书和切点坐标。
Their normalized natural join is the incidence-preserving view
% 它们的规范化自然连接是保持关联关系的视图
\[
 \mathsf{Sec}(S;c,r)=
 \mathbf P\bowtie\mathbf I\bowtie\mathbf E\bowtie\mathbf C .
\]
The appendix assigns every base field and transitive dependency, defines dependency-closed projections \(\pi_J,\pi_{\neg oc},\pi_{\neg rc}\), and fixes query-relative private-name orbits \(\langle V,q\rangle_{\cong}\).
% 附录为每个基础字段及传递依赖指定所有者，定义依赖闭合投影 \(\pi_J,\pi_{\neg oc},\pi_{\neg rc}\)，并确定关于查询的私有名称轨道 \(\langle V,q\rangle_{\cong}\)。
For semantic answer \(\mathsf{Ans}(V,q)\), an equivariant abstraction \(\tau\) is exact when some decoder satisfies
% 对于语义答案 \(\mathsf{Ans}(V,q)\)，当存在某个解码器满足下式时，等变抽象 \(\tau\) 是精确的：
\[
 \mathsf{Exact}(\tau)\Longleftrightarrow
 \exists D_\tau.\ \forall V,q.\
 D_\tau(\langle\tau(V),q\rangle_{\cong})=[\mathsf{Ans}(V,q)]_{\cong}.
\]
Thus the lower bound concerns information, not a literal storage layout.
% 因而，该下界约束的是信息，而非字面存储布局。

\paragraph{Durable Agent-API observation}
% 持久 Agent API 观测
\(\mathcal O_{\rm api}\) contains \(\mathsf{Edge}(u,[\mathcal H]_{\cong})\), \Fresh/\Alias, \(\mathsf{deny}(x)\), \(\Dispatch(d)\), \(\mathsf{Settle}(d,[v]_{\cong})\), and \(\mathsf{Return}(t,[v]_{\cong})\).
% \(\mathcal O_{\rm api}\) 包含 \(\mathsf{Edge}(u,[\mathcal H]_{\cong})\)、\Fresh/\Alias、\(\mathsf{deny}(x)\)、\(\Dispatch(d)\)、\(\mathsf{Settle}(d,[v]_{\cong})\) 和 \(\mathsf{Return}(t,[v]_{\cong})\)。
Private names share one renaming orbit, public result bytes remain visible, and \(\mathsf{obs}_{\rm api}\) maps only Save, computation, inactive preload, failed installation, and recovered crash to \(\tau\).
% 私有名称共享一个重命名轨道，公开结果字节仍然可见，而 \(\mathsf{obs}_{\rm api}\) 只把 Save、计算、非活跃预加载、失败安装与恢复崩溃映射为 \(\tau\)。
Write \(\xRightarrow{\ell}=\tau^*\ell\tau^*\) and \(\xRightarrow{\tau}=\tau^*\).
% 记 \(\xRightarrow{\ell}=\tau^*\ell\tau^*\) 且 \(\xRightarrow{\tau}=\tau^*\)。
Let \(K=(\kappa,H,\Delta,\mathsf{out},\mathcal A)\), \(\mathsf{Live}(H)=X_{\sem{H.T}}\), and \(I=(K,c_I,r_I)\).
% 令 \(K=(\kappa,H,\Delta,\mathsf{out},\mathcal A)\)、\(\mathsf{Live}(H)=X_{\sem{H.T}}\)，并令 \(I=(K,c_I,r_I)\)。
\[
\begin{aligned}
\alpha_I(I)&=(K,c_I,r_I,H.\eta,H.\beta),\\
\alpha_S(S;c,r)&=(K,\mathsf{icut}(c),r,H.\eta,\\[-2pt]
&\qquad \mathsf{bind}|_{\mathsf{Live}(H)}),\\
I\,\mathcal R\,S&\Longleftrightarrow
\exists c,r.\ \mathsf{AgentSec}(S;c,r)\\[-2pt]
&\qquad\land\alpha_I(I)=\alpha_S(S;c,r).
\end{aligned}
\]
\(\alpha_S\) erases representation/protocol state but retains the policy, results, cut, and every \(\mathcal O_{\rm api}\)-visible field.
% \(\alpha_S\) 擦除表示/协议状态，但保留策略、结果、切点以及每个通过 \(\mathcal O_{\rm api}\) 可见的字段。
A \emph{good initial pair} satisfies \(\mathcal R\) with \(r=\epsilon\) immediately after a checked atomic installation.
% \emph{良好初始对}在一次经检查的原子安装后立即以 \(r=\epsilon\) 满足 \(\mathcal R\)。

\begin{theorem}[Agent Security-State Characterization]
% Agent 安全状态刻画
\label{thm:exact-history}
Under \cref{sec:model}'s boundary, clause 1 holds for every finite \(\mathcal W,R\).
% 在 \cref{sec:model} 的边界下，第 1 条对每个有限 \(\mathcal W,R\) 成立。
Clauses 2--5 hold for every \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) at any finite reachable checked-root state satisfying \(\mathsf{AgentSec}(S;c,r)\).
% 第 2--5 条对任意有限可达且满足 \(\mathsf{AgentSec}(S;c,r)\) 的经检查根状态上的每个 \(u\in\mathsf{Edit}_6\uplus\{\mathsf{Extend}(\xi)\}\) 成立。
\begin{enumerate}[leftmargin=*,itemsep=0pt]
\item \textbf{Registration reflection.}
% 注册反射。
\(\mathsf{CheckReg}(\mathcal W,R)\) accepts iff stored \(\lambda\) witnesses \(\mathcal W\sqsubseteq_\lambda R\).
% 当且仅当所存 \(\lambda\) 见证 \(\mathcal W\sqsubseteq_\lambda R\) 时，\(\mathsf{CheckReg}(\mathcal W,R)\) 才接受。
Then the \(\lambda\)-lowerings of source executions modulo \(\equiv_\partial\) are order-isomorphic to \(\mathsf{BRuns}(R)\), preserving outcomes, order, cells, \Fresh/\Alias, admission, and the greatest monitor.
% 此时，模 \(\equiv_\partial\) 的源执行经 \(\lambda\) 降低后与 \(\mathsf{BRuns}(R)\) 序同构，并保持结果、次序、单元、\Fresh/\Alias、准入与最大监控器。
Missing promises, inconsistent cells, or unmediated durable edges reject before bootstrap.
% 缺失承诺、不一致单元或未经中介的持久边会在引导前被拒绝。

\item \textbf{Exact compilation.}
% 精确编译。
Without a derivation, \(\mathsf{Compile}\) rejects structurally and both machines disable every \(\mathsf{Edge}(u,\cdot)\).
% 若不存在派生，\(\mathsf{Compile}\) 会作出结构拒绝，且两台机器都禁用每个 \(\mathsf{Edge}(u,\cdot)\)。
Otherwise let unique witness \(\delta\) derive all subscripts, \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\), and checked record \(c_\delta^+\).
% 否则，令唯一见证 \(\delta\) 派生所有下标，令 \(\mathsf{Out}_\delta=\mathsf{Compile}(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，并令 \(c_\delta^+\) 为经检查记录。
The following conditions are equivalent.
% 以下条件等价。
\[
\begin{aligned}
 &\widehat B^\dagger_\delta\ne\varnothing;\\
 &\text{an exact atomic realization of }(H,u,\delta)\text{ exists};\\
 &\mathsf{Out}_\delta\models\cref{eq:install-premise};\\
 &\exists S^+.\ S\xRightarrow{\mathsf{Edge}(u,[\mathcal H_u^+]_{\cong})}S^+
       \land\mathsf{AgentSec}(S^+;c_\delta^+,\epsilon).
\end{aligned}
\]
When these conditions hold, \((W^\dagger_\delta,\widehat B^\dagger_\delta)\) is greatest and \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) is canonical.
% 当这些条件成立时，\((W^\dagger_\delta,\widehat B^\dagger_\delta)\) 为最大实现，且 \(\mathsf{Can}(W^\dagger_\delta,B^\dagger_\delta)\) 为规范监控器。
Invalid requests have no derivation; a ranked chain ending in \(\varnothing\) excludes every realization.
% 无效请求不存在推导；以 \(\varnothing\) 结束的带秩链会排除所有实现。

\item \textbf{Factor tightness.}
% 因子紧致性。
The full join is sufficient, and every proper factor projection is insufficient:
% 完整连接是充分的，而每个真因子投影均不充分：
\[
 \mathsf{Exact}(\pi_J)
 \quad\Longleftrightarrow\quad
 J=\{\mathbf P,\mathbf I,\mathbf E,\mathbf C\}.
\]
Every exact abstraction distinguishes \cref{tab:projection-pairs}.
% 每个精确抽象都区分 \cref{tab:projection-pairs}。
Both incidence erasures and caller-proposed target-only \(\tau_{\rm tgt}\) remain inexact, while generalized nonblocking becomes exact after trusted target/marking derivation.
% 两种关联擦除与调用方提出的仅目标 \(\tau_{\rm tgt}\) 仍不精确，而广义非阻塞在可信目标/标记派生之后变得精确。

\item \textbf{Sequence closure.}
% 序列闭包。
Each fully parameterized trusted event \(e\) induces a partial function \(\partial\) on pointed state--event orbits, defined exactly when \(e\) is enabled:
% 每个参数完整的可信事件 \(e\) 在带指向的状态--事件轨道上诱导一个偏函数 \(\partial\)，且该函数恰在 \(e\) 启用时有定义：
\[
\begin{aligned}
&\mathsf{AgentSec}(S;c,r)\land S\xrightarrow e S'\\[-2pt]
&\quad\Longrightarrow \exists c',r'.\
  \mathsf{AgentSec}(S';c',r')\\[-2pt]
&\qquad\land [\mathsf{Sec}(S';c',r')]_{\cong}
  =\partial(\langle\mathsf{Sec}(S;c,r),e\rangle_{\cong}).
\end{aligned}
\]
This covers all edits, live extension, use, ledger, installation, and crash.
% 这覆盖全部编辑、在线扩展、使用、账本、安装与崩溃。
Iteration proves the characterization after every finite prefix, including additive schema/policy growth.
% 迭代证明该刻画在每个有限前缀后成立，其中包括仅追加模式/策略增长。

\item \textbf{Durable Agent-API realization.}
% 持久 Agent API 实现。
\(\mathcal R\) is a divergence-insensitive weak bisimulation under \(\mathsf{obs}_{\rm api}\), so every good pair satisfies \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\), including bundles/results but excluding time, fairness, and post-\(\Dispatch\) networking.
% \(\mathcal R\) 在 \(\mathsf{obs}_{\rm api}\) 下是发散不敏感弱互模拟，所以每个良好对都满足 \(S_0\approx_{\mathcal O_{\rm api}}^{\mathsf{di}}I_0\)，其中包括包/结果，但不包括时间、公平性与 \(\Dispatch\) 后网络行为。
Disjoint domains compose asynchronously.
% 互不相交的域异步组合。
\end{enumerate}
\end{theorem}

\begin{proof}[Proof sketch]
% 证明概要。
Finite-checker reflection, greatest-fixed-point induction, opposite-answer pairs, and event induction prove the five clauses.
% 有限检查器反射、最大不动点归纳、答案相反配对与事件归纳证明五个条款。
The appendix gives the witnesses and durable simulation.
% 附录给出见证与持久模拟。
\end{proof}
