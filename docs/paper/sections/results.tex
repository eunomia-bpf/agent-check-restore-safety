\section{Exact Agent History Realization}
\label{sec:results}

The theorem follows the security-compiler pipeline: schema fidelity derives a
target, exact admission decides and constructs its greatest realization, and
durable refinement installs that realization.
Let \(I_0,S_0\) be bootstrap states over the same well-formed security core
and admitted cut, with empty resolved prefix and identical history, receipt ledger,
outbox, gates, and current epoch.  State \(S_0\) additionally has the verified
program at \(q^0\).  Write
\(\mathsf{Ideal}(I_0)\) for the atomic history machine of
\cref{sec:ideal}, and \(\mathsf{Compiled}(S_0)\) for the reference monitor of
\cref{sec:kernel}, including its internal \(\tau\)-steps.

The observable alphabet is
\[
\begin{split}
\mathcal O=\{&
 \mathsf{Edge}(u),\Fresh(x,d),\Alias(x,d),\\[-2pt]
 &\mathsf{deny}(x),\Dispatch(d)\}.
\end{split}
\]
\(\mathsf{Edge}(u)\) includes the suppressed stable payload
\(\mathcal H_u^+\).  Compilation, failed installs, retries, settlement, result
delivery, and crashes are \(\tau\).  Logical \Alias progress remains observable
despite its empty authority projection.  Successful use and installation map
to \(a\) and \(\mathsf{Edge}(u)\).  Invalid use and head release map to
\(\mathsf{deny}(x)\) and \(\Dispatch(d)\).

Write \(\mathsf{Gen}(P)\) and \(\mathsf{Mark}(P)\) for the generated and
marked languages of a finite deterministic occurrence-labeled program \(P\).
For a schema-valid derivation, an \emph{exact atomic reference-monitor
realization} is a pair \((P,\widehat B_P)\) such that
\((\mathsf{Gen}(P),\widehat B_P)\) realizes \((H,u)\),
\(\mathsf{Mark}(P)=\pi_2\widehat B_P\), and one domain transaction persists
\(H'\), closes \(\eta^-\), activates \(\eta^+\), binds every target gate to
\(P\), and publishes \(\mathcal H_u^+\) only after activation.  Subsequent
protected uses take exactly the enabled \(P\)-transitions through the atomic
\Use rule.  \(\widehat B_P\) is specification-only ghost state, not an input to
\(P\).  This definition does not refer to \(\mathsf{Admit}\),
\(\widehat B^\dagger\), \(\mathsf{Compile}\), or \(\mathsf{Can}\).

\begin{theorem}[Exact Agent History Realization]
\label{thm:exact-history}
Assume the trusted boundary of \cref{sec:model}.  Let
\((\kappa,H,\Delta,\mathsf{out},\mathcal A)\) be a reachable well-formed
security core and let the immutable schema registry derive
\[
 \Sigma_\zeta;H\vdash u\Downarrow
 (H',\mathcal C_{H,u},\eta^-,\eta^+).
\]

\begin{enumerate}[leftmargin=*,itemsep=3pt]
 \item \textbf{Schema fidelity.}
 The derived history \(H'\) is unique and well formed.  Its preserved context
 and \(\mathcal P_u\) retain all obligations not discharged by
 schema-authorized retirement.  Each \(\mu_r\) is a global occurrence
 bijection, each
\(\pi_r:O_{\mathcal D_r}\twoheadrightarrow O_{\mathcal C_r}\) is surjective,
and incidence,
 order, cell, and lineage are preserved and reflected.  No occurrence is split
 by outcome or relabeled as a suffix.  Every
 \((r,o)\in\mathsf{Obl}_u\) has a full-target \(\mathsf{Lift}_u\) witness.
 Bypassing context outcomes are preserved by identity.

 \item \textbf{Exact prefix-robust admission.}
 \emph{Existence.}  The following conditions are equivalent.
 \[
 \begin{aligned}
  &\widehat B^\dagger_{H,u}\ne\varnothing;\\
  &\exists (L,\widehat B).\ (L,\widehat B)
       \text{ realizes }(H,u);\\
  &\text{an exact atomic reference-monitor realization exists};\\
 &\mathsf{Compile}(\kappa,H,\Delta,\mathcal A,u)
       \text{ emits a verifiable seal}.
 \end{aligned}
 \]
 \emph{Accepted edits.}
 When these conditions hold, the greatest indexed realization is exactly
 \((W^\dagger_{H,u},\widehat B^\dagger_{H,u})\), with runtime marking
 \(B^\dagger_{H,u}=\pi_2\widehat B^\dagger_{H,u}\).  Every
 realization \((L,\widehat B)\) satisfies
 \(L\subseteq W^\dagger_{H,u}\) and
 \(\widehat B\subseteq\widehat B^\dagger_{H,u}\).  After every
 \(z\in W^\dagger_{H,u}\), every
 \(o\in\mathsf{Compat}(z)\) still has a safe marked extension
 \((o,b)\in\widehat B^\dagger_{H,u}\) with \(z\preceq_{\rm pref}b\).
 At \(z=\epsilon\), the coverage property supplies a safe full-target lift for
 every required regional or context outcome.  At later prefixes, it applies to
 every contract-compatible outcome.

 \emph{Rejected edits.}
 If admission fails, the complete descending chain
 \(\widehat B_0,\widehat B_1,\ldots,\widehat B_n=\varnothing\), together
 with each ranked cause
 \((i,(o_{\rm rem},b),z,o_{\rm miss})\) satisfying
 \((o_{\rm rem},b)\in\widehat B_i\setminus\widehat B_{i+1}\),
 \(z\preceq_{\rm pref}b\),
 \(o_{\rm miss}\in\mathsf{Compat}(z)\), and no extension of \(z\) in
 \(\{b'\mid(o_{\rm miss},b')\in\widehat B_i\}\), is a finite certificate that no
 realization exists.

 \item \textbf{Durable implementation refinement.}
 For bootstrap states \(I_0,S_0\) as above,
 \[
   \mathsf{Compiled}(S_0)
   \ \approx_{\mathcal O}^{\mathsf{di}}\
   \mathsf{Ideal}(I_0)
 \]
 by divergence-insensitive weak bisimulation.  Every successful history edge
 is one domain-wide cut.  It closes \(\eta^-\), persists the
 schema-derived history, rebinds every live target gate, and activates the
 single new epoch \(\eta^+\) with \(\mathcal H_u^+\) in one reference-monitor
 transaction.  The
 theorem makes no within-domain partial-fencing claim.  Domains with disjoint
 cells, receipt ledgers, and policies compose only by asynchronous product.
\end{enumerate}

Consequently, authority remains in \(\mathcal A\), every contract-compatible outcome
retains a completion, only the current epoch authorizes \Fresh or \Alias, and
each occurrence linearizes on one side of a cut.  FIFO release follows \Fresh
receipt order.  Coverage is existential: it implies neither fairness nor that
an enabled step eventually occurs.
\end{theorem}

\begin{proof}
\emph{Schema fidelity.}
\Cref{lem:history-derivation} gives all stated preservation properties,
schema-authorized retirement, witnesses, and domain-wide rebinding.  The Agent cannot
choose a target contract that drops obligations.

\emph{Local equivalence.}
\Cref{lem:greatest-realization} proves that
\(\widehat B^\dagger_{H,u}\ne\varnothing\) iff an indexed realization exists
and identifies \((W^\dagger,\widehat B^\dagger)\) as the greatest one.  If an
exact atomic reference-monitor realization exists, its defining pair
\((\mathsf{Gen}(P),\widehat B_P)\) is an indexed realization, so admission
holds.  Conversely, admission makes
\((W^\dagger,\widehat B^\dagger)\) a realization, and
\cref{lem:compiled-language} constructs
\(\mathsf{Can}(W^\dagger,B^\dagger)\) with those generated and marked
languages.  The trusted installation checker re-derives the nonempty fixed
point, and the atomic transaction installs that program, so an exact
reference-monitor realization exists.  Finally, \(\mathsf{Compile}\) emits a
verifiable seal exactly when \(\mathsf{Verify}_Z\) reaches a nonempty stabilized
family.  This establishes all four implications without assuming
implementation existence in any definition.
At \(\epsilon\), fixed-point coverage supplies a safe pair for every target
outcome.  The checked regional and context lifts therefore supply a safe
full-target preimage for every required obligation instance.
On rejection, let \(P\) be any post-fixed family.  Forward induction maintains
\(P\subseteq\widehat B_i\).  The recomputed base gives the initial inclusion,
and the checked missing-witness cause for every removed pair excludes it from
\(P\).  Hence \(P\subseteq\widehat B_{i+1}\).  An empty final set excludes every
nonempty post-fixed family and therefore every realization.

\emph{Bisimulation relation.}
Relate an ideal state \(I\) and compiled state \(S\) when:
(i) \(\kappa,H,\Delta\), receipt phases and result futures, and the ordered outbox
agree;
(ii) the ideal active cut is
\((H_c,u,W^\dagger,\widehat B^\dagger)\), the compiled current-epoch
certificate is exactly \((H_c,u,W^\dagger,\widehat B^\dagger,Z)\), their
resolved prefix is \(r\), and
\(\mathsf q(H.\mathsf{epoch})=q_r=(W^\dagger/r,B^\dagger/r)\);
(iii) \(\beta\) equals the kernel binding on live occurrences,
\(H.\mathsf{epoch}\) is the only active epoch, every live gate is bound to it and has one
authenticated current handle, and every earlier epoch is closed; unreachable programs and records in inactive,
unbound epochs are ignored; and
(iv) the ordering invariant for occurrences and receipts following
\cref{eq:use-rule} holds.  The bootstrap construction satisfies this
relation.

\emph{Protected occurrences.}
Suppose \(x\) is enabled.  Because the two states agree on \(H\), registry data,
and \(\Delta\), they compute the same resolved symbol \(a\).  By
\cref{lem:compiled-language}, the compiled program has an \(a\)-transition iff
\(ra\in W^\dagger\), which is the same guard used by the ideal machine.  Both atomic steps
residualize the same occurrence, append \(a\) to
\(\chi\), advance the view and residual program state, and, only for \Fresh,
append the same receipt and outbox item.  \Cref{lem:residual-coherence}
re-establishes the greatest fixed point for the residual contract.  Any failed
guard, including a missing program transition, disabled occurrence,
misbinding, or closed epoch, produces the same state-preserving denial.  This
proves both simulation directions for \Fresh, \Alias, and denials.

\emph{History edges.}
For an ideal \(\mathsf{Edge}(u)\), determinism of
\cref{lem:history-derivation} gives one
\((H',\mathcal C_{H,u},\eta^-,\eta^+)\) and the same checked schema
certificates.  Local realizability lets the compiled side take internal
compile, check, and preload steps and then a successful \Install.  Its single
domain transaction persists the same \(H'\), closes \(\eta^-\), rebinds all
live target gates, activates \(\eta^+\), publishes the same
\(\mathcal H_u^+\), starts the canonical program at
\((W^\dagger/\epsilon,B^\dagger/\epsilon)\), and atomically records
\((H_c,u,W^\dagger,\widehat B^\dagger,Z)\) as its certificate.  The successors
are related.  Conversely, every successful install re-derives that judgment
and verifies a nonempty stabilized fixed point, so the ideal edge exists and
matches it.

If a protected occurrence commits before installation, a \Fresh step changes
\(\Delta,\chi,\nu\), while an \Alias changes \(\chi,\nu\).  In either case the old
seal is stale.  If installation commits first, it closes the old policy-domain
epoch, so no gate bound to \(\eta^-\) can resolve either \Fresh or
\Alias.
\Cref{lem:cut-linearization} therefore orders every same-domain
race between a protected use and installation without an intermediate
unmatched state.  Only domains with disjoint cells, receipt ledgers, and policies commute by their asynchronous-product
semantics.

\emph{Remaining transitions.}
Both machines dispatch the same outbox head.  Matching \(\mathsf{Save}\)
transitions append the same authenticated checkpoint and advance the same
view.  Preloading changes only ignored inactive garbage.  Retry, handle-bundle
retrieval, result delivery, settlement, failed installation, and crash recovery
preserve the relation through matching \(\tau\)-steps.
The relation is re-established at
\(\epsilon\) after every successful edge, so coinduction gives weak
bisimulation.  The bisimulation is divergence insensitive, so finite internal
paths may be collapsed without implying termination, progress, or scheduler
fairness.  Policy safety, persistent outcome coverage, and completion
nonblocking follow from \(W^\dagger\).  Epoch exclusion follows from the
relation invariant and the atomic cut, while FIFO dispatch gives the final
ordering claim.
\end{proof}

Thus one object, \(\widehat B^\dagger\), decides a schema-derived Agent history
edge and generates the canonical monitor for every later protected occurrence.
Fork, Restore, and Merge are instances of one history-admission theory.
