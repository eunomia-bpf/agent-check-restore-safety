\section{Conclusion}
% 结论
\label{sec:conclusion}

Agents that Fork, Restore, or Merge an execution require a safety decision that accounts for both logical control state and irreversible external progress.
% 对执行进行 Fork、Restore 或 Merge 的 Agent 需要一种同时考虑逻辑控制状态与不可逆外部进展的安全判定。
Our checker derives this decision from a checked workflow, authenticated history, durable receipts, and the requested edit.
% 我们的检查器从经检查的工作流、经认证历史、持久回执和所请求的编辑中推导这一判定。
Its greatest fixed point yields the most permissive safe monitor when the edit is realizable, while an empty fixed point yields a finite impossibility certificate.
% 当编辑可实现时，其最大不动点给出最宽松的安全监控器；当不动点为空时，则给出有限不可能性证书。
The characterization theorem connects this safety result to atomic installation, identifies the history information required for exact decisions, and preserves the characterization across finite sequences of edits, protected calls, crashes, and additive extensions.
% 刻画定理将该安全判定连接到原子安装，识别精确判定所需的历史信息，并在由编辑、受保护调用、崩溃和仅追加扩展组成的有限序列中保持该刻画。
The Lean modules and executable tests validate the finite checked core and its explicit compiler.
% Lean 模块与可执行测试验证了有限检查核心及其显式编译器。
