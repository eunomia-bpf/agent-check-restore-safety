\section{Conclusion}
% 结论
\label{sec:conclusion}

Our exact checker turns an Agent Fork, Restore, or Merge into either the most permissive safe monitor or a proof that no implementation can meet the requirements.
% 我们的精确检查器将 Agent 的 Fork、Restore 或 Merge 转化为限制最少的安全监控器，或者转化为没有实现能够满足要求的证明。
The Exact Edit-Safety theorem carries this result through atomic installation and runtime execution, shows that none of four state relations can be erased without losing exactness, and remains applicable after every finite reachable execution.
% 精确编辑安全定理将这一结果贯穿原子安装与运行时执行，表明四类状态关系中的任一类都无法在不丧失精确性的情况下被删除，并且在每个有限可达执行之后仍然适用。
