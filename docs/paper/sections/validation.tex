\section{Executable Validation}
% 可执行验证
\label{sec:validation}

\paragraph{Decision kernel}
% 判定内核
The bounded validator enumerates indexed pomset linearizations, resolves \Fresh and \Alias, checks authority and witnesses, iterates \(\widehat\Phi\), and reconstructs \(W^\dagger\) without merging equal-trace outcomes.
% 有界验证器枚举带索引偏序事件集的线性化、解析 \Fresh 与 \Alias、检查权限与见证、迭代 \(\widehat\Phi\)，并重建 \(W^\dagger\) 而不合并同轨迹结果。
It fails closed beyond 128 outcomes, eight occurrences per outcome, 50,000 linearizations, or 100,000 completions; it is neither the trusted checker nor a proof, and these bounds do not constrain the theorem.
% 当结果超过 128 个、每个结果的发生项超过 8 个、线性化超过 50,000 个或完成路径超过 100,000 条时，它以关闭方式失败；它既不是可信检查器也不是证明，且这些界限不约束该定理。

% 试金石测试
All 81 tests pass after clean extraction.
% 全部 81 个测试在干净解压后均通过。

\Cref{tab:projection-pairs} remains pen-and-paper; tests cover its mechanisms, while Lean checks whether erasing a cell's semantic identity or authorized controller reverses redemption.
% \Cref{tab:projection-pairs} 仍是纸笔模型；测试覆盖其机制，而 Lean 检查擦除单元的语义标识或授权控制器是否会反转兑付判定。
Neither artifact mechanizes schema fidelity, sequence closure, handoff, durable refinement, or the theorem.
