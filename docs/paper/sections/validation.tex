\section{Executable Validation}
% 可执行验证
\label{sec:validation}

The main result is a pen-and-paper theorem.
% 主要结果是一个纸笔证明的定理。
The dependency-free bounded artifact validator handles finite instances.
% 这个无依赖的有界制品验证器处理有限实例。
It is neither the trusted installation checker nor a mechanized proof of \cref{thm:exact-history}.
% 它既不是可信安装检查器，也不是 \cref{thm:exact-history} 的机械化证明。

\paragraph{Decision kernel}
% 判定内核
Given a derived indexed-pomset contract, the validator enumerates topological sorts, resolves \Fresh/\Alias occurrences, checks authority projections, iterates \(\widehat\Phi\), verifies removal causes and survivor witnesses, and reconstructs \(W^\dagger\).
% 给定一个派生的带索引偏序事件集契约，验证器会枚举拓扑排序、解析 \Fresh/\Alias 发生项、检查权限投影、迭代 \(\widehat\Phi\)、验证移除原因与幸存者见证，并重建 \(W^\dagger\)。
Outcome indices remain distinct under equal trace projections.
% 即使轨迹投影相同，结果索引仍保持不同。
Search fails closed above 128 outcomes, eight occurrences per outcome, 50,000 linearizations per pomset, or 100,000 safe indexed completions.
% 当结果数超过 128、每个结果的发生项超过 8 个、每个偏序事件集的线性化超过 50,000 个，或安全的带索引完成路径超过 100,000 条时，搜索会以关闭方式失败。
These bounds do not constrain the theorem.
% 这些界限不约束该定理。

\paragraph{Litmus tests}
% 试金石测试
The focused suite comprises 19 of the repository's 81 passing tests.
% 聚焦测试套件由仓库中 81 个通过测试里的 19 个组成。
It covers the rejecting \(2,1,0\) chain, identical-trace indices, completion observability, structural fixtures for all six edit shapes, same-cell and gate-borrowing cases, receipt-silent \Alias progress, and both orders of \Fresh/\Alias versus installation.
% 它覆盖会被拒绝的 \(2,1,0\) 链、轨迹相同但索引不同的情形、完成可观测性、全部六种编辑形态的结构化测试实例、同单元与借用门的情形、不产生回执的 \Alias 进展，以及 \Fresh/\Alias 与安装之间的两种先后次序。
The focused tests also pass after clean archive extraction.
% 从干净归档中解压后，这些聚焦测试也全部通过。
These executions test only the decision kernel and bounded structural/race fixtures.
% 这些执行只测试判定内核以及有界的结构与竞态测试实例。
They do not mechanize schema fidelity, authenticated handle handoff, durable refinement, or \cref{thm:exact-history}.
% 它们没有机械化模式保真性、认证句柄交接、持久细化或 \cref{thm:exact-history}。
Occurrence loss, an unwitnessed elimination, an incorrect survivor language, or stale-cut acceptance falsifies the executable subset.
% 发生项丢失、无见证的淘汰、错误的幸存者语言或接受陈旧切点，都会证伪可执行子集。
Obligation loss, language mismatch, an enabled old epoch, or observable LTS divergence falsifies the theorem.
% 义务丢失、语言不匹配、旧纪元仍被启用或可观测 LTS 发生分歧，都会证伪该定理。
