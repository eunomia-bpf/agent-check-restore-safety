\section{Executable Validation}
% 可执行验证
\label{sec:validation}

Five Lean modules pass \texttt{--trust=0} with mapping in \cref{app:lean-map}.
% 五个 Lean 模块通过 \texttt{--trust=0} 检查，映射见 \cref{app:lean-map}。
The factor bounds, pomset lifting, and bisimulation remain mathematical.
% 因子下界、偏序事件集提升与互模拟仍由数学证明给出。
Across 81 tests, five-process medians are \(53.47/5.51/50.35\) ms for 128-outcome admission/rejection and 720 completions.
% 在 81 项测试中，128 个结果的准入/拒绝与 720 条完成路径的五进程中位数为 \(53.47/5.51/50.35\) ms。
Over-cap inputs return \(\mathsf{ResourceLimit}\) without installation, and all measurements concern the decision kernel.
% 超过上限的输入返回 \(\mathsf{ResourceLimit}\) 且不安装，所有测量均针对判定内核。
