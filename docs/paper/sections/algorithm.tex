\section{Monitor Compilation and Durable Installation}
% 编译与持久精化
\label{sec:kernel}

Admission produces either an impossibility certificate or the greatest safe family of completed executions.
% 准入过程生成不可能性证书或安全完整执行的最大集合。
The durable kernel turns a nonempty family into enforcement in three steps: (1) compile its prefix closure into a canonical monitor, (2) bind the monitor to the authenticated source cut, and (3) atomically install it under a fresh epoch.
% 持久内核分三步将非空集合转化为强制执行：(1) 将其前缀闭包编译为规范监控器，(2) 将监控器绑定到经认证的源切点，(3) 在新纪元下原子安装。
The rules below make racing protected calls occur entirely before or after this installation boundary.
% 下列规则使竞态的受保护调用完整地发生在该安装边界之前或之后。

\subsection{Occurrence-sensitive compilation}
% 发生项敏感编译

The greatest realization has the finite, canonically installable projected pair \((W,B)=(W^\dagger_{H,u},B^\dagger_{H,u})\).
% 最大实现具有有限且可规范安装的投影对 \((W,B)=(W^\dagger_{H,u},B^\dagger_{H,u})\)。
For \(L/z=\{v\mid zv\in L\}\), use residual states \(q_z=(W^\dagger/z,B^\dagger/z)\).
% 对于 \(L/z=\{v\mid zv\in L\}\)，使用残余状态 \(q_z=(W^\dagger/z,B^\dagger/z)\)。
\begin{equation}
\label{eq:canonical-program}
\begin{aligned}
 Q_{W,B} &= \{q_z\mid z\in W\},\\
 q^0&=q_\epsilon=(W^\dagger,B^\dagger),\\
 q_z\xrightarrow{a}q_{za}
 &\quad\Longleftrightarrow\quad za\in W .
\end{aligned}
\end{equation}
Call this automaton \(\mathsf{Can}(W,B)\); every state is reachable and marked exactly when \(\epsilon\in B^\dagger/z\), while each transition symbol \(a\) contains occurrence \(x\), cell \(d\), and \Fresh/\Alias mode, preventing use through another occurrence's gate.
% 将此自动机称为 \(\mathsf{Can}(W,B)\)；每个状态均可达，并且恰在 \(\epsilon\in B^\dagger/z\) 时被标记，而每个转移符号 \(a\) 都包含发生项 \(x\)、单元 \(d\) 以及 \Fresh/\Alias 模式，从而防止通过另一发生项的门进行使用。

\begin{lemma}[Exact compiled realization]
% 精确的编译实现
\label{lem:compiled-language}
The generated and marked languages of the program in \cref{eq:canonical-program} are exactly \((W^\dagger_{H,u},B^\dagger_{H,u})\).
% \cref{eq:canonical-program} 中程序的生成语言和标记语言恰为 \((W^\dagger_{H,u},B^\dagger_{H,u})\)。
The program is the smallest deterministic marked partial automaton for this pair up to state renaming.
% 在忽略状态重命名的意义下，该程序是实现这对语言的最小确定性标记偏自动机。
\end{lemma}
\begin{proof}
Induction on \(z\) shows that the automaton reaches \((W^\dagger/z,B^\dagger/z)\), enables \(a\) iff \(za\in W^\dagger\), and marks the reached state iff \(z\in B^\dagger\).
% 对 \(z\) 的归纳表明，该自动机到达 \((W^\dagger/z,B^\dagger/z)\)，当且仅当 \(za\in W^\dagger\) 时启用 \(a\)，并且当且仅当 \(z\in B^\dagger\) 时标记所到达的状态。
Distinct states differ on a generated or marked suffix and must remain distinct.
% 不同状态在某个生成后缀或标记后缀上存在差异，因此必须保持不同。
The automaton is the paired-language derivative construction~\cite{brzozowski1964derivatives}.
% 该自动机是成对语言的导数构造~\cite{brzozowski1964derivatives}。
\end{proof}

For \(\Theta=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\), let \(\gamma(\Theta)=\mathsf{Seal}_{\rm cut}(\mathsf{enc}(\mathsf{request},\omega,\zeta,\kappa,H,\Delta,\mathsf{out},\mathcal A,u))\) bind a verdict to its request cut.
% 对于 \(\Theta=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，令 \(\gamma(\Theta)=\mathsf{Seal}_{\rm cut}(\mathsf{enc}(\mathsf{request},\omega,\zeta,\kappa,H,\Delta,\mathsf{out},\mathcal A,u))\) 将判定绑定到其请求切点。
\[
\begin{aligned}
\mathsf{Result}(\Theta)::={}&\mathsf{Invalid}([\gamma,C_{\rm str}]_{\cong})
\mid\mathsf{Reject}([\gamma,C_{\rm fp}]_{\cong})\\
&\mid\mathsf{Installable}(\delta,W^\dagger,\widehat B^\dagger,Z).
\end{aligned}
\]
\(\mathsf{Compile}(\Theta)\) returns \(\mathsf{Invalid}\) with the canonical failed-check transcript if derivation is undefined, \(\mathsf{Reject}\) with the complete ranked empty-chain if \(\widehat B^\dagger=\varnothing\), and otherwise \(\mathsf{Installable}\) with the unique \(\delta\), coverage witnesses, \(\mathsf{prog}_Z=\mathsf{Can}(W^\dagger,B^\dagger)\), and
% 若推导未定义，\(\mathsf{Compile}(\Theta)\) 返回带规范检查失败记录的 \(\mathsf{Invalid}\)；若 \(\widehat B^\dagger=\varnothing\)，则返回带完整带秩空链的 \(\mathsf{Reject}\)；否则返回带唯一 \(\delta\)、覆盖见证、\(\mathsf{prog}_Z=\mathsf{Can}(W^\dagger,B^\dagger)\) 以及下述内容的 \(\mathsf{Installable}\)
\[
 Z=(\omega,\zeta,\kappa_Z,\mathsf{cut}_Z,u,
    H_{\mathsf{prog}},\eta^-,\eta^+),
\]
where \(\kappa_Z=\kappa\), \(H_c=H\) is the authenticated pre-installation history, and the history judgment mints \(\eta^+\).
% 其中 \(\kappa_Z=\kappa\)，\(H_c=H\) 是经认证的安装前历史，而历史判定生成 \(\eta^+\)。
Canonical encoding order makes all three finite semantic results unique and equivariant; the bounded wrapper may instead return \(\mathsf{ResourceLimit}(b,n)\), which installs nothing and proves neither admission nor impossibility.
% 规范编码顺序使三种有限语义结果均唯一且保持等变性；有界包装器可能改为返回 \(\mathsf{ResourceLimit}(b,n)\)，它不安装任何内容，也不证明准入或不可能性。

Let \(\mathsf{enc}\) be canonical and length-delimited, with \(\kappa\) authenticating \(\mathcal A\).
% 令 \(\mathsf{enc}\) 为规范且带长度分隔的编码，并由 \(\kappa\) 认证 \(\mathcal A\)。
The symbolic LTS uses domain-separated injective authenticated constructors \(\mathsf{Seal}_{\rm prog}\) and \(\mathsf{Seal}_{\rm cut}\), so equal seals have equal payloads.
% 符号 LTS 使用域分离、单射且经认证的构造器 \(\mathsf{Seal}_{\rm prog}\) 和 \(\mathsf{Seal}_{\rm cut}\)，因此相同封印具有相同载荷。
Define
% 定义
\[
 H_{\mathsf{prog}}=
 \mathsf{Seal}_{\rm prog}(
   \mathsf{enc}(\mathsf{prog}_Z,\widehat B^\dagger_{H,u})).
\]
The cut seal is
% 切点封印为
\begin{equation}
\label{eq:cut-seal}
\begin{split}
 \mathsf{cut}_Z=
 \mathsf{Seal}_{\rm cut}(\mathsf{enc}(&\omega,\zeta,\kappa,H,\Delta,
     \mathsf{out},u,\mathcal C_{H,u},\\[-2pt]
     &H_{\mathsf{prog}},\eta^-,\eta^+)).
\end{split}
\end{equation}
Because \(H\) contains \(\chi,\nu,\rho,\beta\), the cut seal binds logical progress, the history view, registry state, and gate/epoch bindings, and it binds the receipt ledger and outbox directly.
% 由于 \(H\) 包含 \(\chi,\nu,\rho,\beta\)，该切点封印绑定逻辑进度、历史视图、注册表状态和门/纪元绑定，并直接绑定回执账本与发件箱。
Search and inactive preloading remain untrusted because the installation checker re-derives the schema judgment and complete indexed fixed point, reconstructs \((W^\dagger,B^\dagger)\), verifies both seals, and checks
% 搜索和非活跃预加载仍不受信任，因为安装检查器会重新推导模式判定和完整的带索引不动点，重建 \((W^\dagger,B^\dagger)\)，验证两个封印，并检查
\[
 \mathsf{prog}_Z\cong\mathsf{Can}(W^\dagger,B^\dagger),
\]
as a full automaton isomorphism preserving the initial state, marking, and every labeled transition.
% 其是否为保持初始状态、标记及每个带标签转移的完整自动机同构。
A byte implementation may use signatures or collision-resistant digests over \(\mathsf{enc}\), yielding computational refinement up to forgery or collision, while exact bisimulation uses the symbolic constructors.
% 字节级实现可对 \(\mathsf{enc}\) 使用签名或抗碰撞摘要，从而得到除伪造或碰撞外的计算精化，而精确互模拟使用符号构造器。

\subsection{Durable kernel}
% 持久内核

The compiled state for one policy domain is
% 一个策略域的编译状态为
\[
S=(\kappa,H,\Delta,\mathsf{out},\mathcal A,
    \mathsf{phase},\mathsf{bind},\mathsf{prog},\mathsf q,\mathsf{cert}),
\]
where \(\mathsf{phase}\) is a finite partial map with \(\mathsf{phase}(\eta)=\bot\) for an unallocated epoch and values \(\mathsf{inactive}\), \(\mathsf{active}\), or \(\mathsf{closed}\) otherwise.
% 其中 \(\mathsf{phase}\) 是有限偏映射；未分配纪元满足 \(\mathsf{phase}(\eta)=\bot\)，否则其值为 \(\mathsf{inactive}\)、\(\mathsf{active}\) 或 \(\mathsf{closed}\)。
Reserve \(u=\mathsf{Root}(R,n)\) for bootstrap only.
% 保留 \(u=\mathsf{Root}(R,n)\) 仅用于引导。
The root rule is enabled only when \(\mathsf{CheckReg}(\mathcal W,R)\) accepts a finite-state boundary-finite typed Agent workflow \(\mathcal W\) and finite registered slice \(R\).
% 只有当 \(\mathsf{CheckReg}(\mathcal W,R)\) 接受有限状态且边界有限的类型化 Agent 工作流 \(\mathcal W\) 与有限注册切片 \(R\) 时，根规则才启用。
The deterministic judgment \(\mathsf{Reg}(R,n)\vdash\mathsf{Root}\Downarrow(H_R^+,\mathcal C_R,\bot,\eta_R)\) constructs \(\mathsf{src}_R^-=(\kappa,H_R^-,\epsilon,\epsilon,\mathcal A)\) from registered slice \(R\) and private namespace \(n\), with empty progress, checkpoints, bindings, and epoch, sets \(\mathsf{Req}_{\mathsf{Root}}\) to \(R\)'s root outcomes, and defines \(\mathsf{Lift}_{\mathsf{Root}}(t,o)\Longleftrightarrow t=o\).
% 确定性判定 \(\mathsf{Reg}(R,n)\vdash\mathsf{Root}\Downarrow(H_R^+,\mathcal C_R,\bot,\eta_R)\) 从已注册切片 \(R\) 和私有命名空间 \(n\) 构造 \(\mathsf{src}_R^-=(\kappa,H_R^-,\epsilon,\epsilon,\mathcal A)\)，其中进度、检查点、绑定和纪元均为空；它将 \(\mathsf{Req}_{\mathsf{Root}}\) 设为 \(R\) 的根结果，并定义 \(\mathsf{Lift}_{\mathsf{Root}}(t,o)\Longleftrightarrow t=o\)。
The checked record \(\mathsf{cert}(\eta)=c=(\mathsf{src}_c,H_c^+,u,W,\widehat B,Z)\) contains source cut \(\mathsf{src}_c=(\kappa,H_c,\Delta_c,\mathsf{out}_c,\mathcal A)\), pre-progress target \(H_c^+\), and ideal-cut projection \(\mathsf{icut}(c)=(H_c,u,W,\widehat B)\).
% 经检查的记录 \(\mathsf{cert}(\eta)=c=(\mathsf{src}_c,H_c^+,u,W,\widehat B,Z)\) 包含源切点 \(\mathsf{src}_c=(\kappa,H_c,\Delta_c,\mathsf{out}_c,\mathcal A)\)、受保护进展前目标 \(H_c^+\)，以及理想切点投影 \(\mathsf{icut}(c)=(H_c,u,W,\widehat B)\)。
Its tagged origin is the checked root judgment exactly when \(u=\mathsf{Root}(R,n)\) and \(\mathsf{src}_c=\mathsf{src}_R^-\); otherwise it is the checked derivation of either one of the six structural edits or an authenticated live extension.
% 当且仅当 \(u=\mathsf{Root}(R,n)\) 且 \(\mathsf{src}_c=\mathsf{src}_R^-\) 时，其带标签来源为经检查的根判定；否则，它是六种结构编辑之一或一次经认证在线扩展的经检查推导。
Its indexed family is proof-only ghost state, while \(W^\dagger\), \(B^\dagger\), and the seal are checked enforcement data; \(\mathsf{Gen}(P,q)\) and \(\mathsf{Mark}(P,q)\) denote \(P\)'s generated and marked languages from \(q\).
% 其带索引族是仅用于证明的幽灵状态，而 \(W^\dagger\)、\(B^\dagger\) 和封印是经检查的强制执行数据；\(\mathsf{Gen}(P,q)\) 和 \(\mathsf{Mark}(P,q)\) 表示 \(P\) 从 \(q\) 出发的生成语言和标记语言。

\begin{definition}[Agent security-state invariant]
% Agent 安全状态不变量
\label{def:agent-sec}
For \(c=(\mathsf{src}_c,H_c^+,u,W,\widehat B,Z)\) and resolved \(r\), \(\mathsf{AgentSec}(S;c,r)\) holds exactly when the following clauses hold.
% 对 \(c=(\mathsf{src}_c,H_c^+,u,W,\widehat B,Z)\) 和已解析词 \(r\)，当且仅当下列条款成立时，\(\mathsf{AgentSec}(S;c,r)\) 成立。
\begin{enumerate}[leftmargin=*,itemsep=1pt]
\item \emph{Core and schema coherence.}
% 核心与模式一致性。
The current security core is well formed, \(c=\mathsf{cert}(\eta)\), and the tagged origin derives \((H_c^+,\mathcal C,\eta^-,\eta)\) by its corresponding checked root, six-edit, or live-extension judgment; each \(a\in\mathsf{Req}_u\) has a checked full-target \(\mathsf{Lift}_u\) witness.
% 当前安全核心良构，\(c=\mathsf{cert}(\eta)\)，且带标签来源通过相应的经检查根判定、六种编辑判定或在线扩展判定推导出 \((H_c^+,\mathcal C,\eta^-,\eta)\)；每个 \(a\in\mathsf{Req}_u\) 都有经检查的完整目标 \(\mathsf{Lift}_u\) 见证。
\item \emph{Promise coherence.}
% 承诺一致性。
\(\widehat B=\widehat B^\dagger_{H_c,u}\ne\varnothing\), \(W=\Pref(\pi_2\widehat B)\), and the stored certificate passed \(\mathsf{Verify}_Z(W,\pi_2\widehat B,\widehat B)\) at its source cut.
% \(\widehat B=\widehat B^\dagger_{H_c,u}\ne\varnothing\)、\(W=\Pref(\pi_2\widehat B)\)，并且所存证书已在其源切点通过 \(\mathsf{Verify}_Z(W,\pi_2\widehat B,\widehat B)\)。
\item \emph{Execution coherence.}
% 执行一致性。
\((H.G,H.T)=\mathsf{HRes}((H_c^+.G,H_c^+.T),r)\), \(H.\chi=H_c^+.\chi\,r\), \(\mathsf{lab}(\Delta)=\mathsf{lab}(\Delta_c)\mathsf{auth}(r)\), and each occurrence in \(r\) appears once in \(\chi\).
% \((H.G,H.T)=\mathsf{HRes}((H_c^+.G,H_c^+.T),r)\)，\(H.\chi=H_c^+.\chi\,r\)，\(\mathsf{lab}(\Delta)=\mathsf{lab}(\Delta_c)\mathsf{auth}(r)\)，且 \(r\) 中每个发生项都在 \(\chi\) 中出现一次。
Each \Fresh has its unique receipt and ordered outbox preparation, each \Alias names an earlier receipt, receipt phases and releases advance only monotonically, and \(K\) differs from \(H_c^+.K\) only by authenticated \(\mathsf{Save}\) extensions.
% 每个 \Fresh 都有其唯一回执和有序发件箱准备，每个 \Alias 都指明更早的回执，回执阶段和释放仅单调推进，且 \(K\) 与 \(H_c^+.K\) 的差异仅为经认证的 \(\mathsf{Save}\) 扩展。
\item \emph{Monitor coherence.}
% 监控器一致性。
For \(B=\pi_2\widehat B\), checked installation gives \(\mathsf{prog}(\eta)\cong\mathsf{Can}(W,B)\) and makes \(\mathsf q(\eta)\) correspond to canonical derivative \(q_r=(W/r,B/r)\).
% 对 \(B=\pi_2\widehat B\)，经检查的安装给出 \(\mathsf{prog}(\eta)\cong\mathsf{Can}(W,B)\)，并使 \(\mathsf q(\eta)\) 对应规范导数 \(q_r=(W/r,B/r)\)。
\item \emph{Epoch coherence.}
% 纪元一致性。
Only \(\eta\) is active.
% 仅 \(\eta\) 处于活跃状态。
Each live occurrence has exactly one authenticated gate and handle bound to \(\eta\).
% 每个活跃发生项都具有绑定到 \(\eta\) 的唯一认证门和句柄。
Inactive epochs expose no handle.
% 非活跃纪元不暴露句柄。
Closed epochs never reactivate.
% 已关闭纪元永不重新激活。
Each target epoch deterministically minted at the current cut for a registered request is unallocated or inactive and unbound.
% 在当前切点为注册请求确定性生成的每个目标纪元都未分配，或处于非活跃且未绑定状态。
\end{enumerate}
\end{definition}
The full system starts from one empty genesis, accepts a checked finite registration containing only contracts, schemas, policy, and authenticated identity rows, and then performs root installation to construct empty receipt/cursor/outbox state, the first epoch, its certificate, and its monitor.
% 完整系统从唯一的空起源状态开始，接受一个只包含契约、模式、策略和经认证标识行的经检查有限注册，随后执行根安装，以构造空的回执/游标/发件箱状态、第一个纪元及其证书和监控器。
Registration cannot supply runtime fields, while every later cut is produced by a six-edit derivation or an authenticated additive live extension.
% 注册过程不能提供运行时字段，而此后的每个切点都由六种编辑推导之一或一次经认证的仅追加在线扩展产生。

\paragraph{Atomic protected use}
% 原子受保护使用
For submitted invocation \(m\), set \(m^\circ=\mathsf{canon}_\kappa(m)\); for \(x\) bound to gate \(j\) in epoch \(\eta\), \(\mathsf{VerifyHandle}(h,\rho(x),j,d,m^\circ)\) verifies the issuer, scope, gate, cell, lineage, and signed digest and requires \(m^\circ=\mathsf{inv}_\rho(d)\).
% 对于提交的调用 \(m\)，令 \(m^\circ=\mathsf{canon}_\kappa(m)\)；对于纪元 \(\eta\) 中绑定到门 \(j\) 的 \(x\)，\(\mathsf{VerifyHandle}(h,\rho(x),j,d,m^\circ)\) 验证发行方、作用域、门、单元、谱系和签名摘要，并要求 \(m^\circ=\mathsf{inv}_\rho(d)\)。
Set \(a=\Fresh(x,d)\) if \(d\notin D_\Delta\), otherwise \(a=\Alias(x,d)\), and let \(\Use_x(m)=\mathsf{Use}(x,j,h,m)\).
% 若 \(d\notin D_\Delta\)，则令 \(a=\Fresh(x,d)\)，否则令 \(a=\Alias(x,d)\)，并令 \(\Use_x(m)=\mathsf{Use}(x,j,h,m)\)。
Its sole durable transition is the rule below.
% 其唯一持久转移是下列规则。
\begin{equation}
\label{eq:use-rule}
\frac{
\begin{gathered}
 x\text{ enabled in }T\quad
 \mathsf{bind}(x)=(j,\eta)\\[-2pt]
 \eta=H.\mathsf{epoch}\quad
 \mathsf{phase}(\eta)=\mathsf{active}\\[-2pt]
 \mathsf{VerifyHandle}(h,\rho(x),j,d,m^\circ)\quad
 \mathsf q(\eta)\xrightarrow{a}_{\mathsf{prog}(\eta)}q'
\end{gathered}}
{S\xrightarrow{\Use_x(m)/a}S'} .
\end{equation}
The unique structured residual \(T/(x,a)\) removes \(x\) from its leaf contract, selects the containing arm beneath an open choice, and preserves every frontier constructor.
% 唯一结构化残余 \(T/(x,a)\) 从其叶契约移除 \(x\)，在开放选择下选中包含 \(x\) 的分支，并保留每个前沿构造器。
The paired update \(\mathsf{HStep}((G,T),a)\) also appends \(a\) to the unique live branch cursor.
% 成对更新 \(\mathsf{HStep}((G,T),a)\) 还会把 \(a\) 追加到唯一的活跃分支游标。
\(\mathsf{Advance}(S,x,a,q')\) changes exactly the fields below.
% \(\mathsf{Advance}(S,x,a,q')\) 仅修改下列字段。
\[
\begin{aligned}
 (H.G,H.T)&:=\mathsf{HStep}((G,T),a),&
 H.\chi&:=\chi a,\\
 H.\nu&:=\nu+1,& H.\beta&:=\beta\setminus\{x\},\\
 \mathsf{bind}&:=\mathsf{bind}\setminus\{x\},&
 \mathsf q(\eta)&:=q'.
\end{aligned}
\]
In addition, \Fresh appends the immutable labeled receipt and ordered outbox item \((d,\mathsf{inv}_\rho(d))\), never an unchecked caller buffer, while \Alias records the cell's durable-result-future link without changing \(\Delta\), and all other fields remain unchanged.
% 此外，\Fresh 追加不可变的带标签回执和有序发件箱条目 \((d,\mathsf{inv}_\rho(d))\)，而绝不存储未经检查的调用方缓冲区；\Alias 记录该单元的持久结果期值链接且不改变 \(\Delta\)，其余字段保持不变。

An already-resolved \(x\) is a \Retry exactly when \(\mathsf{VerifyRetry}(h,x,j,d,m^\circ,\chi,\Delta)\) authenticates the same canonical invocation through the archived \(\chi\)-to-receipt link.
% 已解析的 \(x\) 当且仅当 \(\mathsf{VerifyRetry}(h,x,j,d,m^\circ,\chi,\Delta)\) 通过归档的从 \(\chi\) 到回执的链接认证同一规范调用时才构成 \Retry。
If the linked future contains stable value \(v\) under its authenticated reply token \(t\), success is the state-preserving observable transition \(S\xrightarrow{\mathsf{Return}(t,[v]_{\cong})}S\).
% 若所链接的结果期值在其经认证的回复令牌 \(t\) 下包含稳定值 \(v\)，则成功是保持状态的可观测转移 \(S\xrightarrow{\mathsf{Return}(t,[v]_{\cong})}S\)。
For unresolved \(x\), \cref{eq:use-rule} applies exactly when all premises hold, while a missing transition, bad handle, unbound occurrence, disabled branch, or closed epoch returns \(\mathsf{deny}(x)\) without changing state.
% 对未解析的 \(x\)，当且仅当全部前提成立时才应用 \cref{eq:use-rule}，而缺失转移、错误句柄、未绑定发生项、禁用分支或已关闭纪元都会返回 \(\mathsf{deny}(x)\) 且不改变状态。
\Dispatch releases exactly the stored canonical invocation in the oldest outbox item, settlement preserves \(\mathsf{AgentSec}\) and its authority projection, and crash is a state self-loop.
% \Dispatch 恰好释放最早发件箱条目中存储的规范调用，结算保持 \(\mathsf{AgentSec}\) 及其权限投影，而崩溃是状态自环。
Here \(\Dispatch\) is the durable local outbox release, not evidence of exactly-once execution by a remote service.
% 此处的 \(\Dispatch\) 是持久的本地发件箱释放，而不是远程服务恰好执行一次的证据。

\paragraph{Atomic verdict and installation}
% 原子判定与安装
At its linearization point, the kernel ignores caller-supplied target and epoch data, sets \(\Theta_S(u)=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\), and re-runs \(\mathsf{Derive}(\Theta_S(u))\) from the current state.
% 在其线性化点，内核忽略调用方提供的目标与纪元数据，令 \(\Theta_S(u)=(\kappa,H,\Delta,\mathsf{out},\mathcal A,u)\)，并根据当前状态重新执行 \(\mathsf{Derive}(\Theta_S(u))\)。
\(\mathsf{VerifyInv}\) accepts exactly a current \(\gamma\), undefined derivation, and canonical failed-check transcript, while \(\mathsf{VerifyRej}\) accepts exactly a current \(\gamma\), defined derivation, empty fixed point, and canonical elimination chain; their read-only transactions emit the corresponding \(\mathsf{Invalid}\) or \(\mathsf{Reject}\) label and preserve state.
% \(\mathsf{VerifyInv}\) 恰好接受当前 \(\gamma\)、未定义推导与规范检查失败记录，而 \(\mathsf{VerifyRej}\) 恰好接受当前 \(\gamma\)、已定义推导、空不动点与规范淘汰链；它们的只读事务发出相应的 \(\mathsf{Invalid}\) 或 \(\mathsf{Reject}\) 标签并保持状态。
For the positive case, write \(\mathsf{Derive}(\Theta_S(u))=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\).
% 对于正面情形，记 \(\mathsf{Derive}(\Theta_S(u))=(\kappa_u,H_u,\mathcal A_u,\mathcal C_u,\eta^-,\eta^+)\)。
\(\mathsf{ReCut}(S,u,Z)\) is undefined without this root, six-edit, or live-extension derivation and otherwise recomputes the right-hand side of \cref{eq:cut-seal}.
% 若无这一根推导、六种编辑推导或在线扩展推导，则 \(\mathsf{ReCut}(S,u,Z)\) 未定义；否则，它重新计算 \cref{eq:cut-seal} 的右侧。
\(\mathsf{Verify}_Z(W,B,\widehat B)\) holds exactly when the trusted checker (1) recomputes \(\widehat B_0\) and every fixed-point iteration, (2) verifies all ranked removal causes and surviving coverage witnesses, (3) checks the stabilized \(\widehat B\ne\varnothing\), (4) reconstructs \(B=\pi_2\widehat B\) and \(W=\Pref(B)\), (5) establishes \(\mathsf{prog}_Z\cong\mathsf{Can}(W,B)\), and (6) verifies the program seal.
% 当且仅当可信检查器执行以下操作时，\(\mathsf{Verify}_Z(W,B,\widehat B)\) 成立：(1) 重新计算 \(\widehat B_0\) 及每次不动点迭代；(2) 验证全部带秩的移除原因和幸存覆盖见证；(3) 检查稳定后的 \(\widehat B\ne\varnothing\)；(4) 重建 \(B=\pi_2\widehat B\) 与 \(W=\Pref(B)\)；(5) 建立 \(\mathsf{prog}_Z\cong\mathsf{Can}(W,B)\)；以及 (6) 验证程序封印。
Installation requires

\begin{equation}
\label{eq:install-premise}
\begin{gathered}

 \mathsf{ReCut}(S,u,Z)=\mathsf{cut}_Z,\\

    \widehat B^\dagger_{H,u}),\\

\end{gathered}
\end{equation}
\(\mathsf{Ready}(S,u,Y)\) holds when \(Y=\mathsf{Installable}(\delta,W^\dagger,\widehat B^\dagger,Z)\), the current derivation is \(\delta\), and all state-dependent premises of \cref{eq:install-premise} hold in \(S\).
% 当 \(Y=\mathsf{Installable}(\delta,W^\dagger,\widehat B^\dagger,Z)\)、当前推导为 \(\delta\) 且 \cref{eq:install-premise} 的全部状态相关前提在 \(S\) 中成立时，\(\mathsf{Ready}(S,u,Y)\) 成立。
If these premises hold, one domain transaction verifies that every target binding in \(H_u\) names a new gate owned by \(\eta^+\) and every replacement triple in \(\mathcal H_u^+\) passes the handle check against \(\rho_u\) and its registered cell.
% 若这些前提成立，一个域事务便验证 \(H_u\) 中的每个目标绑定均指向由 \(\eta^+\) 拥有的新门，并验证 \(\mathcal H_u^+\) 中的每个替换三元组均依据 \(\rho_u\) 及其注册单元通过句柄检查。
Let \(c^+=(\mathsf{src}(\Theta_S(u)),H_u,u,W^\dagger,\widehat B^\dagger,Z)\).
% 令 \(c^+=(\mathsf{src}(\Theta_S(u)),H_u,u,W^\dagger,\widehat B^\dagger,Z)\)。
It then applies
% 随后应用
\[
\begin{aligned}
 \kappa&:=\kappa_u,& \mathcal A&:=\mathcal A_u,\\
 H&:=H_u,&

A stale or malformed precomputed candidate emits no verdict, is discarded as an internal stutter, and must be recomputed against the current request cut before any visible response.

% 其余规则

% \(\mathsf{Preload}(\eta,Z)\) 是一个 \(\tau\) 步，它可以分配尚未分配的纪元或改变处于非活跃且未绑定状态的纪元，并使该纪元保持非活跃，而过期或畸形的候选尝试是保持状态的 \(\tau\) 步。

% 经认证的重试、包取回和结果交付发出 \(\mathsf{Return}(t,[v]_{\cong})\) 且不改变安全核心，而结算发出 \(\mathsf{Settle}(d,[v]_{\cong})\) 并单调填充相应的持久结果期值。

Pure \(\mathsf{Compile}\) is meta-level.

\begin{lemma}[History-cut linearization]
% 历史切点线性化
\label{lem:cut-linearization}
In every reachable well-formed compiled state, a visible admission verdict and a protected use in the same policy domain have a unique order and decision cut.
% 在每个可达的良构编译状态中，同一策略域内的一项可见准入判定与一次受保护使用具有唯一顺序和决策切点。
If the use commits first, that seal cannot install.
% 若该使用先提交，则该封印无法安装。
If \Install commits first, the old use cannot resolve \Fresh or \Alias.
% 若 \Install 先提交，则旧使用无法解析 \Fresh 或 \Alias。
Steps in independent domains commute by product semantics.
% 独立域中的步骤依据乘积语义可交换。
\end{lemma}
\begin{proof}
Prior \Fresh/\Alias invalidates every old cut seal, while prior installation closes the old epoch; disjoint-domain steps commute, and the persisted target and certificate restore the invariant.
% 先发生的 \Fresh/\Alias 会使每个旧切点封印失效，而先发生的安装会关闭旧纪元；互不相交域中的步骤可交换，持久目标与证书则恢复不变量。
\end{proof}
