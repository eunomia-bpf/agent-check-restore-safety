\section{Compilation and Verification}
\label{sec:algorithm}

The theorem yields a compiler for one proposed history cut, not a new Agent
planner.  Its input is the raw request $R$ from \cref{sec:model}; its output is
either a version-bound epoch seal or a promised outcome that no sound epoch
can preserve.

\subsection{Canonical construction}

\begin{enumerate}[leftmargin=*,itemsep=2pt]
  \item \textbf{Validate and normalize.}
  Check the typed edge shape, source versions, authenticated anchors, and
  within-class digest/issuer/scope/lineage agreement.  Translate the plan to a
  finite automaton for $\mathsf{Plant}_R$, making receipt-backed replays
  $\epsilon$-transitions.

  \item \textbf{Take the durable residual.}
  Product the plant with the policy automaton after reading $\delta$.  Remove
  states whose policy component is rejecting.  The resulting prefix automaton
  recognizes exactly $F_R$.

  \item \textbf{Check promises.}
  For each $\omega\in\Omega_e$, explore its linearizations jointly with the
  residual automaton.  If none reaches completion, return
  $(\omega,\mathsf{cut}_\omega)$, where
  $\mathsf{cut}_\omega$ records the first disabled causal frontier on every
  explored linearization.  This is an explanation of the complete
  impossibility in \cref{thm:canonical-epoch}, not a heuristic repair.

  \item \textbf{Emit the canonical epoch.}
  Merge states with the same right residual and encode the transition
  relation of $\mathsf{Can}(R)$.  Mint a target epoch identifier and bind its
  initial state, policy/view versions, exact receipt trace, source-controller
  set, target gate uses, and program hash into a seal.
\end{enumerate}

The construction operates on automata, not an enumerated list of histories.
Choice adds alternatives, sequence connects accepting frontiers, and parallel
takes an order-preserving product.  Parallel composition and promise
linearization can be exponential in the number of protected occurrences; we
claim finite decidability for bounded slices, not a polynomial algorithm for
arbitrary partial orders.  The residual quotient may reduce the emitted
state space, but minimal-automaton theory itself is classical
~\cite{brzozowski1964derivatives}.

\subsection{Small trusted checker}

The compiler is an untrusted witness producer.  A checker reparses $R$,
authenticates its anchors and receipt trace, independently reconstructs the
plan/policy product, and verifies:
\[
\begin{gathered}
 \mathsf{FreshTraces}(\mathsf{program})=F_R,\\
 \forall\omega\in\Omega_e.\quad
 \mathsf{Lin}(\omega)\cap F_R\ne\varnothing,\\
 \mathsf{seal.scope}
  =(\kappa,\nu,\delta,\mathsf{src},\mathsf{hash}(R),
    \mathsf{hash}(\mathsf{program})).
\end{gathered}
\]
Language equality is checked by the standard symmetric-difference product.
The checker does not authorize an individual external effect.  A verified seal
becomes installable only through the \textsc{Install} transition and only
while its entire scope still matches durable state.  This producer/checker
split follows the proof-carrying-code trust pattern
~\cite{necula1997pcc}.

For a negative result, the checker verifies that $\omega$ belongs to the
edge-derived promise set and that its product with $F_R$ has no accepting
state.  It does not accept a compiler-supplied prose reason.  A caller may
change the plan, promise, policy grant, or history operation and submit a new
request; that is a different theorem instance.

\subsection{Why the output is one logical epoch}

$\mathsf{Can}(R)$ is one authoritative logical state machine, even if a
deployment later replicates it behind a consensus service or compiles a
trace-equivalent distributed realization.  This choice removes a hidden
assumption from the security theorem: the caller no longer asserts that
several controllers preserve a correlation.  Decentralized supervisor
synthesis and language separability characterize when such a factorization is
possible~\cite{komenda2017decentralized}; they are optional lowerings below
the verified epoch, not part of causal history admission.

The logical epoch need not be a remote global round trip.  It is scoped to one
bounded Agent edge and can be placed with the protected tool gateway.  It
differs from the reference monitor in how it is obtained and retired: the
global policy and receipt history are compiled at the cut, while subsequent
fresh decisions use the installed residual state until another protected
slice or history edge forces a new cut.
