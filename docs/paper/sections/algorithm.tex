\section{Proof-Producing Monitor Compiler}
\label{sec:algorithm}

The theorem suggests a small compiler, not another Agent runtime.  For one
proposed Fork, Restore, or Merge, the artifact specializes the reference
monitor language to a submitted controller epoch and emits a proof witness.
An independent verifier recomputes the decision.  The tool neither creates
checkpoints nor releases effects; it returns a certificate, a controller
restriction that would make the edge admissible after installation and
resubmission, or a concrete obstruction.

\subsection{Manifest boundary}

A request supplies the authority family, append-only receipt frontier, typed
edge and leaf may/required maxima, explicit stable-cell aliases, and normalized
controller access/local/co-liveness evidence.  Aliases must preserve the cell
anchor, authority atom, commitment key, and effect digest; same-controller
uses must agree on anchor, version, and local family.  Co-liveness evidence is
either full exact $\Gamma$, an attested exact
$P=\Pi_{\le r}(\Gamma)$, or a diagnostic sound upper bound.

These are adapter attestations, not transcript inferences.  Neither executable
proves completeness, a projection label, or old-epoch closure.  A production
adapter must derive the typed label from the runtime constructor; natural
language does not establish a leaf contract or either identity quotient.

\subsection{Compilation pipeline}

The compiler follows the proof decomposition.

\begin{enumerate}[leftmargin=*,itemsep=2pt]
  \item It arm-tags every target occurrence, then folds only alias classes
  backed by explicit stable-cell evidence.  This computes
  $q_{\mathrm{cell}}$ without conflating it with controller identity.

  \item It applies the typed before/after edge rule to the leaf families,
  producing $\mathsf{Cand}_e$ and $\mathsf{Req}_e$ and checking
  $\mathsf{Req}_e\subseteq\mathsf{Cand}_e$.

  \item It computes the exact reference-monitor language by filtering the
  candidate against the current durable prefix and normalized lineage.  The
  result is the greatest admitted family inside this fixed candidate,
  $\mathsf{Adm}_e$; the compiler also records prefix-replay,
  lineage-collision, or forbidden-union reasons for removed configurations.

  \item It recomputes whether the source envelope is structurally inheritable.
  This requires an unchanged durable prefix and a commuting, collision-free
  parent map into the source future.  The prototype does not consume a prior
  verification seal or implement certificate-chain reuse; \textsc{Inherit}
  reports eligibility inside the canonical recomputation.

  \item Independently, it normalizes gate uses by controller anchor and derives
  $r=r(\mathsf{Req}_e,\mathsf{Adm}_e)$.  Projection mode rejects every
  submitted controller set larger than $r$, then the compiler enumerates
  \[
    \mathsf{Raw}(\widehat\Gamma)
      =\bigcup_{G\in\widehat\Gamma}\ \bigotimes_{g\in G} L_g,
  \]
  where $L_g$ is controller $g$'s local family after cell normalization.

  \item With full \texttt{exact} evidence, it checks the monitor-compilation
  sandwich directly.  With \texttt{exact\_projection\_through\_r}, it checks
  the same
  predicate on $P$ and applies \cref{thm:observation-arity} to decide readiness
  for hidden $\Gamma$ without reconstructing optional behavior.  A safe
  \texttt{sound\_overapprox} product proves only upper safety: it cannot prove
  hidden $\Gamma$ covers required behavior and therefore never yields
  \textsc{Ready} or a structural seal.
\end{enumerate}

The same capped pass filters the submitted family to its hereditary-safe
subfamily.  For full exact $\Gamma$, this is the greatest fixed-$E,L$ repair in
\cref{prop:principal-coliveness-repair}.  For exact projection $P$, the claim
is scoped only to $P$; a feasible result becomes a concrete full epoch policy
only after installation and resubmission.  For a sound upper bound, it is
diagnostic and never installable.  No proposal changes the current decision or
seal.

The output separates semantic feasibility from controller realization.  Full
exact evidence distinguishes exact, safely restricted, unsafe, incomplete,
and doubly failing layouts; exact projection preserves the readiness bit.
Sound upper bounds never seal.  A proposed safe restriction becomes effective
only after installation and resubmission under a new version-bound
certificate.

\subsection{Constructive negative evidence}

For a deterministic bad cover the compiler emits: the cell for
\textsc{OutsideSupport}; a contained minimal nonface and controller for
\textsc{LocalOverpermission}; or an inclusion-minimal multi-controller cover
for \textsc{CorrelationCut}.  Declared common origins further label the last
case \textsc{GateClone}.  The causes are exclusive for the chosen cover, not
globally unique.  Missing behavior instead yields a witness in
$\mathsf{Req}_e\setminus\mathsf{Raw}(\widehat\Gamma)$; both differences may be
reported.  A witness from a sound upper bound describes that bound, not
necessarily the hidden runtime.

\subsection{Independent verification and fail-closed limits}

The untrusted compiler emits canonical JSON.  A verifier that imports no
compiler code reparses the request, reconstructs the semantics with bit masks,
and compares the complete result.  It rejects unknown/duplicate fields,
malformed receipts, inconsistent aliases or anchors, tampering, and
\texttt{sound\_overapprox} certificates.  Digests bind the decision to its
request and evidence mode.  Fixed caps (12 source and target cells, 10
controllers, 4,096 configurations, and 200,000 product iterations) fail
closed; the artifact targets small contracts, not scale.

Even a valid positive result is only a \emph{history-admission} certificate,
and the verifier always emits
$\mathsf{effect\_authorizes}=\mathsf{false}$.  In
projection mode, $\mathsf{Raw}(P)$ is not claimed to upper-bound runtime
behavior.  The adapter must attest exact projection, hidden-$\Gamma$ downward
closure, and the same installed $E,L$; the runtime must establish the
version-bound edge cut and
\[
  \mathsf{Req}_e\subseteq\mathsf{Actual}
  \subseteq\mathsf{Raw}(E,L,\Gamma).
\]
Receipt authenticity, complete mediation, controller installation and
freshness, atomic redemption, and lease revalidation remain external
obligations.
The Lean model specifies the finite decision but is not an extraction of the
Python parser or verifier; proof replay, independent reimplementation, and
exhaustive small-model cross-checks are distinct evidence layers.
