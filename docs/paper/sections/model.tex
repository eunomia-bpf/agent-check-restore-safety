\section{Authority over Durable Futures}
\label{sec:model}

\subsection{Typed claims and durability configurations}

Let \(\calK\) be a finite set of authority coordinates.
A coordinate fixes issuer, resource, scope, and grant epoch, so quantities are substitutable only within that coordinate.
Issued historical capacity is \(G\in\Nat^{\calK}\).
A claim \(c\) has a globally unique ID, an effect binding, and demand \(w(c)\in\Nat^{\calK}\).
Bindings are validated by typed schemas, issuers, or deterministic policy; an LLM may propose but cannot certify them.

Let \(B\) be the live branch epochs.
The durable ledger partitions all issued claim IDs:
\begin{equation}
I_{\mathrm{issued}}
=D\;\dot\cup\;X\;\dot\cup\;\dot\bigcup_{b\in B}Q_b.
\label{eq:partition}
\end{equation}
\(D\) contains durable or conservatively uncertain consumption, \(X\) contains terminal IDs that never revive, and \(Q_b\) contains conditional commitments owned by \(b\).
Here \(I_{\mathrm{issued}}\) is state-indexed and monotone: Reserve adds its fresh ID, certified fragmentation adds its fresh target IDs, and every other rule only moves already issued IDs.
Copying an ID violates \cref{eq:partition}; minting a fresh second claim counts its demand twice.
For \(c\in\bigcup_b Q_b\), write \(\mathsf{own}_A(c)=b\) exactly when \(c\in Q_b\).
Ownership is therefore state indexed and may move once under a certified topology transfer; the claim ID, grant epoch, demand, and effect binding remain immutable.

\begin{definition}[Conditional commitment]
The bundle \(Q_b\) is a runtime promise that, if \(b\) remains eligible under the declared lifecycle and each claim's grant epoch is open, all claims in the bundle may jointly pass the trusted effect gate without acquiring new authority.
\end{definition}

Pure speculation can instead leave child bundles empty and retain authority in parent escrow.
An internal either/or between claims must be represented as lifecycle choice; otherwise summing the bundle is a conservative approximation.

The lifecycle contract denotes a nonempty downward-closed family \(\Phi\subseteq2^B\).
We call \(C\in\Phi\) a \emph{durability configuration}: every branch in \(C\) may contribute a reserved outcome to one durable result.
Downward closure permits further discard.
Define
\[
d=\sum_{c\in D}w(c),
\qquad
r_b=\sum_{c\in Q_b}w(c),
\qquad
q(C)=\sum_{b\in C}r_b.
\]

\begin{definition}[Authority continuity]
\label{def:ac}
An authority state \(\Sigma=(G,D,Q,\Phi)\) is continuous when
\begin{equation}
\ac(\Sigma)
\quad\Longleftrightarrow\quad
\forall C\in\Phi.\ d+q(C)\le G.
\label{eq:ac}
\end{equation}
\end{definition}

For reporting and the unguarded fast path, write
\[
\need(\Sigma)=d+\bigvee_{C\in\Phi}q(C).
\]
Then \(\ac(\Sigma)\) iff \(\need(\Sigma)\le G\).

Actual durable outcomes may be a subset of \(\Phi\), making \cref{eq:ac} conservative.
An exact converse additionally requires that every advertised configuration is selectable and each bundle is jointly realizable.

\subsection{Residual authorization profiles}

For a configuration \(C\), its residual slack is
\begin{equation}
s_\Sigma(C)=G-d-q(C).
\label{eq:slack}
\end{equation}
For supported branch \(b\), define its componentwise headroom
\begin{equation}
H_\Sigma(b)=
\bigwedge_{\substack{C\in\Phi\\b\in C}}s_\Sigma(C),
\label{eq:headroom}
\end{equation}
and set \(H_\Sigma(b)=\bot\) if no allowed configuration contains \(b\).
Write \(B^+=\{b\in B\mid H_\Sigma(b)\ne\bot\}\); structural admission rejects Reserve for \(B\setminus B^+\).

Headroom describes one branch at a time.
The correlated residual region describes arbitrary additional reservation batches:
\begin{equation}
\mathcal R_\Sigma=
\left\{x\in\Nat^{B^+\times\calK}\ \middle|\
\forall C\in\Phi.\ \sum_{b\in C}x_b\le s_\Sigma(C)
\right\}.
\label{eq:residual}
\end{equation}
It is a downward-closed set.
The distinction between \(H\) and \(\mathcal R\) will expose why local balances lose the correlation needed by fork and merge.

\subsection{Structured and guarded contracts}

A base lifecycle contract is
\[
P::=\mathbf0\mid b\mid P\mathbin\Box P\mid P\parallel P,
\]
with unique leaf labels.
Choice permits at most one side, while parallel permits both:
\begin{align*}
\front(\mathbf0)&=\{\varnothing\},\\
\front(b)&=\{\varnothing,\{b\}\},\\
\front(P\Box Q)&=\front(P)\cup\front(Q),\\
\front(P\parallel Q)&=\{C\cup C'\mid
 C\in\front(P),\ C'\in\front(Q)\}.
\end{align*}

Promotion will require a strictly richer durable policy.
A frozen guard row is \(\gamma=(\{(a_i,\lambda_i)\}_{i=1}^m,k)\), where \(a_i,k\in\Nat^{\calK}\) and each lineage predicate \(\lambda_i:2^B\to\{0,1\}\) is an explicitly represented monotone, zero-preserving Boolean circuit.
It accepts \(C\) iff
\begin{equation}
C\models\gamma
\quad\Longleftrightarrow\quad
\sum_i a_i\lambda_i(C)\le k.
\label{eq:guard}
\end{equation}
A guarded contract \(T=(P,\Gamma)\) denotes base configurations satisfying every row.
Nonnegative coefficients and monotone predicates preserve downward closure; zero preservation ensures that the empty configuration remains accepted when \(0\le k\).
Rows contain frozen values, not pointers to current \(Q\); later claim withdrawal cannot silently reopen a discarded future.
Representation size includes predicate-circuit size, not only numeric coefficients.

Each old branch initially uses \(\lambda_b(C)=\mathbf1[b\in C]\).
A zero-preserving lifecycle projection \(\pi:2^{B'}\to2^B\) transports old rows by \(\lambda\leftarrow\lambda\circ\pi\).
Refining \(b\) into live descendants substitutes the disjunction of their membership variables, charging the old lineage once even when several descendants survive.
Standard fork/restore projections preserve compact OR-lineage predicates; a general merge must provide and pay for an explicit projection circuit or use full target re-admission.

\subsection{Concrete state and well-formedness}

A concrete state pairs reconstructable values \(V\) with durable controller state
\[
A=(G,N,B,D,X,Q,T,J,R),
\]
where \(N\) records branch/grant epoch status, \(J\) maps protected operation IDs to one-shot tickets in \(\mathsf{prepared}\), \(\mathsf{inflight}\), or \(\mathsf{uncertain}\) phase, and \(R\) records settled receipts.
The abstraction \(\alpha\) drops payload and scheduling detail but retains the authority fields and \(\Phi=\front(T)\).
A snapshot may overwrite \(V\), never \(A\).

Well-formedness requires \cref{eq:partition}, monotone epoch and terminal status, valid bindings, and support for every promised owner.
Let \(\mathsf{claim}_{J,R}(e)\) project the claim from either a ticket or receipt.
We require \(\operatorname{dom}J\cap\operatorname{dom}R=\varnothing\), \(\mathsf{claim}_{J,R}\) injective on \(\operatorname{dom}J\cup\operatorname{dom}R\), and \(\operatorname{ran}(\mathsf{claim}_{J,R})\subseteq D\).
Thus every protected external operation ID is bound to exactly one durable claim and distinct IDs have distinct claims, except that physical retries reuse the same stable ID and ticket.
Its concrete demand is bounded by \(w(c)\), and the matching claim must already be durable or uncertain before emission.
These effect-coverage obligations are part of the trusted gate, not consequences of \cref{eq:ac} alone.
