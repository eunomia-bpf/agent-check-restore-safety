\section{Model and Edit Derivation}
% 模型与编辑推导
\label{sec:model}

The model separates unrestricted internal Agent reasoning from tool calls whose effects pass through a trusted runtime monitor.
% 该模型将不受限制的 Agent 内部推理与效果必须经过可信运行时监控器的工具调用分开。
Such a call must identify its registered position in the workflow, present an authorization token, and submit a concrete tool request.
% 这类调用必须标明它在工作流中的已注册位置、提供授权令牌，并提交具体工具请求。
The monitor decides whether the call may use a new authorization, reuse an earlier completion record, or make no progress.
% 监控器决定该调用能否使用新的授权、复用先前的完成记录，或不得推进。
Each modeled state covers one policy domain.
% 每个建模状态涵盖一个策略域。
Domains with disjoint protected actions, completion logs, and policies compose by product.
% 受控动作、完成日志和策略彼此不相交的域通过乘积组合。
Every state snapshot is finite, although an execution may contain an unbounded number of snapshots.
% 每个状态快照都是有限的，但一次执行可以包含数量不受固定上界约束的快照。
The definitions below first describe the required outcomes and then the authenticated record needed to preserve them across edits.
% 下文首先描述要求实现的结果，随后定义在编辑过程中保留这些结果所需的认证记录。

\subsection{Workflow outcomes and call order}
% 工作流结果与调用次序

\paragraph{Typed runtime vocabulary}
% 类型化运行时词汇
We capitalize \emph{Agent} for the untrusted principal requesting execution edits.
% 我们将请求执行编辑的不受信任主体称为 \emph{Agent}。
An \emph{occurrence} \(x\) identifies one position for a protected tool call in the workflow.
% \emph{发生项} \(x\) 标识工作流中一次受控工具调用的位置。
An \emph{effect identity} \(d\), called a cell in the formulas, identifies the one protected action and one-use permission behind that position.
% \emph{效果标识} \(d\) 在公式中称为单元，它标识该调用位置背后的受控动作与一次性权限。
The first authorized use of an effect identity creates a receipt.
% 一个效果标识首次获得授权使用时会创建回执。
After Fork or Restore, several occurrences may refer to the same effect identity.
% Fork 或 Restore 之后，多个发生项可能指向同一个效果标识。
A monitor entry \(j\) belongs to one monitor version \(\eta\).
% 监控器入口 \(j\) 属于一个监控器版本 \(\eta\)。
An authorization token \(h\) binds an occurrence to its monitor entry, effect identity, scope, and normalized tool request \(m^\circ\).
% 授权令牌 \(h\) 将发生项绑定到监控器入口、效果标识、作用域和规范化工具请求 \(m^\circ\)。
\emph{Lineage} is the certified ancestry preserved when an edit carries or copies a workflow region.
% \emph{谱系}是编辑携带或复制工作流区域时保留的认证祖先关系。
\(T,\Delta,\chi\) denote the active workflow, receipt log, and ordered record of resolved occurrences.
% \(T,\Delta,\chi\) 分别表示当前工作流、回执日志和已解析发生项的有序记录。
An edit takes effect at an atomic installation point, which also replaces the policy domain's monitor version.
% 一次编辑在原子安装点生效，该安装点同时替换策略域的监控器版本。
Registry \(\rho\) authenticates each occurrence's monitor entry and token.
% 注册表 \(\rho\) 认证每个发生项的监控器入口和令牌。
It maps the occurrence to \(q_{\rm cell}(x)=d\), immutable normalized request \(\mathsf{inv}(d)=m^\circ\), and permission label \(\ell(d)\).
% 它将发生项映射到 \(q_{\rm cell}(x)=d\)、不可变的规范化请求 \(\mathsf{inv}(d)=m^\circ\) 和权限标签 \(\ell(d)\)。

A pomset \(p=(X_p,\prec_p)\) is a finite set of occurrences with a strict partial order.
% 偏序事件集 \(p=(X_p,\prec_p)\) 是带有严格偏序的有限发生项集合。
Its linearizations \(\Lin(p)\) are the words containing each member of \(X_p\) once and respecting \(\prec_p\).
% 它的线性化 \(\Lin(p)\) 是各包含 \(X_p\) 中每个成员一次且遵循 \(\prec_p\) 的序列。
An \emph{indexed workflow contract} \(\mathcal C=(O,\{p_o\}_{o\in O})\) is a finite nonempty family of pomsets.
% \emph{带索引的工作流契约} \(\mathcal C=(O,\{p_o\}_{o\in O})\) 是一个有限非空的偏序事件集族。
Each index \(o\) names one allowed completion outcome.
% 每个索引 \(o\) 命名一种允许的完成结果。
Two outcomes remain distinct even if the calls still required for them later become identical.
% 即使两个结果后来仍需执行的调用变得相同，它们仍保持不同。
Write \(X_{\mathcal C}=\bigcup_{o\in O}X_{p_o}\) and \(\mathsf{CL}(\mathcal C)=\bigcup_{o\in O}\Lin(p_o)\).
% 记 \(X_{\mathcal C}=\bigcup_{o\in O}X_{p_o}\) 且 \(\mathsf{CL}(\mathcal C)=\bigcup_{o\in O}\Lin(p_o)\)。
We require the runtime to distinguish completion from continuation.
% 我们要求运行时能够区分完成与继续执行。
\[
 v,w\in\mathsf{CL}(\mathcal C)\ \land\
 v\preceq_{\rm pref}w \quad\Longrightarrow\quad v=w .
\]
This condition permits incomparable traces and different outcomes with the same trace, so it does not require deterministic outcomes.
% 该条件允许不可比较的轨迹以及共享同一轨迹的不同结果，因此并不要求结果具有确定性。
It requires a registered occurrence whenever continuing after a shared partial execution performs more work.
% 如果在一段共享的部分执行之后继续会执行更多工作，该条件要求存在一个已注册发生项来表示继续。
An otherwise silent choice between stopping and continuing lies outside the interface.
% 一个不产生可观察事件的停止或继续选择不属于该接口。
A deployment may represent such a choice with an authenticated terminal occurrence handled by the controller, without claiming that a remote action occurred.
% 部署可以用由控制器处理的认证终止发生项表示这种选择，而不声称远端动作已经发生。

Contracts use the three partial constructors below.
% 契约使用下列三个偏构造器。
Each constructor requires occurrence-disjoint operands and is defined only when its result remains completion-observable.
% 每个构造器都要求操作数的发生项互不相交，并且仅在结果仍满足完成可观测性时有定义。
\begin{equation}
\label{eq:contract-algebra}
\begin{aligned}
 O_{\mathcal C\oplus\mathcal D}
  &= (\{L\}\mathbin{\times}O_{\mathcal C})
     \uplus(\{R\}\mathbin{\times}O_{\mathcal D}),\\
 p_{(L,o)}&=p_o,\qquad p_{(R,v)}=p_v,\\
 O_{\mathcal C\otimes\mathcal D}
  &=O_{\mathcal C}\mathbin{\times}O_{\mathcal D},\\
 p_{(o,v)}&=p_o\uplus p_v,\\
 O_{\mathcal C\triangleright\mathcal D}
  &=O_{\mathcal C}\mathbin{\times}O_{\mathcal D},\\
 p_{(o,v)}&=p_o\triangleright p_v.
\end{aligned}
\end{equation}
Before adding a registered or copied operand, the edit derivation deterministically renames its occurrences and extends \(\rho\) while retaining their authenticated effect identities.
% 在加入已注册或复制的操作数之前，编辑推导会确定性地重命名其发生项并扩展 \(\rho\)，同时保留其认证效果标识。
Well-formedness already makes carried operands disjoint.
% 良构性已经保证被携带的操作数互不相交。
In \cref{eq:contract-algebra}, \(\uplus\) adds no cross-order and \(\triangleright\) orders every event of \(p\) before every event of \(q\), while choice uses a tagged union of outcome indices and parallel and sequence use Cartesian products.
% 在 \cref{eq:contract-algebra} 中，\(\uplus\) 不添加跨操作数次序，\(\triangleright\) 将 \(p\) 的每个事件置于 \(q\) 的每个事件之前，而选择使用带标签的结果索引不交并，并行和顺序则使用笛卡尔积。
Consequently, choice retains each arm's full indexed family, parallel pairs outcomes while permitting every causal linearization, and sequence adds a barrier.
% 因此，选择保留每个分支的完整带索引结果族，并行对结果配对并允许每种因果线性化，而顺序添加一道屏障。
For raw prefix \(w\), \(\mathcal C/w\) retains each index whose pomset has a linearization prefixed by \(w\) and removes \(w\)'s occurrences and incident order, and it is undefined if none remains.
% 对于原始前缀 \(w\)，\(\mathcal C/w\) 保留其偏序事件集存在以 \(w\) 为前缀的线性化的每个索引，并移除 \(w\) 中的发生项及其关联次序；若没有索引保留，则其无定义。
This operational ``remaining contract'' preserves outcome and occurrence identity.
% 这一“剩余契约”的操作定义会保留结果标识和发生项标识。

\begin{lemma}[Observable completion]
% 可观测完成
\label{lem:observable-completion}
Every defined residual \(\mathcal C/w\) is completion-observable, and either every retained pomset is empty or no retained pomset is empty.
% 每个有定义的残余 \(\mathcal C/w\) 都满足完成可观测性，并且保留的偏序事件集要么全为空，要么全都非空。
\end{lemma}
\begin{proof}
If a residual suffix \(v\) strictly prefixes \(v'\), then \(wv\) strictly prefixes \(wv'\) in \(\mathsf{CL}(\mathcal C)\).
% 如果残余后缀 \(v\) 是 \(v'\) 的真前缀，那么在 \(\mathsf{CL}(\mathcal C)\) 中，\(wv\) 是 \(wv'\) 的真前缀。
If one retained pomset is empty and another is nonempty, choose a nonempty linearization \(v\) of the latter.
% 如果一个保留的偏序事件集为空而另一个非空，则选择后者的一条非空线性化 \(v\)。
Then \(w\) strictly prefixes \(wv\).
% 此时 \(w\) 是 \(wv\) 的真前缀。
Both contradict completion observability.
% 两种情况都与完成可观测性矛盾。
\end{proof}

\subsection{Trusted history state}
% 可信历史状态

\subsubsection{History State and Live Frontier}

An Agent history state is
% Agent 的历史状态为
\begin{equation}
\label{eq:history-state}
 H=(\omega,G,T,K,\Sigma_\zeta,\rho,\beta,\chi,\nu,\eta).
\end{equation}
\(\omega\) is the policy-domain identity and \(\eta\) its single current policy-domain epoch.
% \(\omega\) 是策略域标识，\(\eta\) 是该域唯一的当前策略域纪元。
\(G\) is a finite append-only provenance store whose node identities, base contracts, and typed topology records never change.
% \(G\) 是有限的仅追加溯源存储，其中的节点标识、基础契约和类型化拓扑记录永不改变。
Each continuation node \(b\) carries an immutable registered base contract \(\Gamma_b\), while its branch-local resolved cursor \(\chi_b\) is the event projection of append-only progress records tagged by \(b\).
% 每个延续节点 \(b\) 携带一个不可变的已注册基础契约 \(\Gamma_b\)，而其分支局部已解析游标 \(\chi_b\) 是带 \(b\) 标签的仅追加进度记录的事件投影。
The immutable topology records form a DAG whose edges record typed Fork, Restore, and Merge operations.
% 不可变拓扑记录形成一个 DAG，其边记录类型化的 Fork、Restore 和 Merge 操作。
\(T\) is the live structural frontier.
% \(T\) 是活跃结构前沿。
\[
 T ::= b{:}\mathcal C
     \mid T\oplus_g^s T
     \mid T\parallel_g T
     \mid \mathsf{jbar}(T,T)
     \mid T;T .
\]
\(s\in\{\mathsf{open},L,R\}\) records an unresolved choice or the arm that made durable progress, and \(g\) groups exclusive or jointly live siblings.
% \(s\in\{\mathsf{open},L,R\}\) 记录尚未解决的选择或已取得持久进展的分支，\(g\) 则将互斥或共同活跃的同级项分组。
\(\sem{T}\) uses both arms of an open choice and only the selected arm thereafter.
% \(\sem{T}\) 对开放选择使用两个分支，此后仅使用选中的分支。
It interprets parallel and \(\mathsf{jbar}\) with \(\otimes\), and sequence with \(\triangleright\).
% 它用 \(\otimes\) 解释并行和 \(\mathsf{jbar}\)，并用 \(\triangleright\) 解释顺序。
The unaddressed \(\mathsf{jbar}\) marks a joined group and prevents another Merge.
% 未被寻址的 \(\mathsf{jbar}\) 标记一个已合并组，并阻止再次 Merge。

\(T\) is \(\mathsf{complete}\) when every pomset in \(\sem{T}\) is empty.
% 当 \(\sem{T}\) 中的每个偏序事件集都为空时，\(T\) 为 \(\mathsf{complete}\)。
\Cref{lem:observable-completion} excludes a residual containing both empty and nonempty pomsets.
% \Cref{lem:observable-completion} 排除了同时包含空与非空偏序事件集的残余。
Set \(\mathsf{heads}(b{:}\mathcal C)=\{b\}\).
% 令 \(\mathsf{heads}(b{:}\mathcal C)=\{b\}\)。
Open choice exposes both arms, selected choice its winner, parallel and \(\mathsf{jbar}\) both arms, and sequence its left operand until completion and then its right.
% 开放选择暴露两个分支，已选选择暴露胜出分支，并行和 \(\mathsf{jbar}\) 暴露两个分支，而顺序先暴露左操作数直至其完成，再暴露右操作数。
Occurrence progress residualizes leaves without deleting structure.
% 发生项进展会使叶节点残余化，但不删除结构。
Because sequence exposure tests \(\mathsf{complete}\), it retains completed left-outcome indices, so an isolated completed leaf remains addressable for later Fork or Restore.
% 由于顺序暴露检查 \(\mathsf{complete}\)，它会保留已完成的左侧结果索引，因此孤立的已完成叶节点仍可供后续 Fork 或 Restore 寻址。
Joining removes \(g\) immediately but keeps its continuation behind a barrier until both arms complete.
% Join 会立即移除 \(g\)，但在两个分支都完成之前，将其延续保持在屏障之后。
An occurrence is enabled when minimal in some pomset of \(\sem{T}\), consistent with sequence exposure by observable completion.
% 当一个发生项在 \(\sem{T}\) 的某个偏序事件集中为极小元时，它即被启用；这与完成可观测性所确定的顺序暴露一致。
Occurrence disjointness and unique context decomposition give every enabled \(x\) a unique exposed leaf \(\mathsf{leaf}_T(x)=b\).
% 发生项互不重叠以及上下文分解的唯一性，使每个已启用的 \(x\) 都具有唯一的已暴露叶节点 \(\mathsf{leaf}_T(x)=b\)。
For \(a\in\{\Fresh(x,d),\Alias(x,d)\}\), define the paired history residual
% 对于 \(a\in\{\Fresh(x,d),\Alias(x,d)\}\)，定义成对历史残余
\[
 \mathsf{HStep}((G,T),a)=
 \bigl(G\mathbin{\|}(b,a),\,T/(x,a)\bigr),
 \qquad b=\mathsf{leaf}_T(x),
\]
where \(G\mathbin{\|}(b,a)\) appends the progress record \((b,a)\), and \(T/(x,a)\) residualizes the leaf and records any choice selection without storing a second cursor.
% 其中 \(G\mathbin{\|}(b,a)\) 追加进度记录 \((b,a)\)，而 \(T/(x,a)\) 对叶节点取残余并记录任何选择结果，但不存储第二份游标。
Write \(\mathsf{HRes}((G,T),r)\) for iterating this paired residual over a resolved word \(r\).
% 用 \(\mathsf{HRes}((G,T),r)\) 表示沿已解析词 \(r\) 迭代这一成对残余。

\(\mathsf{addr}(T)\) follows the same recursion over branch and group identifiers.
% \(\mathsf{addr}(T)\) 对分支标识和组标识采用相同的递归。
It includes exposed groups before descending into their live arms and only the exposed sequence operand, excluding dormant losers and unexposed operands.
% 它在递归进入活跃分支之前纳入已暴露的组，并且只纳入已暴露的顺序操作数，排除休眠的败者和未暴露的操作数。

\(K\) maps checkpoint identifiers to immutable earlier continuation records.
% \(K\) 将检查点标识映射到不可变的先前延续记录。
Write \(\mathcal C_k=\mathsf{contract}(K(k))\) for the residual contract stored by checkpoint \(k\).
% 将检查点 \(k\) 存储的残余契约记为 \(\mathcal C_k=\mathsf{contract}(K(k))\)。
\(\Sigma_\zeta\) is a versioned immutable registry of typed edit schemas.
% \(\Sigma_\zeta\) 是带版本且不可变的类型化编辑模式注册表。
\(\rho\) contains the authenticated occurrence-to-gate/cell, handle, lineage, scope, canonical-invocation, and effect-digest data.
% \(\rho\) 包含经认证的发生项到门/单元的映射、句柄、谱系、作用域、规范调用和效果摘要数据。
For each live occurrence \(x\), binding \(\beta(x)=(j,\eta)\) names its gate and the domain's current epoch, while \(\chi\) is the ordered append-only trace of durably \emph{resolved} logical occurrences, including \Fresh and \Alias bindings, and \(\nu\) is the history-view version.
% 对于每个活跃发生项 \(x\)，绑定 \(\beta(x)=(j,\eta)\) 指明其门和该域的当前纪元，而 \(\chi\) 是持久\emph{已解析}逻辑发生项的有序仅追加轨迹，包括 \Fresh 和 \Alias 绑定，\(\nu\) 则是历史视图版本。
Because \(\chi\) records authorization and causal progress rather than physical completion, the corresponding external result may still await remote settlement or return.
% 由于 \(\chi\) 记录授权和因果进展而非物理完成，相应的外部结果仍可能等待远程结算或返回。

\(\mathsf{Save}(k,b)\) is an explicit checkpoint transition, not a seventh execution edit, and requires fresh \(k\) and addressable \(b\).
% \(\mathsf{Save}(k,b)\) 是显式检查点转移，而非第七种执行编辑，并要求 \(k\) 为新标识且 \(b\) 可寻址。
A trusted transaction snapshots the current pair \((\mathcal C_b,\chi_b)\) by value and appends \((\omega,b,\mathcal C_b,\chi_b,\rho|_{X_{\mathcal C_b}},\zeta)\) and its authenticated fingerprint to \(K\).
% 一个可信事务按值快照当前的 \((\mathcal C_b,\chi_b)\) 对，并向 \(K\) 追加 \((\omega,b,\mathcal C_b,\chi_b,\rho|_{X_{\mathcal C_b}},\zeta)\) 及其认证指纹。
The checkpoint check requires \(\mathcal C_b=\Gamma_b/\mathsf{raw}(\chi_b)\), and the transaction advances \(\nu\) without changing the frontier, receipts, bindings, epochs, or authority.
% 检查点检查要求 \(\mathcal C_b=\Gamma_b/\mathsf{raw}(\chi_b)\)，且该事务推进 \(\nu\) 而不改变前沿、回执、绑定、纪元或权限。
Both machines take this \(\tau\)-transition, which makes a concurrent installation stale because installation authenticates \(H\).
% 两台机器都执行该 \(\tau\)-转移；由于安装过程认证 \(H\)，该转移会使并发安装过期。
Restore accepts only records created by this rule.
% Restore 仅接受由此规则创建的记录。

\subsubsection{Well-Formedness}

\begin{definition}[Well-formed history]
% 良构历史
\label{def:well-formed-history}
\(H\) is well formed when the following groups hold.
% 当下列各组条件成立时，\(H\) 是良构的。
\begin{enumerate}[leftmargin=*,itemsep=0pt,topsep=1pt]
\item \emph{Structure.}
% \emph{结构。}
\(G\) is acyclic, and continuation and group identifiers are globally unique across the recorded DAG and live frontier.
% \(G\) 是无环的；延续标识和组标识在所记录的 DAG 与活跃前沿中全局唯一；每个可寻址标识都有唯一的上下文分解；\(T\) 的每个头节点都是活跃极大节点；并且每个检查点都指明一个不可变节点坐标以及从 \(G\) 派生并按值快照的残余/游标对。
Every addressable identifier has a unique context decomposition, and every head of \(T\) is a live maximal node.
% 每个可寻址标识都有唯一的上下文分解，且 \(T\) 的每个头节点都是活跃极大节点。
Every checkpoint names an immutable node coordinate and a value-snapshotted residual/cursor pair derived from \(G\).
% 每个检查点都指明一个不可变节点坐标以及从 \(G\) 派生并按值快照的残余/游标对。
\item \emph{Identity and progress.}
% \emph{标识与进展。}
Occurrence and gate identifiers are unique, while occurrences mapped to the same cell agree on protected-call issuer, scope, canonical invocation, digest, and lineage.
% 发生项标识和门标识是唯一的，而映射到同一单元的发生项在受保护调用发行方、作用域、规范调用、摘要和谱系上保持一致。
Resolved occurrences are downward closed in their pomset, consistent with every choice status, and absent from the residual frontier.
% 已解析发生项在其偏序事件集中向下闭合，与每个选择状态一致，并且不出现在残余前沿中。
\item \emph{Live frontier.}
% \emph{活跃前沿。}
\(\operatorname{dom}(\beta)=X_{\sem T}\), and every live occurrence \(x\) has exactly one authenticated binding \(\beta(x)=(j_x,\eta)\) to the domain's single current epoch.
% \(\operatorname{dom}(\beta)=X_{\sem T}\)，且每个活跃发生项 \(x\) 都恰有一个经认证的绑定 \(\beta(x)=(j_x,\eta)\)，指向该域唯一的当前纪元。
Every live leaf \(b{:}\mathcal C\) is exactly the indexed residual of its immutable registered base \(\Gamma_b\) by the raw projection of its resolved cursor \(\chi_b\), rather than a caller-pruned subfamily.
% 每个活跃叶节点 \(b{:}\mathcal C\) 恰好是其不可变已注册基础 \(\Gamma_b\) 按已解析游标 \(\chi_b\) 的原始投影所得的带索引残余，而不是由调用方裁剪的子族。
Every constructor in \(T\) is defined, so every subtree interpretation is completion-observable.
% \(T\) 中的每个构造器都有定义，因此每个子树解释都满足完成可观测性。
\item \emph{Schema and domain.}
% \emph{模式与域。}
Every edge and introduced contract is justified by one immutable schema at version \(\zeta\).
% 每条边和每个引入的契约都由版本 \(\zeta\) 的一个不可变模式提供依据。
Every current, checkpoint, or schema occurrence, cell, gate, lineage, and scope belongs to \(\omega\).
% 当前状态、检查点或模式中的每个发生项、单元、门、谱系和作用域都属于 \(\omega\)。
Cells, receipt ledgers, and policies of distinct domains are disjoint, and an edit never crosses a domain.
% 不同域的单元、回执账本和策略互不相交，并且编辑绝不跨域。
\end{enumerate}
The durable kernel additionally requires that the one current policy-domain epoch is active.
% 持久内核还要求唯一的当前策略域纪元处于活跃状态。
\end{definition}

\subsubsection{Ledger and Security Core}

Outside \(H\), ledger state stores policy version \(\kappa\), a regular prefix-closed authority policy \(\mathcal A\subseteq\mathcal U^*\) over label alphabet \(\mathcal U\), monotone receipt ledger \(\Delta\), and ordered outbox \(\mathsf{out}\).
% 在 \(H\) 之外，账本状态存储策略版本 \(\kappa\)、定义在标签字母表 \(\mathcal U\) 上的正则前缀闭合权限策略 \(\mathcal A\subseteq\mathcal U^*\)、单调回执账本 \(\Delta\) 和有序发件箱 \(\mathsf{out}\)。
Receipt creation is append-only.
% 回执创建仅可追加。
Settlement advances receipt phases and fills durable result futures with stable results.
% 结算会推进回执阶段，并用稳定结果填充持久结果期值。
Each receipt binds its cell, immutable canonical invocation, creator occurrence, and authority label.
% 每条回执都绑定其单元、不可变规范调用、创建者发生项和权限标签。
Each record in \(\chi\) points to its own \Fresh receipt or, for \Alias, an earlier receipt, making retry and \Alias-result lookup functions of \((\chi,\Delta)\).
% \(\chi\) 中的每条记录都指向其自身的 \Fresh 回执；若为 \Alias，则指向更早的回执，从而使重试和 \Alias 结果查找成为 \((\chi,\Delta)\) 的函数。
\(\mathsf{lab}(\Delta)\) is the authority word.
% \(\mathsf{lab}(\Delta)\) 是权限词。
Restore may reconstruct workspace payload but never restores \(\Delta\).
% Restore 可以重建工作区载荷，但绝不会恢复 \(\Delta\)。

A security core \((\kappa,H,\Delta,\mathsf{out},\mathcal A)\) is \emph{well formed} when \(H\) is well formed, \(\mathsf{lab}(\Delta)\in\mathcal A\), each cell has at most one \Fresh receipt, each \Fresh record names its unique receipt, each \Alias record names an earlier receipt, the receipt ledger, outbox, and policy are scoped to \(\omega\), and the outbox preserves \Fresh order.
% 当 \(H\) 良构、\(\mathsf{lab}(\Delta)\in\mathcal A\)、每个单元至多有一条 \Fresh 回执、每条 \Fresh 记录指明其唯一回执、每条 \Alias 记录指明一条更早回执、回执账本、发件箱和策略均限定于 \(\omega\)，且发件箱保持 \Fresh 次序时，安全核心 \((\kappa,H,\Delta,\mathsf{out},\mathcal A)\) 是\emph{良构的}。
This joint invariant is assumed below.
% 下文假定这一联合不变量成立。

\subsection{Adversary and trusted boundary}
% 对手与可信边界

The adversary controls Agent output, edit requests, tool arguments, copied workspace, retries, stale authorization tokens, and scheduling, including races between calls and edits.
% 对手控制 Agent 输出、编辑请求、工具参数、复制的工作区、重试、过期授权令牌和调度，包括调用与编辑之间的竞态。
It cannot forge registries, the checkpoint directed acyclic graph (DAG), effect-identity certificates, policy, or receipt log.
% 它无法伪造注册表、检查点有向无环图（DAG）、效果标识证书、策略或回执日志。
The trusted computing base (TCB) includes the policy authority and protected-call authority.
% 可信计算基（TCB）包括策略权限方和受控调用权限方。
Within one policy domain, it completely mediates every protected use and provides a linearizable, crash-stable transaction for every modeled state change and visible edit answer.
% 在一个策略域内，它完全中介每次受控使用，并为每项已建模状态变更和可见编辑答案提供可线性化且崩溃稳定的事务。
A recovered labeled transition system (LTS) state shows each transaction entirely uncommitted or committed according to whether its linearization point occurred.
% 恢复后的标号转移系统（LTS）状态根据事务的线性化点是否已经发生，将每项事务完整地呈现为未提交或已提交；任何事务都不会撕裂，而易失的编译器缓存不在模型中。
No transaction is torn, and volatile compiler caches lie outside the model.
% 任何事务都不会撕裂，而易失的编译器缓存不在模型中。
Before the checker takes a source snapshot, the protected-call authority may instantiate finitely many pre-authorized schema templates.
% 在检查器获取源状态快照之前，受控调用权限方可以实例化有限个预授权模式模板。
For tool request \(m\), it computes normalized request \(m^\circ=\mathsf{canon}_\kappa(m)\), reuses only an effect identity certified for \(m^\circ\) or allocates a fresh one, and signs \((x,j,d,\mathsf{scope},\mathsf{digest}(m^\circ),\mathsf{lineage})\) into the authenticated registry.
% 对于工具请求 \(m\)，它计算规范化请求 \(m^\circ=\mathsf{canon}_\kappa(m)\)，只复用已认证用于 \(m^\circ\) 的效果标识或分配新标识，并把 \((x,j,d,\mathsf{scope},\mathsf{digest}(m^\circ),\mathsf{lineage})\) 签入认证注册表。
The resulting finite registered call model \(R\) remains unchanged while that snapshot is checked.
% 由此得到的有限已注册调用模型 \(R\) 在检查该状态快照期间保持不变。
Unmatched calls fail closed.
% 不匹配的调用以关闭方式失败。
The platform supplies authenticated \(\mathcal W,R\), edit schemas, normalization rules, policy, checkpoints, and one consistent snapshot of the receipt log and dispatch queue.
% 平台提供经认证的 \(\mathcal W,R\)、编辑模式、规范化规则、策略、检查点，以及回执日志与派发队列的一致状态快照。
From these inputs and an identifier-only Agent request, the controller derives the edited workflow, required outcomes, resolved calls, fixed point, monitor, certificate, monitor version, and authorization tokens.
% 控制器根据这些输入与 Agent 仅含标识符的请求推导编辑后的工作流、要求实现的结果、已解析调用、不动点、监控器、证书、监控器版本和授权令牌。
The Agent may supply or weaken none of these derived objects.
% Agent 不得提供或弱化这些派生对象中的任何一个。

\begin{definition}[Checked registration refinement]
% 经检查的注册精化
\label{def:registration-refinement}
A boundary-finite typed Agent workflow \(\mathcal W\) is a finite-state outcome-labeled LTS whose complete paths end at outcome terminals and whose \(\tau\)-erased durable-site projections \(\partial e=(o,s_1\cdots s_n)\) form finitely many classes under equality \(\equiv_\partial\).
% 边界有限的类型化 Agent 工作流 \(\mathcal W\) 是一个带结果标签的有限状态 LTS；其完整路径终止于结果终点，并且经 \(\tau\) 擦除的持久位置投影 \(\partial e=(o,s_1\cdots s_n)\) 在相等关系 \(\equiv_\partial\) 下形成有限多个等价类。
\(\mathsf{CheckReg}\) decides this by rejecting any reachable and terminal-co-reachable strongly connected component containing a durable-site edge while permitting erased \(\tau\)-cycles, then enumerates the finite classes.
% \(\mathsf{CheckReg}\) 通过拒绝任何既可达、又可到达终止点且包含持久位置边的强连通分量，同时允许被擦除的 \(\tau\) 环，来判定该性质，随后枚举有限等价类。
\(R\) stores a candidate registration map \(\lambda\), and \(\mathsf{BRuns}(R)\) is the finite outcome-indexed language obtained by linearizing its registered root pomsets and labeling each occurrence by its protected \Use.
% \(R\) 存储候选注册映射 \(\lambda\)，而 \(\mathsf{BRuns}(R)\) 是通过线性化其已注册根偏序事件集，并以受保护 \Use 标记每个发生项而得到的有限结果索引语言。
\(\mathcal W\sqsubseteq_\lambda R\) means that \(\lambda\) induces a bijection from boundary classes to \(\mathsf{BRuns}(R)\) that preserves outcomes, incidence, and order.
% \(\mathcal W\sqsubseteq_\lambda R\) 表示 \(\lambda\) 从边界等价类到 \(\mathsf{BRuns}(R)\) 诱导一个保持结果、关联与次序的双射。
The finite checker also requires effect identities to be exactly the equivalence classes of normalized requests.
% 有限检查器还要求效果标识恰好对应规范化请求的等价类。
The registration map must be total, unique, and free of raw instructions, and receipt evolution must commute with \(\Resolve\) without dropping a required outcome, call site, or receipt.
% 注册映射必须全定义、唯一且不包含原始指令，并且回执演化必须与 \(\Resolve\) 交换而不丢弃要求实现的结果、调用位置或回执。
\end{definition}

\Cref{thm:exact-history} proves checker reflection and a source-boundary/registered-realization bijection.
% \Cref{thm:exact-history} 证明检查器反射以及源边界与注册实现之间的双射。
The theory neither infers natural-language contracts nor equates local commit with remote physical exactly-once execution, which additionally requires an idempotent or queryable sink.
% 该理论既不推断自然语言契约，也不把本地提交等同于远端物理恰好一次执行；后者还要求接收端具有幂等性或可查询性。

\subsection{Six Execution-Edit Rules}
% 六条执行编辑规则

\subsubsection{Edit Certificates}

The six disjoint constructors of \(\mathsf{Edit}_6\) are exactly the typed operation signatures in \cref{tab:history-rules}.
% \(\mathsf{Edit}_6\) 的六个互不相交构造器恰为 \cref{tab:history-rules} 中带类型的操作签名。
The set excludes \(\mathsf{Save}\), \(\mathsf{Root}\), \(\mathsf{Extend}\), protected use, and caller-supplied targets.
% \(\mathsf{Edit}_6\) 的六个互不相交构造器恰为 \cref{tab:history-rules} 中带类型的操作签名；\(\mathsf{Save}\)、\(\mathsf{Root}\)、\(\mathsf{Extend}\)、受保护使用与调用方提供的目标均被排除。

An untrusted request \(u\) supplies an edit kind, live object identifiers, and schema identifier \(\sigma\), never a target contract, while \(\Sigma_\zeta\) binds \(\sigma\) to that kind, exact source and checkpoint fingerprints, introduced suffix contracts, and a lineage certificate.
% 不受信任的请求 \(u\) 提供编辑种类、活跃对象标识和模式标识 \(\sigma\)，但绝不提供目标契约，而 \(\Sigma_\zeta\) 将 \(\sigma\) 绑定到该种类、精确的源与检查点指纹、引入的后缀契约和谱系证书。

The edit certificate defined below makes the derivation checkable.
% 下文定义的编辑证书使该推导成为可检查的性质。
For indexed source \(\mathcal C\), schema-designated carried or cloned target region \(\mathcal D\), and parent map \(\mu:X_{\mathcal D}\to X_{\mathcal C}\), write \(\mathcal C\preccurlyeq_\mu\mathcal D\) exactly when \(\mu\) is a global bijection, some surjection \(\pi:O_{\mathcal D}\twoheadrightarrow O_{\mathcal C}\) satisfies the conditions below for every target outcome \(v\), and \(\mu\) preserves cell identity and lineage.
% 对于带索引的源 \(\mathcal C\)、由模式指定的携带或克隆目标区域 \(\mathcal D\) 以及父映射 \(\mu:X_{\mathcal D}\to X_{\mathcal C}\)，当且仅当 \(\mu\) 是全局双射、存在满射 \(\pi:O_{\mathcal D}\twoheadrightarrow O_{\mathcal C}\) 使下列条件对每个目标结果 \(v\) 成立，且 \(\mu\) 保持单元标识和谱系时，记作 \(\mathcal C\preccurlyeq_\mu\mathcal D\)。
\[
\begin{aligned}
 x\in X_{p_v}
   &\Longleftrightarrow \mu(x)\in X_{p_{\pi(v)}},\\
 x\prec_v y
   &\Longleftrightarrow \mu(x)\prec_{\pi(v)}\mu(y).
\end{aligned}
\]
Global bijection and occurrence--outcome membership equivalence prevent splitting a source occurrence shared across outcomes into outcome-specific target occurrences.
% 全局双射和发生项--结果成员关系等价防止将跨结果共享的源发生项拆分为特定于结果的目标发生项。

For candidate \(T'\), let \(R_u\) index the disjoint carried or cloned target regions inside the replaced subtree.
% 对候选 \(T'\)，令 \(R_u\) 索引被替换子树中互不相交的携带或克隆目标区域。
A rewrite certificate \(\mathcal P_u=\{(\mathcal C_r,\mathcal D_r,\mu_r,\pi_r)\}_{r\in R_u}\) contains the relation for each indexed region.
% 对于候选 \(T'\)，令 \(R_u\) 为被替换子树内互不相交的携带或克隆目标区域的索引集；重写证书 \(\mathcal P_u=\{(\mathcal C_r,\mathcal D_r,\mu_r,\pi_r)\}_{r\in R_u}\) 包含这些区域的关系。
A separate identity map checks that the exposed one-hole context preserves syntax, outcome indices, occurrences, cells, lineage, and order.
% 另一个恒等映射检查已暴露单孔上下文是否保持语法、结果索引、发生项、单元、谱系和次序。
Writing \(X_{\rm ctx}\) for its occurrences and \(X_{\rm suf(u)}\) for schema-declared suffix occurrences, the checker verifies the following disjoint cover.
% 将其发生项记为 \(X_{\rm ctx}\)，将模式声明后缀中的发生项记为 \(X_{\rm suf(u)}\)，检查器验证下列不交覆盖。
\[
 X_{\sem{T'}}=X_{\rm ctx}\uplus
   \biguplus_{r\in R_u}X_{\mathcal D_r}\uplus X_{\rm suf(u)} .
\]
The row constructor and exposed-context syntax induce \(\mathsf{pr}^u_r:O_{\sem{T'}}\rightharpoonup O_{\mathcal D_r}\).
% 表行构造器和已暴露上下文语法诱导 \(\mathsf{pr}^u_r:O_{\sem{T'}}\rightharpoonup O_{\mathcal D_r}\)。
For choice, this projection is defined only in the arm containing \(r\), while product and sequence select the corresponding indexed component.
% 对于选择，该投影仅在包含 \(r\) 的分支上有定义，而乘积和顺序选择相应的带索引分量。
Define
% 定义
\[
\begin{aligned}
 \mathsf{RegionReq}_u&=\{(r,o)\mid r\in R_u,\ o\in O_{\mathcal C_r}\},\\
 \mathsf{Lift}_u(t,r,o)&\Longleftrightarrow
   \exists v\in O_{\mathcal D_r}.\quad
   \mathsf{pr}^u_r(t)=v\ \land\ \pi_r(v)=o .
\end{aligned}
\]
Let \(O_{\rm byp}\) be source-context outcomes whose alternatives bypass the hole, and let \(\iota^u_{\rm ctx}:O_{\rm byp}\hookrightarrow O_{\sem{T'}}\) be the injection induced by context identity.
% 令 \(O_{\rm byp}\) 为其备选路径绕过该孔的源上下文结果，并令 \(\iota^u_{\rm ctx}:O_{\rm byp}\hookrightarrow O_{\sem{T'}}\) 为上下文恒等映射诱导的单射。
Define the single required-outcome set and its bypass lift by
% 统一的必需结果集合及其绕过提升定义为
\[
\begin{aligned}
 \mathsf{Req}_u&=\mathsf{RegionReq}_u
   \uplus(\{\mathsf{ctx}\}\times O_{\rm byp}),\\
 \mathsf{Lift}_u(t,(\mathsf{ctx},o))
   &\Longleftrightarrow t=\iota^u_{\rm ctx}(o).
\end{aligned}
\]
For regional \(a=(r,o)\in\mathsf{RegionReq}_u\), \(\mathsf{Lift}_u(t,a)\) denotes the relation above.
% 对区域元素 \(a=(r,o)\in\mathsf{RegionReq}_u\)，\(\mathsf{Lift}_u(t,a)\) 表示上述关系。
The checker also requires \(\forall a\in\mathsf{Req}_u.\ \exists t\in O_{\sem{T'}}.\ \mathsf{Lift}_u(t,a)\), ensuring a full-target lift for every required source outcome, no outcome-specific splitting of shared occurrences, and no inherited occurrence mislabeled as a suffix.
% 检查器还要求 \(\forall a\in\mathsf{Req}_u.\ \exists t\in O_{\sem{T'}}.\ \mathsf{Lift}_u(t,a)\)，从而保证每个必需源结果都有完整目标提升、共享发生项不会按结果拆分，且继承发生项不会被误标为后缀。

The schema-verification phase checks the following judgment.
% 模式验证阶段检查以下判定。
\[
\Sigma_\zeta;H\vdash_{\rm edit}u\Rightarrow(T',\mathcal P_u)
\]
It holds exactly when every named current object belongs to \(\mathsf{addr}(T)\), every introduced object remains scoped to \(\omega\), the source fingerprint matches, the applicable \(\mathcal P_u\), disjoint cover, and \(\mathsf{Lift}_u\) requirements in \cref{tab:history-rules} hold, any removal is authorized, and \(\sem{T'}\) is defined.
% 当且仅当每个具名当前对象属于 \(\mathsf{addr}(T)\)、每个引入对象仍限定于 \(\omega\)、源指纹匹配、\cref{tab:history-rules} 中适用的 \(\mathcal P_u\)、不交覆盖和 \(\mathsf{Lift}_u\) 要求成立、任何移除均获授权且 \(\sem{T'}\) 有定义时，该判定才成立。
Authorized removal is confined to a typed \(\mathsf{MergeSelect}\)'s losing arm or to a \(\mathsf{RestoreReplace}\)'s current continuation that is complete or explicitly certified for removal.
% 获授权的移除仅限于类型化 \(\mathsf{MergeSelect}\) 的失败分支，或 \(\mathsf{RestoreReplace}\) 中已经完成或已被显式认证可移除的当前延续。
The rule checks these recorded facts rather than Agent declarations.
% 该规则检查这些已有记录，而不接受 Agent 的声明。
The removal certificate is an immutable record signed by the policy authority at version \(\zeta\).
% 移除证书是策略权限方在版本 \(\zeta\) 下签名的不可变记录。
It binds \((\omega,\sigma)\), the exact source fingerprint, the exact outcome indices and occurrence lineages that may be removed, and verifies that no other occurrence disappears.
% 它绑定 \((\omega,\sigma)\)、精确源指纹以及可以移除的精确结果索引和发生项谱系，并验证没有其他发生项消失。
Its certified set must equal the typed losing arm for MergeSelect or the current continuation for RestoreReplace.
% 对于 MergeSelect，其认证集合必须等于类型化失败分支；对于 RestoreReplace，则必须等于当前延续。
\subsubsection{Preserving required outcomes}
% 保留要求实现的结果

A row-tagged source outcome identifies one outcome that the edit must account for.
% 带行标签的源结果标识编辑必须处理的一个结果。
\(\mathsf{Req}_u\) contains those that must still be realized in the edited workflow.
% \(\mathsf{Req}_u\) 包含编辑后的工作流仍然必须实现的结果。
The occurrences of such an outcome are the calls needed to realize it.
% 这类结果中的发生项是实现该结果所需的调用。

Independently of \(T'\), let \(\mathsf{SourceReq}(H,u)\) be all row-tagged source outcomes, \(\mathsf{Completed}_{H,u}\) those already completed at the current cursor, and \(\mathsf{Removed}_{H,u}\) the exact set whose removal the policy authority has signed.
% 独立于 \(T'\)，令 \(\mathsf{SourceReq}(H,u)\) 为全部带行标签的源结果，\(\mathsf{Completed}_{H,u}\) 为当前游标处已经完成的结果，并令 \(\mathsf{Removed}_{H,u}\) 为策略权限方已经签名允许移除的精确集合。
The checker enforces \emph{required-outcome preservation}:
\[
\mathsf{SourceReq}(H,u)=
\mathsf{Req}_u\uplus\mathsf{Completed}_{H,u}\uplus\mathsf{Removed}_{H,u}.
\]
Checked lifts preserve effect identity, lineage, and order.
% 经检查的提升保持效果标识、谱系与次序。
The installed edit retains completion evidence and records the authorized removal set, which the Agent cannot enlarge.
% 已安装编辑保留完成证据并记录获授权的移除集合，而 Agent 无法扩大该集合。
% 检查器执行\emph{源承诺守恒律} \(\mathsf{SrcProm}(H,u)=\mathsf{Req}_u\uplus\mathsf{Done}_{H,u}\uplus\mathsf{Dec}_{H,u}\)：提升保持单元、谱系和次序；该边保留已履行证据并记录解除集合，而 Agent 无法扩大该集合。

Let \(\mathcal E[-]\) be a one-hole \emph{exposed} frontier context, so its hole has the addressability property above.
% 令 \(\mathcal E[-]\) 为单孔的\emph{已暴露}前沿上下文，因此其孔具有上述可寻址性质。
\(\mathsf{carry}\) is the identity on continuation, outcome, and occurrence identifiers, pomset order, cells, lineage, base contracts, current branch cursors, and nested choice status.
% \(\mathsf{carry}\) 在延续标识、结果标识、发生项标识、偏序事件集次序、单元、谱系、基础契约、当前分支游标和嵌套选择状态上均为恒等操作。
\(\mathsf{clone}_r\) applies deterministic injective renamings to continuation, outcome, and occurrence identifiers, preserves pomset order and authenticated cell, scope, digest, and lineage data, and registers each cloned residual as a new base contract with an empty cursor.
% \(\mathsf{clone}_r\) 对延续标识、结果标识和发生项标识施加确定性的单射重命名，保持偏序事件集次序以及经认证的单元、作用域、摘要和谱系数据，并将每个克隆残余注册为带空游标的新基础契约。
Schema suffix leaves likewise start with their registered base contract and an empty cursor.
% 模式后缀叶节点同样以其已注册基础契约和空游标为起点。
The schema-derived contracts \(E_\sigma^L,E_\sigma^R,E_\sigma^J\) are suffixes, not replacements.
% 由模式派生的契约 \(E_\sigma^L,E_\sigma^R,E_\sigma^J\) 是后缀，而不是替代项。
Define
% 定义
\[
 L_\sigma=\mathsf{clone}_L(\mathcal C)\triangleright E_\sigma^L,\qquad
 R_\sigma=\mathsf{clone}_R(\mathcal C)\triangleright E_\sigma^R .
\]
New identifiers and the target epoch \(\eta^+\) are deterministically allocated from \((\omega,\zeta,\nu,u,\mathsf{role})\).
% 新标识和目标纪元 \(\eta^+\) 由 \((\omega,\zeta,\nu,u,\mathsf{role})\) 确定性分配。
\(\mathsf{role}\) identifies the edit row and operand position.
% \(\mathsf{role}\) 标识编辑行和操作数位置。
Write \(\mathsf{Cl}_r(\mathcal C)\) for the certified tuple \((\mathcal C,\mathsf{clone}_r(\mathcal C),\mu_r,\pi_r)\), and \(\mathsf{Ca}(\mathcal C)\) for \((\mathcal C,\mathsf{carry}(\mathcal C),\mu,\pi)\).
% 将认证元组 \((\mathcal C,\mathsf{clone}_r(\mathcal C),\mu_r,\pi_r)\) 记为 \(\mathsf{Cl}_r(\mathcal C)\)，并将 \((\mathcal C,\mathsf{carry}(\mathcal C),\mu,\pi)\) 记为 \(\mathsf{Ca}(\mathcal C)\)。
Each abbreviation asserts the corresponding \(\preccurlyeq_\mu\) relation.
% 每个缩写都断言相应的 \(\preccurlyeq_\mu\) 关系。
For a frontier \(T_0\), \(\mathsf{Ca}(T_0)\) abbreviates \(\mathsf{Ca}(\sem{T_0})\) and has target contract \(\sem{\mathsf{carry}(T_0)}\).
% 对于前沿 \(T_0\)，\(\mathsf{Ca}(T_0)\) 是 \(\mathsf{Ca}(\sem{T_0})\) 的缩写，其目标契约为 \(\sem{\mathsf{carry}(T_0)}\)。
Every \(b\) or \(g\) named below must lie in \(\mathsf{addr}(T)\).
% 下文具名的每个 \(b\) 或 \(g\) 都必须位于 \(\mathsf{addr}(T)\) 中。

\subsubsection{Common Epoch Handoff}

The execution-edit judgment is the least relation generated by one row of \cref{tab:history-rules} inside a well-typed single-hole context \(\mathcal E\), followed by the common update below; no other execution-edit derivation exists.
% 执行编辑判定是如下最小关系：在良类型单孔上下文 \(\mathcal E\) 中应用 \cref{tab:history-rules} 的一行，再执行下述公共更新；不存在其他执行编辑推导。
Let \(e_u\) contain its typed edge and exactly the newly allocated clone, suffix, and group nodes prescribed by \(T'\); carried node identities remain unchanged.
% 令 \(e_u\) 包含其类型化边，以及恰由 \(T'\) 指定的新分配克隆节点、后缀节点和组节点；被携带节点的标识保持不变。
For every live target occurrence \(x\), the trusted protected-call issuer deterministically mints \(j_x^+,h_x^+\), and \(\rho'\) preserves the row-certified cell, lineage, scope, digest, and historical records needed for \Retry while refreshing live gate and handle fields.
% 对每个活跃目标发生项 \(x\)，可信的受保护调用发行方确定性地签发 \(j_x^+,h_x^+\)，而 \(\rho'\) 保留表行认证的单元、谱系、作用域、摘要以及 \Retry 所需的历史记录，同时刷新活跃门和句柄字段。
Define
% 定义
\[
\begin{aligned}
 \mathcal H_u^+
   &=\{(x,j_x^+,h_x^+)\mid x\in X_{\sem{T'}}\},\\
 \beta'(x)&=(j_x^+,\eta^+).
\end{aligned}
\]
The bundle is neither live nor caller-accessible before installation.
% 安装前，该包既未激活，调用方也无法访问。
The complete judgment is shown below.
% 完整判定如下。
\begin{equation}
\label{eq:derived-cut}
\begin{aligned}
 \Sigma_\zeta;H\vdash u\Downarrow
   &(H',\mathcal C_{H,u},\eta^-,\eta^+),\\
 H'&=(\omega,G\mathbin{\cdot}e_u,T',K,\Sigma_\zeta,
      \rho',\beta',\chi,\nu+1,\eta^+),\\
 \mathcal C_{H,u}&=\sem{T'},\qquad \eta^-=\eta .
\end{aligned}
\end{equation}
Here \(G\mathbin{\cdot}e_u\) retains every source progress record and retired or carried node, and initializes each new clone or suffix node with its residual base and no progress records.
% 其中 \(G\mathbin{\cdot}e_u\) 保留源中的每条进度记录以及每个已退役或被携带节点，并以残余基础和空进度记录初始化每个新克隆节点或后缀节点。
Thus an edit preserves \(K,\Sigma_\zeta,\chi\), appends one typed provenance edge and its target nodes, refreshes every live gate and handle, and moves the domain to \(\eta^+\).
% 因此，一次编辑保持 \(K,\Sigma_\zeta,\chi\)，追加一条类型化溯源边及其目标节点，刷新每个活跃门和句柄，并将整个域迁移到 \(\eta^+\)。
Table constructors determine new group modes, while carried nested modes remain unchanged.
% 表中构造器决定新组模式，而被携带的嵌套模式保持不变。
A request naming a nonexistent checkpoint, wrong group mode, nonmember winner, mismatched schema fingerprint, retirement without schema authorization, or undefined composition has no derivation.
% 如果请求指明不存在的检查点、错误的组模式、非成员胜者、不匹配的模式指纹、未经模式授权的退役或无定义的组合，则没有可用推导。
Independent domains step by asynchronous product, and no theorem allows fencing only a selected subset of one domain's gates.
% 独立域通过异步乘积推进，而没有任何定理允许只隔离单个域内选定的一部分门。

\begin{lemma}[Schema fidelity and handoff totality]
% 模式保真性与交接完备性
\label{lem:history-derivation}
For well-formed \(H\), the judgment in \cref{eq:derived-cut} is deterministic.
% 对于良构的 \(H\)，\cref{eq:derived-cut} 中的判定是确定性的。
If it derives \(H'\), then \(H'\) is well formed.
% 如果它推导出 \(H'\)，则 \(H'\) 是良构的。
It preserves required outcomes: completion evidence remains recorded, and no pending source lineage disappears outside the exact set \(\mathsf{Removed}_{H,u}\).
% 它保留要求实现的结果：完成证据保持记录，且任何待处理源谱系都不会在精确集合 \(\mathsf{Removed}_{H,u}\) 之外消失。
The identity-preserved context and family \(\mathcal P_u\) preserve global occurrence sharing, cell, lineage, and causal order.
% 由恒等映射保持的上下文和族 \(\mathcal P_u\) 会保持全局发生项共享、单元、谱系和因果次序。
For every \(a\in\mathsf{Req}_u\), some full target outcome \(t\) satisfies \(\mathsf{Lift}_u(t,a)\), including the identity lift of every bypassing context outcome.
% 对每个 \(a\in\mathsf{Req}_u\)，都存在某个完整目标结果 \(t\) 满足 \(\mathsf{Lift}_u(t,a)\)，其中包括每个绕过上下文结果的恒等提升。
Every live target gate is bound to \(\eta^+\), has one authenticated handle in \(\mathcal H_u^+\), and no target gate remains bound to \(\eta^-\).
% 每个活跃目标门都绑定到 \(\eta^+\)，在 \(\mathcal H_u^+\) 中具有一个认证句柄，并且没有目标门仍绑定到 \(\eta^-\)。
\end{lemma}
\begin{proof}
Unique object and schema identifiers select one row and record, while context identity preserves everything outside the hole.
% 唯一的对象标识和模式标识选定一个表格行和一条记录，而上下文恒等映射保持孔外的一切内容。
The Fork rows certify both clones; RestoreReplace certifies the checkpoint clone and source retirement, while RestoreLive certifies the carried source and checkpoint clone.
% Fork 行认证两个克隆；RestoreReplace 认证检查点克隆和源退役，而 RestoreLive 认证被携带的源和检查点克隆。
MergeSelect certifies the winner and typed loser, while MergeJoin certifies both carried regions before its barrier.
% MergeSelect 认证胜者和类型化败者，而 MergeJoin 认证其屏障之前的两个携带区域。
Clone and carry supply the global bijections and occurrence--outcome membership preservation; constructor induction defines \(\mathsf{pr}^u_r\), proves the cover, and supplies every \(\mathsf{Lift}_u\) witness.
% 克隆和携带给出全局双射与发生项--结果成员关系保持；构造器归纳定义 \(\mathsf{pr}^u_r\)、证明覆盖，并给出每个 \(\mathsf{Lift}_u\) 见证。
The common poststate fixes all remaining fields and preserves or initializes branch cursors as specified above, while new identifiers, partial-constructor checks, and \cref{lem:observable-completion} preserve uniqueness, acyclicity, and contract well-formedness.
% 公共后状态固定所有其余字段，并按上述规则保持或初始化分支游标；新标识、偏构造器检查和 \cref{lem:observable-completion} 则保持唯一性、无环性与契约良构性。
Finally, \(\beta'\) and \(\mathcal H_u^+\) establish handoff totality at \(\eta^+\).
% 最后，\(\beta'\) 和 \(\mathcal H_u^+\) 在 \(\eta^+\) 上建立交接完备性。
\end{proof}

\subsection{Registered extension}
% 已注册扩展

A registered extension adds new schemas and policy entries without changing the current workflow or its required outcomes.
% 已注册扩展在不改变当前工作流及其要求实现结果的情况下增加新的模式与策略条目。
It is not a seventh execution edit.
% 它不是第七种执行编辑。
The Agent may name only an immutable record \(\xi\) binding the exact predecessor schema, registry, and policy roots to finite disjoint additions \(D_\Sigma,D_\rho\) and a successor policy \(\mathcal A^+\).
% Agent 只能指名一个不可变记录 \(\xi\)，该记录将精确的前驱模式、注册表和策略根绑定到有限且不交的新增集合 \(D_\Sigma,D_\rho\) 以及后继策略 \(\mathcal A^+\)。
Both issuers authenticate \(\xi\).
% 两个发行方都认证 \(\xi\)。
Existing schema identifiers, occurrence--effect-identity and invocation rows, labels, scopes, lineages, receipts, and normalization rules retain their meanings.
% 现有模式标识、发生项--效果标识与调用行、标签、作用域、谱系、回执和规范化规则保持原有含义。
New identifiers are fresh, finite, domain-scoped, foreign-key closed, and completion-observable.
% 新标识是新鲜、有限、域限定、外键闭合且完成可观测的。
The record contains no cursor, receipt, dispatch-queue entry, monitor version, return value, monitor, or installed certificate.
% 该记录不包含游标、回执、派发队列条目、监控器版本、返回值、监控器或已安装证书。
The successor policy is regular and prefix closed and conservatively extends the old policy, \(\mathcal A\subseteq\mathcal A^+\).
% 后继策略是正则且前缀闭合的，并保守扩展旧策略，即 \(\mathcal A\subseteq\mathcal A^+\)。

For fresh \(\eta^+\), refresh every current monitor entry and authorization token but leave the active workflow unchanged:
% 对于新鲜的 \(\eta^+\)，刷新每个当前监控器入口和授权令牌，但保持当前工作流不变：
\[
\begin{aligned}
 H_\xi^+
   &= (\omega,G,T,K,\Sigma_{\zeta^+},\rho^+,\beta^+,
       \chi,\nu+1,\eta^+),\\
 \mathcal C_\xi&=\sem T,\qquad
 \mathsf{SourceReq}(H,\xi)=\mathsf{Req}_\xi=O_{\sem T},\\
 \mathsf{Completed}_{H,\xi}&=\mathsf{Removed}_{H,\xi}=\varnothing,\qquad
 \mathsf{Lift}_\xi(t,o)\Longleftrightarrow t=o .
\end{aligned}
\]
The checked judgment
% 经检查的判定
\[
(\kappa,H,\mathcal A)\vdash\mathsf{Extend}(\xi)\Downarrow
  (\kappa^+,H_\xi^+,\mathcal A^+,\mathcal C_\xi,\eta,\eta^+)
\]
preserves \(G,T,K,\chi,\Delta,\mathsf{out}\), every current outcome, occurrence, effect identity, lineage, and causal edge, and authorizes no removal.
% 它保持 \(G,T,K,\chi,\Delta,\mathsf{out}\)、每个当前结果、发生项、效果标识、谱系与因果边，并且不授权任何移除。
It appends one authenticated version record and then uses the same checker and atomic monitor installation as an execution edit.
% 它追加一条经认证的版本记录，随后使用与执行编辑相同的检查器和原子监控器安装。
