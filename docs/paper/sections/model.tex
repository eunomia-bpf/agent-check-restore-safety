\section{Agent History Semantics}
\label{sec:model}

Each cut is finite, but histories may contain unboundedly many cuts.  One state
covers one policy domain.  Domains with disjoint cells, receipt ledgers, and policies
compose by product.  Internal reasoning remains unrestricted.  A protected
call must name a current registered occurrence and present an authenticated handle.  A
successful protected use is the monitor transition that may change durable
state.

\subsection{Causal-completion contracts}

\paragraph{Typed runtime vocabulary}
We capitalize \emph{Agent} for the untrusted principal requesting history
operations.  A logical protected occurrence \(x\) is an invocation slot, and
its protected \emph{use} is a monitor transition.  A semantic cell \(d\) is an
irreversible authority-redemption identity whose first redemption creates a
receipt.  A gate \(j\) is an epoch-bound monitor entry, and a handle \(h\)
authenticates an occurrence's gate, cell, scope, and effect digest.
\emph{Lineage} is certified ancestry preserved by carry and clone.
\(T,\Delta,\chi\) denote the live structural frontier, receipt ledger, and
resolved-occurrence trace.  A \emph{history cut} atomically installs a derived
edit and replaces the policy-domain epoch.  Registry \(\rho\) authenticates
each occurrence's gate and handle and maps it to
\(q_{\rm cell}(x)=d\) and authority label \(\ell(d)\).  Fork or Restore may map
several occurrences to one cell.

A pomset \(p=(X_p,\prec_p)\) is a finite set of occurrences with a strict
partial order.  Its linearizations \(\Lin(p)\) are the words containing each
member of \(X_p\) once and respecting \(\prec_p\).  A
\emph{causal-completion contract}
\(\mathcal C=(O,\{p_o\}_{o\in O})\) is a finite nonempty
\emph{indexed} family of pomsets.  Index \(o\) is a complete outcome identity,
and it remains distinct even if two residual pomsets later become equal.  Write
\(X_{\mathcal C}=\bigcup_{o\in O}X_{p_o}\) and
\(\mathsf{CL}(\mathcal C)=\bigcup_{o\in O}\Lin(p_o)\).  We require
\emph{completion observability}.
\[
 v,w\in\mathsf{CL}(\mathcal C)\ \land\
 v\preceq_{\rm pref}w \quad\Longrightarrow\quad v=w .
\]
This condition permits incomparable traces and different indices with the same
trace, so it does not impose outcome determinism.  It fixes the interface
boundary by requiring a registered logical occurrence to distinguish stopping
from continuing at a shared prefix.

Contracts compose through three partial constructors, each defined only when
its result remains completion-observable.
\begin{equation}
\label{eq:contract-algebra}
\begin{aligned}
 O_{\mathcal C\oplus\mathcal D}
  &= (\{L\}\mathbin{\times}O_{\mathcal C})
     \uplus(\{R\}\mathbin{\times}O_{\mathcal D}),\\
 p_{(L,o)}&=p_o,\qquad p_{(R,v)}=p_v,\\
 O_{\mathcal C\otimes\mathcal D}
  &=O_{\mathcal C}\mathbin{\times}O_{\mathcal D},\\
 p_{(o,v)}&=p_o\uplus p_v,\\
 O_{\mathcal C\triangleright\mathcal D}
  &=O_{\mathcal C}\mathbin{\times}O_{\mathcal D},\\
 p_{(o,v)}&=p_o\triangleright p_v.
\end{aligned}
\end{equation}
Every binary constructor has occurrence-disjoint operands.  Before composing
a newly registered or cloned operand, the history judgment deterministically
renames its logical occurrence identifiers and extends \(\rho\), while
preserving authenticated cell identities.  Existing carried operands are
already disjoint by history well-formedness.
The parallel product \(\uplus\) adds no cross-order.  The ordered product
\(\triangleright\) places every event of \(p\) before every event of \(q\).
The index set of \(\oplus\) is a tagged disjoint union, while those of
\(\otimes\) and \(\triangleright\) are Cartesian products.  Thus choice
preserves an outcome from each arm, parallel requires both arms but permits
any causal linearization, and sequence adds a barrier.

For a raw prefix \(w\), the residual \(\mathcal C/w\) retains every index
\(o\) for which \(w\) is a linearization prefix of \(p_o\), and removes the
occurrences in \(w\) with their incident order.  The residual is undefined
when no index remains.  This derivative gives an operational meaning to ``remaining
contract'' without erasing either outcome or occurrence identity.

\begin{lemma}[Observable completion]
\label{lem:observable-completion}
Every defined residual \(\mathcal C/w\) is completion-observable, and either
every retained pomset is empty or no retained pomset is empty.
\end{lemma}
\begin{proof}
If a residual suffix \(v\) strictly prefixes \(v'\), then \(wv\) strictly
prefixes \(wv'\) in \(\mathsf{CL}(\mathcal C)\).  If one retained pomset is
empty and another is not, choose its nonempty suffix \(v\).  Then \(w\)
strictly prefixes \(wv\).  Both contradict completion observability.
\end{proof}

\subsection{Trusted history state}

An Agent history state is
\begin{equation}
\label{eq:history-state}
 H=(\omega,G,T,K,\Sigma_\zeta,\rho,\beta,\chi,\nu,\eta).
\end{equation}
\(\omega\) is the policy-domain identity and \(\eta\) its single current
policy-domain epoch.  \(G\) is a finite append-only provenance DAG.  Each
continuation node \(b\) carries an immutable registered base contract
\(\Gamma_b\) and branch-local resolved cursor \(\chi_b\).  The DAG's edges record
typed Fork, Restore, and Merge operations.
\(T\) is the live structural frontier.
\[
 T ::= b{:}\mathcal C
     \mid T\oplus_g^s T
     \mid T\parallel_g T
     \mid \mathsf{jbar}(T,T)
     \mid T;T .
\]
\(s\in\{\mathsf{open},L,R\}\) records an unresolved choice or the arm that made
durable progress, and \(g\) groups exclusive or jointly live siblings.
\(\sem{T}\) uses both open arms and only the selected arm afterward,
\(\otimes\) for parallel and \(\mathsf{jbar}\), and \(\triangleright\) for
sequence.  The unaddressed \(\mathsf{jbar}\) marks a joined group and prevents
another Merge.

\(T\) is \(\mathsf{complete}\) when every pomset in \(\sem{T}\) is empty.
\Cref{lem:observable-completion} excludes mixed active outcomes.  Set
\(\mathsf{heads}(b{:}\mathcal C)=\{b\}\).  Open choice exposes both arms,
selected choice its winner, parallel and \(\mathsf{jbar}\) both arms, and
sequence its left operand until completion and then its right.  Occurrence
progress residualizes leaves without deleting structure.  Predicate-driven
sequence exposure retains completed left-outcome indices, so an isolated
completed leaf remains addressable for later Fork or Restore.  Joining removes
\(g\) immediately but keeps its continuation behind a barrier until both arms
complete.  An occurrence is enabled when minimal in some pomset of
\(\sem{T}\), consistent with sequence exposure by observable completion.

\(\mathsf{addr}(T)\) follows the same recursion over branch and group
identifiers.  It includes exposed groups before descending into their live
arms and only the exposed sequence operand, excluding dormant losers and
unexposed operands.

\(K\) maps checkpoint identifiers to immutable earlier continuation records.
Write \(\mathcal C_k=\mathsf{contract}(K(k))\) for the residual contract
stored by checkpoint \(k\).  \(\Sigma_\zeta\) is a versioned immutable
registry of typed edit schemas.
\(\rho\) contains the authenticated occurrence-to-gate/cell, handle,
lineage, scope, and effect-digest data.  For each live occurrence \(x\), binding
\(\beta(x)=(j,\eta)\) names its gate \(j\) and the domain's current epoch.
Finally, \(\chi\) is the ordered append-only trace of durably
\emph{resolved} logical occurrences, including \Fresh and \Alias bindings,
and \(\nu\) is the history-view version.  Resolution may still await remote
settlement or return.  The trace \(\chi\) records authorization and causal
progress rather than physical completion.

Checkpoint creation is explicit but is not a seventh history rewrite.
\(\mathsf{Save}(k,b)\) requires new \(k\) and addressable \(b\).  One trusted
transaction adds
\((\omega,b,\mathcal C_b,\chi_b,\rho|_{X_{\mathcal C_b}},\zeta)\) and its
authenticated fingerprint to \(K\), then increments \(\nu\).
\(\mathcal C_b\) is \(b\)'s current residual.  No frontier, receipt, binding,
epoch, or authority changes.  Both machines take this \(\tau\)-transition.
Because the cut seal binds \(H\), a concurrent installation becomes stale.
Restore accepts only records created by this rule.

\begin{definition}[Well-formed history]
\label{def:well-formed-history}
\(H\) is well formed when the following groups hold.
\begin{enumerate}[leftmargin=*,itemsep=0pt,topsep=1pt]
\item \emph{Structure.}
\(G\) is acyclic; continuation and group identifiers are globally unique
across the recorded DAG and live frontier; every addressable identifier has a
unique context decomposition; every head of \(T\) is a live maximal node; and
every checkpoint names an immutable node and contract in \(G\).
\item \emph{Identity and progress.}
Occurrence and gate identifiers are unique, while cell aliases agree on
protected-call issuer, scope, digest, and lineage.  Resolved occurrences are downward closed
in their pomset, consistent with every choice status, and absent from the
residual frontier.
\item \emph{Live frontier.}
Every live gate has exactly one binding \((j,\eta)\) to the domain's single
current epoch.  Every live leaf \(b{:}\mathcal C\) is exactly the indexed
residual of its immutable registered base \(\Gamma_b\) by the raw projection
of its branch-local suffix \(\chi_b\), rather than a caller-pruned subfamily.
Every constructor in \(T\) is defined, so every subtree interpretation is
completion-observable.
\item \emph{Schema and domain.}
Every edge and introduced contract is justified by one immutable schema at
version \(\zeta\).  Every current, checkpoint, or schema occurrence, cell,
gate, lineage, and scope belongs to \(\omega\).  Cells, receipt ledgers, and policies
of distinct domains are disjoint, and an edit never crosses a domain.
\end{enumerate}
The durable kernel additionally requires that the one current policy-domain
epoch is active.
\end{definition}

Outside \(H\), ledger state stores policy version \(\kappa\), monotone receipt
ledger \(\Delta\), and an ordered outbox.  Receipt creation is append-only.
Receipt phases and stable result futures advance on settlement.  Each receipt binds its
cell, the invocation that created it, and its authority label.  Each record in \(\chi\) points
to its own \Fresh receipt or, for \Alias, an earlier receipt, making retry and
\Alias-result lookup functions of \((\chi,\Delta)\).
\(\mathsf{lab}(\Delta)\) is the authority trace.  Restore may reconstruct
workspace payload but never restores \(\Delta\).

A security state
\((\kappa,H,\Delta,\mathsf{out},\mathcal A)\) is \emph{well formed} when
\(H\) is well formed, \(\mathsf{lab}(\Delta)\in\mathcal A\), each cell has at
most one \Fresh receipt, each \Fresh record names its unique receipt, each
\Alias record names an earlier receipt, the receipt ledger, outbox, and policy are scoped to
\(\omega\), and the outbox preserves \Fresh order.  This joint invariant is
assumed below.

\subsection{Adversary and trusted boundary}

The adversary controls Agent output, operations, tool arguments, copied
workspace, retries, stale seals, and scheduling, including use/edit races.  It
cannot forge registries, the checkpoint/DAG store, cell certificates, policy,
or the receipt ledger.  The trusted computing base (TCB) includes the
policy issuer and protected-call issuer and provides complete mediation and one
linearizable, crash-stable transaction per domain for resolution or installation.  We
introduce no storage protocol, infer no natural-language contract, and assume
no deployed Codex or Claude already supplies this state.

\subsection{Six structural rewrite rules}

An untrusted request contains a mode, live object identifiers, and an edit
schema identifier \(\sigma\), never a target contract.  Registry
\(\Sigma_\zeta\) binds \(\sigma\) to its operation kind, exact source and
checkpoint fingerprints, introduced suffix contracts, and a lineage
certificate.

The certificate makes ``history-derived'' checkable.  For indexed source
\(\mathcal C\), one schema-designated carried or cloned target region
\(\mathcal D\), and parent map \(\mu:X_{\mathcal D}\to X_{\mathcal C}\),
write \(\mathcal C\preccurlyeq_\mu\mathcal D\) when \(\mu\) is a global
bijection and some surjection
\(\pi:O_{\mathcal D}\twoheadrightarrow O_{\mathcal C}\) satisfies, for every
target outcome \(v\),
\[
\begin{aligned}
 x\in X_{p_v}
   &\Longleftrightarrow \mu(x)\in X_{p_{\pi(v)}},\\
 x\prec_v y
   &\Longleftrightarrow \mu(x)\prec_{\pi(v)}\mu(y),
\end{aligned}
\]
and \(\mu\) preserves cell identity and lineage.  The global bijection and
incidence equivalence prevent a source occurrence shared across outcomes from
being split into outcome-specific target occurrences.

For a candidate target \(T'\), a rewrite certificate is a family
\(\mathcal P_u=\{(\mathcal C_r,\mathcal D_r,\mu_r,\pi_r)\}_{r\in R_u}\)
of these relations over disjoint target regions inside the replaced subtree.
The exposed one-hole context is checked separately by an identity map that
preserves its syntax, outcome indices, occurrences, cells, lineage, and order.
Let \(X_{\rm ctx}\) be the identity-preserved context occurrences and
\(X_{\rm suf(u)}\) the occurrences in the schema-declared suffixes.  The
installation checker's schema-verification phase verifies the disjoint cover
\[
 X_{\sem{T'}}=X_{\rm ctx}\uplus
   \biguplus_{r\in R_u}X_{\mathcal D_r}\uplus X_{\rm suf(u)} .
\]
The row constructor and exposed-context syntax induce the following partial
outcome projection
\(\mathsf{pr}^u_r:O_{\sem{T'}}\rightharpoonup O_{\mathcal D_r}\):
choice is defined only in the arm containing region \(r\), while product and
sequence select the corresponding indexed component.  Define
\[
\begin{aligned}
 \mathsf{Obl}_u&=\{(r,o)\mid r\in R_u,\ o\in O_{\mathcal C_r}\},\\
 \mathsf{Lift}_u(t,r,o)&\Longleftrightarrow
   \exists v\in O_{\mathcal D_r}.\quad
   \mathsf{pr}^u_r(t)=v\ \land\ \pi_r(v)=o .
\end{aligned}
\]
The same phase requires
\(\forall(r,o)\in\mathsf{Obl}_u.\ \exists t\in O_{\sem{T'}}.\
\mathsf{Lift}_u(t,r,o)\).  Context alternatives bypassing the hole retain
their full outcome index by identity.  Hence every required regional source
outcome has a full-target lift, no shared occurrence is split by outcome, and
no inherited occurrence is mislabeled as a suffix.

The schema-verification phase accepts
\[
\Sigma_\zeta;H\vdash_{\rm edit}u\Rightarrow(T',\mathcal P_u)
\]
only when every named live object lies in \(\mathsf{addr}(T)\), every
introduced object remains scoped to \(\omega\), the source
fingerprint matches, the appropriate
\(\mathcal P_u\), disjoint-cover, and \(\mathsf{Lift}_u\) obligations in
\cref{tab:history-rules} hold, any
retirement is authorized, and \(\sem{T'}\) is defined.  Retirement is limited
to the losing arm of a typed \(\mathsf{MergeSelect}\), or the current
continuation of \(\mathsf{RestoreReplace}\) when it is complete or
\(\sigma\) contains an explicit retirement certificate.  These retirement
conditions are checked edge facts, not Agent declarations.  A retirement
certificate is a policy-issuer-authenticated immutable record at version
\(\zeta\) binding \((\omega,\sigma)\), the exact source fingerprint, and the exact retired
outcome indices and occurrence lineages.  It verifies that no
occurrence outside that set disappears.  For MergeSelect the certified set
must equal the typed losing arm.  For RestoreReplace it must equal the current
continuation.  Treating that explicitly authorized set as discharged is a
trusted schema decision, not a theorem that the retirement was desirable.

Let \(\mathcal E[-]\) be a one-hole \emph{exposed} frontier context, so its
hole has the addressability property above.
\(\mathsf{carry}\) is the identity on outcome and occurrence identifiers,
pomset order, cells, lineage, base contracts, cursors, and nested choice
status.  \(\mathsf{clone}_r\) applies deterministic injective renamings to
continuation, outcome, and occurrence identifiers; preserves pomset order and
authenticated cell, scope, digest, and lineage data; and registers each cloned
residual as a new base contract with an empty cursor.  Schema suffix leaves
likewise start with their registered base contract and an empty cursor.
The schema-derived contracts
\(E_\sigma^L,E_\sigma^R,E_\sigma^J\) are suffixes, not replacements.  Define
\[
 L_\sigma=\mathsf{clone}_L(\mathcal C)\triangleright E_\sigma^L,\qquad
 R_\sigma=\mathsf{clone}_R(\mathcal C)\triangleright E_\sigma^R .
\]
New identifiers and the target epoch \(\eta^+\) are deterministically
allocated from \((\omega,\zeta,\nu,u,\mathsf{role})\).
\(\mathsf{role}\) identifies the rewrite row and operand position.
Write \(\mathsf{Cl}_r(\mathcal C)\) for the certified tuple
\((\mathcal C,\mathsf{clone}_r(\mathcal C),\mu_r,\pi_r)\), and
\(\mathsf{Ca}(\mathcal C)\) for
\((\mathcal C,\mathsf{carry}(\mathcal C),\mu,\pi)\).  Each abbreviation
asserts the corresponding \(\preccurlyeq_\mu\) relation.  For a frontier \(T_0\),
\(\mathsf{Ca}(T_0)\) abbreviates \(\mathsf{Ca}(\sem{T_0})\) and has target contract
\(\sem{\mathsf{carry}(T_0)}\).  Every \(b\) or \(g\) named below must lie in
\(\mathsf{addr}(T)\).

The first \Fresh or \Alias occurrence in an open choice atomically sets its
status.  Later occurrences from the other arm are disabled.  Hence
\(\mathsf{MergeSelect}(g,w,\sigma)\) has no derivation after durable logical
progress in the loser, even when that progress was receipt silent.
In \(\mathsf{MergeJoin}\), replacing the addressable
\(\parallel_g\) node by \(\mathsf{jbar}\) retires \(g\) in the same rewrite.
The same pair therefore cannot be joined twice.

The model deliberately uses domain-wide handoff instead of selective owner
analysis.  Every live gate in \(H\) belongs to \(\eta^-=\eta\).  A table row,
together with the following common update, is the complete rewrite rule.  Let
\(e_u\) contain its typed edge and exactly the new target nodes prescribed by
\(T'\).  For each live target occurrence \(x\), the trusted protected-call issuer
deterministically mints a new gate \(j_x^+\) and authenticated handle \(h_x^+\).
Registry \(\rho'\) preserves the row-certified cell, lineage, scope, and digest
data, refreshes the live gate and handle fields, and retains historical records
needed for \Retry.  Define
\[
\begin{aligned}
 \mathcal H_u^+
   &=\{(x,j_x^+,h_x^+)\mid x\in X_{\sem{T'}}\},\\
 \beta'(x)&=(j_x^+,\eta^+).
\end{aligned}
\]
The bundle is not live or available to a caller before installation.  The
complete judgment is
\begin{equation}
\label{eq:derived-cut}
\begin{aligned}
 \Sigma_\zeta;H\vdash u\Downarrow
   &(H',\mathcal C_{H,u},\eta^-,\eta^+),\\
 H'&=(\omega,G\mathbin{\cdot}e_u,T',K,\Sigma_\zeta,
      \rho',\beta',\chi,\nu+1,\eta^+),\\
 \mathcal C_{H,u}&=\sem{T'},\qquad \eta^-=\eta .
\end{aligned}
\end{equation}
\(G\mathbin{\cdot}e_u\) retains retired nodes.  Thus an edit leaves
\(K,\Sigma_\zeta,\chi\) unchanged, appends one typed provenance edge and its
target nodes, refreshes every live gate and handle, and moves the entire
policy domain to \(\eta^+\).  Table constructors determine every new group
mode.  Carried nested modes are unchanged.  A request naming a nonexistent checkpoint, wrong group mode,
nonmember winner, mismatched schema fingerprint, retirement without schema
authorization, or
undefined composition has no derivation.  Independent domains step by
asynchronous product.  No theorem below claims within-domain partial fencing.

\begin{lemma}[Schema fidelity and handoff totality]
\label{lem:history-derivation}
For well-formed \(H\), the judgment in \cref{eq:derived-cut} is deterministic.
If it derives \(H'\), then \(H'\) is well formed.
No pending source lineage disappears except through schema-authorized retirement.
The identity-preserved context and family \(\mathcal P_u\) preserve global
occurrence sharing, cell, lineage, and causal order.  For every
\((r,o)\in\mathsf{Obl}_u\), some full target outcome \(t\) satisfies
\(\mathsf{Lift}_u(t,r,o)\).  A context outcome bypassing the hole is preserved
by identity.  Every live target gate is bound to
\(\eta^+\), has one authenticated handle in \(\mathcal H_u^+\), and no target
gate remains bound to \(\eta^-\).
\end{lemma}
\begin{proof}
Unique object and schema identifiers select one row and record.  Context
identity preserves everything outside the hole.  The Fork rows certify both
clones.  RestoreReplace certifies the checkpoint clone and source retirement,
whereas RestoreLive certifies the carried source and checkpoint clone.
MergeSelect certifies the winner and typed loser, and MergeJoin certifies both
carried regions before its barrier.  Clone and carry give the global
bijections and incidence preservation.  Constructor induction defines
\(\mathsf{pr}^u_r\), proves the cover, and supplies every \(\mathsf{Lift}_u\)
witness.  The common poststate fixes all other fields.  New identifiers,
partial-constructor checks, and \cref{lem:observable-completion} preserve
uniqueness, acyclicity, and contract well-formedness.  The fields \(\beta'\) and
\(\mathcal H_u^+\) establish handoff totality at \(\eta^+\).
\end{proof}

Thus no caller supplies a semantic oracle: Fork arms must project onto pending
\(\mathcal C\), and Join reads both residuals before appending \(E_\sigma^J\).
