\section{Raw Edges and Causal Reference Semantics}
\label{sec:model}

We model only protected effects between two history cuts.  The Agent may reason,
edit files, query models, and create speculative state without appearing in the
model.  An operation that would make a protected effect durable must pass
through the epoch described below.  This separation permits rich, open-ended
computation without pretending to predict the Agent's complete future.

\subsection{A bounded protected-slice calculus}

Let $\mathcal H$ be raw handle occurrences and $\mathcal J$ raw gate-use
occurrences.  A protected action and a finite plan are
\begin{equation}
\label{eq:raw-plan}
\begin{split}
 a &::= \mathsf{use}(j,h),\\
 P &::= \mathbf 0 \mid a \mid P;P \mid P\oplus P
                 \mid P\parallel P .
\end{split}
\end{equation}
Every syntactic action occurrence is branch tagged.  Repeated payload text
does not create an alias.

Write $\mathsf D(P)$ for the completed raw traces of $P$ and
$\shuf$ for order-preserving shuffle:
\begin{equation}
\label{eq:done-language}
\begin{aligned}
\mathsf D(\mathbf 0)&=\{\epsilon\},&
\mathsf D(a)&=\{a\},\\
\mathsf D(P;Q)&=\mathsf D(P)\mathsf D(Q),&
\mathsf D(P\oplus Q)&=\mathsf D(P)\cup\mathsf D(Q),\\
\mathsf D(P\parallel Q)&=
  \mathsf D(P)\shuf\mathsf D(Q).&&
\end{aligned}
\end{equation}
The union remains tagged because action occurrences are branch tagged.
The executable plant of a plan is its prefix closure
\[
  \mathsf{Pref}(P)=\mathsf{prefixes}(\mathsf D(P)).
\]
Thus $a;b$ does not enable $b$ first, whereas
$a\parallel b$ permits either interleaving.  Choice is resolved by the first
arm-specific fresh commitment; after that point the other arm has no trace in
the same epoch.

A \emph{promised outcome} $\omega$ is a finite partial order of protected
occurrences; $\mathsf{Lin}(\omega)$ is its set of linearizations.  A plan
contract carries a finite, nonempty set $\Omega_P$ of outcomes that installing
the plan promises to keep possible.  The promise concerns possibility, not
scheduler fairness or task completion.  Sequence, choice, and parallel derive
outcome contracts by ordered product, tagged union, and disjoint partial-order
union, respectively.  Leaf promises come from the protected tool API or the
operation request.  Understating them weakens only the stated transparency
guarantee; it cannot enlarge the language enforced by the synthesized epoch.
Writing $\omega\mathbin{\triangleright}\omega'$ for adding every event of
$\omega$ as a predecessor of every event of $\omega'$ and $\uplus$ for
disjoint partial-order union, the derivation is
\begin{equation}
\label{eq:promise-algebra}
\begin{aligned}
\Omega_{P;Q}
 &=\{\omega\triangleright\omega'
       \mid\omega\in\Omega_P,\omega'\in\Omega_Q\},\\
\Omega_{P\oplus Q}&=\Omega_P\uplus\Omega_Q,\\
\Omega_{P\parallel Q}
 &=\{\omega\uplus\omega'
       \mid\omega\in\Omega_P,\omega'\in\Omega_Q\}.
\end{aligned}
\end{equation}

A raw edge request
\[
 R=(\kappa,\nu,\delta,e,P_e,\Omega_e,\mathsf{src},\mathsf{anchors})
\]
contains a policy version $\kappa$, view version $\nu$, authenticated durable
receipt trace $\delta$, one typed edge from
\cref{tab:edge-semantics}, its derived target plan and promises, and the source
controller anchors that the cut must close.  The caller chooses the operation
and leaf plans, but cannot submit an arbitrary target language or target
controller layout.  A new protected action outside $P_e$ is denied until a new
request extends the bounded slice.

\subsection{Authenticated normalization}

Snapshots copy handles and gate references, so syntax is not security
identity.  The redemption service authenticates for each $h\in\mathcal H$ a
cell anchor, issuer, scope, effect digest, and authority lineage.  Define
\[
  h\equiv_{\rm cell}h'
  \quad\Longleftrightarrow\quad
  \mathsf{cellAnchor}(h)=\mathsf{cellAnchor}(h')
\]
and let $q_{\rm cell}:\mathcal H\to\mathcal D$ be the quotient.  A request is
well formed only when issuer, scope, digest, and lineage agree inside each
class.  Consequently lineage descends to
$\ell:\mathcal D\to\mathcal U$, where $\mathcal U$ is the authority-event
alphabet.  Independent arm occurrences receive fresh anchors by default;
only authenticated equality creates an alias.

Gate-use occurrences have a separate source relation
\begin{equation}
\label{eq:source-equivalence}
\begin{aligned}
  j\equiv_{\rm src}j'
  \quad\Longleftrightarrow\quad{}
  &\mathsf{controllerAnchor}(j)\\[-2pt]
  &{}=\mathsf{controllerAnchor}(j').
\end{aligned}
\end{equation}
Its classes determine which old controller states an installation must close.
It does \emph{not} determine the target layout.  Successful synthesis mints
one edge-scoped epoch identifier $\eta$ and binds every target gate use to its
new residual state.  Hence the target controller identity is a compiler
output, not an attested $q_{\rm ctrl}$, access relation, or co-liveness family.

Normalization is stateful because replay is not a second authority event.
Starting from the receipt ledger named by $\delta$, a deterministic transducer
$N_\delta$ processes a raw trace.  On $\mathsf{use}(j,h)$ it resolves
$d=q_{\rm cell}(h)$.  If $d$ already has a receipt, or was emitted earlier in
this raw trace, the step emits $\epsilon$; otherwise it emits the fresh cell
$d$ and marks it pending.  Malformed anchor collisions reject the request
rather than guessing.  The normalized plant is
\begin{equation}
\label{eq:normalized-plant}
  \mathsf{Plant}_R
  =\{N_\delta(\hat\sigma)\mid
       \hat\sigma\in\mathsf{Pref}(P_e)\}.
\end{equation}
Its words contain no repeated cell.  Because $N_\delta$ is
prefix preserving, $\mathsf{Plant}_R$ is prefix closed.

\begin{lemma}[Normalization matters]
\label{lem:normalization}
For every well-formed request, $\mathsf{Plant}_R$ is a finite prefix-closed
language.  Changing an authenticated cell class can change
$\mathsf{Plant}_R$, while changing a source controller class can change the
set closed by installation even when $\mathsf{Plant}_R$ is unchanged.
\end{lemma}
\begin{proof}
Induction on a raw trace prefix proves prefix preservation.  Two branch-tagged
uses mapped to different cells emit two symbols; mapping them to one cell
makes the second a stutter.  Conversely, source classes occur in the
\textsc{Install} premise in \cref{sec:semantics}, not in cell emission.
\end{proof}

This is the formal separation missing from a workspace-only account: one
quotient decides fresh redemption, while another decides which stale
authoritative state must lose commit eligibility.

\subsection{Durable causal policy and the exact monitor}

Let $\mathcal A\subseteq\mathcal U^*$ be a regular prefix-closed
durable-authority policy and assume the authenticated receipt trace
$\delta\in\mathcal A$.  Symbols in $\mathcal U$ are qualified ledger events:
they include the authority root, scope, unit/cell anchor, and effect class, so
$\delta$ is the exact receipt trace rather than a trace of coarse action
names.  Order is semantic: for example, the policy may contain
$\mathsf{approve}\,\mathsf{pay}$ but not
$\mathsf{pay}\,\mathsf{approve}$.  Extend lineage homomorphically to traces as
$\ell^*$.  The exact safe future at request $R$ is
\begin{definition}[Durable residual language]
\label{def:reference-language}
\begin{equation}
\label{eq:reference-language}
 F_R=\{\sigma\in\mathsf{Plant}_R
       \mid \delta\cdot\ell^*(\sigma)\in\mathcal A\}.
\end{equation}
\end{definition}
$F_R$ is prefix closed: both the plant and policy are prefix closed.

The strongest atomic reference monitor $\mathsf{GM}(R)$ stores the normalized
within-epoch trace $\sigma$ and has the fresh transition
\begin{equation}
\label{eq:gm-step}
 \frac{\sigma d\in F_R}
      {\sigma\xrightarrow{\mathsf{fresh}(d)}\sigma d}.
\end{equation}
Retry, replay, settlement, and crash recovery are stutters in its fresh trace.
By construction,
\begin{equation}
\label{eq:gm-language}
  \mathsf{FreshTraces}(\mathsf{GM}(R))=F_R .
\end{equation}
This monitor is the baseline, not a straw man: under complete mediation and an
atomic durable ledger it is maximally permissive for the fixed plan, receipt
trace, and policy.

The edge's preservation condition is
\begin{definition}[Causal history admission]
\label{def:causal-admission}
\begin{equation}
\label{eq:causal-admission}
 \mathsf{Admit}(R)
 \iff
 \forall\omega\in\Omega_e.\quad
 \mathsf{Lin}(\omega)\cap F_R\ne\varnothing .
\end{equation}
\end{definition}
Parallel scheduler orders count as one promised partial-order outcome, so one
policy-legal linearization suffices.  A sequential prerequisite, exclusive
choice, or join barrier is part of $\omega$ and cannot be reordered away.
When the only promise is the empty outcome, a seal can still enforce safety,
but it is reported as carrying no nontrivial transparency claim.

\subsection{Adversary and trusted boundary}

The adversary controls Agent output, tool arguments, stale snapshots, retries,
and requested history edges.  It may race a fresh commitment against an
installation and present copied raw handles.  Trusted components are the
policy issuer, authenticated cell and source-controller anchors, the
append-only receipt ledger, complete mediation of protected effects, and the
linearizable crash-stable primitives used by \textsc{Prepare} and
\textsc{Install}.  The calculus does not infer natural-language intent or
external state.  Remote exactly-once delivery still requires an idempotent or
queryable sink, an outbox, or conservative issue-time charging.
