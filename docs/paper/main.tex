\title{When May an Agent Rewrite Its History?\\
A Prefix-Robust Theory of Fork, Restore, and Merge}

\author{}

\begin{document}
\maketitle

\begin{abstract}
Tool-using Agents rewrite which past continuations may act: Fork creates
several presents, Restore revives an earlier one, and Merge selects or joins
their futures.  The world does not follow: commitments are append only,
copied occurrences may share one irreversible receipt, and old controllers
may race the rewrite.  We ask exactly when such an edit has a policy-safe,
history-faithful, completion-nonblocking implementation preserving every
promised outcome.  Endpoint checks fail because a prefix shared by
individually safe outcomes can strand one that the Agent history still
promises.

We develop a prefix-robust \emph{Agent History-Admission Theory}.  Trusted
schemas derive obligation-preserving target contracts; fresh commitments and
receipt-silent aliases remain first-class occurrences.  Its greatest fixed
point removes a completion whose prefix lacks a safe continuation for even
one still-compatible outcome.  The Exact Agent History Realization Theorem
proves that the fixed point is nonempty exactly when a realization exists,
yields the greatest realization on acceptance, and a finite cascading-pruning
certificate on rejection.  We compile it into an occurrence-sensitive
controller and prove weak bisimulation between an ideal atomic Agent history
machine and a durable reference monitor across arbitrary edit sequences,
fresh/alias races, retries, dispatch, and crashes.  One policy-domain epoch
orders every live gate against each cut.  A bounded checker validates the
fixed point, alias resolution, and representative races.
\end{abstract}
