\title{The Security State of a History-Rewriting Agent\\
% 历史重写 Agent 的安全状态
Exact Admission for Fork, Restore, and Merge}
% Fork、Restore 与 Merge 的精确准入

\author{}

\begin{document}
\maketitle

\begin{abstract}
Tool-using Agents can Fork live continuations, Restore checkpoints, and Merge descendants, but the world does not rewind: receipts are append-only, copied occurrences may share one effect, and old calls may race a rewrite.
% 使用工具的 Agent 可以 Fork 活跃延续、Restore 检查点并 Merge 后代，但现实世界不会回退：回执只能追加，复制的发生项可能共享一个效果，旧调用还可能与历史重写竞态。
We characterize when such an edit has a policy-safe, history-faithful, completion-nonblocking realization preserving every outcome not discharged by schema-authorized retirement, construct a joined relational state sufficient for exact compilation, and prove which distinctions every exact encoding must preserve.
% 我们刻画此类编辑何时具有策略安全、历史忠实且完成非阻塞的实现，能够保留每个未由模式授权退役解除的结果；构造一种足以支持精确编译的关系连接状态；并证明每种精确编码都必须保留哪些区分。
Agent History Admission answers with a security-compiler theory whose relational state joins promised causal completions, occurrence-to-cell effect identity, the receipt ledger, and the exact history cut.
% Agent 历史准入以一套安全编译器理论作答；其关系状态连接已承诺的因果完成、发生项到单元的效果标识、回执账本和精确历史切点。
Outcome-wise checking is unsound because a shared prefix can strand an outcome that the edited history still promises.
% 逐结果检查并不可靠，因为共享前缀可能使编辑后历史仍承诺的某个结果无法完成。
The Agent Security-State Characterization Theorem proves exact compilation to the greatest safe monitor or a finite impossibility certificate, observational lower bounds for every exact encoding, closure after every finite prefix of arbitrarily long sequences of the six edits and protected calls, and durable refinement to an ideal atomic Agent-history machine.
% Agent 安全状态刻画定理证明：精确编译会产生最大安全监控器或有限不可能性证书；每种精确编码都受观测下界约束；该状态在由六种编辑与受保护调用组成的任意长序列的每个有限前缀后保持闭合；且持久实现精化理想原子 Agent 历史机。
The Agent submits only an edit; a trusted checker derives the target and outcome-compatible markings, uses conditional generalized nonblocking as its synthesis backend, and atomically installs the canonical occurrence-sensitive monitor and replacement handles under a fresh epoch.
% Agent 只提交编辑；可信检查器推导目标和结果兼容标记，以条件广义非阻塞作为综合后端，并在新纪元下原子安装规范的发生项敏感监控器与替换句柄。
Under crash-stable linearizable domain transactions, the refinement covers arbitrary edit sequences, \Fresh/\Alias races, retries, dispatch, and crashes; a kernel-checked Lean core and 81 executable tests validate the finite decision kernel and its critical examples.
% 在崩溃稳定的可线性化域事务下，该精化覆盖任意编辑序列、\Fresh/\Alias 竞态、重试、派发和崩溃；一个由内核检查的 Lean 核心和 81 项可执行测试验证有限判定内核及其关键案例。
\end{abstract}
