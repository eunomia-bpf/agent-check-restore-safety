\title{The Security State of a History-Rewriting Agent\\
% 历史重写 Agent 的安全状态
Exact Admission for Fork, Restore, and Merge}
% Fork、Restore 与 Merge 的精确准入

\author{}

\maketitle

\begin{abstract}
Tool-using Agents can Fork live continuations, Restore a checkpoint, and Merge descendants, but the external world does not rewind.
% 使用工具的 Agent 可以 Fork 活跃延续、Restore 检查点并 Merge 后代，但外部世界不会回退。
Commitments are append-only, copied occurrences may share one irreversible receipt, and old protected calls may race the rewrite.
% 承诺只能追加，复制的发生项可能共享同一不可逆回执，旧的受保护调用还可能与历史重写发生竞态。
We ask what security state is necessary and sufficient to decide and realize these edits without retracting any outcome not discharged by schema-authorized retirement.
% 我们研究何种安全状态是判定并实现这些编辑的充要依据，同时不撤回任何未由模式授权退役解除的结果。
Checking outcomes separately is unsound because a shared prefix can strand an outcome that the edited history still promises.
% 分别检查各个结果并不可靠，因为共享前缀可能使编辑后历史仍承诺的某个结果无法完成。
We identify one relational Agent security state joining four kinds of evidence: (1) promised causal futures, (2) occurrence-to-cell effect identity, (3) the irreversible receipt frontier, and (4) the exact live cut.
% 我们识别出一种关系化的 Agent 安全状态，它连接四类证据：(1) 已承诺的因果未来，(2) 发生项到单元的效果标识关系，(3) 不可逆回执前沿，以及 (4) 精确的活跃切点。
The Agent Security-State Characterization Theorem proves this state sufficient for exact compilation and irredundant among its factor projections.
% Agent 安全状态刻画定理证明，该状态足以支持精确编译，并且在其因子投影中不可约简。
Finite pairs of histories show that erasing any factor, the decisive occurrence--cell incidence, or the receipt--cell incidence and its reconstructing links can make two histories indistinguishable to the compiler even though they require opposite correct decisions.
% 成对的有限历史表明，擦除任何因子、关键的发生项--单元关联，或回执--单元关联及其重建链接，都可能使两条历史对编译器不可区分，尽管它们要求相反的正确判定。
The state remains closed after every finite prefix of an arbitrarily long sequence of the six trusted edits and protected calls.
% 对六种可信编辑与受保护调用组成的任意长序列，该状态在每个有限前缀之后仍保持闭合。
A compiler proposes the edited obligations and outcome-compatible markings, and the trusted installation checker re-derives both before installation.
% 编译器提出编辑后的义务和结果兼容标记，可信安装检查器在安装前重新推导二者。
Conditional generalized nonblocking then serves as a synthesis backend that constructs the greatest safe realization or a finite impossibility certificate.
% 随后，条件广义非阻塞作为综合后端，构造最大的安全实现或有限的不可能性证书。
The untrusted Agent only requests an edit and cannot supply a weaker target or discard inconvenient obligations.
% 不受信任的 Agent 只能请求编辑，无法提供更弱的目标或丢弃不便的义务。
On acceptance, a durable kernel atomically installs the canonical occurrence-sensitive monitor and authenticated replacement handles under one new policy-domain epoch.
% 准入后，持久内核在一个新的策略域纪元下原子安装规范的发生项敏感监控器和经过认证的替换句柄。
We prove divergence-insensitive weak bisimulation between this reference monitor and an ideal atomic Agent-history machine across arbitrary edit sequences, first-redemption and receipt-reuse races, retries, dispatch, and crashes.
% 我们证明该参考监控器与理想原子 Agent 历史机在任意编辑序列、首次兑付与回执复用竞态、重试、派发和崩溃下满足发散不敏感弱互模拟。
A bounded artifact checks the executable decision kernel, identity-erasure cases, and representative cut races.
% 一个有界制品检查可执行判定内核、标识擦除案例和代表性切点竞态。
\end{abstract}
