\title{When May an Agent Rewrite Its History?\\
A Prefix-Robust Theory of Fork, Restore, and Merge}

\author{}

\begin{document}
\maketitle

\begin{abstract}
Tool-using Agents rewrite which past continuations may act.  Fork creates live
continuations, Restore revives an earlier checkpoint, and Merge selects or
joins branches.  The external world does not rewind.  Commitments are
append-only, copied occurrences may share one irreversible receipt, and old
protected calls may race the rewrite.  We ask when such an edit has a policy-safe,
history-faithful, completion-nonblocking implementation preserving every
promised outcome not discharged by authenticated typed retirement.  Endpoint
checks fail because a prefix shared by individually safe outcomes can strand
an outcome that the Agent history still promises.
We develop a prefix-robust \emph{Agent History-Admission Theory}.  Its greatest
fixed point removes any completion whose prefix lacks a safe continuation for
a still-compatible outcome.  Trusted schemas preserve inherited obligations
or retire them explicitly, while resolution keeps fresh commitments and
receipt-silent aliases as distinct occurrences.  The Exact Agent History
Realization Theorem proves that the fixed point is nonempty exactly when a
realization exists and yields either the greatest realization or a finite
ranked missing-witness certificate.  The theory serves as a security compiler
for Agent history operations.  The platform registers policy and immutable
schemas, while the Agent only requests an edit.  A trusted checker re-derives
the target and fixed point.  It reports structural errors or fixed-point
rejection certificates, while the durable kernel atomically installs an
accepted canonical occurrence-sensitive program under a fresh policy-domain
epoch.  We prove weak bisimulation between an ideal atomic Agent history
machine and the durable reference monitor across arbitrary edit sequences,
fresh/alias races, retries, dispatch, and crashes.  A bounded checker validates
the fixed point, alias resolution, and representative races.
\end{abstract}
